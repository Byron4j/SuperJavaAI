## 引言：大模型幻觉的本质

大模型幻觉（Hallucination）不是"AI在撒谎"，而是**概率生成模型在不确定性区域的高置信度错误输出**。

核心认知：

```
LLM生成的本质：P(next_token | context)

幻觉产生的本质：
当 P(token) 在以下情况被错误地最大化：
1. 训练数据中信息不足的区域
2. 知识截止后的新信息
3. 多个可能答案的模糊区域
4. 模型被迫回答但不确定的问题

关键区别：
- 不确定性（Uncertainty）：模型知道"我不知道"
- 幻觉（Hallucination）：模型认为"我知道"，但实际错误

质量差异的根源：
- 差的工程化：直接信任AI输出 → 错误信息传播
- 好的工程化：多层验证+不确定性量化 → 可靠输出
```

**关键洞察**：幻觉不是模型的"bug"，而是概率生成机制的**固有特性**——需要通过工程手段管理而非消除。

**关键理解**：
- 模型没有**真实性判断**能力，只有**概率预测**能力
- 训练数据中的错误会被当作"事实"学习
- 高频出现的错误信息可能比低频的正确信息更容易被生成

### 2. 架构局限导致的幻觉

```
Transformer架构的幻觉倾向：

局限1：上下文窗口限制
- 模型只能看到固定长度的上下文
- 长文档中的信息可能被截断或遗忘
- 示例：回答关于文档第100页的问题，但模型只看到了前50页

局限2：注意力稀释
- 长序列中注意力权重分散
- 关键信息可能获得不够高的权重
- 示例：文档中间部分的重要细节被忽略

局限3：位置偏见
- 开头和结尾的信息获得更高注意力
- 中间信息容易被遗忘
- 示例：列表中间的项被遗漏或错误描述

局限4：缺乏事实核查机制
- 模型没有外部知识检索能力（原生）
- 无法验证生成内容的正确性
- 示例：生成不存在的人名或事件

局限5：曝光偏见（Exposure Bias）
- 训练时使用真实前缀，生成时使用模型自己的输出
- 错误会累积
- 示例：第一步生成错误，后续基于错误继续生成
```

```
幻觉问题的早期研究：

2019年："Neural Text Degeneration"论文
- 发现模型生成时会陷入重复或偏离主题
- 提出Top-p采样（nucleus sampling）缓解

2020年："On the Dangers of Stochastic Parrots"
- 讨论语言模型的风险，包括幻觉
- 呼吁关注模型的局限性

早期特征：
- 主要关注文本流畅性而非事实性
- 幻觉被视为"生成质量"问题
- 缺乏系统的检测和评估方法
```

```
幻觉问题的系统研究：

2021年："Understanding Factuality in Abstractive Summarization"
- 系统研究摘要中的事实一致性
- 提出基于 entailment 的事实检查方法

2022年："Survey of Hallucination in Natural Language Generation"
- 第一篇全面的幻觉综述
- 定义了幻觉的分类体系
- 提出了检测和缓解方法

关键进展：
- 幻觉分类：内在幻觉 vs 外在幻觉
- 检测方法：基于模型、基于规则、人工评估
```

### 1. 幻觉分类体系

```
大模型幻觉分类：

按内容类型：
┌─────────────────────────────────────────┐
│ 事实性幻觉（Factual Hallucination）      │
│ - 错误的事实陈述                         │
│ - 虚构的人名、地名、事件                 │
│ - 过时的信息                             │
│ 示例："爱因斯坦获得了诺贝尔文学奖"       │
├─────────────────────────────────────────┤
│ 逻辑性幻觉（Logical Hallucination）      │
│ - 自相矛盾的陈述                         │
│ - 错误的推理过程                         │
│ - 违反常识的结论                         │
│ 示例："水在标准大气压下的沸点是50度"     │
├─────────────────────────────────────────┤
│ 上下文幻觉（Contextual Hallucination）   │
│ - 与输入上下文矛盾                       │
│ - 忽略关键约束                           │
│ - 引入无关信息                           │
│ 示例：用户问A，模型回答B                 │
├─────────────────────────────────────────┤
│ 代码幻觉（Code Hallucination）           │
│ - 不存在的API                            │
│ - 错误的参数                             │
│ - 过时的语法                             │
│ 示例：pd.read_excel_fast()               │
└─────────────────────────────────────────┘

按与输入关系：
- 内在幻觉（Intrinsic）：与输入源矛盾
- 外在幻觉（Extrinsic）：无法从输入源验证
```

### 2. RAG（检索增强生成）深度解析

```python
class RAGSystem:
    """
    检索增强生成系统
    """
    
    def __init__(self, retriever, generator, knowledge_base):
        self.retriever = retriever
        self.generator = generator
        self.knowledge_base = knowledge_base
    
    def generate(self, query, top_k=5):
        """
        RAG生成流程
        """
        # 1. 检索相关知识
        retrieved_docs = self.retriever.retrieve(
            query=query,
            knowledge_base=self.knowledge_base,
            top_k=top_k
        )
        
        # 2. 重排序
        ranked_docs = self.rerank_documents(query, retrieved_docs)
        
        # 3. 构建增强提示
        augmented_prompt = self.build_augmented_prompt(query, ranked_docs)
        
        # 4. 生成答案
        answer = self.generator.generate(augmented_prompt)
        
        # 5. 事实核查
        verified_answer = self.fact_check(answer, ranked_docs)
        
        # 6. 添加来源引用
        final_answer = self.add_citations(verified_answer, ranked_docs)
        
        return final_answer
    
    def build_augmented_prompt(self, query, documents):
        """
        构建增强提示词
        """
        prompt = "基于以下参考资料回答问题。\n\n"
        prompt += "参考资料：\n"
        
        for i, doc in enumerate(documents, 1):
            prompt += f"[{i}] {doc.content}\n"
            prompt += f"来源：{doc.source}\n\n"
        
        prompt += "要求：\n"
        prompt += "1. 只使用参考资料中的信息\n"
        prompt += "2. 如果资料不足，明确说明\n"
        prompt += "3. 标注信息来源（使用[ref:X]格式）\n"
        prompt += "4. 不要编造信息\n\n"
        prompt += f"问题：{query}\n"
        prompt += "答案："
        
        return prompt
    
    def fact_check(self, answer, documents):
        """
        事实核查
        """
        # 提取答案中的事实陈述
        facts = self.extract_facts(answer)
        
        for fact in facts:
            # 检查每个事实是否在文档中有支持
            supported = False
            for doc in documents:
                if self.entails(doc.content, fact):
                    supported = True
                    break
            
            if not supported:
                # 标记为不确定
                answer = answer.replace(
                    fact.text,
                    f"{fact.text} [待验证]"
                )
        
        return answer

class AdvancedRAG:
    """
    高级RAG系统（查询重写 + 混合检索 + 重排序）
    """
    
    def __init__(self):
        self.query_rewriter = QueryRewriter()
        self.hybrid_retriever = HybridRetriever(
            dense_retriever=DenseRetriever(),
            sparse_retriever=SparseRetriever()
        )
        self.reranker = CrossEncoderReranker()
        self.generator = Generator()
    
    def retrieve_and_generate(self, query):
        """
        完整的RAG流程
        """
        # 1. 查询重写（扩展同义词、澄清歧义）
        rewritten_queries = self.query_rewriter.rewrite(query)
        
        # 2. 混合检索（密集 + 稀疏）
        all_docs = []
        for rq in rewritten_queries:
            docs = self.hybrid_retriever.retrieve(rq)
            all_docs.extend(docs)
        
        # 3. 去重和重排序
        unique_docs = self.deduplicate(all_docs)
        ranked_docs = self.reranker.rerank(query, unique_docs)
        
        # 4. 上下文压缩（如果文档太长）
        compressed_context = self.compress_context(ranked_docs)
        
        # 5. 生成
        answer = self.generator.generate(query, compressed_context)
        
        return answer
```

### 3. 幻觉检测方法

```python
class HallucinationDetector:
    """
    幻觉检测系统
    """
    
    def __init__(self):
        self.detectors = {
            "factuality": FactualityDetector(),
            "consistency": ConsistencyDetector(),
            "source_verification": SourceVerificationDetector()
        }
    
    def detect(self, generated_text, source_documents=None, query=None):
        """
        综合幻觉检测
        """
        results = {
            "is_hallucination": False,
            "confidence": 0.0,
            "issues": []
        }
        
        # 1. 事实性检测
        fact_result = self.detectors["factuality"].check(generated_text)
        if fact_result.is_factual == False:
            results["issues"].extend(fact_result.issues)
        
        # 2. 一致性检测（如果有源文档）
        if source_documents:
            consistency_result = self.detectors["consistency"].check(
                generated_text, source_documents
            )
            if not consistency_result.is_consistent:
                results["issues"].extend(consistency_result.issues)
        
        # 3. 源验证（如果是RAG生成）
        if source_documents:
            source_result = self.detectors["source_verification"].check(
                generated_text, source_documents
            )
            if not source_result.all_verified:
                results["issues"].extend(source_result.issues)
        
        # 综合判断
        results["is_hallucination"] = len(results["issues"]) > 0
        results["confidence"] = self.calculate_confidence(results["issues"])
        
        return results
    
    def calculate_confidence(self, issues):
        """
        计算幻觉置信度
        """
        if not issues:
            return 0.0
        
        # 根据问题严重程度加权
        severity_weights = {
            "critical": 1.0,
            "high": 0.8,
            "medium": 0.5,
            "low": 0.2
        }
        
        total_weight = sum(
            severity_weights.get(issue.severity, 0.5)
            for issue in issues
        )
        
        return min(1.0, total_weight / len(issues))


# 基于NLI的事实性检测
class NLIFactualityDetector:
    """
    基于自然语言推理的事实性检测器
    """
    
    def __init__(self, nli_model):
        self.nli_model = nli_model  # 如：roberta-large-mnli
    
    def check(self, generated_text, source_documents=None):
        """
        检查生成文本的事实性
        """
        issues = []
        
        # 将生成文本分解为事实陈述
        facts = self.extract_fact_sentences(generated_text)
        
        for fact in facts:
            if source_documents:
                # 检查事实是否与源文档一致
                doc_entailments = []
                for doc in source_documents:
                    entailment = self.nli_model.predict(
                        premise=doc.content,
                        hypothesis=fact.text
                    )
                    doc_entailments.append(entailment)
                
                # 如果没有文档支持该事实
                if not any(e.label == "entailment" for e in doc_entailments):
                    if any(e.label == "contradiction" for e in doc_entailments):
                        issues.append(HallucinationIssue(
                            type="contradiction",
                            severity="high",
                            text=fact.text,
                            description="与源文档矛盾"
                        ))
                    else:
                        issues.append(HallucinationIssue(
                            type="unverified",
                            severity="medium",
                            text=fact.text,
                            description="无法从源文档验证"
                        ))
            else:
                # 无源文档时，使用知识库或常识检查
                if self.is_common_knowledge(fact):
                    continue
                
                # 标记为需要验证
                issues.append(HallucinationIssue(
                    type="unverified",
                    severity="low",
                    text=fact.text,
                    description="无法验证，可能为幻觉"
                ))
        
        return FactualityResult(
            is_factual=len(issues) == 0,
            issues=issues
        )
```

**挑战**：

```python
class EnterpriseQASystem:
    """
    企业级问答系统（幻觉控制）
    """
    
    def __init__(self):
        self.retriever = HybridRetriever()
        self.generator = LLMGenerator()
        self.fact_checker = FactChecker()
        self.confidence_estimator = ConfidenceEstimator()
    
    def answer(self, question):
        """
        回答问题（带幻觉控制）
        """
        # 1. 检索相关文档
        docs = self.retriever.retrieve(question, top_k=10)
        
        # 2. 生成初步答案
        draft_answer = self.generator.generate(question, docs)
        
        # 3. 事实核查
        fact_check_result = self.fact_checker.verify(
            draft_answer, docs
        )
        
        # 4. 置信度评估
        confidence = self.confidence_estimator.estimate(
            draft_answer, docs, fact_check_result
        )
        
        # 5. 根据置信度处理
        if confidence > 0.9:
            return {
                "answer": draft_answer,
                "confidence": confidence,
                "sources": self.extract_sources(docs),
                "status": "high_confidence"
            }
        elif confidence > 0.7:
            # 中等置信度，添加警告
            return {
                "answer": draft_answer + "\n\n[注意：此答案基于有限信息，建议核实]",
                "confidence": confidence,
                "sources": self.extract_sources(docs),
                "status": "medium_confidence"
            }
        else:
            # 低置信度，拒绝回答或转人工
            return {
                "answer": "基于现有资料无法确定答案。建议：\n1. 查看以下相关文档\n2. 联系相关部门确认",
                "confidence": confidence,
                "related_docs": docs[:3],
                "status": "low_confidence",
                "escalation": True
            }
    
    def handle_conflicting_docs(self, docs):
        """
        处理矛盾文档
        """
        # 识别矛盾信息
        conflicts = self.identify_conflicts(docs)
        
        if conflicts:
            # 按文档时效性排序
            docs_sorted = sorted(docs, key=lambda d: d.last_updated, reverse=True)
            
            # 优先使用最新文档
            return docs_sorted[0]
        
        return docs
```

### 1. 自我一致性检查

```python
class SelfConsistencyChecker:
    """
    自我一致性检查
    
    核心思想：多次采样，检查答案是否一致
    """
    
    def __init__(self, generator, num_samples=5):
        self.generator = generator
        self.num_samples = num_samples
    
    def check(self, question):
        """
        通过多次生成检查一致性
        """
        # 1. 多次生成答案
        answers = []
        for _ in range(self.num_samples):
            # 使用不同的温度参数
            temperature = random.uniform(0.5, 1.0)
            answer = self.generator.generate(
                question,
                temperature=temperature
            )
            answers.append(answer)
        
        # 2. 提取核心答案（去除冗余）
        core_answers = [self.extract_core(a) for a in answers]
        
        # 3. 计算一致性
        consistency = self.calculate_consistency(core_answers)
        
        # 4. 选择最一致的答案
        if consistency > 0.8:
            best_answer = self.select_most_common(core_answers)
            return {
                "answer": best_answer,
                "consistency": consistency,
                "confidence": "high"
            }
        else:
            # 一致性低，可能存在幻觉
            return {
                "answer": answers[0],  # 返回一个答案但标记不确定
                "consistency": consistency,
                "confidence": "low",
                "warning": "答案一致性低，可能存在不确定性"
            }
    
    def calculate_consistency(self, answers):
        """
        计算答案间的一致性
        """
        # 使用语义相似度
        similarities = []
        for i in range(len(answers)):
            for j in range(i + 1, len(answers)):
                sim = self.semantic_similarity(answers[i], answers[j])
                similarities.append(sim)
        
        return sum(similarities) / len(similarities) if similarities else 0
```

```python
class KnowledgeGraphFactChecker:
    """
    基于知识图谱的事实核查
    """
    
    def __init__(self, knowledge_graph):
        self.kg = knowledge_graph
        self.entity_extractor = EntityExtractor()
        self.relation_extractor = RelationExtractor()
    
    def verify(self, text):
        """
        核查文本中的事实
        """
        # 1. 提取实体和关系
        entities = self.entity_extractor.extract(text)
        relations = self.relation_extractor.extract(text, entities)
        
        # 2. 在知识图谱中验证
        verified_facts = []
        unverified_facts = []
        contradictions = []
        
        for relation in relations:
            # 查询知识图谱
            kg_facts = self.kg.query(
                subject=relation.subject,
                predicate=relation.predicate,
                object=relation.object
            )
            
            if kg_facts:
                # 检查是否一致
                if self.is_consistent(relation, kg_facts):
                    verified_facts.append(relation)
                else:
                    contradictions.append({
                        "claim": relation,
                        "kg_facts": kg_facts
                    })
            else:
                unverified_facts.append(relation)
        
        return VerificationResult(
            verified=verified_facts,
            unverified=unverified_facts,
            contradictions=contradictions
        )
```

```python
class HallucinationMetrics:
    """
    幻觉评估指标
    """
    
    def calculate_metrics(self, predictions, references):
        """
        计算幻觉相关指标
        """
        metrics = {}
        
        # 1. 事实一致性（Factuality）
        metrics["factuality"] = self.calculate_factuality(
            predictions, references
        )
        
        # 2. 幻觉率（Hallucination Rate）
        metrics["hallucination_rate"] = self.calculate_hallucination_rate(
            predictions, references
        )
        
        # 3. 精确率（Precision）
        # 生成内容中正确信息的比例
        metrics["precision"] = self.calculate_precision(predictions, references)
        
        # 4. 召回率（Recall）
        # 参考内容中被正确覆盖的比例
        metrics["recall"] = self.calculate_recall(predictions, references)
        
        # 5. F1分数
        metrics["f1"] = 2 * (metrics["precision"] * metrics["recall"]) / \
                       (metrics["precision"] + metrics["recall"])
        
        return metrics
    
    def calculate_factuality(self, predictions, references):
        """
        计算事实一致性
        """
        factual_count = 0
        
        for pred, ref in zip(predictions, references):
            # 使用NLI模型判断
            entailment = self.nli_model.predict(pred, ref)
            if entailment.label == "entailment":
                factual_count += 1
        
        return factual_count / len(predictions)
```

```python
class CodeHallucinationHandler:
    """
    代码幻觉处理系统
    """
    
    def __init__(self):
        self.api_validator = APIValidator()
        self.syntax_checker = SyntaxChecker()
        self.execution_tester = ExecutionTester()
    
    def process_generated_code(self, code, language="python"):
        """
        处理生成的代码，检测并修复幻觉
        """
        issues = []
        
        # 1. 语法检查
        syntax_issues = self.syntax_checker.check(code, language)
        issues.extend(syntax_issues)
        
        # 2. API验证
        api_issues = self.api_validator.validate(code, language)
        issues.extend(api_issues)
        
        # 3. 执行测试
        if language in ["python", "javascript"]:
            execution_issues = self.execution_tester.test(code, language)
            issues.extend(execution_issues)
        
        # 4. 尝试自动修复
        if issues:
            fixed_code = self.attempt_fix(code, issues)
            return {
                "code": fixed_code,
                "issues": issues,
                "fixed": fixed_code != code
            }
        
        return {"code": code, "issues": [], "fixed": False}
    
    def attempt_fix(self, code, issues):
        """
        尝试自动修复代码幻觉
        """
        fixed_code = code
        
        for issue in issues:
            if issue.type == "fictitious_api":
                # 查找替代API
                alternative = self.find_alternative_api(issue.api_name)
                if alternative:
                    fixed_code = fixed_code.replace(issue.api_name, alternative)
            
            elif issue.type == "deprecated_api":
                # 替换为新版API
                replacement = self.get_replacement(issue.api_name)
                fixed_code = fixed_code.replace(issue.api_name, replacement)
            
            elif issue.type == "syntax_error":
                # 尝试修复语法（简单的）
                fixed_code = self.fix_syntax(fixed_code, issue)
        
        return fixed_code
```
