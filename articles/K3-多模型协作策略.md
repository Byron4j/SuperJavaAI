## 引言：多模型协作的工程本质

多模型协作（Multi-Model Collaboration）不是简单的"哪个模型便宜用哪个"的成本游戏，而是一门**基于任务特征空间的概率分布匹配**的系统工程。

核心认知：

```
单一模型的本质：P(output | task, model_i)

多模型协作的本质：argmax_{model_i} P(output | task, model_i) 
                    + 集成策略 Ensemble({output_i})

质量差异的根源：
- 单一模型：在任务空间T上的平均表现 E[Performance]
- 多模型协作：在任务子空间T_i上选择最优模型 max_i E[Performance|T_i]

信息论视角：
- 单一模型：信息瓶颈限制，特定任务的信息损失不可恢复
- 多模型协作：通过模型间的信息互补，降低整体条件熵
```

**关键洞察**：多模型协作的效果不取决于"模型数量"，而取决于**任务分解粒度**与**模型能力边界**的匹配精度。

## 理论基础：为什么多模型协作能超越单一模型

### 1. 模型能力的概率分布差异

#### 每个模型都是条件概率分布的近似器

```python
# 模型能力的数学表达
"""
模型M在任务T上的表现：
Performance(M, T) = Accuracy(M, T) × Speed(M, T) × CostEfficiency(M, T)

其中：
- Accuracy(M, T) = P(correct | M, T)  在任务T上的正确率
- Speed(M, T) = 1 / Latency(M, T)     响应速度的倒数
- CostEfficiency(M, T) = Quality(M, T) / Cost(M, T)  性价比

关键事实：
不存在模型M*使得 ∀T, Performance(M*, T) = max_M Performance(M, T)
即：没有 universally best 的模型
"""
```

**关键理解**：
- 每个模型在其训练数据分布上表现最优
- 不同模型的训练数据分布存在差异（代码、对话、多语言、推理等）
- 任务空间是多维的：复杂度、领域、语言、创意需求、安全等级

#### 模型能力的互补性原理

```
模型互补性的数学解释：

设任务空间为 T，模型集合为 {M_1, M_2, ..., M_n}

单一模型M_i的期望性能：
E[Perf(M_i)] = ∫_T P(t) × Perf(M_i, t) dt

多模型协作的期望性能（Oracle选择器）：
E[Perf(collaboration)] = ∫_T P(t) × max_i Perf(M_i, t) dt

性能增益：
Gain = E[Perf(collaboration)] - max_i E[Perf(M_i)]
     = ∫_T P(t) × [max_i Perf(M_i, t) - Perf(M_best, t)] dt

其中 M_best = argmax_i E[Perf(M_i)]

关键结论：
- 当模型能力差异越大，Gain越大
- 当任务空间越多样化，Gain越大
- 当路由精度越高，实际性能越接近Oracle
```

**工程启示**：
- 模型选择的关键不是"哪个最好"，而是"哪个最适合当前任务"
- 需要建立任务特征 → 模型能力的映射函数
- 路由精度直接影响协作系统的性能上限

### 2. 计算经济学：为什么多模型能降低成本

```
计算经济学的核心不等式：

场景：N个任务，分为K个复杂度等级

方案A（单一高端模型）：
Cost_A = N × Cost_high
Quality_A = N × Quality_high

方案B（多模型协作，分级处理）：
假设：
- α_1比例任务 → 低端模型（Cost_low, Quality_low）
- α_2比例任务 → 中端模型（Cost_mid, Quality_mid）  
- α_3比例任务 → 高端模型（Cost_high, Quality_high）
其中 α_1 + α_2 + α_3 = 1

Cost_B = N × (α_1×Cost_low + α_2×Cost_mid + α_3×Cost_high)
Quality_B = N × (α_1×Quality_low + α_2×Quality_mid + α_3×Quality_high)

典型场景（2026年价格）：
- Cost_low (DeepSeek-V4) = $0.001/1K tokens
- Cost_mid (Claude 4 Sonnet) = $0.015/1K tokens  
- Cost_high (GPT-5.5) = $0.025/1K tokens

任务分布（经验法则）：
- α_1 = 70%（简单任务：翻译、格式化、简单问答）
- α_2 = 20%（中等任务：代码审查、文档生成）
- α_3 = 10%（复杂任务：架构设计、复杂推理）

Cost_A = N × $0.025 = $0.025N
Cost_B = N × (0.7×$0.001 + 0.2×$0.015 + 0.1×$0.025)
       = N × ($0.0007 + $0.003 + $0.0025)
       = N × $0.0062

成本节省： (0.025 - 0.0062) / 0.025 = 75.2%

质量分析：
假设 Quality_low = 0.85, Quality_mid = 0.92, Quality_high = 0.95
Quality_A = 0.95
Quality_B = 0.7×0.85 + 0.2×0.92 + 0.1×0.95 = 0.595 + 0.184 + 0.095 = 0.874

质量损失： (0.95 - 0.874) / 0.95 = 8%

性价比提升： 成本节省75%，质量损失8% → 性价比提升约3.5倍
```

### 3. 集成学习的理论保证

```python
# 多模型集成的理论分析
"""
集成学习的方差-偏差分解：

对于回归问题，期望平方误差：
E[(y - f(x))^2] = Bias^2 + Variance + Noise

单一模型：
- 高方差（对训练数据敏感）
- 特定偏差（模型架构带来的系统性偏差）

多模型集成（简单平均）：
f_ensemble(x) = (1/M) × Σ_i f_i(x)

偏差：Bias_ensemble ≈ average(Bias_i)
方差：Var_ensemble ≈ (1/M) × average(Var_i) + (1 - 1/M) × Cov(f_i, f_j)

关键洞察：
- 当模型间相关性低时（Cov小），方差显著降低
- 不同架构、不同训练数据的模型相关性天然较低
- 集成效果最好的情况：模型"好而不同"

分类问题的提升：
假设每个模型独立，错误率为ε < 0.5

简单多数投票（M个模型）：
P_error = Σ_{k=⌈M/2⌉}^M C(M,k) × ε^k × (1-ε)^{M-k}

当M=3, ε=0.3:
P_error = C(3,2)×0.3²×0.7 + C(3,3)×0.3³
        = 3×0.09×0.7 + 0.027
        = 0.189 + 0.027 = 0.216

相比单一模型错误率0.3，降低28%
"""
```

## 深度解析：多模型协作的核心架构与算法原理

### 1. 任务特征空间与模型能力映射

#### 任务的多维特征表示

```python
"""
任务特征向量的数学表示：

Task = (complexity, domain, language, creativity, safety, latency_sensitivity)

各维度定义：
1. complexity ∈ [0, 1]：任务复杂度
   - 0：简单问答、翻译、格式化
   - 0.5：代码生成、文档总结
   - 1.0：架构设计、数学证明、多步推理

2. domain ∈ {code, math, writing, analysis, chat, ...}
   任务领域

3. language ∈ {zh, en, multi, code_syntax}
   语言类型

4. creativity ∈ [0, 1]：创意需求
   - 0：确定性任务（代码、计算）
   - 1：开放性任务（写作、brainstorming）

5. safety ∈ [0, 1]：安全敏感度
   - 0：低风险（代码补全）
   - 1：高风险（医疗、法律、金融建议）

6. latency_sensitivity ∈ [0, 1]：延迟敏感度
   - 0：批处理，可等待
   - 1：实时交互，要求秒级响应
"""

class TaskFeatureExtractor:
    """任务特征提取器"""
    
    def __init__(self):
        # 关键词到特征的映射
        self.complexity_keywords = {
            'high': ['设计', '架构', '证明', '优化', '分析', '重构', '算法'],
            'medium': ['实现', '编写', '生成', '解释', '转换', '审查'],
            'low': ['翻译', '格式化', '补全', '简单', '简述', '什么是']
        }
        
        self.domain_keywords = {
            'code': ['代码', '函数', '类', 'API', 'bug', '程序', 'Java', 'Python'],
            'math': ['计算', '证明', '公式', '数学', '统计', '优化问题'],
            'writing': ['写作', '文章', '故事', '文案', '邮件', '报告'],
            'analysis': ['分析', '对比', '评估', '诊断', '总结']
        }
    
    def extract(self, query: str) -> dict:
        """从查询中提取任务特征"""
        query_lower = query.lower()
        
        # 复杂度评分
        complexity = 0.5  # 默认中等
        if any(kw in query_lower for kw in self.complexity_keywords['high']):
            complexity = 0.9
        elif any(kw in query_lower for kw in self.complexity_keywords['low']):
            complexity = 0.2
        
        # 领域识别
        domain_scores = {}
        for domain, keywords in self.domain_keywords.items():
            score = sum(1 for kw in keywords if kw in query_lower)
            domain_scores[domain] = score
        
        domain = max(domain_scores, key=domain_scores.get) if domain_scores else 'general'
        
        # 语言识别
        language = 'zh' if any('\u4e00' <= c <= '\u9fff' for c in query) else 'en'
        
        # 创意需求
        creativity = 0.5
        if any(kw in query_lower for kw in ['创意', '写作', '故事', 'brainstorm', '想法']):
            creativity = 0.9
        elif any(kw in query_lower for kw in ['代码', '计算', '证明', '精确']):
            creativity = 0.1
        
        # 安全敏感度
        safety = 0.0
        if any(kw in query_lower for kw in ['医疗', '法律', '金融', '投资', '诊断']):
            safety = 1.0
        
        # 延迟敏感度
        latency = 0.5
        if any(kw in query_lower for kw in ['实时', '快速', '马上', '立即']):
            latency = 1.0
        
        return {
            'complexity': complexity,
            'domain': domain,
            'language': language,
            'creativity': creativity,
            'safety': safety,
            'latency_sensitivity': latency
        }
```

```python
        complexity = task_features.get('complexity', 0.5)
        if complexity > 0.7:
            # 复杂任务需要高能力模型
            score += cap.get('analysis', 0.5) * 0.25
        else:
            score += 0.25  # 简单任务，大部分模型都能处理
        
        # 创意需求
        creativity = task_features.get('creativity', 0.5)
        score += cap.get('creativity', 0.5) * creativity * 0.15
        
        # 安全需求
        safety = task_features.get('safety', 0.0)
        score += cap.get('safety', 0.5) * safety * 0.10
        
        return score
    
    def get_best_model(self, task_features: dict, budget_constraint: float = None) -> str:
        """获取最适合任务的模型"""
        scores = {}
        
        for model_name in self.capabilities:
            score = self.score_model(model_name, task_features)
            
            # 应用预算约束
            if budget_constraint:
                cost = self.capabilities[model_name]['cost_per_1k']
                if cost > budget_constraint:
                    score *= 0.5  # 惩罚超预算模型
            
            scores[model_name] = score
        
        return max(scores, key=scores.get)
```

#### 基于机器学习的路由

```python
"""
机器学习路由器的训练：

训练数据：
{task_features, ground_truth_model, user_satisfaction}

模型选择作为分类问题：
P(model | task_features) = softmax(W × task_features + b)

损失函数：
L = -Σ log P(m* | task_features) + λ × cost_penalty

其中 m* 是用户标注的最佳模型
"""

import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.preprocessing import StandardScaler

class MLRouter:
    """基于机器学习的智能路由器"""
    
    def __init__(self):
        self.scaler = StandardScaler()
        self.classifier = RandomForestClassifier(n_estimators=100)
        self.is_trained = False
        self.models = ['deepseek-v4', 'claude-4', 'gpt-5.5', 'glm-5', 'kimi-k2.6']
    
    def features_to_vector(self, task_features: dict) -> np.ndarray:
        """将任务特征转换为特征向量"""
        return np.array([
            task_features.get('complexity', 0.5),
            task_features.get('creativity', 0.5),
            task_features.get('safety', 0.0),
            task_features.get('latency_sensitivity', 0.5),
            hash(task_features.get('domain', 'general')) % 100 / 100.0,
            hash(task_features.get('language', 'zh')) % 100 / 100.0,
            task_features.get('context_length', 0) / 1000000.0,
        ])
    
    def train(self, training_data: list):
        """
        训练路由器
        
        training_data: [
            {'features': {...}, 'best_model': 'deepseek-v4', 'satisfaction': 0.9},
            ...
        ]
        """
        X = []
        y = []
        
        for data in training_data:
            X.append(self.features_to_vector(data['features']))
            y.append(data['best_model'])
        
        X = np.array(X)
        y = np.array(y)
        
        X_scaled = self.scaler.fit_transform(X)
        self.classifier.fit(X_scaled, y)
        self.is_trained = True
    
    def route(self, task_features: dict) -> tuple:
        """返回模型选择和置信度"""
        if not self.is_trained:
            # 回退到规则路由
            return 'deepseek-v4', 0.5
        
        X = self.features_to_vector(task_features).reshape(1, -1)
        X_scaled = self.scaler.transform(X)
        
        # 预测概率
        proba = self.classifier.predict_proba(X_scaled)[0]
        best_idx = np.argmax(proba)
        
        return self.models[best_idx], proba[best_idx]
    
    def route_with_fallback(self, task_features: dict, confidence_threshold: float = 0.7):
        """带降级的路由"""
        model, confidence = self.route(task_features)
        
        if confidence < confidence_threshold:
            # 置信度低，使用多模型集成
            return {
                'strategy': 'ensemble',
                'models': [model, 'claude-4'],  # 主模型 + 备用高质量模型
                'confidence': confidence
            }
        
        return {
            'strategy': 'single',
            'model': model,
            'confidence': confidence
        }
```

#### 多目标优化路由

```python
"""
多目标优化路由：

目标函数（帕累托优化）：
maximize: Quality(model, task)
minimize: Cost(model, task)
minimize: Latency(model, task)

约束条件：
Cost ≤ Budget
Latency ≤ Deadline
Quality ≥ Min_Quality

解法：
1. 加权求和法（Weighted Sum）
   Score = w1×Quality - w2×Cost - w3×Latency

2. 约束法（ε-constraint）
   固定Cost和Latency，最大化Quality

3. 进化算法（NSGA-II）
   多目标进化优化
"""

class MultiObjectiveRouter:
    """多目标优化路由器"""
    
    def __init__(self):
        self.model_matrix = ModelCapabilityMatrix()
        self.default_weights = {
            'quality': 0.5,
            'cost': 0.3,
            'latency': 0.2
        }
    
    def compute_objectives(self, model_name: str, task_features: dict) -> dict:
        """计算三个目标值"""
        cap = self.model_matrix.capabilities[model_name]
        
        # 质量分数
        quality = self.model_matrix.score_model(model_name, task_features)
        
        # 成本（归一化，越低越好）
        cost = cap['cost_per_1k'] / 0.025  # 归一化到GPT-5.5价格
        
        # 延迟（归一化，越低越好）
        latency = cap['latency_ms'] / 1500.0  # 归一化到GPT-5.5延迟
        
        return {
            'quality': quality,
            'cost': 1.0 - cost,  # 转换为最大化问题
            'latency': 1.0 - latency
        }
    
    def route(self, task_features: dict, preferences: dict = None) -> dict:
        """
        多目标路由
        
        preferences: {'quality': 0.6, 'cost': 0.3, 'latency': 0.1}
        """
        weights = preferences or self.default_weights
        
        best_model = None
        best_score = -float('inf')
        
        for model_name in self.model_matrix.capabilities:
            objectives = self.compute_objectives(model_name, task_features)
            
            # 加权求和
            score = (
                weights['quality'] * objectives['quality'] +
                weights['cost'] * objectives['cost'] +
                weights['latency'] * objectives['latency']
            )
            
            # 检查约束
            cap = self.model_matrix.capabilities[model_name]
            if task_features.get('max_cost') and cap['cost_per_1k'] > task_features['max_cost']:
                continue
            if task_features.get('max_latency_ms') and cap['latency_ms'] > task_features['max_latency_ms']:
                continue
            
            if score > best_score:
                best_score = score
                best_model = model_name
        
        return {
            'model': best_model,
            'score': best_score,
            'objectives': self.compute_objectives(best_model, task_features) if best_model else None
        }
```

```python
        feedback: [
            {'complexity': 0.2, 'model_used': 'simple', 'satisfaction': 0.9},
            {'complexity': 0.8, 'model_used': 'simple', 'satisfaction': 0.3},
            ...
        ]

            satisfaction = record['satisfaction']
            model_used = record['model_used']
            
            # 如果简单模型处理复杂任务导致满意度低，降低简单阈值
            if model_used == 'simple' and satisfaction < 0.5 and complexity > 0.2:
                self.thresholds['simple'] = max(0.1, self.thresholds['simple'] - self.learning_rate)
            
            # 如果中等模型处理简单任务（浪费），提高中等阈值
            if model_used == 'medium' and complexity < 0.3 and satisfaction > 0.8:
                self.thresholds['medium'] = min(0.9, self.thresholds['medium'] + self.learning_rate)
        
        self.performance_history.extend(feedback)
    
    def get_stats(self) -> dict:

        if not self.performance_history:
            return {}
        
        total = len(self.performance_history)
        simple_count = sum(1 for r in self.performance_history if r['model_used'] == 'simple')
        avg_satisfaction = sum(r['satisfaction'] for r in self.performance_history) / total
        
        return {
            'total_requests': total,
            'simple_ratio': simple_count / total,
```

```python
class VotingEnsemble:
    """投票集成系统"""
    
    def __init__(self):
        self.models = ['deepseek-v4', 'claude-4', 'gpt-5.5']
    
    def vote(self, responses: list, strategy: str = 'majority') -> dict:
        """
        多模型投票
        
        responses: [
            {'model': 'deepseek-v4', 'output': '...', 'confidence': 0.9},
            {'model': 'claude-4', 'output': '...', 'confidence': 0.85},
            {'model': 'gpt-5.5', 'output': '...', 'confidence': 0.88}
        ]
        """
        if strategy == 'majority':
            return self._majority_vote(responses)
        elif strategy == 'weighted':
            return self._weighted_vote(responses)
        elif strategy == 'consensus':
            return self._consensus_vote(responses)
        else:
            raise ValueError(f"Unknown strategy: {strategy}")
    
    def _majority_vote(self, responses: list) -> dict:
        """简单多数投票"""
        # 对于代码生成，使用BLEU或精确匹配
        # 对于开放性问题，使用语义相似度
        
        from collections import Counter
        
        # 简化的投票：选择最长的（通常更完整）
        # 实际应使用语义相似度聚类
        outputs = [r['output'] for r in responses]
        
        # 启发式：选择与其他输出最相似的
        def similarity(a, b):
            # Jaccard相似度
            set_a = set(a.split())
            set_b = set(b.split())
            intersection = len(set_a & set_b)
            union = len(set_a | set_b)
            return intersection / union if union > 0 else 0
        
        best_output = None
        best_score = -1
        
        for i, output in enumerate(outputs):
            score = sum(similarity(output, other) for j, other in enumerate(outputs) if i != j)
            if score > best_score:
                best_score = score
                best_output = output
        
        return {
            'output': best_output,
            'method': 'majority_vote',
            'agreement_score': best_score / len(outputs),
            'all_responses': responses
        }
    
    def _weighted_vote(self, responses: list) -> dict:
        """加权投票（基于模型置信度）"""
        total_weight = sum(r.get('confidence', 0.5) for r in responses)
        
        # 选择权重最高的
        best = max(responses, key=lambda r: r.get('confidence', 0))
        
        return {
            'output': best['output'],
            'method': 'weighted_vote',
            'selected_model': best['model'],
            'weight': best.get('confidence', 0) / total_weight,
            'all_responses': responses
        }
    
    def _consensus_vote(self, responses: list, min_agreement: float = 0.7) -> dict:
        """共识投票：要求高度一致"""
        # 检查是否有共识
        outputs = [r['output'] for r in responses]
        
        # 简化的共识检测
        from difflib import SequenceMatcher
        
        agreements = []
        for i in range(len(outputs)):
            for j in range(i+1, len(outputs)):
                similarity = SequenceMatcher(None, outputs[i], outputs[j]).ratio()
                agreements.append(similarity)
        
        avg_agreement = sum(agreements) / len(agreements) if agreements else 0
        
        if avg_agreement >= min_agreement:
            # 有共识，选择置信度最高的
            best = max(responses, key=lambda r: r.get('confidence', 0))
            return {
                'output': best['output'],
                'method': 'consensus',
                'consensus_reached': True,
                'agreement': avg_agreement
            }
        else:
            # 无共识，需要人工审核或更高级别模型
            return {
                'output': None,
                'method': 'consensus',
                'consensus_reached': False,
                'agreement': avg_agreement,
                'recommendation': '需要人工审核或调用更高级模型'
            }
```

```python
            'response': safe_response,
            'intent': intent,

            'processing_time': elapsed,
```

```python
        return breakdown
```

```python
    """多模型内容审核系统"""
    
    def __init__(self):
        self.fast_filter = FastFilter()
        self.moderation_models = {
            'porn': 'moderation-porn-v2',
            'violence': 'moderation-violence-v2',
            'political': 'moderation-political-v2',
            'spam': 'moderation-spam-v2',
            'copyright': 'moderation-copyright-v2'
        }
        self.judge_model = 'claude-4'
    
    def moderate(self, content: dict) -> dict:
        """内容审核流程"""
        
        # 步骤1：快速预审
        fast_result = self.fast_filter.check(content)
        if fast_result['decision'] == 'reject':
            return {
                'decision': 'reject',
                'reason': fast_result['reason'],
                'confidence': 1.0
            }
        
        # 步骤2：多维度并行审核
        moderation_results = {}
        for dimension, model in self.moderation_models.items():
            moderation_results[dimension] = self._moderate_dimension(
                content, dimension, model
            )
        
        # 步骤3：综合决策
        final_decision = self._judge(moderation_results)
        
        return final_decision
    
    def _moderate_dimension(self, content: dict, dimension: str, model: str) -> dict:
        """单维度审核"""
        # 实际应调用专用审核模型
        return {
            'dimension': dimension,
            'score': 0.1,  # 违规概率
            'confidence': 0.95
        }
    
    def _judge(self, results: dict) -> dict:
        """综合决策"""
        max_score = max(r['score'] for r in results.values())
        
        if max_score > 0.8:
            return {'decision': 'reject', 'confidence': max_score}
        elif max_score > 0.5:
            return {'decision': 'manual_review', 'confidence': max_score}
        else:
            return {'decision': 'approve', 'confidence': 1 - max_score}
```

```python
class ThroughputOptimizer:
    """吞吐量优化器"""
    
    def __init__(self):
        self.batch_sizes = {
            'deepseek-v4': 32,
            'claude-4': 16,
            'gpt-5.5': 8
        }
        self.concurrent_limits = {
            'deepseek-v4': 100,
            'claude-4': 50,
            'gpt-5.5': 20
        }
    
    def optimize_batch(self, requests: list, model: str) -> list:
        """
        请求批处理优化
        
        批处理提升吞吐量原理：
        - 共享模型权重加载
        - 并行矩阵计算
        - 摊销推理框架开销
        
        批处理代价：
        - 尾部延迟增加（等最慢的请求）
        - 内存需求增加
        - 缓存效率降低
        
        最优批大小：
        batch_size* = argmax_{b} throughput(b) / latency(b)
        """
        batch_size = self.batch_sizes.get(model, 16)
        
        # 按相似度分组（提高缓存效率）
        batches = []
        current_batch = []
        
        for req in requests:
            current_batch.append(req)
            if len(current_batch) >= batch_size:
                batches.append(current_batch)
                current_batch = []
        
        if current_batch:
            batches.append(current_batch)
        
        return batches
    
    def adaptive_concurrency(self, model: str, current_load: float) -> int:
        """
        自适应并发控制
        
        使用PID控制器思路：
        - 监控当前延迟
        - 如果延迟 > target，降低并发
        - 如果延迟 < target，提高并发
        """
        base_limit = self.concurrent_limits.get(model, 50)
        
        if current_load > 0.8:
            return int(base_limit * 0.8)
        elif current_load < 0.3:
            return int(base_limit * 1.2)
        else:
            return base_limit
```

```python
5. 成本优化
   - 缓存高频请求
   - 批处理降低单位成本
   - 离线任务使用低价模型

6. 质量保障
   - A/B测试框架
   - 人工评估流水线
   - 自动回归测试

7. 可观测性
   - 全链路追踪
   - 模型性能监控
   - 成本归因分析

8. 安全与合规
   - 敏感数据路由到私有化模型
   - 审计日志
   - 数据隔离
"""

class BestPracticeRouter:
    """遵循最佳实践的路由器"""
    
    def __init__(self):
        self.models = self._initialize_models()
        self.cache = {}
        self.health_status = {}
        self.fallback_chain = [
            'gpt-5.5', 'claude-4', 'deepseek-v4', 'glm-5'
        ]
    
    def _initialize_models(self):
        """初始化模型连接"""
        return {
            'deepseek-v4': {'latency': 800, 'error_rate': 0.001},
            'claude-4': {'latency': 1200, 'error_rate': 0.002},
            'gpt-5.5': {'latency': 1500, 'error_rate': 0.001},
            'glm-5': {'latency': 600, 'error_rate': 0.003}
        }
    
    def route_with_best_practices(self, query: str, context: dict = None) -> dict:
        """遵循最佳实践的路由"""
        
        # 1. 检查缓存
        cache_key = hash(query)
        if cache_key in self.cache:
            return {
                'result': self.cache[cache_key],
                'source': 'cache',
                'cost': 0
            }
        
        # 2. 特征提取
        features = self._extract_features(query)
        
        # 3. 健康检查
        healthy_models = [
            m for m in self.models 
            if self.health_status.get(m, True)
        ]
        
        # 4. 路由决策
        model = self._select_model(features, healthy_models)
        
        # 5. 带降级的调用
        result = self._call_with_fallback(model, query, context)
        
        # 6. 缓存结果
        if len(self.cache) < 10000:  # LRU缓存
            self.cache[cache_key] = result
        
        return result
    
    def _extract_features(self, query: str) -> dict:
        """特征提取"""
        extractor = TaskFeatureExtractor()
        return extractor.extract(query)
    
    def _select_model(self, features: dict, healthy_models: list) -> str:
        """模型选择"""
        router = MultiObjectiveRouter()
        result = router.route(features)
        
        if result['model'] in healthy_models:
            return result['model']
        
        # 选择健康的次优模型
        for model in self.fallback_chain:
            if model in healthy_models:
                return model
        
        return healthy_models[0] if healthy_models else None
    
    def _call_with_fallback(self, primary_model: str, query: str, context: dict) -> dict:
        """带降级的调用"""
        try:
            # 实际应调用API
            return {
                'model': primary_model,
                'result': f'[{primary_model}] 处理结果',
                'status': 'success'
            }
        except Exception as e:
            # 降级到下一个模型
            idx = self.fallback_chain.index(primary_model)
            if idx < len(self.fallback_chain) - 1:
                fallback_model = self.fallback_chain[idx + 1]
                return self._call_with_fallback(fallback_model, query, context)
            else:
                raise Exception("所有模型都不可用")
```

## 面试题与参考答案

### Q1：多模型协作的核心优势是什么？

**参考答案**：

多模型协作的核心优势体现在三个维度：

1. **质量维度**：不同模型在不同任务子空间上有不同的能力边界。通过任务分解和模型匹配，可以在每个子任务上使用最优模型，整体质量高于单一模型的平均表现。

2. **成本维度**：利用计算经济学原理，将任务按复杂度分级处理。简单任务使用低成本模型，复杂任务使用高能力模型，在保证质量的前提下显著降低成本（通常可节省60-80%）。

3. **可靠性维度**：多模型互为备份，单个模型故障时自动降级。同时通过集成策略（投票、裁判模型）降低单一模型的错误率。

数学上，设任务空间为T，模型集合为{M_i}，则：
- 单一模型性能：E[Perf(M_best)] = ∫ P(t) × Perf(M_best, t) dt
- 协作性能：E[Perf(collab)] = ∫ P(t) × max_i Perf(M_i, t) dt
- 性能增益：Gain = E[Perf(collab)] - E[Perf(M_best)]

### Q2：如何设计一个智能路由系统？

**参考答案**：

智能路由系统设计分为四层：

1. **特征提取层**：
   - 提取任务的多维特征：复杂度、领域、语言、创意需求、安全等级、延迟敏感度
   - 使用NLP技术（关键词匹配、分类器）自动提取

2. **能力评估层**：
   - 维护模型能力矩阵：每个模型在各维度上的能力评分
   - 定期通过benchmark更新能力评估
   - 考虑成本、延迟、可靠性等非功能指标

3. **决策引擎层**：
   - 规则引擎：基于硬规则的快速路由（如安全相关→Claude）
   - ML分类器：训练任务特征→最佳模型的映射
   - 多目标优化：在质量、成本、延迟之间做帕累托优化

4. **反馈优化层**：
   - 收集用户满意度反馈
   - A/B测试不同路由策略
   - 在线学习优化路由参数

关键指标：路由准确率（实际最佳模型与路由选择的一致率）应>90%。

### Q3：级联处理和并行集成有什么区别？适用场景是什么？

**参考答案**：

**级联处理（Cascading）**：
- 特点：按顺序使用多个模型，前级模型的输出作为后级的输入或触发条件
- 优势：延迟低（通常只需处理一个模型），成本低（大部分请求被前级拦截）
- 劣势：错误传播（前级错误会导致后级错误），质量上限受限于最后一级
- 适用：高并发、成本敏感、任务复杂度差异大的场景（如客服、内容审核）

**并行集成（Parallel Ensemble）**：
- 特点：同时调用多个模型，然后合并结果
- 优势：质量高（综合多个模型的优点），鲁棒性好（单个模型错误不影响整体）
- 劣势：延迟高（取决于最慢的模型），成本高（调用多个模型）
- 适用：质量优先、错误成本高、低并发的场景（如金融风控、医疗诊断）

**混合策略**：
实际系统中常使用混合策略：先用级联快速过滤简单任务，对复杂任务使用并行集成。

### Q4：如何处理模型间的上下文传递？

**参考答案**：

上下文传递是多模型协作的关键挑战，解决方案包括：

1. **标准化中间表示（IR）**：
   - 定义统一的上下文格式（JSON Schema）
   - 包含：任务类型、已处理步骤、中间结果、置信度、元数据
   - 示例：
   ```json
   {
     "task_id": "uuid",
     "current_step": 2,
     "history": [
       {"step": 1, "model": "glm-5", "output": "意图识别结果"}
     ],
     "context": {"user_intent": "order_query", "urgency": "high"},
     "confidence": 0.92
   }
   ```

2. **上下文压缩**：
   - 长上下文摘要：将前级输出压缩为关键信息
   - 选择性传递：只传递下游模型需要的信息
   - 避免信息过载

3. **错误处理**：
   - 前级错误时传递错误标记
   - 下游模型识别到错误标记后采取降级策略
   - 全链路追踪便于问题定位

4. **状态管理**：
   - 使用分布式缓存（Redis）存储会话状态
   - 支持多轮对话的上下文保持
   - TTL机制避免内存泄漏

### Q5：多模型协作系统的成本如何优化？

**参考答案**：

成本优化策略分为五个层次：

1. **路由层优化**：
   - 精准路由减少大模型调用次数
   - 经验法则：70%简单任务用小模型，20%中等任务用中模型，10%复杂任务用大模型
   - 节省：60-80%

2. **缓存层优化**：
   - 高频查询缓存（Redis）
   - 相似问题匹配（Embedding相似度>0.95直接返回缓存）
   - 节省：20-40%

3. **批处理优化**：
   - 请求攒批处理，摊销推理开销
   - 最优批大小：根据模型特性和延迟要求动态调整
   - 节省：30-50%

4. **级联优化**：
   - 小模型预处理过滤简单请求
   - 大模型只做关键决策
   - 节省：50-70%

5. **基础设施优化**：
   - 使用长连接减少TCP握手开销
   - 压缩传输数据
   - 就近部署（边缘计算）
   - 节省：10-20%

综合以上策略，实际系统可实现成本降低80-90%，同时保持质量损失<10%。

### Q6：如何评估多模型协作系统的效果？

**参考答案**：

评估体系包含四个层面：

1. **业务指标**：
   - 用户满意度（CSAT）
   - 任务完成率
   - 错误率（需要人工介入的比例）
   - 平均处理时间

2. **质量指标**：
   - 路由准确率：路由选择的模型与实际最优模型的一致率
   - 集成增益：集成后的质量 vs 单模型质量的提升
   - 一致性：相同输入多次调用的输出稳定性

3. **成本指标**：
   - 平均每次调用的成本
   - 成本分布（各模型的成本占比）
   - 预算利用率
   - ROI（质量提升 / 成本增加）

4. **系统指标**：
   - 延迟分布（P50, P95, P99）
   - 吞吐量（QPS）
   - 可用性（SLA达标率）
   - 降级触发频率

评估方法：
- A/B测试：对比协作系统 vs 单一模型
- 离线评测：使用标注数据集评估路由和集成效果
- 在线监控：实时仪表盘追踪关键指标

### Q7：在实际落地中，多模型协作面临哪些挑战？

**参考答案**：

主要挑战包括：

1. **技术挑战**：
   - 模型能力评估困难：不同评测基准结果不一致
   - 上下文传递复杂：不同模型的输入格式、上下文长度限制不同
   - 延迟优化困难：并行调用增加系统复杂度
   - 错误传播：前级错误影响后级

2. **工程挑战**：
   - 运维复杂度：需要监控多个模型服务
   - 版本管理：模型更新不同步导致行为不一致
   - 测试困难：组合爆炸，难以覆盖所有路径
   - 调试困难：跨模型的问题定位复杂

3. **业务挑战**：
   - 成本归因：难以精确计算每个业务线的模型成本
   - 效果归因：难以确定质量提升来自哪个模型
   - 组织阻力：团队可能偏好单一模型方案（简单）
   - 供应商管理：与多个模型供应商合作增加商务复杂度

4. **安全挑战**：
   - 数据隔离：不同模型可能由不同供应商提供，数据安全策略需统一
   - 合规要求：某些行业要求数据不出境，限制模型选择
   - 审计需求：需要记录完整的模型调用链
