## 二、日常编码（最高频，每天必用）

### 模板 01：新增 CRUD 接口

> 🔥 使用频率最高，没有之一。

**适用场景**：接到需求"新增一个 XX 管理模块"，需要快速生成 Controller + Service + Mapper 全套。

**⭐ 效果评分**：⭐⭐⭐⭐⭐（5/5，可直接运行）

**📏 Token 消耗**：约 400-600 tokens

```markdown
你是资深 Java 后端工程师，技术栈 Spring Boot 3 + MyBatis-Plus + MySQL。

请为以下实体生成完整 CRUD 接口：

【实体信息】
- 实体类名：{EntityName}  
- 字段列表：{field1:Type, field2:Type, ...}
- 主键策略：{ASSIGN_ID | AUTO}
- 数据库表名：{table_name}

【功能要求】
- 分页查询，支持按 {searchable_fields} 模糊搜索
- 新增时自动填充 create_time、update_time
- 删除为逻辑删除（is_deleted=1）
- 统一返回类 Result<T>（字段 code、msg、data）

【输出格式】
按顺序输出：Entity → Mapper → Service接口 → ServiceImpl → Controller

【可变参数】
- {EntityName}：实体类名，如 User、Order、Product
- {field1:Type}：字段名和类型，如 id:Long, name:String, price:BigDecimal
- {searchable_fields}：支持搜索的字段，逗号分隔，如 name,phone,email
- {table_name}：数据库表名，如 t_user
```
