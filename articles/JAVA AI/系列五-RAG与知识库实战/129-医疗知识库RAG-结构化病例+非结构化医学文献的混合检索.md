# 医疗知识库 RAG：结构化病例 + 非结构化医学文献的混合检索，临床决策辅助系统

> "这个患者的症状和肝功能指标，在近 3 年的医学文献中有没有相似的病例报道？""二甲双胍和格列美脲联用，最新的临床指南怎么说？"——医生需要的不是搜索引擎，而是一个能同时检索结构化病例和非结构化文献的 AI 助手。

## 一、医疗场景对 RAG 的独特要求

医疗 RAG 和通用 RAG 至少有以下关键差异：

| 维度 | 通用 RAG | 医疗 RAG |
|------|---------|---------|
| 数据异构性 | 文档为主 | 结构化病例表 + 非结构化论文 |
| 术语体系 | 无 | ICD-10、SNOMED CT、LOINC 等标准术语 |
| 同义词 | 少量 | 大量（"心肌梗死"="心梗"="MI"="急性冠脉综合征 STEMI 型"） |
| 隐私 | 无需 | 必须脱敏（姓名、身份证号、电话等） |
| 置信度 | 可模糊 | 必须明确标注（不确定的风险可能误导临床决策） |
| 时效性 | 普通 | 强烈（医学知识更新快，过期信息可能有害） |

### 3.2 结构化病例的向量化策略

结构化数据不能直接 Embedding，需要转换为自然语言描述：

```java
public class StructuredCaseEncoder {

    /**
     * 将一个完整的病例（患者 + 入院 + 检查 + 诊断）转换为自然语言描述
     */
    public String encodeCaseToText(
            MedicalCaseData.Patient patient,
            MedicalCaseData.Admission admission,
            List<MedicalCaseData.LabResult> labResults,
            List<MedicalCaseData.Diagnosis> diagnoses) {

        StringBuilder text = new StringBuilder();

        // 患者基本信息
        text.append("患者: ").append(patient.gender()).append(", ")
            .append(patient.age()).append("岁");
        if (!patient.chronicDiseases().isEmpty()) {
            text.append(", 慢性病史: ");
            text.append(String.join("、", patient.chronicDiseases()));
        }
        text.append("\n");

        // 就诊信息
        text.append("主诉: ").append(admission.chiefComplaint()).append("\n");
        text.append("现病史: ").append(admission.presentIllness()).append("\n");
        if (admission.symptoms() != null && admission.symptoms().length > 0) {
            text.append("症状: ").append(String.join("、", admission.symptoms())).append("\n");
        }

        // 异常检查结果（重点关注异常值）
        text.append("异常检查结果:\n");
        for (var lab : labResults) {
            if ("H".equals(lab.abnormalFlag()) || "L".equals(lab.abnormalFlag())) {
                text.append(String.format("  - %s: %.2f %s (参考范围 %.2f-%.2f) %s\n",
                    lab.testName(), lab.value(), lab.unit(),
                    lab.refLow(), lab.refHigh(),
                    "H".equals(lab.abnormalFlag()) ? "偏高" : "偏低"));
            }
        }

        // 诊断
        text.append("诊断:\n");
        for (var diag : diagnoses) {
            text.append(String.format("  - [%s] %s (%s)\n",
                diag.icd10Code(), diag.diagnosisName(), diag.diagnosisType()));
        }

        return text.toString();
    }

    /**
     * 构建结构化检索的 SQL 条件
     * 用于精确匹配：年龄范围、性别、检查指标范围
     */
    public Map<String, Object> buildStructuredFilters(
            int ageMin, int ageMax, String gender,
            List<LabRangeFilter> labFilters) {

        Map<String, Object> filters = new LinkedHashMap<>();
        filters.put("ageMin", ageMin);
        filters.put("ageMax", ageMax);
        if (gender != null && !gender.isEmpty()) {
            filters.put("gender", gender);
        }
        filters.put("labFilters", labFilters);
        return filters;
    }

    public record LabRangeFilter(String testCode, double minValue, double maxValue) {}
}
```

### 3.3 结构化检索 + 向量检索的混合查询

```java
public class HybridMedicalRetriever {

    private final StructuredCaseEncoder caseEncoder;
    private final VectorStore caseVectorStore;    // 病例向量库
    private final VectorStore literatureStore;    // 文献向量库
    private final MedicalTermExpander termExpander;

    /**
     * 混合检索：结构化过滤 + 语义检索 + 术语扩展
     */
    public HybridSearchResult hybridSearch(MedicalQuery query) {
        // 1. 医学术语同义词扩展
        String expandedQuery = termExpander.expand(query.text());
        List<String> relatedTerms = termExpander.getRelatedTerms(query.text());

        // 2. 结构化条件过滤（精确匹配）
        Map<String, Object> structuredFilters = caseEncoder.buildStructuredFilters(
            query.ageMin(), query.ageMax(),
            query.gender(), query.labFilters());

        // 3. 语义向量检索（模糊匹配）
        List<Float> queryEmbedding = embeddingService.embed(expandedQuery);
        List<VectorDocument> caseResults = caseVectorStore.searchWithFilters(
            queryEmbedding, 10, structuredFilters);
        List<VectorDocument> literatureResults = literatureStore.search(
            queryEmbedding, 10);

        // 4. 使用扩展术语做二次检索
        for (String term : relatedTerms) {
            List<Float> termEmbedding = embeddingService.embed(term);
            caseResults.addAll(caseVectorStore.searchWithFilters(
                termEmbedding, 3, structuredFilters));
            literatureResults.addAll(literatureStore.search(termEmbedding, 3));
        }

        // 5. 去重和融合排序
        return fuseAndRank(caseResults, literatureResults, query);
    }

    private HybridSearchResult fuseAndRank(
            List<VectorDocument> cases, List<VectorDocument> literature,
            MedicalQuery query) {

        // 病例结果按结构化匹配度加权
        List<RankedDocument> ranked = new ArrayList<>();

        for (var doc : cases) {
            // 结构化匹配度 = 年龄/性别/指标精确匹配的程度
            double structuredScore = calculateStructuredMatchScore(doc.metadata(), query);
            double finalScore = doc.similarity() * 0.6 + structuredScore * 0.4;
            ranked.add(new RankedDocument(doc, finalScore, "CASE"));
        }

        for (var doc : literature) {
            // 医学文献按发表年份/期刊影响因子加权
            double impactFactor = extractImpactFactor(doc.metadata());
            double freshness = extractFreshness(doc.metadata());
            double finalScore = doc.similarity() * 0.5 + impactFactor * 0.3 + freshness * 0.2;
            ranked.add(new RankedDocument(doc, finalScore, "LITERATURE"));
        }

        ranked.sort((a, b) -> Double.compare(b.score(), a.score()));

        return new HybridSearchResult(
            ranked.stream().limit(10).toList(),
            expandedQuery,
            termExpander.getTermMappings()
        );
    }

    private double calculateStructuredMatchScore(
            Map<String, Object> metadata, MedicalQuery query) {
        double score = 0;
        // 年龄匹配
        // 性别匹配
        // 检查指标匹配
        return Math.min(1.0, score);
    }

    private double extractImpactFactor(Map<String, Object> metadata) {
        String factor = (String) metadata.getOrDefault("impactFactor", "0");
        return Double.parseDouble(factor) / 50.0;  // 归一化
    }

    private double extractFreshness(Map<String, Object> metadata) {
        String year = (String) metadata.getOrDefault("publishYear", "2020");
        int y = Integer.parseInt(year);
        return Math.max(0, 1.0 - (2026 - y) * 0.15);  // 越新越好
    }

    public record RankedDocument(VectorDocument doc, double score, String sourceType) {}

    public record HybridSearchResult(
        List<RankedDocument> documents,
        String expandedQuery,
        Map<String, List<String>> termMappings  // 术语映射关系
    ) {}

    // 依赖注入
    private final EmbeddingService embeddingService;

    public interface EmbeddingService {
        List<Float> embed(String text);
    }
}
```

```java
        return SYNONYM_MAP.getOrDefault(term, List.of());

     * 查询扩展：将用户输入中的所有术语扩展为同义词列表

    public String expand(String query) {
        StringBuilder expanded = new StringBuilder(query);

        for (var entry : SYNONYM_MAP.entrySet()) {
            String standard = entry.getKey();
            if (query.contains(standard)) {
                // 添加同义词增强检索
                for (String syn : entry.getValue()) {
                    expanded.append(" ").append(syn);
                }
            }
            // 也检查反向情况：用户用了同义词
            for (String syn : entry.getValue()) {
                if (query.contains(syn) && !query.contains(standard)) {
                    expanded.append(" ").append(standard);
                    break;
                }
            }
        }

        return expanded.toString();
    }

    /**
     * 获取查询中涉及的所有相关术语（用于多路检索）
     */
    public List<String> getRelatedTerms(String query) {
        Set<String> terms = new LinkedHashSet<>();

        for (var entry : SYNONYM_MAP.entrySet()) {
            if (query.contains(entry.getKey())) {
                terms.addAll(entry.getValue());
            }
            for (String syn : entry.getValue()) {
                if (query.contains(syn)) {
                    terms.add(entry.getKey());
                    terms.addAll(entry.getValue());
                    break;
                }
            }
        }

        return new ArrayList<>(terms);
    }

    /**
     * 术语映射关系（用于告知用户做了哪些术语扩展）
     */
    public Map<String, List<String>> getTermMappings() {
        return new HashMap<>(SYNONYM_MAP);
    }
}
```

## 五、隐私保护（脱敏处理）

### 5.1 医疗数据脱敏引擎

```java
import java.util.regex.*;

public class MedicalDataAnonymizer {

    /**
     * 脱敏规则配置
     */
    public enum SensitiveField {
        NAME,           // 姓名
        ID_CARD,        // 身份证号
        PHONE,          // 电话号码
        ADDRESS,        // 地址
        MEDICAL_RECORD,  // 病历号
        SOCIAL_SECURITY // 社保号
    }

    /**
     * 对病例文本进行脱敏处理
     * 在 Embedding 之前和展示之前都需要执行
     */
    public String anonymize(String text) {
        String result = text;

        // 1. 身份证号：前三后四保留，中间用*替代
        result = Pattern.compile("(\\d{6})\\d{8}(\\d{4}|\\d{3}[Xx])")
            .matcher(result)
            .replaceAll(m -> m.group(1) + "****" + m.group(2));

        // 2. 手机号：前三后四保留
        result = Pattern.compile("(1[3-9]\\d)\\d{4}(\\d{4})")
            .matcher(result)
            .replaceAll(m -> m.group(1) + "****" + m.group(2));

        // 3. 姓名：姓保留，名用*替代
        result = Pattern.compile("(((患者|联系人|家属|监护人)(姓名)?[：:])|(姓名[：:]))?\\s*([\\u4e00-\\u9fa5]{2,4})")
            .matcher(result)
            .replaceAll(m -> {
                String name = m.group(m.groupCount());
                if (name.length() <= 2) {
                    return m.group().replace(name, name.charAt(0) + "*");
                }
                return m.group().replace(name,
                    name.charAt(0) + "*".repeat(name.length() - 2) + name.charAt(name.length() - 1));
            });

        // 4. 地址：保留省市区，后续用***
        result = Pattern.compile("([\\u4e00-\\u9fa5]{2,3}(省|市|自治区|特别行政区))" +
            "([\\u4e00-\\u9fa5]{2,3}(市|区|县))?(.{0,50})?(医院|小区|街道|路|号|栋|单元|楼|室|房间)?")
            .matcher(result)
            .replaceAll(m -> {
                String full = m.group();
                if (full.contains("医院") || full.contains("小区")) {
                    // 保留省市区 + 医院/小区名
                    return full.replaceAll("(?<=(省|市|区|县)).{4,}?(?=(医院|小区))", "***");
                }
                return full;
            });

        // 5. 病历号/社保号
        result = Pattern.compile("(病历号|社保号|医保号|住院号)[：:]\\s*(\\d+)")
            .matcher(result)
            .replaceAll(m -> m.group(1) + ": ****" + m.group(2).substring(
                Math.max(0, m.group(2).length() - 4)));

        // 6. 邮箱
        result = Pattern.compile("([a-zA-Z0-9._%-]+)@([a-zA-Z0-9.-]+)")
            .matcher(result)
            .replaceAll(m -> m.group(1).substring(0, 2) + "***@" + m.group(2));

        return result;
    }

    /**
     * 数据集级别的差分隐私保护
     * 防止通过多次查询重建个体信息
     */
    public class DifferentialPrivacyGuard {
        private final double epsilon;  // 隐私预算
        private int queryCount;

        public DifferentialPrivacyGuard(double epsilon) {
            this.epsilon = epsilon;
        }

        /**
         * 在返回聚合结果时添加拉普拉斯噪声
         */
        public double addNoise(double trueValue) {
            queryCount++;
            double remainingBudget = epsilon - queryCount * 0.01;

            if (remainingBudget <= 0) {
                throw new RuntimeException("隐私预算耗尽，请明天再试");
            }

            // 拉普拉斯机制
            double scale = 1.0 / remainingBudget;
            double noise = laplaceNoise(scale);

            return trueValue + noise;
        }

        private double laplaceNoise(double scale) {
            double u = Math.random() - 0.5;
            return -scale * Math.signum(u) * Math.log(1 - 2 * Math.abs(u));
        }
    }
}
```

## 六、置信度标注

```java
public class MedicalConfidenceScorer {

    public record ConfidenceAnnotation(
        double score,                    // 0.0 ~ 1.0
        ConfidenceLevel level,          // 置信度等级
        String reasoning,               // 置信度依据
        List<String> alternativeViews,  // 不同观点（如果存在分歧）
        List<String> knowledgeGaps      // 知识缺口
    ) {}

    public enum ConfidenceLevel {
        HIGH("基于多个高质量来源，建议可信度高"),
        MODERATE("基于有限来源，建议进一步验证"),
        LOW("来源不充分或存在矛盾，建议咨询资深医生"),
        UNKNOWN("未找到相关证据，无法给出建议");

        final String description;
        ConfidenceLevel(String desc) { this.description = desc; }
    }

    /**
     * 评估检索结果的置信度
     */
    public ConfidenceAnnotation evaluate(HybridMedicalRetriever.HybridSearchResult result) {
        List<HybridMedicalRetriever.RankedDocument> docs = result.documents();

        if (docs.isEmpty()) {
            return new ConfidenceAnnotation(0.0, ConfidenceLevel.UNKNOWN,
                "未找到相关病例或文献", List.of(), List.of("该方向可能缺乏研究"));
        }

        double score = 0.0;
        StringBuilder reasoning = new StringBuilder();

        // 1. 来源丰富度
        boolean hasCase = docs.stream().anyMatch(d -> "CASE".equals(d.sourceType()));
        boolean hasLiterature = docs.stream().anyMatch(d -> "LITERATURE".equals(d.sourceType()));
        if (hasCase && hasLiterature) score += 0.2;
        reasoning.append("来源类型: 病例" + (hasCase ? "✓" : "✗")
            + " 文献" + (hasLiterature ? "✓" : "✗") + "; ");

        // 2. 最高相似度
        double topSimilarity = docs.get(0).score();
        score += topSimilarity * 0.4;
        reasoning.append(String.format("最高匹配度: %.2f; ", topSimilarity));

        // 3. Top-K 的一致性
        double consistency = calculateConsistency(docs.stream().limit(5).toList());
        score += consistency * 0.2;
        reasoning.append(String.format("结果一致性: %.2f; ", consistency));

        // 4. 时效性
        double freshness = calculateAvgFreshness(docs);
        score += freshness * 0.2;
        reasoning.append(String.format("时效性: %.2f; ", freshness));

        // 5. 来源权威性
        double authority = calculateAuthority(docs);
        score += authority * 0.1;

        ConfidenceLevel level;
        if (score >= 0.7) level = ConfidenceLevel.HIGH;
        else if (score >= 0.4) level = ConfidenceLevel.MODERATE;
        else level = ConfidenceLevel.LOW;

        return new ConfidenceAnnotation(score, level, reasoning.toString(),
            List.of(), List.of());
    }

    private double calculateConsistency(
            List<HybridMedicalRetriever.RankedDocument> docs) {
        if (docs.size() < 2) return 0.5;

        // 检查 Top-K 是否都指向相似的诊断/结论
        // 简化实现：用得分方差衡量
        double mean = docs.stream().mapToDouble(HybridMedicalRetriever.RankedDocument::score)
            .average().orElse(0);
        double variance = docs.stream()
            .mapToDouble(d -> Math.pow(d.score() - mean, 2))
            .average().orElse(0);
        return 1.0 / (1.0 + variance * 10);
    }

    private double calculateAvgFreshness(
            List<HybridMedicalRetriever.RankedDocument> docs) {
        // 医学文献强调时效性：5 年内最好，10 年以上降低权重
        return docs.stream().mapToDouble(d -> {
            String year = (String) d.doc().metadata().getOrDefault("publishYear", "2020");
            int y = Integer.parseInt(year);
            return Math.max(0, 1.0 - (2026 - y) * 0.1);
        }).average().orElse(0.5);
    }

    private double calculateAuthority(
            List<HybridMedicalRetriever.RankedDocument> docs) {
        // 文献来源权威性：期刊影响因子、指南级别等
        return 0.7; // 简化
    }
}
```

```java
public class ClinicalDecisionSupport {

    private final HybridMedicalRetriever retriever;
    private final MedicalConfidenceScorer confidenceScorer;
    private final MedicalDataAnonymizer anonymizer;
    private final LLMClient llmClient;

    private static final String CLINICAL_ANSWER_PROMPT = """
        你是一个临床决策辅助 AI。基于检索到的病例和文献，回答以下临床问题。
        
        ## 检索到的病例：
        %s
        
        ## 检索到的文献：
        %s
        
        ## 临床问题：
        %s
        
        ## 回答要求：
        1. 先给出核心结论（带置信度标注）
        2. 列出支持证据（引用具体病例/文献）
        3. 标注不同观点（如有）
        4. 明确知识缺口（不要编造）
        5. 附上参考文献列表
        6. 最后加上免责声明
        """;

    public DecisionReport generateReport(MedicalQuery query) {
        // 1. 混合检索
        var searchResult = retriever.hybridSearch(query);

        // 2. 置信度评估
        var confidence = confidenceScorer.evaluate(searchResult);

        // 3. 构建回答
        String caseContext = buildCaseContext(searchResult);
        String literatureContext = buildLiteratureContext(searchResult);

        String answer = llmClient.chat(String.format(CLINICAL_ANSWER_PROMPT,
            caseContext, literatureContext, query.text()));

        // 4. 脱敏（返回之前最后一道防线）
        String safeAnswer = anonymizer.anonymize(answer);

        return new DecisionReport(
            safeAnswer,
            confidence,
            searchResult.documents(),
            searchResult.termMappings(),
            List.of("本系统仅供辅助参考，不构成医疗建议。请以执业医师的诊断为准。")
        );
    }

    public record DecisionReport(
        String answer,
        MedicalConfidenceScorer.ConfidenceAnnotation confidence,
        List<HybridMedicalRetriever.RankedDocument> references,
        Map<String, List<String>> termMappings,
        List<String> disclaimers  // 免责声明
    ) {}

    private String buildCaseContext(HybridMedicalRetriever.HybridSearchResult result) {
        return result.documents().stream()
            .filter(d -> "CASE".equals(d.sourceType()))
            .map(d -> String.format("[相似度: %.2f]\n%s",
                d.score(), d.doc().content()))
            .reduce("", (a, b) -> a + "\n---\n" + b);
    }

    private String buildLiteratureContext(HybridMedicalRetriever.HybridSearchResult result) {
        return result.documents().stream()
            .filter(d -> "LITERATURE".equals(d.sourceType()))
            .map(d -> String.format("[相似度: %.2f, 来源: %s, 年份: %s]\n%s",
                d.score(),
                d.doc().metadata().getOrDefault("journal", "未知"),
                d.doc().metadata().getOrDefault("publishYear", "未知"),
                d.doc().content()))
            .reduce("", (a, b) -> a + "\n---\n" + b);
    }

    public interface LLMClient { String chat(String prompt); }
}
```

## 八、总结

医疗 RAG 的五个核心设计要点：

1. **混合检索**：结构化条件过滤（年龄、性别、指标范围）+ 语义向量检索，双管齐下
2. **术语扩展**：医学术语同义词映射，弥合"心梗"和"急性心肌梗死"之间的语义鸿沟
3. **隐私脱敏**：多层脱敏策略——姓名脱敏、ID 脱敏、地址脱敏、差分隐私保护
4. **置信度标注**：综合来源类型、相似度、一致性、时效性、权威性等多维度，给出明确的可信度等级
5. **免责声明**：医疗 AI 绝对不能省略免责声明，这是合规的基本要求
