# 法律文书 RAG：长文本合同的条款级检索与风险提示，AI 法律顾问的幕后技术

> "这份 200 页的采购合同里，违约金条款在哪里？""我们签的三个供应商合同，知识产权归属条款有什么区别？""这合同里有没有对我不利的隐藏条款？"——合同审查是法务最繁重的工作，而 RAG 可以成为他们的"第二个大脑"。

## 一、法律文书 RAG 的特殊挑战

法律合同是 RAG 技术的"终极 Boss"，因为：

| 挑战 | 具体表现 |
|------|---------|
| 长文本 | 一份合同动辄 100-300 页，远超 Embedding 模型的上下文窗口 |
| 结构严谨 | 条->款->项，层级嵌套，乱切会破坏法律语义 |
| 术语密集 | "甲方""乙方""不可抗力""瑕疵担保"……通用 Embedding 难以理解 |
| 精确性要求 | 差一个字可能差出几百万赔偿金 |
| 多合同对比 | 需要跨文档检索，条款级别的横向对比 |

## 二、长文本合同的条款级切割策略

### 2.1 为什么不能简单按字数切割？

如果一个条款跨了两个 chunk：

```
Chunk 1: "……违约方应向守约方支付违约金，金额为合同总"
Chunk 2: "额的 30%。如违约金不足以弥补损失的……"
```

检索"违约金比例"时，这两个 chunk 可能都匹配不上，因为关键信息被切断了。

**正确策略：条款级切割**。利用法律合同的层级编号结构（第 X 条、第 X 款、第 X 项）作为天然的分割点。

### 2.2 合同条款解析器

```java
import java.util.*;
import java.util.regex.*;

public class ContractClauseParser {

    public record ClauseNode(
        int level,           // 层级: 1=条, 2=款, 3=项
        String number,       // 编号: "第十五条" / "3.1.2"
        String title,        // 标题（如有）
        String fullText,     // 完整文本
        String parentPath,   // 父级路径: "八、违约责任/第十五条"
        int startLine,       // 起始行号
        int endLine          // 结束行号
    ) {}

    // 中文法律条款的层级编号模式
    private static final Pattern ARTICLE_PATTERN = Pattern.compile(
        "^\\s*(第[一二三四五六七八九十百千万零]+条|[第]?[0-9]+\\.[0-9]+|[（(][一二三四五六七八九十][)）])"
    );

    private static final Pattern CLAUSE_PATTERN = Pattern.compile(
        "^\\s*[0-9]+\\.[0-9]+\\.[0-9]+|^\\s*（[一二三四五六七八九十]）|^\\s*\\([a-z]\\)"
    );

    /**
     * 将合同文本按条款层级解析为树状结构
     */
    public List<ClauseNode> parse(String contractText) {
        List<ClauseNode> nodes = new ArrayList<>();
        String[] lines = contractText.split("\n");

        Stack<ClauseNode> parentStack = new Stack<>();
        int currentLevel = 1;

        for (int i = 0; i < lines.length; i++) {
            String line = lines[i].trim();
            if (line.isEmpty()) continue;

            // 检查是否是新条款的开始
            Matcher articleMatcher = ARTICLE_PATTERN.matcher(line);
            Matcher clauseMatcher = CLAUSE_PATTERN.matcher(line);

            if (articleMatcher.find()) {
                // 新的一级条款（"第X条"）
                String number = articleMatcher.group(1);

                // 弹出比当前层级高的所有节点
                while (!parentStack.isEmpty() && parentStack.peek().level >= 1) {
                    parentStack.pop();
                }

                String parentPath = parentStack.isEmpty() ? ""
                    : parentStack.peek().parentPath() + "/" + parentStack.peek().number();

                ClauseNode node = new ClauseNode(
                    1, number, extractTitle(line),
                    "", parentPath, i + 1, i + 1
                );
                parentStack.push(node);
                nodes.add(node);

            } else if (clauseMatcher.find() && !parentStack.isEmpty()) {
                // 新的一款或一项
                String number = clauseMatcher.group(1).trim();

                while (!parentStack.isEmpty() && parentStack.peek().level >= 2) {
                    parentStack.pop();
                }

                String parentPath = parentStack.peek().parentPath() + "/"
                    + parentStack.peek().number();

                ClauseNode node = new ClauseNode(
                    2, number, "",
                    "", parentPath, i + 1, i + 1
                );
                parentStack.push(node);
                nodes.add(node);

            } else if (!parentStack.isEmpty()) {
                // 续行：将当前行的内容追加到最后一个节点
                ClauseNode lastNode = nodes.get(nodes.size() - 1);
                String updatedText = lastNode.fullText() + "\n" + line;
                nodes.set(nodes.size() - 1, new ClauseNode(
                    lastNode.level(), lastNode.number(), lastNode.title(),
                    updatedText, lastNode.parentPath(),
                    lastNode.startLine(), i + 1
                ));
            }
        }

        System.out.printf("解析完成：共识别 %d 个条款节点\n", nodes.size());
        return nodes;
    }

    private String extractTitle(String line) {
        // 提取条款标题（通常在条款编号之后，冒号或换行之前）
        Pattern p = Pattern.compile("第.+?条\\s*(.+?)(?:\\s|：|。|$)");
        Matcher m = p.matcher(line);
        return m.find() ? m.group(1).trim() : "";
    }

    /**
     * 将过长的条款进一步拆分（保留语义单元）
     */
    public List<ClauseNode> splitLongClauses(List<ClauseNode> nodes, int maxChars) {
        List<ClauseNode> result = new ArrayList<>();
        for (ClauseNode node : nodes) {
            if (node.fullText().length() <= maxChars) {
                result.add(node);
            } else {
                // 按句子拆分，每个子块保留完整的父级路径
                String[] sentences = node.fullText().split("(?<=[。；])");
                StringBuilder chunk = new StringBuilder();
                int chunkStart = node.startLine();

                for (int i = 0; i < sentences.length; i++) {
                    if (chunk.length() + sentences[i].length() > maxChars && chunk.length() > 0) {
                        result.add(new ClauseNode(
                            node.level(), node.number() + "(续)",
                            node.title(), chunk.toString(),
                            node.parentPath(), chunkStart, node.endLine()
                        ));
                        chunk = new StringBuilder();
                        chunkStart = node.startLine() + i;
                    }
                    chunk.append(sentences[i]);
                }

                if (chunk.length() > 0) {
                    result.add(new ClauseNode(
                        node.level(), node.number() + "(续)",
                        node.title(), chunk.toString(),
                        node.parentPath(), chunkStart, node.endLine()
                    ));
                }
            }
        }
        return result;
    }
}
```

## 三、关键条款识别与分类

### 3.1 合同条款自动分类器

法律合同中的条款可以按"风险相关度"自动分类：

```java
import java.util.*;

public class ClauseClassifier {

    public enum RiskCategory {
        PAYMENT,           // 付款条款
        DELIVERY,          // 交付条款
        WARRANTY,          // 质保/瑕疵担保
        LIABILITY,         // 违约责任/赔偿
        TERMINATION,       // 合同解除
        INTELLECTUAL_PROPERTY, // 知识产权
        CONFIDENTIALITY,   // 保密
        DISPUTE_RESOLUTION,    // 争议解决
        FORCE_MAJEURE,     // 不可抗力
        GOVERNING_LAW,     // 管辖法律
        GENERAL            // 一般条款
    }

    // 每个风险类别对应的关键词/短语
    private static final Map<RiskCategory, List<String>> CATEGORY_KEYWORDS = Map.ofEntries(
        Map.entry(RiskCategory.PAYMENT, List.of(
            "付款", "支付", "价款", "费用", "报酬", "定金", "尾款", "发票", "结算", "对账")),
        Map.entry(RiskCategory.LIABILITY, List.of(
            "违约", "赔偿", "损失", "罚金", "违约金", "定金罚则", "赔偿责任", "间接损失",
            "责任上限", "免责", "保证", "连带责任")),
        Map.entry(RiskCategory.TERMINATION, List.of(
            "解除", "终止", "撤销", "单方解除", "协议解除", "退租", "提前终止")),
        Map.entry(RiskCategory.INTELLECTUAL_PROPERTY, List.of(
            "知识产权", "著作权", "专利", "商标", "软件著作权", "源代码", "授权",
            "非独占许可", "排他许可", "归属")),
        Map.entry(RiskCategory.CONFIDENTIALITY, List.of(
            "保密", "商业秘密", "敏感信息", "竞业限制", "数据安全", "隐私", "信息保护")),
        Map.entry(RiskCategory.DISPUTE_RESOLUTION, List.of(
            "仲裁", "诉讼", "管辖", "争议解决", "法院", "仲裁委", "法律适用")),
        Map.entry(RiskCategory.FORCE_MAJEURE, List.of(
            "不可抗力", "自然灾害", "战争", "疫情", "政府行为", "意外事件")),
        Map.entry(RiskCategory.WARRANTY, List.of(
            "质保", "保修", "瑕疵", "质量保证", "检验", "验收", "合格标准", "售后服务")),
        Map.entry(RiskCategory.DELIVERY, List.of(
            "交付", "验收", "工期", "交货", "地点", "运输", "包装", "到货",
            "延期", "分批交付")),
        Map.entry(RiskCategory.GOVERNING_LAW, List.of(
            "适用法律", "管辖法院", "仲裁地", "准据法"))
    );

    /**
     * 对条款进行风险分类
     */
    public Map<RiskCategory, Double> classify(ContractClauseParser.ClauseNode clause) {
        Map<RiskCategory, Double> scores = new EnumMap<>(RiskCategory.class);
        String text = clause.fullText() + clause.title();

        for (var entry : CATEGORY_KEYWORDS.entrySet()) {
            double score = 0;
            for (String keyword : entry.getValue()) {
                int count = countOccurrences(text, keyword);
                score += count;
            }
            if (score > 0) {
                scores.put(entry.getKey(), Math.min(score / 5.0, 1.0));
            }
        }

        return scores;
    }

    /**
     * 获取最高得分的分类
     */
    public RiskCategory getPrimaryCategory(ContractClauseParser.ClauseNode clause) {
        Map<RiskCategory, Double> scores = classify(clause);
        return scores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElse(RiskCategory.GENERAL);
    }

    private int countOccurrences(String text, String keyword) {
        int count = 0;
        int idx = 0;
        while ((idx = text.indexOf(keyword, idx)) != -1) {
            count++;
            idx += keyword.length();
        }
        return count;
    }
}
```

## 四、风险条款自动标注

### 4.1 风险规则引擎

```java
public class RiskAnnotationEngine {

    public record RiskAnnotation(
        String clausePath,       // 条款路径: "第八章 违约责任/第三十条"
        RiskLevel riskLevel,     // 风险等级
        String riskType,         // 风险类型
        String description,      // 风险描述
        String highlightedText,  // 高亮文本
        String suggestion        // 修改建议
    ) {}

    public enum RiskLevel {
        CRITICAL,  // 严重（可能导致重大损失）
        HIGH,      // 高
        MEDIUM,    // 中
        LOW,       // 低
        INFO       // 提示
    }

    // 风险检测规则
    private final List<RiskRule> rules = new ArrayList<>();

    public RiskAnnotationEngine() {
        initRules();
    }

    private void initRules() {
        // 规则 1：违约金超过 30%
        rules.add(new RiskRule(
            RiskLevel.CRITICAL, "过高违约金",
            Pattern.compile("违约金.*?(\\d{2,3})\\s*%"),
            matcher -> {
                int percent = Integer.parseInt(matcher.group(1));
                if (percent > 30) {
                    return Optional.of(String.format(
                        "违约金比例 %d%% 超出合理范围（通常不超过 30%%），建议协商降低",
                        percent));
                }
                return Optional.empty();
            }
        ));

        // 规则 2：缺失违约金上限
        rules.add(new RiskRule(
            RiskLevel.HIGH, "违约金无上限",
            Pattern.compile("(违约金|赔偿).*?(实际损失|全部损失)"),
            matcher -> Optional.of(
                "违约金未设上限，建议明确约定违约金上限（如不超过合同总价的 30%）")
        ));

        // 规则 3：单方解除权（期限过短）
        rules.add(new RiskRule(
            RiskLevel.HIGH, "单方解除权",
            Pattern.compile("(甲方|乙方|任何一方)(有权|可以).*?(提前|随时).*?解除"),
            matcher -> Optional.of(
                "存在单方随时解除合同条款，对另一方存在较大不确定性风险")
        ));

        // 规则 4：知识产权归属不明确
        rules.add(new RiskRule(
            RiskLevel.CRITICAL, "知识产权归属不明",
            Pattern.compile("知识产权.*?归.*?所有"),
            matcher -> {
                String match = matcher.group();
                if (match.contains("归属另行约定") || match.contains("双方协商")) {
                    return Optional.of("知识产权归属约定不明确，存在潜在纠纷风险。"
                        + "建议明确归属方和使用权限");
                }
                return Optional.empty();
            }
        ));

        // 规则 5：管辖地在对方所在地
        rules.add(new RiskRule(
            RiskLevel.MEDIUM, "不利管辖",
            Pattern.compile("(管辖|诉讼|仲裁).*?(甲方|乙方)所在地"),
            matcher -> Optional.of(
                "争议管辖地为对方所在地，增加维权成本。建议争取己方所在地管辖")
        ));

        // 规则 6：无限期保密义务
        rules.add(new RiskRule(
            RiskLevel.MEDIUM, "永久保密义务",
            Pattern.compile("(保密义务|保密期限).*?(永久|无限期|长期)"),
            matcher -> Optional.of(
                "保密义务期限为永久，合理期限通常为合同终止后 2-5 年")
        ));

        // 规则 7：免责范围过大
        rules.add(new RiskRule(
            RiskLevel.HIGH, "免责范围过大",
            Pattern.compile("(不(承担|负)|免除).*?(任何|一切|全部|所有).*?责任"),
            matcher -> Optional.of(
                "存在完全免除责任的条款，可能被认定为无效的格式条款")
        ));

        // 规则 8：自动续约无提前通知
        rules.add(new RiskRule(
            RiskLevel.MEDIUM, "自动续约",
            Pattern.compile("(合同|协议).*?(自动续期|自动延长|自动延续)"),
            matcher -> {
                String fullText = matcher.toString();
                if (!fullText.contains("提前") && !fullText.contains("通知")) {
                    return Optional.of("自动续约条款缺乏提前通知义务，"
                        + "建议增加到期前 30 日书面通知的要求");
                }
                return Optional.empty();
            }
        ));
    }

    /**
     * 对合同全文进行风险扫描
     */
    public List<RiskAnnotation> scanContract(List<ContractClauseParser.ClauseNode> clauses) {
        List<RiskAnnotation> annotations = new ArrayList<>();

        for (ContractClauseParser.ClauseNode clause : clauses) {
            for (RiskRule rule : rules) {
                Matcher matcher = rule.pattern().matcher(clause.fullText());
                while (matcher.find()) {
                    Optional<String> suggestion = rule.onMatch().apply(matcher);
                    suggestion.ifPresent(s -> annotations.add(new RiskAnnotation(
                        clause.parentPath() + "/" + clause.number(),
                        rule.level(),
                        rule.type(),
                        s,
                        matcher.group(),
                        s
                    )));
                }
            }
        }

        // 按严重程度排序
        annotations.sort(Comparator.comparing(a -> a.riskLevel().ordinal()));
        return annotations;
    }

    @FunctionalInterface
    public interface RuleMatcher {
        Optional<String> apply(Matcher matcher);
    }

    public record RiskRule(
        RiskLevel level,
        String type,
        Pattern pattern,
        RuleMatcher onMatch
    ) {}
}
```

### 4.2 合同风险评分

```java
public class ContractRiskScorer {

    /**
     * 根据风险标注结果计算合同整体风险得分
     * 得分 0-100，分数越高风险越大
     */
    public int calculateRiskScore(List<RiskAnnotationEngine.RiskAnnotation> annotations) {
        Map<RiskLevel, Integer> countByLevel = new EnumMap<>(RiskLevel.class);

        for (var ann : annotations) {
            countByLevel.merge(ann.riskLevel(), 1, Integer::sum);
        }

        // 加权计算
        int score = 0;
        score += countByLevel.getOrDefault(RiskLevel.CRITICAL, 0) * 25;
        score += countByLevel.getOrDefault(RiskLevel.HIGH, 0) * 15;
        score += countByLevel.getOrDefault(RiskLevel.MEDIUM, 0) * 8;
        score += countByLevel.getOrDefault(RiskLevel.LOW, 0) * 3;

        return Math.min(100, score);
    }

    /**
     * 生成风险摘要
     */
    public String generateRiskSummary(List<RiskAnnotationEngine.RiskAnnotation> annotations,
                                       int totalScore) {
        StringBuilder summary = new StringBuilder();
        summary.append("=== 合同风险评估报告 ===\n\n");
        summary.append("综合风险评分：").append(totalScore).append(" / 100\n");

        if (totalScore >= 80) {
            summary.append("⚠️ 风险等级：高。建议重新审议合同条款。\n");
        } else if (totalScore >= 50) {
            summary.append("⚠️ 风险等级：中。重点关注以下条款。\n");
        } else {
            summary.append("✅ 风险等级：低。个别条款可进一步优化。\n");
        }

        summary.append("\n风险清单：\n");
        for (var ann : annotations) {
            summary.append(String.format("[%s] %s - %s\n",
                ann.riskLevel(), ann.riskType(), ann.description()));
        }

        return summary.toString();
    }
}
```

## 五、条款对比：多合同条款差异

### 5.1 跨合同条款对比引擎

这是法律 RAG 最有价值的场景之一——供应商 A 和供应商 B 的合同中，知识产权条款有何不同？

```java
public class ContractComparisonEngine {

    public record ClauseComparison(
        String clauseType,           // 条款类型（如"知识产权"）
        List<ClauseDiff> differences // 差异列表
    ) {}

    public record ClauseDiff(
        String contractA,            // 合同 A 名称
        String contractB,            // 合同 B 名称
        String fieldName,            // 对比字段
        String valueA,               // A 的值
        String valueB,               // B 的值
        String remark                // 评注
    ) {}

    /**
     * 对比两份合同的同类型条款
     */
    public Map<String, List<ClauseComparison>> compareContracts(
            String contractA, List<ContractClauseParser.ClauseNode> clausesA,
            String contractB, List<ContractClauseParser.ClauseNode> clausesB) {

        ClauseClassifier classifier = new ClauseClassifier();
        Map<String, List<ClauseComparison>> results = new LinkedHashMap<>();

        // 按条款分类分别对比
        for (ClauseClassifier.RiskCategory category : ClauseClassifier.RiskCategory.values()) {
            List<ContractClauseParser.ClauseNode> aClauses = clausesA.stream()
                .filter(c -> classifier.getPrimaryCategory(c) == category)
                .toList();
            List<ContractClauseParser.ClauseNode> bClauses = clausesB.stream()
                .filter(c -> classifier.getPrimaryCategory(c) == category)
                .toList();

            if (aClauses.isEmpty() && bClauses.isEmpty()) continue;

            List<ClauseDiff> diffs = compareClauseList(
                contractA, aClauses,
                contractB, bClauses
            );

            if (!diffs.isEmpty()) {
                results.put(category.name(), List.of(new ClauseComparison(
                    category.name(), diffs)));
            }
        }

        return results;
    }

    private List<ClauseDiff> compareClauseList(
            String nameA, List<ContractClauseParser.ClauseNode> aClauses,
            String nameB, List<ContractClauseParser.ClauseNode> bClauses) {

        List<ClauseDiff> diffs = new ArrayList<>();

        // 1. 检查一方有另一方没有的条款
        if (aClauses.isEmpty() && !bClauses.isEmpty()) {
            diffs.add(new ClauseDiff(nameA, nameB, "条款存在性",
                "无此条款", "有此条款", nameB + " 包含了 " + nameA + " 中缺失的条款"));
            return diffs;
        }
        if (bClauses.isEmpty() && !aClauses.isEmpty()) {
            diffs.add(new ClauseDiff(nameA, nameB, "条款存在性",
                "有此条款", "无此条款", nameA + " 包含了 " + nameB + " 中缺失的条款"));
            return diffs;
        }

        // 2. 提取关键字段进行对比
        for (int i = 0; i < Math.min(aClauses.size(), bClauses.size()); i++) {
            var aClause = aClauses.get(i);
            var bClause = bClauses.get(i);

            // 提取百分比数值进行对比
            Map<String, String> aValues = extractKeyValues(aClause.fullText());
            Map<String, String> bValues = extractKeyValues(bClause.fullText());

            for (String key : new HashSet<String>() {{
                addAll(aValues.keySet());
                addAll(bValues.keySet());
            }}) {
                String va = aValues.getOrDefault(key, "未约定");
                String vb = bValues.getOrDefault(key, "未约定");
                if (!va.equals(vb)) {
                    diffs.add(new ClauseDiff(nameA, nameB, key, va, vb,
                        String.format("%s: %s vs %s", key, va, vb)));
                }
            }
        }

        return diffs;
    }

    /**
     * 从条款文本中提取关键数值和字段
     */
    private Map<String, String> extractKeyValues(String clauseText) {
        Map<String, String> values = new LinkedHashMap<>();

        // 提取百分比
        Pattern percentPattern = Pattern.compile("(\\d{1,3})\\s*%");
        Matcher m = percentPattern.matcher(clauseText);
        if (m.find()) {
            values.put("百分比", m.group(1) + "%");
        }

        // 提取金额
        Pattern amountPattern = Pattern.compile("(\\d+(?:,\\d{3})*(?:\\.\\d+)?)\\s*(元|万元|万)");
        m = amountPattern.matcher(clauseText);
        if (m.find()) {
            values.put("金额", m.group());
        }

        // 提取天数
        Pattern dayPattern = Pattern.compile("(\\d+)\\s*(日|天|工作日)");
        m = dayPattern.matcher(clauseText);
        while (m.find()) {
            values.put("期限", m.group());
        }

        // 提取归属方
        if (clauseText.contains("归甲方所有")) values.put("归属", "甲方");
        else if (clauseText.contains("归乙方所有")) values.put("归属", "乙方");
        else if (clauseText.contains("双方共有")) values.put("归属", "双方共有");

        // 提取管辖地
        Pattern courtPattern = Pattern.compile("(甲方|乙方|被告|原告)所在地");
        m = courtPattern.matcher(clauseText);
        if (m.find()) {
            values.put("管辖地", m.group());
        }

        return values;
    }
}
```

### 5.2 条款对齐（Clause Alignment）

当两份合同结构不同时，需要先做条款对齐：

```java
public class ClauseAligner {

    /**
     * 基于语义相似度的条款对齐
     * 两边的条款编号可能不同，需要找到"说的是同一件事"的条款对
     */
    public List<AlignedPair> align(
            List<ContractClauseParser.ClauseNode> clausesA,
            List<ContractClauseParser.ClauseNode> clausesB,
            EmbeddingService embeddingService) {

        List<AlignedPair> aligned = new ArrayList<>();

        for (var aClause : clausesA) {
            float[] aEmb = embeddingService.embed(aClause.title() + " " + aClause.fullText());

            // 在 B 中找到最相似的条款
            double bestScore = 0;
            ContractClauseParser.ClauseNode bestMatch = null;

            for (var bClause : clausesB) {
                float[] bEmb = embeddingService.embed(
                    bClause.title() + " " + bClause.fullText());
                double sim = cosineSimilarity(aEmb, bEmb);
                if (sim > bestScore) {
                    bestScore = sim;
                    bestMatch = bClause;
                }
            }

            if (bestScore >= 0.6 && bestMatch != null) {
                aligned.add(new AlignedPair(aClause, bestMatch, bestScore));
            }
        }

        return aligned;
    }

    public record AlignedPair(
        ContractClauseParser.ClauseNode clauseA,
        ContractClauseParser.ClauseNode clauseB,
        double similarity
    ) {}

    private double cosineSimilarity(float[] a, float[] b) {
        double dot = 0, normA = 0, normB = 0;
        for (int i = 0; i < a.length; i++) {
            dot += a[i] * b[i];
            normA += a[i] * a[i];
            normB += b[i] * b[i];
        }
        return dot / (Math.sqrt(normA) * Math.sqrt(normB));
    }

    public interface EmbeddingService {
        float[] embed(String text);
    }
}
```

## 六、法律合同 RAG 服务

```java
public class ContractRAGService {

    private final ContractClauseParser parser;
    private final ClauseClassifier classifier;
    private final RiskAnnotationEngine riskEngine;
    private final ContractRiskScorer riskScorer;
    private final ContractComparisonEngine comparisonEngine;
    private final VectorStore vectorStore;
    private final LLMClient llmClient;

    /**
     * 上传并索引合同
     */
    public String uploadContract(String contractName, String contractText) {
        // 1. 条款级切割
        List<ContractClauseParser.ClauseNode> clauses = parser.parse(contractText);
        clauses = parser.splitLongClauses(clauses, 2000);

        // 2. 逐条款分类和风险标注
        for (var clause : clauses) {
            ClauseClassifier.RiskCategory category = classifier.getPrimaryCategory(clause);
            Map<String, Object> metadata = Map.of(
                "contractName", contractName,
                "clausePath", clause.parentPath() + "/" + clause.number(),
                "title", clause.title(),
                "category", category.name(),
                "level", String.valueOf(clause.level())
            );

            vectorStore.insert(new VectorDocument(
                contractName + ":" + clause.number(),
                null, // Embedding 稍后生成
                clause.fullText(),
                metadata
            ));
        }

        // 3. 风险扫描
        List<RiskAnnotationEngine.RiskAnnotation> annotations = riskEngine.scanContract(clauses);
        int riskScore = riskScorer.calculateRiskScore(annotations);
        String riskReport = riskScorer.generateRiskSummary(annotations, riskScore);

        System.out.printf("合同 %s 已索引，共 %d 条款，风险评分: %d\n",
            contractName, clauses.size(), riskScore);

        return riskReport;
    }

    /**
     * 检索特定条款
     */
    public String retrieveClause(String contractName, String query) {
        Map<String, String> filters = Map.of("contractName", contractName);
        List<VectorDocument> docs = vectorStore.searchWithFilters(query, 5, filters);

        if (docs.isEmpty()) return "未找到相关条款。";

        StringBuilder response = new StringBuilder();
        response.append("找到以下相关条款：\n\n");
        for (int i = 0; i < docs.size(); i++) {
            var doc = docs.get(i);
            response.append(String.format("## 条款 %d (%s)\n",
                i + 1, doc.metadata().get("clausePath")));
            response.append(doc.content()).append("\n\n");
        }

        return response.toString();
    }

    /**
     * AI 合同问答
     */
    public String askLegalQuestion(String question, List<String> contractNames) {
        // 1. 检索所有相关合同的相关条款
        List<VectorDocument> allDocs = new ArrayList<>();
        for (String name : contractNames) {
            Map<String, String> filters = Map.of("contractName", name);
            allDocs.addAll(vectorStore.searchWithFilters(question, 5, filters));
        }

        // 2. 构建 Prompt
        StringBuilder context = new StringBuilder();
        for (var doc : allDocs) {
            context.append(String.format("[合同: %s, 条款: %s]\n%s\n\n",
                doc.metadata().get("contractName"),
                doc.metadata().get("clausePath"),
                doc.content()));
        }

        String prompt = """
            你是一个法律顾问助手。基于以下合同条款，回答法律相关问题。
            回答要：严谨、引用具体条款、指出法律依据。
            
            ## 合同条款：
            %s
            
            ## 问题：
            %s
            
            ## 要求：
            1. 引用具体条款原文
            2. 指出潜在的法律风险
            3. 如有多个合同，指出各合同的差异
            """.formatted(context.toString(), question);

        return llmClient.chat(prompt);
    }

    public interface LLMClient { String chat(String prompt); }
}
```

## 八、总结

法律合同 RAG 的四大核心技术：

1. **条款级切割**：利用法律文档的层级结构（条/款/项）做天然分割，避免重要信息被切断
2. **风险自动标注**：基于规则引擎 + 正则提取，自动识别违约金异常、管辖不利、知识产权隐患等风险条款
3. **多合同对比**：语义对齐 + 关键字段提取，横向对比多份合同的核心条款差异
4. **引用原文**：法律场景下回答必须引用具体条款原文，不能"自行发挥"

法律 RAG 不是要替代法务，而是帮法务快速锁定需要人工审查的重点条款，将合同审查效率提升 3-5 倍。
