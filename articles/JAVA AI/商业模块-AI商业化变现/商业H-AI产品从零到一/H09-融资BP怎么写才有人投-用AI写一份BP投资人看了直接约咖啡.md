## 一、投资人看BP的"5秒法则"

首先搞清楚一个残酷的事实：**投资人看BP的平均时间不是5分钟，是5秒。**

```
投资人收到BP的真实反应：

5秒内：扫标题+第一段 → 決定继续看还是直接关掉
30秒：看核心数据和差异化 → 決定是否感兴趣
2分钟：看完整BP → 決定是否约聊
```

如果你不能在5秒内让投资人觉得"这个值得往下看"，你的BP就死在了他的邮箱里。

### 5秒内必须让投资人看到三个信息：

```
1. 你解决什么问题？（一句话）
2. 市场有多大？（一个数字）
3. 你凭什么能做成？（一个理由）

反例：
"我们是一家专注于利用先进AI技术为企业提供智能化解决方案的科技公司..."
→ 投资人：删了。下一封。

正例：
"Java开发者的AI代码审查工具。2500万Java开发者的日常痛点。
创始人8年Java后端经验，已获200付费用户，月MRR $6000。"
→ 投资人：嗯，继续看看。
```

## 三、AI写BP的完整Prompt

### 3.1 核心定位生成

```
你是一个资深风险投资人，专注于AI/SaaS早期投资。

我是一个正在融资的AI产品创始人。产品是：[一句话描述]

请帮我打磨这个定位。好的定位应该：
1. 让投资人在5秒内理解你做什么
2. 暗示市场规模（用数字）
3. 暗示你的独特优势
4. 不超过30个字

参考格式：
"[目标用户]的[核心功能]，已经[数据验证]"

请给我10个版本。不要夸大，不要假大空。
```

### 3.2 市场分析生成

```
基于我提供的产品信息，请帮我写BP的市场分析部分。

产品：[描述]
目标用户：[描述]
当前阶段数据：[用户数/收入/增长率]

请分析：
1. TAM（总可寻址市场）：全球/全国范围内所有可能有这个需求的人
2. SAM（可服务市场）：TAM中你能触达的部分
3. SOM（可获取市场）：SAM中你合理预期能拿到的份额
4. 市场增长趋势：为什么这个市场在变大？
5. 为什么现在是最佳时机？（AI技术进步/用户习惯改变/政策利好等）

计算方式（自下而上）：
目标用户总数 × 你能触达的比例 × 你的定价 = SOM

不要给出夸大的数字。投资人一眼就能看出来。
```

### 3.3 竞争格局分析

```
我是[产品名称]的创始人。请帮我做竞争格局分析。

我的产品：[描述]
我的差异化：[你的独特优势]

请分析以下竞品，并帮我填这个对比矩阵：

| 维度 | 我们 | 竞品A | 竞品B | 竞品C |
|------|------|-------|-------|-------|
| 目标用户 | | | | |
| 核心功能 | | | | |
| 定价 | | | | |
| AI能力 | | | | |
| 用户量 | | | | |
| 融资 | | | | |
| 我们的优势 | | | | |
| 我们的劣势 | | | | |

重点：诚实展示劣势。投资人更相信知道自己弱点的人。
```

### 3.4 成长路径规划

```
基于我们当前的[用户数/收入/增长率]数据，请帮我规划未来12个月的成长路径。

要求：
1. 每月一个里程碑（具体可衡量的数字）
2. 需要的资源（人力/资金）
3. 关键风险点和应对方案

格式：
Month 1: [里程碑] → 需要[X个工程师] → 预算[$X] → 风险：[XXX]
Month 2: [里程碑] → ...
...
Month 12: [里程碑] → ...

假设融资后团队从[X人]扩充到[Y人]。
```

## 五、BP的3个致命错误

### 错误1：没有Traction数据

```
如果你没有任何数据（用户、收入、签约意向），你的BP很难过初筛。
但如果你实在没有数据，可以放：

✓ 用户调研结果（"我们访谈了50个目标用户，80%表示愿意付费"）
✓ 等待名单（"我们有500+个用户注册了等待名单"）
✓ LOI（"3家企业签署了购买意向书"）
✓ 竞品的数据（"竞品A在这个市场做到年收入$10M，说明需求真实"）

✗ 不要放："根据行业报告，这个市场将达到XXX亿"
   → 这是行业数据，不是你的Traction。毫无意义。
```

### 错误2：技术术语轰炸

```
❌ 坏的写法：
"我们采用基于Transformer架构的LLM，通过RAG技术结合向量数据库，
实现了多模态内容理解与生成的端到端解决方案..."

→ 投资人内心：我不懂，我也不想懂。感觉创始人不懂怎么和商业人士沟通。

✓ 好的写法：
"输入一段描述，AI自动生成产品文案。
以前需要文案团队花3天，现在30秒。"
```

### 错误3：融资金额不合理

```
❌ "Pre-seed轮，融资500万美元"
→ 投资人：你没验证任何东西，凭什么要这么多钱？

✓ "Pre-seed轮，融资50万美元，用到以下地方：
   - 2个工程师 × 12个月 × $X = $X
   - 服务器和AI API费用 = $X
   - 基础运营 = $X
   资金将支撑我们达到：[具体里程碑]"

融资金额 = 从现在的状态到达下一个milestone所需的资金 × 1.3（安全边际）
不是越多越好。
```

## 六、AI辅助写BP的完整流程

```
Step 1: 用AI生成BP初稿（2小时）
- 把每个板块的Prompt分别喂给AI
- AI生成初版内容

Step 2: 人工修改和注入数据（4小时）
- 把AI生成的"通用描述"替换为真实数据
- 加入你的实际经验和个人故事
- 调整语气（AI写的东西太"平"，加入你的人格）

Step 3: 用AI做反向审查（1小时）
- 把BP喂给AI，要求它扮演"挑剔的投资人"
- 列出10个可能被质疑的点
- 针对每个质疑点准备好回答

Step 4: 找3个朋友做"冷读"（1小时）
- 给没见过的朋友看BP
- 30秒后问：你看懂我是做什么的吗？
- 如果朋友说"不太确定"，重写第一页

Step 5: 终版定稿+发送（30分钟）
```
