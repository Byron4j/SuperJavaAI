# 律所AI提效：内部工具帮律所省了30%的人力成本

> 一家180人的律所，用3个Java服务+LLM，每年节省300万+人力成本。这套内部AI工具箱是怎么搭的？

---

## 一、律所的效率困境：律师的时间都去哪了？

今年3月，一家二线城市百人所的管委会主任找到我，开门见山：“我们律所180个人，去年营收8000万，看着不错吧？但算下来人均创收才44万，扣掉房租、行政、市场费用，利润薄得可怜。”

他给我看了律所的内部时间统计：

| 工作类型 | 时间占比 | 可AI化程度 | 年耗时 |
|----------|----------|------------|--------|
| 法律检索/研究 | 22% | 高（80%） | 约3.5万小时 |
| 合同审查/起草 | 25% | 高（70%） | 约4万小时 |
| 文书校对/排版 | 10% | 高（90%） | 约1.6万小时 |
| 会议记录整理 | 8% | 中（60%） | 约1.3万小时 |
| 法规跟踪/研究 | 5% | 高（85%） | 约0.8万小时 |
| 客户沟通/咨询 | 15% | 低（20%） | - |
| 出庭/谈判 | 10% | 低（10%） | - |
| 其他 | 5% | - | - |

**惊人的结论**：律师70%的工作时间花在了“可被AI大幅提效”的任务上。如果每个律师每天省出1.5小时，180人一年就是9.8万小时——按人均时薪计算，相当于**300万+的人力成本**。

### 模块1：智能合同审查（见D01文章详解）

这里重点讲集成到律所工作流的改造：

```java
@Component
public class FeishuContractBot {
    
    private final ContractRiskScanService scanService;
    private final ReportGenerationService reportService;
    
    /**
     * 飞书消息卡片回调 — 律师在群里@机器人上传合同即可
     */
    @EventListener
    public void onFileReceived(FeishuFileEvent event) {
        if (!isContractFile(event.getFileName())) {
            return;
        }
        
        // 1. 下载文件
        byte[] fileBytes = feishuApi.downloadFile(event.getFileId());
        
        // 2. 异步审查（发送"正在审查..."消息）
        feishuApi.sendMessage(event.getChatId(), 
            CardBuilder.processingCard("🔍 正在审查合同，预计30秒..."));
        
        CompletableFuture.supplyAsync(() -> {
            try {
                ContractRiskReport report = scanService.scanAndReport(
                    fileBytes, event.getFileName(), 
                    event.getSenderId()  // 关联律师身份
                );
                
                // 3. 发送审查结果卡片
                feishuApi.sendMessage(event.getChatId(), 
                    buildResultCard(report));
                
                // 4. 保存审查记录（律所知识管理）
                reviewHistoryService.save(report, event.getSenderId());
                
            } catch (Exception e) {
                log.error("合同审查失败", e);
                feishuApi.sendMessage(event.getChatId(),
                    "合同审查失败：" + e.getMessage());
            }
            return null;
        });
    }
    
    private FeishuCard buildResultCard(ContractRiskReport report) {
        // 构建丰富的飞书消息卡片
        return FeishuCard.builder()
            .header("📋 合同审查报告 - " + report.getContractName())
            .content(renderRiskSummary(report))
            .buttons(List.of(
                FeishuButton.of("查看完整报告", report.getReportUrl()),
                FeishuButton.of("导出PDF", report.getPdfUrl()),
                FeishuButton.of("分享给客户", report.getShareUrl())
            ))
            .build();
    }
}
```

### 模块2：智能法律研究助手

律师最常说的一句话：“帮我查一下类似判例”。这个模块是D02判例搜索的律所内网版：

```java
@Service
public class LegalResearchService {
    
    private final HybridSearchService searchService;
    private final ReportGenerationService reportService;
    private final KnowledgeBaseService kbService;
    
    /**
     * 律师用自然语言发起法律研究请求
     * 
     * 输入示例：
     * "我们客户是一家SaaS公司，销售总监离职去了竞品公司，
     *  带走了20个销售，但竞业限制协议只写了'核心岗位'，
     *  这种情况能不能告？"
     */
    public LegalResearchReport research(LegalResearchRequest request) {
        
        // Step 1: 问题结构化（提取法律关系、争议焦点）
        LegalIssue issue = decomposeLegalIssue(request.getQuestion());
        
        // Step 2: 多路并行检索
        CompletableFuture<List<CaseDigest>> casesFuture = 
            CompletableFuture.supplyAsync(() -> 
                searchService.searchSimilarCases(issue));
        
        CompletableFuture<List<LawArticle>> lawsFuture = 
            CompletableFuture.supplyAsync(() -> 
                searchService.searchApplicableLaws(issue));
        
        CompletableFuture<List<Article>> articlesFuture = 
            CompletableFuture.supplyAsync(() -> 
                searchService.searchLegalArticles(issue));
        
        // Step 3: 律所内部知识库检索（过往案例经验）
        CompletableFuture<List<InternalCase>> internalFuture = 
            CompletableFuture.supplyAsync(() -> 
                kbService.searchInternalKnowledge(issue));
        
        // Step 4: 等待所有检索完成并生成综合报告
        List<CaseDigest> cases = casesFuture.join();
        List<LawArticle> laws = lawsFuture.join();
        List<Article> articles = articlesFuture.join();
        List<InternalCase> internalCases = internalFuture.join();
        
        // Step 5: LLM综合分析和创作
        return reportService.generateResearchReport(
            request.getQuestion(), issue, 
            cases, laws, articles, internalCases
        );
    }
    
    /**
     * 法律问题结构化：用LLM将自然语言转为结构化法律问题
     */
    private LegalIssue decomposeLegalIssue(String question) {
        return chatClient.prompt()
            .system("""
                你是一名资深法律研究员。分析用户提出的法律问题，分解为：
                
                {
                  "legalRelations": ["法律关系1", "法律关系2"],
                  "legalIssues": ["争议焦点1", "争议焦点2"],
                  "applicableLawCategories": ["领域1", "领域2"],
                  "keySearchTerms": ["专业检索词1", "专业检索词2"],
                  "subQuestions": ["子问题1", "子问题2"]  
                }
                
                关键：将口语化描述转化为专业法律术语。
                例如"挖走团队" → "竞业限制/不正当竞争/侵害商业秘密"
                """)
            .user(question)
            .call()
            .entity(LegalIssue.class);
    }
}
```

### 模块3：智能文书生成

起诉状、答辩状、律师函、法律意见书——这些是律师的日常工作产出，格式高度结构化但内容需要定制：

```java
@Service
public class DocumentGenerationService {
    
    private final ChatClient chatClient;
    private final TemplateRepository templateRepository;
    
    /**
     * 基于事实描述和模板，自动生成法律文书
     */
    public GeneratedDocument generateDocument(DocumentGenerateRequest request) {
        
        // 1. 加载模板
        DocumentTemplate template = templateRepository.findByTypeAndStyle(
            request.getDocumentType(),   // 起诉状/答辩状/律师函/法律意见书
            request.getStyle()            // 法院/仲裁/商业
        );
        
        // 2. 事实验证（LLM检查逻辑一致性）
        String validatedFacts = validateFacts(request.getFactDescription());
        
        // 3. 检索相关法条
        List<LawArticle> laws = searchService.searchApplicableLaws(
            request.getLegalIssue()
        );
        
        // 4. 生成文书
        String document = generateWithTemplate(
            template, validatedFacts, laws, request
        );
        
        // 5. 格式校验和法律用语检查
        String polished = polishLegalDocument(document);
        
        return new GeneratedDocument(
            request.getDocumentType(),
            polished,
            laws,
            LocalDateTime.now()
        );
    }
    
    private String validateFacts(String rawFacts) {
        return chatClient.prompt()
            .system("""
                你是律所资深律师。请验证以下事实描述的完整性和逻辑一致性：
                1. 时间线是否清晰？
                2. 主体身份是否明确？
                3. 因果关系是否合理？
                4. 是否有需要补充的关键事实？
                
                如果需要补充信息，标注【需要补充：xxx】
                如果存在逻辑矛盾，标注【矛盾：xxx】
                """)
            .user(rawFacts)
            .call()
            .content();
    }
    
    private String generateWithTemplate(DocumentTemplate template,
                                          String facts,
                                          List<LawArticle> laws,
                                          DocumentGenerateRequest request) {
        
        return chatClient.prompt()
            .system("""
                你是经验丰富的执业律师，擅长撰写法律文书。
                
                文书撰写要求：
                1. 严格使用法律专业术语
                2. 事实陈述客观、准确、完整
                3. 法律依据引用精确到条、款
                4. 诉求明确、具体、可执行
                5. 格式符合%s要求
                """.formatted(request.getDocumentType()))
            .user("""
                请根据以下信息生成%s：
                
                【文书模板】
                %s
                
                【事实描述】
                %s
                
                【相关法条】
                %s
                
                【当事人信息】
                原告/申请人：%s
                被告/被申请人：%s
                
                【诉求】
                %s
                """.formatted(
                    request.getDocumentType(),
                    template.getTemplateContent(),
                    facts,
                    laws.stream()
                        .map(l -> l.getLawName() + "第" + l.getArticle() + "条：" + 
                                  l.getContent())
                        .collect(Collectors.joining("\n")),
                    request.getPlaintiff(),
                    request.getDefendant(),
                    request.getClaims()
                ))
            .call()
            .content();
    }
    
    /**
     * AI写作的法律文书润色
     */
    private String polishLegalDocument(String rawDocument) {
        return chatClient.prompt()
            .system("""
                你是资深法律编辑。请润色以下法律文书，不改动法律实质内容：
                1. 规范标点符号（中文全角）
                2. 统一法律术语
                3. 优化句式，减少长句
                4. 检查法条引用格式
                5. 确保逻辑严密，无歧义表述
                """)
            .user(rawDocument)
            .call()
            .content();
    }
}
```

### 模块4：法规自动追踪

```java
@Service
public class RegulationTrackingService {
    
    private final ChatClient chatClient;
    private final EmailService emailService;
    
    /**
     * 每日扫描新发布法规，匹配各律师团队的关注领域
     */
    @Scheduled(cron = "0 0 8 * * ?")  // 每天早上8点
    public void dailyRegulationScan() {
        // 1. 拉取今日新发布的法规
        List<NewRegulation> todayRegulations = regulationSourceService
            .fetchTodayRegulations();
        
        // 2. 加载所有律师的关注领域
        List<LawyerProfile> lawyers = lawyerProfileService.findAllActive();
        
        // 3. 为每个律师匹配相关法规
        for (LawyerProfile lawyer : lawyers) {
            List<RelevantRegulation> relevant = matchRegulations(
                todayRegulations, lawyer.getPracticeAreas()
            );
            
            if (!relevant.isEmpty()) {
                // 4. 生成个性化法规简报并推送
                String digest = generatePersonalizedDigest(relevant, lawyer);
                
                emailService.send(
                    lawyer.getEmail(),
                    "📋 今日法规更新 - " + LocalDate.now(),
                    digest
                );
                
                // 同时发送飞书消息
                feishuService.sendMessage(
                    lawyer.getFeishuId(), digest
                );
            }
        }
    }
    
    private List<RelevantRegulation> matchRegulations(
            List<NewRegulation> regulations, 
            List<String> practiceAreas) {
        
        return regulations.stream()
            .filter(r -> {
                // 用LLM判断法规是否与律师执业领域相关
                return chatClient.prompt()
                    .system("你是一个法律主题分类器，只输出 YES 或 NO")
                    .user("""
                        律师执业领域：%s
                        法规标题：%s
                        法规摘要：%s
                        
                        该法规是否与律师执业领域相关？请只输出YES或NO。
                        """.formatted(
                            String.join("、", practiceAreas),
                            r.getTitle(),
                            r.getSummary()
                        ))
                    .call()
                    .content()
                    .trim()
                    .equals("YES");
            })
            .map(r -> {
                // 提取法规要点
                String highlights = extractHighlights(r, practiceAreas);
                return new RelevantRegulation(r, highlights);
            })
            .collect(Collectors.toList());
    }
    
    private String generatePersonalizedDigest(
            List<RelevantRegulation> regulations, 
            LawyerProfile lawyer) {
        
        return chatClient.prompt()
            .system("你是律所知识管理顾问")
            .user("""
                %s律师您好，今日有%d条与您执业领域相关的新法规/政策：
                
                %s
                
                请撰写一段100字以内的总体分析，并指出对客户业务的可能影响。
                """.formatted(
                    lawyer.getName(),
                    regulations.size(),
                    regulations.stream()
                        .map(r -> "- 《%s》：%s".formatted(
                            r.getRegulation().getTitle(), 
                            r.getHighlights()))
                        .collect(Collectors.joining("\n"))
                ))
            .call()
            .content();
    }
}
```

## 四、实施策略与成效

### 分阶段上线策略

```

→ 数据看板：AI使用率、节省时间、质量评分
```
