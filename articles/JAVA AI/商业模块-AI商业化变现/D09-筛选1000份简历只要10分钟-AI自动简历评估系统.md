## 一、行业痛点：HR不是在面试，是在"洗简历"

### 令人崩溃的简历筛选

某中型互联网公司的招聘负责人跟我算了一笔账：

```
岗位：Java高级开发工程师
发布渠道：BOSS直聘 + 猎聘 + 拉勾 + 内推
收到简历：487份

HR初筛时间分布：
- 打开简历（3秒）
- 扫一眼技能关键词（10秒）
- 看工作经历（30秒）
- 判断是否匹配（5秒）
- 标注通过/不通过（2秒）
───────────────
单份简历平均：50秒

总耗时：487 × 50秒 = 24,350秒 ≈ 6.8小时 ≈ 1个工作日

而这只是1个岗位。公司同时在招8个岗位，HR团队3人。
按这个节奏，光筛简历就占用了HR 70%的工作时间。
```

**更严重的问题**：人工筛选的准确率

```
某公司HR手动筛选数据统计（2024年Q3）：
- 初筛通过率：15%（HR觉得可以面试的）
- 面试到场率：80%（约58人）
- 通过面试率：25%（约14人）
- 终面通过率：40%（约6人）
- 最终入职率：50%（约3人）

初始487份简历 → 最终入职3人
有效转化率：0.6%

问题在于：
- HR筛掉的85%里，可能有5%-10%是"误杀"的优秀候选人
- HR通过的15%里，可能有30%其实不适合（通过了但面试浪费了时间）
```

```java
@Service
public class ResumeParserService {
    
    private final Map<ResumeFormat, ResumeParser> parsers;
    
    public ResumeParserService(PDFResumeParser pdfParser,
                                DocxResumeParser docxParser,
                                ImageResumeParser imageParser,
                                HtmlResumeParser htmlParser) {
        this.parsers = Map.of(
            ResumeFormat.PDF, pdfParser,
            ResumeFormat.DOCX, docxParser,
            ResumeFormat.IMAGE, imageParser,
            ResumeFormat.HTML, htmlParser
        );
    }
    
    /**
     * 解析简历为结构化数据
     */
    public ParsedResume parse(byte[] fileBytes, ResumeFormat format) {
        ResumeParser parser = parsers.get(format);
        if (parser == null) {
            throw new UnsupportedFormatException("不支持的简历格式: " + format);
        }
        
        // 1. 提取纯文本
        String rawText = parser.extractText(fileBytes);
        
        // 2. 结构化信息抽取
        return extractStructuredInfo(rawText);
    }

/**
 * PDF简历解析器

@Component
public class PDFResumeParser implements ResumeParser {
    
    @Override
    public ResumeFormat supports() { return ResumeFormat.PDF; }
    
    @Override
    public String extractText(byte[] fileBytes) {
        try (PDDocument document = PDDocument.load(fileBytes)) {
            // 方案A: 直接提取文本（适用于文字型PDF）
            PDFTextStripper stripper = new PDFTextStripper();
            stripper.setSortByPosition(true);
            stripper.setShouldSeparateByBeads(true);
            String text = stripper.getText(document);
            
            // 如果提取的文本过少，可能是图片型PDF
            if (text.trim().length() < 50) {
                // 方案B: OCR处理
                return ocrPdf(document);
            }
            
            return text;
        } catch (IOException e) {
            throw new ResumeParseException("PDF解析失败", e);
        }
    }
    
    private String ocrPdf(PDDocument document) throws IOException {
        PDFRenderer renderer = new PDFRenderer(document);
        StringBuilder result = new StringBuilder();
        
        for (int page = 0; page < document.getNumberOfPages(); page++) {
            BufferedImage image = renderer.renderImageWithDPI(page, 300);
            String pageText = doOCR(image);
            result.append(pageText).append("\n");
        }
        
        return result.toString();
    }
}
```

### 3.2 多维评估打分引擎

```java
@Service
public class ResumeScoringEngine {
    
    private final ChatClient chatClient;
    private final JobRequirementRepository jdRepository;
    
    /**
     * 对一份简历进行多维度评估
     */
    public ResumeScore evaluate(ParsedResume resume, JobDescription jd) {
        
        // 并行评估5个维度
        CompletableFuture<DimensionScore> skillScore = CompletableFuture
            .supplyAsync(() -> evaluateSkillMatch(resume, jd));
        
        CompletableFuture<DimensionScore> experienceScore = CompletableFuture
            .supplyAsync(() -> evaluateExperienceMatch(resume, jd));
        
        CompletableFuture<DimensionScore> educationScore = CompletableFuture
            .supplyAsync(() -> evaluateEducationMatch(resume, jd));
        
        CompletableFuture<DimensionScore> projectScore = CompletableFuture
            .supplyAsync(() -> evaluateProjectMatch(resume, jd));
        
        CompletableFuture<DimensionScore> stabilityScore = CompletableFuture
            .supplyAsync(() -> evaluateCareerStability(resume));
        
        // 聚合分数
        DimensionScore skill = skillScore.join();
        DimensionScore experience = experienceScore.join();
        DimensionScore education = educationScore.join();
        DimensionScore project = projectScore.join();
        DimensionScore stability = stabilityScore.join();
        
        // 加权总分（不同岗位权重不同）
        double totalScore = calculateWeightedScore(
            jd.getWeightConfig(), 
            skill, experience, education, project, stability
        );
        
        // 生成面试官建议追问问题
        List<String> interviewQuestions = generateInterviewQuestions(
            resume, jd, skill, experience
        );
        
        return ResumeScore.builder()
            .resumeId(resume.getPersonalInfo().getEmail())
            .totalScore(totalScore)
            .dimensions(Map.of(
                "技能匹配", skill,
                "经验匹配", experience,
                "学历匹配", education,
                "项目匹配", project,
                "稳定性", stability
            ))
            .strengths(buildStrengths(resume, jd))
            .concerns(buildConcerns(resume, jd))
            .interviewQuestions(interviewQuestions)
            .recommendation(totalScore >= jd.getPassThreshold() 
                ? Recommendation.INTERVIEW : Recommendation.REJECT)
            .build();
    }
    
    /**
     * 技能匹配评估
     */
    private DimensionScore evaluateSkillMatch(ParsedResume resume, 
                                               JobDescription jd) {
        
        List<String> requiredSkills = jd.getRequiredSkills();
        List<String> preferredSkills = jd.getPreferredSkills();
        
        Set<String> candidateSkills = collectAllSkills(resume);
        
        // 硬匹配：精确名称匹配
        long requiredMatched = requiredSkills.stream()
            .filter(s -> fuzzySkillMatch(s, candidateSkills))
            .count();
        
        double requiredCoverage = (double) requiredMatched / requiredSkills.size();
        
        long preferredMatched = preferredSkills.stream()
            .filter(s -> fuzzySkillMatch(s, candidateSkills))
            .count();
        
        double preferredCoverage = preferredSkills.isEmpty() ? 1.0 :
            (double) preferredMatched / preferredSkills.size();
        
        // LLM语义评估：技能深度
        String depthAnalysis = chatClient.prompt()
            .system("评估候选人的技能掌握深度")
            .user("""
                JD要求技能：%s
                候选人技能：%s
                候选人技能上下文：
                %s
                
                请评估候选人每项技能的掌握深度（1-5分），JSON格式：
                [{"skill": "Java", "score": 4.5, "evidence": "5年经验，带过团队"}]
                """.formatted(
                    requiredSkills,
                    candidateSkills,
                    buildSkillContext(resume)
                ))
            .call()
            .content();
        
        List<SkillDepth> depths = parseSkillDepths(depthAnalysis);
        double avgDepth = depths.stream()
            .mapToDouble(SkillDepth::getScore)
            .average()
            .orElse(0.0);
        
        // 综合评分：覆盖率50% + 深度50%
        double score = (requiredCoverage * 0.4 + preferredCoverage * 0.1 
                       + avgDepth / 5.0 * 0.5) * 100;
        
        return DimensionScore.builder()
            .score(score)
            .maxScore(100.0)
            .details(String.format(
                "必须技能覆盖：%d/%d；优先技能覆盖：%d/%d；平均深度：%.1f/5",
                requiredMatched, requiredSkills.size(),
                preferredMatched, preferredSkills.size(),
                avgDepth
            ))
            .build();
    }
    
    /**
     * 经验匹配评估
     */
    private DimensionScore evaluateExperienceMatch(ParsedResume resume,
                                                    JobDescription jd) {
        
        String analysis = chatClient.prompt()
            .system("""
                你是资深技术面试官。评估候选人的工作经验与JD的匹配度。
                
                评估维度：
                1. 行业匹配度（是否在同类公司/行业工作过）
                2. 职级匹配度（当前职级与目标职级的差距）
                3. 业务复杂度（是否有类似复杂度的项目经验）
                4. 团队规模经验（是否带过团队、跨部门协作）
                5. 技术栈演进（技术栈是否持续更新）
                
                请以JSON格式返回评分：
                {
                  "score": 85.0,
                  "industryMatch": "高/中/低 - 原因",
                  "levelMatch": "高/中/低 - 原因",
                  "complexityMatch": "高/中/低 - 原因",
                  "teamScaleMatch": "高/中/低 - 原因",
                  "techEvolution": "积极/一般/停滞 - 原因",
                  "redFlags": ["需要注意的点"],
                  "highlights": ["亮点"]
                }
                """)
            .user("""
                JD要求：
                职级：%s
                行业：%s
                经验要求：%s
                
                候选人经历：
                %s
                """.formatted(
                    jd.getLevel(),
                    jd.getIndustry(),
                    jd.getExperienceRequirement(),
                    formatWorkHistory(resume.getWorkExperience())
                ))
            .call()
            .content();
        
        return parseDimensionScore(analysis);
    }
    
    /**
     * 职业稳定性评估
     * 
     * 识别频繁跳槽、空窗期等风险信号
     */
    private DimensionScore evaluateCareerStability(ParsedResume resume) {
        
        List<WorkExperience> workHistory = resume.getWorkExperience();
        
        if (workHistory.isEmpty()) {
            return DimensionScore.of(100.0, "无工作经历（应届生）");
        }
        
        // 分析跳槽频率
        double avgTenure = calculateAverageTenure(workHistory);
        int jumpCount = countFrequentJumps(workHistory, 1.0); // 1年内跳槽
        double maxGap = findMaxGap(workHistory);
        
        double score = 100.0;
        StringBuilder details = new StringBuilder();
        
        if (avgTenure < 1.5) {
            score -= 30;
            details.append(String.format("平均在职时长仅%.1f年，", avgTenure));
        } else if (avgTenure < 2.5) {
            score -= 15;
            details.append(String.format("平均在职时长%.1f年，", avgTenure));
        }
        
        if (jumpCount >= 2) {
            score -= 20;
            details.append(String.format("最近%d次跳槽间隔<1年，", jumpCount));
        }
        
        if (maxGap > 6) {
            score -= 15;
            details.append(String.format("最长空窗期%.0f个月，", maxGap));
        }
        
        if (details.isEmpty()) {
            details.append("职业稳定性良好");
        }
        
        return DimensionScore.builder()
            .score(Math.max(0, score))
            .maxScore(100.0)
            .details(details.toString())
            .build();
    }
    
    private double calculateAverageTenure(List<WorkExperience> history) {
        return history.stream()
            .mapToDouble(w -> {
                double months = calculateMonths(w.getStartDate(), w.getEndDate());
                return months / 12.0;
            })
            .average()
            .orElse(0);
    }
}
```

### 3.3 批量评估与智能排序

```java
@Service
public class BatchResumeEvaluator {
    
    private final ResumeScoringEngine scoringEngine;
    private final RabbitTemplate rabbitTemplate;
    
    /**
     * 批量评估：提交后异步处理，通过WebSocket推送进度
     */
    public BatchEvaluationJob submitBatchEvaluation(
            List<ParsedResume> resumes, 
            JobDescription jd,
            String hrId) {
        
        String jobId = UUID.randomUUID().toString();
        
        BatchEvaluationJob job = BatchEvaluationJob.builder()
            .jobId(jobId)
            .hrId(hrId)
            .totalCount(resumes.size())
            .status(BatchStatus.PROCESSING)
            .build();
        
        jobRepository.save(job);
        
        // 将每个简历的评估作为消息发送到队列
        for (int i = 0; i < resumes.size(); i++) {
            rabbitTemplate.convertAndSend(
                "resume.evaluation.queue",
                new EvaluationTask(jobId, i, resumes.get(i), jd)
            );
        }
        
        return job;
    }
    
    @RabbitListener(queues = "resume.evaluation.queue", concurrency = "5")
    public void processEvaluation(EvaluationTask task) {
        try {
            ResumeScore score = scoringEngine.evaluate(
                task.getResume(), task.getJd()
            );
            
            // 保存评分
            scoreRepository.save(task.getJobId(), task.getIndex(), score);
            
            // 推送进度更新（每完成5个推送一次）
            if (task.getIndex() % 5 == 0) {
                int completed = scoreRepository.countByJobId(task.getJobId());
                webSocketService.sendProgress(task.getJobId(), 
                    completed, task.getTotalCount());
            }
            
        } catch (Exception e) {
            log.error("简历评估失败: jobId={}, index={}", 
                task.getJobId(), task.getIndex(), e);
            failedTaskRepository.save(task.getJobId(), task.getIndex(), e.getMessage());
        }
    }
}
```
