## 三、知识库：AI分身的"大脑"

AI分身不是凭空回答的——它是基于我已有的公开内容来回答的。这是保证"回复像你"的关键。

```java
@Service
public class AvatarKnowledgeBase {
    
    private final VectorStore vectorStore;
    private final ContentIndexer contentIndexer;
    private final QAPairRepository qaRepository;
    
    /**
     * 初始化知识库：把所有公开内容索引化
     */
    @PostConstruct
    public void initialize() {
        // 数据源1：所有已发布的文章
        List<Article> allArticles = articleRepository.findAllByStatus(Status.PUBLISHED);
        contentIndexer.indexArticles(allArticles);
        
        // 数据源2：所有视频的文字稿
        List<VideoTranscript> transcripts = videoRepository.findAllTranscripts();
        contentIndexer.indexTranscripts(transcripts);
        
        // 数据源3：历史真实问答
        List<QAHistory> historyQA = qaRepository.findAll();
        contentIndexer.indexQAHistory(historyQA);
        
        // 数据源4：我手动编写的"观点文档"
        String myOpinions = """
            关于AI：我相信AI是工具而非替代者，程序员应该学会驾驭AI而非恐惧AI。
            关于Spring AI：我认为这是Java拥抱AI的最佳路径，但框架还处在快速迭代期。
            关于副业：我不建议辞职做副业，先用业余时间验证模式。
            关于外包：接外包是起点不是终点，最终要转向产品。
            （更多观点...）
            """;
        contentIndexer.indexManualContent(myOpinions, ContentType.AUTHOR_OPINIONS);
        
        log.info("AI分身知识库初始化完成：包含{}篇文章，{}个视频稿，{}个历史QA",
            allArticles.size(), transcripts.size(), historyQA.size());
    }
    
    /**
     * 检索与读者问题最相关的知识
     */
    public RelevantKnowledge retrieve(String question) {
        // 1. 语义搜索（向量相似度）
        List<Document> semanticResults = vectorStore.similaritySearch(
            SearchRequest.query(question).withTopK(15));
        
        // 2. 关键词搜索（精确匹配）
        List<Document> keywordResults = keywordSearch(question);
        
        // 3. 历史QA命中（完全相同或相似的问题）
        List<QAHistory> similarQAs = qaRepository.findSimilar(question, 0.85);
        
        // 4. 我的观点文档（基于主题匹配）
        List<String> relevantOpinions = matchOpinions(question);
        
        return RelevantKnowledge.builder()
            .semanticResults(semanticResults)
            .keywordResults(keywordResults)
            .similarQAs(similarQAs)
            .myOpinions(relevantOpinions)
            .build();
    }
}
```

## 五、路由模块：AI分身的"决策中心"

并不是所有问题都应该由AI分身来回答。路由器决定了哪些问题AI处理，哪些转人工。

```java
@Component
public class MessageRouter {
    
    private final PersonaEngine personaEngine;
    private final AvatarKnowledgeBase knowledgeBase;
    private final ChatClient chatClient;
    
    /**
     * 处理一条读者消息
     * 返回：AI回复 or 转人工标记
     */
    public RoutingResult route(ReaderMessage message) {
        // Step 1: 意图分类
        Intent intent = classifyIntent(message.getContent());
        
        // Step 2: 根据意图决定处理方式
        return switch (intent) {
            case TECHNICAL_QUESTION -> handleTechQuestion(message);
            case GREETING_THANKS -> handleGreeting(message);
            case BUSINESS_INQUIRY -> handleBusiness(message);
            case COMPLAINT_NEGATIVE -> escalateToHuman(message, "负面/投诉内容需人工处理");
            case OFF_TOPIC -> politelyDecline(message);
            case UNKNOWN -> handleWithAI(message);
        };
    }
    
    private RoutingResult handleTechQuestion(ReaderMessage message) {
        // 1. 在知识库中检索相关信息
        RelevantKnowledge knowledge = knowledgeBase.retrieve(message.getContent());
        
        // 2. AI生成初步回复
        String aiResponse = generateResponse(message, knowledge);
        
        // 3. 置信度评估
        double confidence = evaluateConfidence(aiResponse, knowledge);
        
        if (confidence >= 0.7) {
            // 高置信度 → AI直接回复
            return RoutingResult.aiReply(aiResponse, confidence);
        } else if (confidence >= 0.4) {
            // 中置信度 → AI回复 + 标记博主稍后查看
            return RoutingResult.aiReplyWithFlag(aiResponse, confidence, 
                "建议博主稍后确认此回复是否准确");
        } else {
            // 低置信度 → 转人工
            return escalateToHuman(message, 
                "AI置信度仅%.0f%%，建议人工回复".formatted(confidence * 100));
        }
    }
    
    private RoutingResult handleBusiness(ReaderMessage message) {
        String response = """
            感谢你的认可和咨询！
            
            博主目前接受的合作形式：
            - AI技术咨询（按小时计费）
            - 企业AI系统定制开发
            - 技术培训和分享
            - 公众号广告合作
            
            方便的话请加博主微信XXX详细聊。这条消息我也会同步推送给博主。
            """;
        return RoutingResult.aiReply(response, 1.0);
    }
    
    /**
     * 置信度评估：AI回答有多靠谱？
     */
    private double evaluateConfidence(String aiResponse, RelevantKnowledge knowledge) {
        double score = 0.0;
        
        // 1. 知识库覆盖率（回复引用了多少知识库内容）
        double coverage = calculateKnowledgeCoverage(aiResponse, knowledge);
        score += coverage * 0.4;
        
        // 2. 幻觉检测（AI有没有编造不存在的内容）
        double hallucinationRisk = detectHallucination(aiResponse, knowledge);
        score += (1 - hallucinationRisk) * 0.4;
        
        // 3. 回复质量（长度是否合适、格式是否正常）
        double qualityScore = assessResponseQuality(aiResponse);
        score += qualityScore * 0.2;
        
        return Math.min(score, 1.0);
    }
}
```

### 技巧1：渐进式身份暴露

不要让AI分身一上来就说"我是AI"。设计三段式身份暴露：

```java
public class IdentityDisclosureStrategy {
    
    /**
     * 根据对话轮次决定AI分身的身份披露程度
     */
    public String getIdentityText(int messageRound) {
        return switch (messageRound) {
            case 1 -> "你好！博主正在忙，我先帮他筛选一下你的问题。"; 
            // 不说自己是AI
            
            case 2 -> "我问了博主类似的案例，他的经验是...";
            // 暗示背后有真人
            
            case 3 -> "我是博主的AI知识助手，学了他所有的文章和观点。"
                   + "如果我没说清楚，他会来补充。";
            // 坦诚相告
        };
    }
}
```

## 九、为什么不直接用ChatGPT？

有人可能会问："直接用ChatGPT回复不就行了？为什么要搞这么复杂？"

答案很简单：**ChatGPT不知道你是谁，也不知道你写过什么。**

```
ChatGPT直接回复：
问："Spring AI怎么接入？"
答："Spring AI是Spring生态系统中的...（通用回答，像官方文档摘要）"

AI分身回复：
问："Spring AI怎么接入？"
答："说实话，Spring AI的接入比官方文档写的简单多了。
我之前在一篇文章里详细写过（你可以翻我上周的那篇《5分钟接入》），
核心就三步：加依赖、配Key、建ChatClient。
有个坑要提醒你——如果你用的是Spring Boot 3.1，
需要用1.0.0-M2版本，3.2以上用正式版。这事我踩过坑..."
```

区别在于：**前者像百度百科，后者像一个有经验的程序员朋友。**读者要的是后者。
