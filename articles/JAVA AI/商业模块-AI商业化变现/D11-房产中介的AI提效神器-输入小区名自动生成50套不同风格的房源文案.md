# 房产中介的AI提效神器：输入小区名，自动生成50套不同风格的房源文案

> 一个房产经纪人每天花2小时写房源描述，一个月就是60小时。我们做了个AI文案工具，输入房源信息，3分钟生成50套不同风格的文案，帮经纪人把时间还给带看和成交。

---

## 一、行业痛点：房产文案的"写、改、发"困境

### 房产经纪人的日常

链家某门店的经纪人小李给我展示了他的工作流：

```
单套房源的发布流程：

1. 拍照片（30分钟） → 修图（15分钟）
2. 写标题（10分钟） → 纠结用哪个版
3. 写房源描述（30-40分钟）
4. 改文案适配不同平台：
   - 链家App（正式风格）：改1版
   - 抖音短视频描述（活泼风格）：改1版
   - 小红书（种草风格）：改1版
   - 朋友圈（亲切风格）：改1版
   - 微信群（简洁风格）：改1版
5. 检查是否违规词（10分钟）
6. 发布到6-8个平台
────────────────────────
单套房源：约2-3小时
每月维护20套房源 × 2.5小时 = 50小时
相当于6.25个工作日  ← 花在"写文案"上
```

**更关键的问题**：好文案和差文案的流量差距巨大。

```
同小区、同户型两套房源的数据对比：

房源A（经纪人手写文案，182字）：
- 30天浏览量：127次
- 咨询量：3次
- 带看量：1次

房源B（精心优化文案，有场景感+数据支撑，450字）：
- 30天浏览量：1680次
- 咨询量：22次  
- 带看量：8次
────────────────
流量差距：13倍！咨询差距：7倍！
```

### 3.1 小区知识库RAG

```java
@Service
public class CommunityKnowledgeBase {
    
    private final VectorStore vectorStore;
    private final CommunityDataService dataService;
    
    /**
     * 构建小区知识库
     * 每个小区的信息包括：基本属性、周边配套、历史成交、学区等
     */
    @PostConstruct
    public void loadCommunityData() {
        List<CommunityProfile> communities = dataService.loadAll();
        
        for (CommunityProfile community : communities) {
            String knowledgeText = buildKnowledgeText(community);
            
            Document doc = Document.builder()
                .id("COMM_" + community.getId())
                .content(knowledgeText)
                .metadata(Map.of(
                    "communityId", community.getId(),
                    "communityName", community.getName(),
                    "district", community.getDistrict(),
                    "avgPrice", community.getAvgPrice().toString(),
                    "propertyType", community.getPropertyType(),
                    "greenRate", community.getGreenRate().toString(),
                    "buildYear", community.getBuildYear().toString()
                ))
                .build();
            
            vectorStore.add(List.of(doc));
        }
    }
    
    private String buildKnowledgeText(CommunityProfile c) {
        return String.format("""
            【小区名称】%s
            【区位】位于%s区%s板块，%s
            【交通】距离%s号线%s站约%d米，%s
            【建成年代】%s年，由%s开发
            【物业】%s物业，物业费%.2f元/平米/月
            【绿化率】%.0f%%
            【容积率】%.1f
            【总户数】%d户
            【主力户型】%s
            【周边配套】学校：%s；医院：%s；商业：%s；公园：%s
            【均价】%.0f元/平米（近半年成交均价）
            【最近成交】%s
            【卖点1】%s
            【卖点2】%s
            【卖点3】%s
            """,
            c.getName(), c.getDistrict(), c.getBlock(), c.getLocation(),
            c.getNearestMetroLine(), c.getNearestMetroStation(), 
            c.getMetroDistance(),
            c.getBuildYear(), c.getDeveloper(),
            c.getPropertyCompany(), c.getPropertyFee(),
            c.getGreenRate(), c.getFloorAreaRatio(),
            c.getTotalUnits(),
            c.getMainUnitTypes(),
            c.getSchools(), c.getHospitals(), c.getShopping(), c.getParks(),
            c.getAvgPrice(),
            c.getRecentTransactions(),
            c.getSellingPoint1(), c.getSellingPoint2(), c.getSellingPoint3()
        );
    }
    
    /**
     * RAG检索：根据小区名获取丰富的小区信息
     */
    public CommunityEnrichment enrichCommunityInfo(String communityName) {
        
        // 向量检索 + 精确匹配
        List<Document> docs = vectorStore.similaritySearch(
            SearchRequest.query(communityName)
                .withTopK(3)
                .withSimilarityThreshold(0.85)
        );
        
        if (docs.isEmpty()) {
            // 降级：直接用LLM搜索公开信息
            return enrichViaLLM(communityName);
        }
        
        return parseCommunityInfo(docs.get(0).getContent());
    }
}
```

```java
                                                    List<CopyStyle> styles) {
        
        // 1. 先获取小区知识增强
        CommunityEnrichment community = kbService.enrichCommunityInfo(
            property.getCommunityName()
        );
        
        // 2. 获取市场数据
        MarketContext market = marketService.getMarketContext(
            property.getCommunityName(), property.getUnitType()
        );
        
        // 3. 并行生成所有风格
        Map<CopyStyle, CompletableFuture<CopyVariant>> futures = new HashMap<>();
        
        for (CopyStyle style : styles) {
            futures.put(style, CompletableFuture.supplyAsync(
                () -> generateSingleStyle(property, community, market, style)
            ));
        }
        
        // 4. 收集结果
        Map<CopyStyle, CopyVariant> results = new LinkedHashMap<>();
        for (Map.Entry<CopyStyle, CompletableFuture<CopyVariant>> entry : 
             futures.entrySet()) {
            results.put(entry.getKey(), entry.getValue().join());

            .property(property)
            .variants(results)
            .seoTags(seoTags)
            .recommendedTitles(recommendedTitles)
            .communityEnrichment(community)
            .build();
```

### 3.3 合规检查——房产广告禁区

```java
@Component
public class PropertyCopyCompliance {
    
    private static final Set<String> FORBIDDEN_ABSOLUTE_TERMS = Set.of(
        "最好", "最佳", "第一", "唯一", "首选", "顶级",
        "最高", "最大", "最全", "绝无仅有", "独一无二",
        "国家级", "世界级", "最高级", "极致"
    );
    
    private static final Set<String> FORBIDDEN_FALSE_PROMISES = Set.of(
        "包租", "返租", "稳赚", "升值保证", "一定升值",
        "100%", "零风险", "稳赚不赔"
    );
    
    private static final Set<String> FORBIDDEN_SCHOOL_PROMISES = Set.of(
        "学区房", "保证入学", "一定能上", "学位承诺"
    );
    
    /**
     * 多层级合规检查
     */
    public ComplianceResult checkCopy(String copy, PropertyInfo property) {
        
        List<ComplianceIssue> issues = new ArrayList<>();
        
        // 层级1：绝对化用语检查
        for (String term : FORBIDDEN_ABSOLUTE_TERMS) {
            if (copy.contains(term)) {
                issues.add(ComplianceIssue.builder()
                    .type(IssueType.ABSOLUTE_TERM)
                    .severity(IssueSeverity.HIGH)
                    .description("使用了违规绝对化用语：'%s'".formatted(term))
                    .suggestion("建议改为客观描述，如'稀缺''优选'")
                    .build());
            }
        }
        
        // 层级2：虚假承诺检查
        for (String promise : FORBIDDEN_FALSE_PROMISES) {
            if (copy.contains(promise)) {
                issues.add(ComplianceIssue.builder()
                    .type(IssueType.FALSE_PROMISE)
                    .severity(IssueSeverity.CRITICAL)
                    .description("包含了投资回报承诺：'%s'".formatted(promise))
                    .suggestion("删除此表述，改用历史数据客观说明")
                    .build());
            }
        }
        
        // 层级3：学区承诺检查
        for (String school : FORBIDDEN_SCHOOL_PROMISES) {
            if (copy.contains(school)) {
                issues.add(ComplianceIssue.builder()
                    .type(IssueType.SCHOOL_PROMISE)
                    .severity(IssueSeverity.CRITICAL)
                    .description("包含学区/学位承诺：'%s'".formatted(school))
                    .suggestion("改为'位于XX学校招生范围内（具体以当年教育局划片为准）'")
                    .build());
            }
        }
        
        // 层级4：AI辅助检查——用LLM识别更隐蔽的违规表述
        String aiCheck = chatClient.prompt()
            .system("""
                你是房产广告合规审查专家。检查以下房源文案是否存在
                《广告法》《房地产广告发布规定》的违规表述。
                
                重点检查：
                1. 是否有变相的绝对化表述
                2. 是否暗示投资回报
                3. 是否模糊了距离描述（应用具体距离/时间）
                4. 是否暗示学区/学位
                5. 是否使用了"内部认购""内部价"等违规用语
                
                输出JSON: {"hasIssues": true/false, "issues": [...]}
                """)
            .user(copy)
            .call()
            .content();
        
        List<ComplianceIssue> aiIssues = parseAIComplianceIssues(aiCheck);
        issues.addAll(aiIssues);
        
        return ComplianceResult.builder()
            .hasIssues(!issues.isEmpty())
            .issues(issues)
            .passRate(1.0 - (double) issues.size() / 10)
            .build();
    }
}
```

### 3.4 SEO关键词智能嵌入

```java
@Service
public class SEOOptimizationService {
    
    private final ChatClient chatClient;
    
    /**
     * 根据房源信息生成SEO标签和关键词
     * 针对不同平台有不同的SEO策略
     */
    public SEOKeywords generatePlatformSEO(PropertyInfo property,
                                            CommunityEnrichment community,
                                            PlatformType platform) {
        
        return switch (platform) {
            case LIANJIA_BEKE -> generateBeikeSEO(property, community);
            case ANJUKE -> generateAnjukeSEO(property, community);
            case DOUYIN -> generateDouyinSEO(property, community);
            case XIAOHONGSHU -> generateXiaohongshuSEO(property, community);
            case WECHAT -> generateWechatSEO(property, community);
        };
    }
    
    private SEOKeywords generateBeikeSEO(PropertyInfo property,
                                          CommunityEnrichment community) {
        
        List<String> keywords = new ArrayList<>();
        
        // 链家贝壳的搜索逻辑：小区名 > 户型 > 标签
        keywords.add(property.getCommunityName());
        keywords.add("%d室%d厅".formatted(
            property.getBedrooms(), property.getLivingRooms()));
        keywords.add("满五年唯一");
        
        if (property.getArea() < 90) keywords.add("小户型");
        if (property.getArea() > 140) keywords.add("改善型");
        if (property.getDecoration().contains("精装")) keywords.add("精装修");
        if (property.getFloor() <= 3) keywords.add("低楼层");
        if (property.getFloor() >= property.getTotalFloors() - 3) 
            keywords.add("高楼层");
        if ("南北通透".equals(property.getOrientation())) 
            keywords.add("南北通透");
        
        // 用AI优化关键词排列
        String optimized = chatClient.prompt()
            .system("将以下关键词组织为适合链家/贝壳搜索的标签字符串")
            .user(String.join(", ", keywords))
            .call()
            .content();
        
        return new SEOKeywords(
            property.getCommunityName() + " " + keywords.stream()
                .filter(k -> !k.equals(property.getCommunityName()))
                .limit(5)
                .collect(Collectors.joining(" ")),
            optimized
        );
    }
    
    private SEOKeywords generateDouyinSEO(PropertyInfo property,
                                           CommunityEnrichment community) {
        
        // 抖音的SEO逻辑：热门话题标签 #XX区买房 #XX看房
        List<String> hashtags = new ArrayList<>();
        hashtags.add("#" + community.getDistrict() + "买房");
        hashtags.add("#" + community.getDistrict() + "看房");
        hashtags.add("#好房推荐");
        
        if (property.getArea() < 90) hashtags.add("#刚需上车");
        if (property.getArea() > 140) hashtags.add("#改善换房");
        
        String district = community.getDistrict();
        hashtags.add("#" + district + "二手房");
        
        // 热度标签
        String priceRange = property.getPrice() < 200 ? "200万以下"
            : property.getPrice() < 500 ? "200-500万"
            : property.getPrice() < 1000 ? "500-1000万"
            : "1000万以上";
        hashtags.add("#" + priceRange);
        
        return new SEOKeywords(
            String.join(" ", hashtags),
            community.getDistrict() + " " + property.getCommunityName() + " " + 
            property.getBedrooms() + "室好房"
        );
    }
}
```
