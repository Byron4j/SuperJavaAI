### 场景 1：手机号验证（含港澳台 + 国际）

**需求描述**：验证中国大陆手机号（1 开头的 11 位数字），同时支持港澳台（+852、+853、+886）和国际格式（+86）。

**AI Prompt**：

```

2. 支持港澳台格式：+852/+853/+886 开头，后跟8-9位数字
3. 支持国际格式：带+86前缀，中间可能有空格或连字符
```

**Java 代码封装**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class PhoneValidator {

    // 中国大陆手机号（严格号段校验）
    private static final Pattern CN_PHONE_PATTERN = Pattern.compile(
        "^(?:(?:\\+?86)?(?:\\s|-)?)?1(?:3[0-9]|4[5-79]|5[0-35-9]|6[2567]|7[0-8]|8[0-9]|9[0-35-9])\\d{8}$"
    );

    // 港澳台手机号
    private static final Pattern HK_PHONE_PATTERN = Pattern.compile(
        "^\\+852\\s?[5-9]\\d{7}$"
    );
    private static final Pattern MO_PHONE_PATTERN = Pattern.compile(
        "^\\+853\\s?[6]\\d{7}$"
    );
    private static final Pattern TW_PHONE_PATTERN = Pattern.compile(
        "^\\+886\\s?[0]?9\\d{8}$"
    );

    /**
     * 验证是否为有效的手机号（中国大陆 + 港澳台）
     */
    public static boolean isValid(String phone) {
        if (phone == null || phone.isBlank()) return false;
        String cleaned = phone.trim();
        return CN_PHONE_PATTERN.matcher(cleaned).matches()
            || HK_PHONE_PATTERN.matcher(cleaned).matches()
            || MO_PHONE_PATTERN.matcher(cleaned).matches()
            || TW_PHONE_PATTERN.matcher(cleaned).matches();
    }

    /**
     * 提取手机号并统一格式化为 +86 格式
     */
    public static String normalize(String phone) {
        String cleaned = phone.replaceAll("[\\s-]", "");
        if (cleaned.startsWith("+86")) {
            return cleaned;
        }
        if (cleaned.matches("^1\\d{10}$")) {
            return "+86" + cleaned;
        }
        return cleaned;
    }
}
```

### 场景 2：身份证号验证（18 位含校验码算法）

**需求描述**：验证中国大陆 18 位身份证号，不仅要校验格式，还要校验最后一位校验码（ISO 7064:1983 MOD 11-2 算法）。

**AI Prompt**：

```
请实现Java代码校验中国大陆18位身份证号码，包括：
1. 前17位必须为数字，第18位为数字或X
2. 地区码前两位需在省级行政区划范围内（11-82）
3. 出生日期必须合法（含闰年判断）
4. 校验最后一位校验码（加权求和 mod 11，映射到1 0 X 9 8 7 6 5 4 3 2）
请给出带注释的完整Java代码。
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.ResolverStyle;

public class IdCardValidator {

    // 第一步：正则格式校验
    private static final Pattern ID_CARD_PATTERN = Pattern.compile(
        "^[1-9]\\d{5}(19|20)\\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\\d|3[01])\\d{3}[\\dXx]$"
    );

    // 加权因子
    private static final int[] WEIGHT = {7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2};
    // 校验码映射
    private static final char[] CHECK_CODE = {'1', '0', 'X', '9', '8', '7', '6', '5', '4', '3', '2'};

    /**
     * 完整校验身份证号
     */
    public static boolean isValid(String idCard) {
        if (idCard == null || !ID_CARD_PATTERN.matcher(idCard.toUpperCase()).matches()) {
            return false;
        }
        return validateCheckCode(idCard.toUpperCase()) && validateBirthDate(idCard);
    }

    /**
     * 验证校验码
     */
    private static boolean validateCheckCode(String idCard) {
        int sum = 0;
        for (int i = 0; i < 17; i++) {
            sum += (idCard.charAt(i) - '0') * WEIGHT[i];
        }
        return idCard.charAt(17) == CHECK_CODE[sum % 11];
    }

    /**
     * 验证出生日期合法性（含闰年）
     */
    private static boolean validateBirthDate(String idCard) {
        try {
            String birth = idCard.substring(6, 14);
            LocalDate.parse(birth, DateTimeFormatter.ofPattern("uuuuMMdd")
                .withResolverStyle(ResolverStyle.STRICT));
            return true;
        } catch (Exception e) {
            return false;
        }
    }

    /**
     * 从身份证号提取信息
     */
    public static IdCardInfo extract(String idCard) {
        if (!isValid(idCard)) return null;
        String areaCode = idCard.substring(0, 6);
        String birthDate = idCard.substring(6, 14);
        int gender = (idCard.charAt(16) - '0') % 2 == 0 ? 2 : 1; // 1男 2女
        return new IdCardInfo(areaCode, birthDate, gender);
    }

    public record IdCardInfo(String areaCode, String birthDate, int gender) {}
}
```

```java
import java.util.regex.Pattern;

public class EmailValidator {

    // 实用版邮箱正则（宽松模式，覆盖99.9%的实际场景）
    private static final Pattern EMAIL_PATTERN = Pattern.compile(
        "^[a-zA-Z0-9.!#$%&'*+/=?^_`{|}~-]+" +            // 本地部分
        "@" +                                               // @符号
        "[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?" + // 域名
        "(?:\\.[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?)*" +
        "\\.[a-zA-Z]{2,24}$"                               // 顶级域名
    );

    // RFC 5321 严格版（用于需要精确校验的场景）
    private static final Pattern EMAIL_RFC_PATTERN = Pattern.compile(
        "(?:[a-z0-9!#$%&'*+/=?^_`{|}~-]+(?:\\.[a-z0-9!#$%&'*+/=?^_`{|}~-]+)*" +
        "|\"(?:[\\x01-\\x08\\x0b\\x0c\\x0e-\\x1f\\x21\\x23-\\x5b\\x5d-\\x7f]" +
        "|\\\\[\\x01-\\x09\\x0b\\x0c\\x0e-\\x7f])*\")@" +
        "(?:(?:[a-z0-9](?:[a-z0-9-]*[a-z0-9])?\\.)+[a-z0-9](?:[a-z0-9-]*[a-z0-9])?" +
        "|\\[(?:(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\\.){3}" +
        "(?:25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?|[a-z0-9-]*[a-z0-9]:" +
        "(?:[\\x01-\\x08\\x0b\\x0c\\x0e-\\x1f\\x21-\\x5a\\x53-\\x7f]" +
        "|\\\\[\\x01-\\x09\\x0b\\x0c\\x0e-\\x7f])+)])",
        Pattern.CASE_INSENSITIVE
    );

    public static boolean isValid(String email) {
        if (email == null || email.isBlank()) return false;
        if (email.length() > 254) return false; // RFC 5321 总长度限制
        return EMAIL_PATTERN.matcher(email.trim()).matches();
    }

    /**
     * 提取邮箱的域名部分
     */
    public static String extractDomain(String email) {
        int atIndex = email.lastIndexOf('@');
        return atIndex > 0 ? email.substring(atIndex + 1) : null;
    }
}
```

### 场景 4：URL 提取（从一段文本中提取所有 URL）

**需求描述**：从日志、聊天记录、文章等文本中提取所有 URL 链接，包括 HTTP/HTTPS/ftp 协议，支持带端口号和路径参数。

**AI Prompt**：

```
请写一个Java方法，能从一段任意文本中提取所有URL链接，要求：
1. 支持http、https、ftp协议
2. 支持带端口号（如 http://localhost:8080/path）
3. 支持查询参数和锚点（如 ?key=value#anchor）
4. 支持不带协议的网址（如 www.example.com）
5. 避开中文标点符号的干扰（如"访问www.example.com，"后面的逗号不应被捕获）
请使用正则表达式实现。
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
import java.util.List;
import java.util.ArrayList;
import java.util.stream.Collectors;

public class UrlExtractor {

    private static final Pattern URL_PATTERN = Pattern.compile(
        "\\b(" +
        // 带协议的URL
        "((https?|ftp)://" +
        "[\\w-]+(\\.[\\w-]+)+" +
        "(:\\d{2,5})?" +
        "(/[\\w#!:.?+=&%@!\\-/]*)?)" +
        "|" +
        // 不带协议的www开头URL
        "(www\\.[\\w-]+(\\.[\\w-]+)+" +
        "(/\\S*)?)" +
        ")",
        Pattern.CASE_INSENSITIVE
    );

    /**
     * 从文本中提取所有URL
     */
    public static List<String> extract(String text) {
        if (text == null || text.isBlank()) return List.of();

        List<String> urls = new ArrayList<>();
        Matcher matcher = URL_PATTERN.matcher(text);
        while (matcher.find()) {
            String url = matcher.group().trim();
            // 去除尾部可能误捕获的中文标点
            url = url.replaceAll("[,，。！!？?；;）)\"']+$", "");
            // 去除尾部可能误捕获的英文标点（保留URL路径中的有效字符）
            url = url.replaceAll("[.!?,;:'\")\\]}]+$", "");
            urls.add(url);
        }
        return urls;
    }

    /**
     * 提取并去重
     */
    public static List<String> extractDistinct(String text) {
        return extract(text).stream().distinct().collect(Collectors.toList());
    }
}
```

### 场景 5：日志解析（Apache/Nginx 日志格式）

**需求描述**：解析 Apache 组合日志格式（Combined Log Format）和 Nginx 默认日志格式，提取 IP、时间、请求方法、状态码、User-Agent 等字段。

**示例日志行**：

```
127.0.0.1 - frank [10/Oct/2000:13:55:36 -0700] "GET /apache_pb.gif HTTP/1.0" 200 2326 "http://www.example.com/start.html" "Mozilla/4.08 [en] (Win98; I ;Nav)"
```

**AI Prompt**：

```
请写Java代码，使用正则表达式解析Apache/Nginx组合日志格式的一行日志，提取如下字段：
- 客户端IP
- 远程用户名（RFC 1413，通常为-）
- 认证用户名
- 时间戳（方括号内）
- 请求行（HTTP方法、路径、协议版本）
- 状态码
- 响应字节数
- Referer
- User-Agent
请使用命名捕获组，方便代码中引用。
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
import java.util.Map;
import java.util.HashMap;
import java.util.Optional;

public class LogParser {

    // Apache/Nginx Combined Log Format
    // 使用命名捕获组 (?<name>...)
    private static final Pattern LOG_PATTERN = Pattern.compile(
        "^(?<ip>\\S+)" +                                   // 客户端IP
        "\\s+(?<rfc1413>\\S+)" +                           // RFC 1413标识
        "\\s+(?<remoteUser>\\S+)" +                        // 认证用户名
        "\\s+\\[(?<timestamp>[^]]+)\\]" +                  // 时间戳 [10/Oct/2000:13:55:36 -0700]
        "\\s+\"(?<request>[^\"]*)\"" +                     // 请求行 "GET /index.html HTTP/1.0"
        "\\s+(?<status>\\d{3})" +                          // 状态码 200
        "\\s+(?<bytes>\\d+|-)" +                           // 响应字节数
        "\\s+\"(?<referer>[^\"]*)\"" +                     // Referer
        "\\s+\"(?<userAgent>[^\"]*)\"" +                   // User-Agent
        "\\s*$",
        Pattern.CASE_INSENSITIVE
    );

    // 请求行解析子正则
    private static final Pattern REQUEST_PATTERN = Pattern.compile(
        "^(?<method>GET|POST|PUT|DELETE|HEAD|OPTIONS|PATCH|TRACE|CONNECT)" +
        "\\s+(?<path>\\S+)" +
        "\\s+(?<protocol>HTTP/\\d\\.\\d)$"
    );

    /**
     * 解析单行日志
     */
    public static Optional<LogEntry> parse(String logLine) {
        if (logLine == null || logLine.isBlank()) return Optional.empty();

        Matcher matcher = LOG_PATTERN.matcher(logLine);
        if (!matcher.matches()) return Optional.empty();

        LogEntry entry = new LogEntry();
        entry.ip = matcher.group("ip");
        entry.remoteUser = parseDashToNull(matcher.group("remoteUser"));
        entry.timestamp = matcher.group("timestamp");
        entry.status = Integer.parseInt(matcher.group("status"));
        String bytesStr = matcher.group("bytes");
        entry.bytes = "-".equals(bytesStr) ? 0 : Long.parseLong(bytesStr);
        entry.referer = parseDashToNull(matcher.group("referer"));
        entry.userAgent = parseDashToNull(matcher.group("userAgent"));

        // 解析请求行
        Matcher reqMatcher = REQUEST_PATTERN.matcher(matcher.group("request"));
        if (reqMatcher.matches()) {
            entry.method = reqMatcher.group("method");
            entry.path = reqMatcher.group("path");
            entry.protocol = reqMatcher.group("protocol");
        }

        return Optional.of(entry);
    }

    private static String parseDashToNull(String val) {
        return val == null || val.isBlank() || "-".equals(val) ? null : val;
    }

    public static class LogEntry {
        public String ip;
        public String remoteUser;
        public String timestamp;
        public String method;
        public String path;
        public String protocol;
        public int status;
        public long bytes;
        public String referer;
        public String userAgent;

        @Override
        public String toString() {
            return String.format("[%s] %s %s %s -> %d (%d bytes)",
                timestamp, ip, method, path, status, bytes);
        }
    }
}
```

### 场景 6：JSON 字段值提取（不用 JSON 库的场景）

**需求描述**：有时候你不想因为提取一个简单字段就引入 Jackson/Gson，比如在一堆日志字符串中快速提取某个 JSON key 的值。这时候正则就派上用场了。

**AI Prompt**：

```
请写几个Java方法，使用正则表达式从JSON字符串中提取指定字段的值（不用JSON解析库）：
1. 提取简单字符串值：{"name":"张三","age":25}
2. 提取嵌套字段中的值
3. 提取数组中的值
4. 提取数字字段的值
注意处理边界情况：转义引号、null值、负数、科学计数法等。
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
import java.util.ArrayList;
import java.util.List;

public class JsonFieldExtractor {

    /**
     * 提取 JSON 中指定字段的字符串值
     * 例如：json={"name":"张三"}, field="name" → "张三"
     */
    public static String extractString(String json, String field) {
        Pattern pattern = Pattern.compile(
            "\"" + Pattern.quote(field) + "\"\\s*:\\s*\"((?:[^\"\\\\]|\\\\.)*)\""
        );
        Matcher matcher = pattern.matcher(json);
        if (matcher.find()) {
            return unescapeJson(matcher.group(1));
        }
        return null;
    }

    /**
     * 提取 JSON 中指定字段的数字值
     */
    public static Number extractNumber(String json, String field) {
        Pattern pattern = Pattern.compile(
            "\"" + Pattern.quote(field) + "\"\\s*:\\s*(-?\\d+(?:\\.\\d+)?(?:[eE][+-]?\\d+)?)"
        );
        Matcher matcher = pattern.matcher(json);
        if (matcher.find()) {
            String numStr = matcher.group(1);
            return numStr.contains(".") || numStr.contains("e") || numStr.contains("E")
                ? Double.parseDouble(numStr)
                : Long.parseLong(numStr);
        }
        return null;
    }

    /**
     * 提取 JSON 中指定字段的布尔值
     */
    public static Boolean extractBoolean(String json, String field) {
        Pattern pattern = Pattern.compile(
            "\"" + Pattern.quote(field) + "\"\\s*:\\s*(true|false)"
        );
        Matcher matcher = pattern.matcher(json);
        if (matcher.find()) {
            return Boolean.parseBoolean(matcher.group(1));
        }
        return null;
    }

    /**
     * 使用 JSONPath 风格的路径提取嵌套字段值
     * 例如：json= {"user":{"name":"张三"}}, path="user.name"
     */
    public static String extractByPath(String json, String path) {
        String[] keys = path.split("\\.");
        String currentJson = json;
        for (int i = 0; i < keys.length - 1; i++) {
            Pattern pattern = Pattern.compile(
                "\"" + Pattern.quote(keys[i]) + "\"\\s*:\\s*\\{"
            );
            Matcher matcher = pattern.matcher(currentJson);
            if (!matcher.find()) return null;
            int start = matcher.end() - 1;
            int depth = 0;
            int end = start;
            for (int j = start; j < currentJson.length(); j++) {
                if (currentJson.charAt(j) == '{') depth++;
                if (currentJson.charAt(j) == '}') depth--;
                if (depth == 0) { end = j + 1; break; }
            }
            currentJson = currentJson.substring(start, end);
        }
        return extractString(currentJson, keys[keys.length - 1]);
    }

    /**
     * 提取 JSON 数组中指定字段的所有值
     */
    public static List<String> extractArrayField(String json, String field) {
        List<String> results = new ArrayList<>();
        Pattern pattern = Pattern.compile(
            "\"" + Pattern.quote(field) + "\"\\s*:\\s*\"((?:[^\"\\\\]|\\\\.)*)\""
        );
        Matcher matcher = pattern.matcher(json);
        while (matcher.find()) {
            results.add(unescapeJson(matcher.group(1)));
        }
        return results;
    }

    /**
     * 处理 JSON 中的转义字符
     */
    private static String unescapeJson(String s) {
        return s.replace("\\\"", "\"")
                .replace("\\\\", "\\")
                .replace("\\/", "/")
                .replace("\\n", "\n")
                .replace("\\r", "\r")
                .replace("\\t", "\t");
    }
}
```

### 场景 7：驼峰与下划线互转

**需求描述**：在 Java 实体类（驼峰命名）和数据库字段（下划线命名）之间进行批量转换。这是每个 MyBatis 开发者的日常需求。

**AI Prompt**：

```
请写Java方法，使用正则表达式将驼峰命名和下划线命名互相转换：
1. camelToSnake：userName → user_name
2. snakeToCamel：user_name → userName
3. 都要求支持批量转换（整个JSON key集合、SQL列名列表等）
4. 处理特殊情况：连续大写缩写词（如 XMLParser → xml_parser）
5. 处理首字母大写/小写变体
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
import java.util.stream.Collectors;
import java.util.List;
import java.util.Arrays;

public class CaseConverter {

    // 匹配大写字母前插入下划线（排除开头、数字前、已带下划线）
    private static final Pattern CAMEL_TO_SNAKE_UPPER = Pattern.compile("([A-Z])");
    private static final Pattern CAMEL_TO_SNAKE_ABBR = Pattern.compile("([A-Z]+)([A-Z][a-z])");
    private static final Pattern CAMEL_TO_SNAKE_NUM = Pattern.compile("([a-zA-Z])(\\d)");
    private static final Pattern CAMEL_TO_SNAKE_NUM2 = Pattern.compile("(\\d)([a-zA-Z])");

    /**
     * 驼峰 → 下划线
     * 示例：userName → user_name
     *       XMLParser → xml_parser
     *       orderId1 → order_id_1
     */
    public static String camelToSnake(String camel) {
        if (camel == null || camel.isEmpty()) return camel;
        String result = camel;
        // 1. 处理连续大写缩写：XMLParser → XML_Parser
        result = CAMEL_TO_SNAKE_ABBR.matcher(result).replaceAll("$1_$2");
        // 2. 在大写字母前插入下划线
        result = CAMEL_TO_SNAKE_UPPER.matcher(result).replaceAll("_$1");
        // 3. 处理字母和数字之间插入下划线
        result = CAMEL_TO_SNAKE_NUM.matcher(result).replaceAll("$1_$2");
        result = CAMEL_TO_SNAKE_NUM2.matcher(result).replaceAll("$1_$2");
        // 4. 去除开头和重复下划线，转为小写
        return result.replaceAll("_+", "_")
                     .replaceAll("^_", "")
                     .toLowerCase();
    }

    /**
     * 下划线 → 驼峰
     * 示例：user_name → userName
     *       xml_parser → xmlParser
     */
    public static String snakeToCamel(String snake) {
        if (snake == null || snake.isEmpty()) return snake;
        Matcher matcher = Pattern.compile("_(.)").matcher(snake.toLowerCase());
        StringBuilder sb = new StringBuilder();
        int lastEnd = 0;
        while (matcher.find()) {
            sb.append(snake, lastEnd, matcher.start());
            sb.append(Character.toUpperCase(matcher.group(1).charAt(0)));
            lastEnd = matcher.end();
        }
        sb.append(snake, lastEnd, snake.length());
        return sb.toString();
    }

    /**
     * 下划线 → 首字母大写的驼峰（PascalCase）
     * 示例：user_name → UserName
     */
    public static String snakeToPascal(String snake) {
        String camel = snakeToCamel(snake);
        if (camel.isEmpty()) return camel;
        return Character.toUpperCase(camel.charAt(0)) + camel.substring(1);
    }

    /**
     * 批量转换 Map 的 key
     */
    public static List<String> batchCamelToSnake(List<String> camelKeys) {
        return camelKeys.stream()
            .map(CaseConverter::camelToSnake)
            .collect(Collectors.toList());
    }

    /**
     * 批量转换 Map 的 key
     */
    public static List<String> batchSnakeToCamel(List<String> snakeKeys) {
        return snakeKeys.stream()
            .map(CaseConverter::snakeToCamel)
            .collect(Collectors.toList());
    }

    public static void main(String[] args) {
        // 驼峰 → 下划线
        System.out.println(camelToSnake("userName"));      // user_name
        System.out.println(camelToSnake("XMLParser"));     // xml_parser
        System.out.println(camelToSnake("orderId1"));      // order_id_1
        System.out.println(camelToSnake("HTTPSConnection"));// https_connection

        // 下划线 → 驼峰
        System.out.println(snakeToCamel("user_name"));     // userName
        System.out.println(snakeToCamel("xml_parser"));     // xmlParser
    }
}
```

### 场景 8：SQL 注入模式检测

**需求描述**：编写一个 SQL 注入检测器，用于日志审计或 WAF（Web 应用防火墙）场景。识别常见的 SQL 注入模式，如 `UNION SELECT`、`' OR '1'='1'`、注释符注入、堆叠查询等。

**AI Prompt**：

```
请用Java正则表达式实现一个SQL注入检测器，识别以下注入模式：
1. UNION SELECT注入
2. OR '1'='1' 类型
3. 注释符注入（--、#、/**/）
4. 分号堆叠查询
5. 时间盲注 sleep()/benchmark()
6. 报错注入 extractvalue/updatexml
7. 布尔盲注的常见payload特征
每个检测模式单独一个方法，返回是否可疑及匹配到的具体内容。
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
import java.util.Map;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.ArrayList;

public class SqlInjectionDetector {

    // 注入模式枚举
    public enum InjectType {
        UNION_SELECT,
        TAUTOLOGY,
        COMMENT_INJECTION,
        STACKED_QUERY,
        TIME_BLIND,
        ERROR_INJECTION,
        BOOLEAN_BLIND,
        INFORMATION_SCHEMA
    }

    // 危险关键字检测（大小写不敏感）
    private static final Pattern UNION_SELECT = Pattern.compile(
        "(?i)\\bunion\\b.*\\bselect\\b"
    );

    private static final Pattern TAUTOLOGY = Pattern.compile(
        "(?i)(?:'|\")\\s*(?:or|and)\\s*(?:(?:'|\")\\d+|\"\\d+)?\\s*=\\s*(?:(?:'|\")\\d+|\"\\d+)?\\s*(?:--|#|/\\*)"
    );

    private static final Pattern COMMENT_INJECT = Pattern.compile(
        "(?i)(?:--\\s|#|/\\*!?(?:\\d+)?|\\*/)"
    );

    private static final Pattern STACKED_QUERY = Pattern.compile(
        "(?i);\\s*(?:drop|delete|update|insert|alter|create|truncate|exec|execute)\\b"
    );

    private static final Pattern TIME_BLIND = Pattern.compile(
        "(?i)\\b(?:sleep|benchmark|pg_sleep|waitfor\\s+delay)\\s*\\(\\s*\\d+"
    );

    private static final Pattern ERROR_INJECT = Pattern.compile(
        "(?i)\\b(?:extractvalue|updatexml|geometrycollection|multipoint|polygon|multipolygon|linestring)\\s*\\(|" +
        "\\b(?:exp|convert|dbms_java\\.runjava|dbms_pipe\\.receive_message)"
    );

    private static final Pattern BOOLEAN_BLIND = Pattern.compile(
        "(?i)(?:\\bodbc|\"\\s*\\+\\s*\"|char\\s*\\(|ascii\\s*\\(|substring\\s*\\()\\s*.*\\s*" +
        "(?:like|\\bin\\b|\\bbetween\\b|load_file|into\\s+(?:out|dump)file|outfile)"
    );

    private static final Pattern INFORMATION_SCHEMA = Pattern.compile(
        "(?i)\\b(?:information_schema|sys\\.(?:tables|columns|schemas)|sqlite_master|" +
        "all_tables|all_tab_columns|user_tab_columns|dual)"
    );

    /**
     * 全面检测，返回所有命中的注入类型和匹配内容
     */
    public static Map<InjectType, List<String>> detect(String input) {
        Map<InjectType, List<String>> results = new LinkedHashMap<>();
        if (input == null || input.isBlank()) return results;

        checkPattern(results, input, InjectType.UNION_SELECT, UNION_SELECT);
        checkPattern(results, input, InjectType.TAUTOLOGY, TAUTOLOGY);
        checkPattern(results, input, InjectType.COMMENT_INJECTION, COMMENT_INJECT);
        checkPattern(results, input, InjectType.STACKED_QUERY, STACKED_QUERY);
        checkPattern(results, input, InjectType.TIME_BLIND, TIME_BLIND);
        checkPattern(results, input, InjectType.ERROR_INJECTION, ERROR_INJECT);
        checkPattern(results, input, InjectType.BOOLEAN_BLIND, BOOLEAN_BLIND);
        checkPattern(results, input, InjectType.INFORMATION_SCHEMA, INFORMATION_SCHEMA);

        return results;
    }

    /**
     * 快速判断是否可疑
     */
    public static boolean isSuspicious(String input) {
        return !detect(input).isEmpty();
    }

    /**
     * 生成安全报告
     */
    public static String generateReport(String input) {
        Map<InjectType, List<String>> findings = detect(input);
        if (findings.isEmpty()) return "未发现可疑SQL注入特征";

        StringBuilder report = new StringBuilder("=== SQL注入检测报告 ===\n");
        report.append("输入: ").append(input).append("\n");
        report.append("风险等级: ");

        long criticalCount = findings.keySet().stream()
            .filter(k -> k == InjectType.UNION_SELECT || k == InjectType.STACKED_QUERY)
            .count();
        String level = criticalCount > 0 ? "高危" : findings.size() > 2 ? "中危" : "低危";
        report.append(level).append("\n\n检测详情:\n");

        findings.forEach((type, matches) -> {
            report.append("  [").append(type).append("]\n");
            matches.forEach(m -> report.append("    → ").append(m).append("\n"));
        });

        return report.toString();
    }

    private static void checkPattern(Map<InjectType, List<String>> results, String input,
                                      InjectType type, Pattern pattern) {
        Matcher matcher = pattern.matcher(input);
        List<String> matches = new ArrayList<>();
        while (matcher.find()) {
            matches.add(matcher.group().trim());
        }
        if (!matches.isEmpty()) {
            results.put(type, matches);
        }
    }
}
```

### 场景 9：HTML 标签清理

**需求描述**：从富文本中提取纯文本内容（用于搜索摘要、RSS 摘要生成），或者移除 XSS 攻击向量中的 `<script>` 标签和危险属性。

**AI Prompt**：

```
请写Java方法，使用正则表达式实现HTML标签清理：
1. 移除所有HTML标签（包括自闭合标签如 <br/>、<img/>）
2. 保留标签之间的文本内容
3. 将常见的HTML实体转回普通字符（&amp; → &, &lt; → < 等）
4. 移除 <script> 和 <style> 标签及其内容（XSS清洗）
5. 移除事件处理器属性（onclick, onerror等）
```

**AI 生成的代码**：

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;
import java.util.HashMap;
import java.util.Map;

public class HtmlCleaner {

    // 移除 script 和 style 标签及其内容（跨行模式）
    private static final Pattern SCRIPT_STYLE = Pattern.compile(
        "<(script|style)\\b[^>]*>[\\s\\S]*?</\\1>",
        Pattern.CASE_INSENSITIVE
    );

    // 移除事件处理器属性
    private static final Pattern EVENT_ATTR = Pattern.compile(
        "\\s+on\\w+\\s*=\\s*(?:\"[^\"]*\"|'[^']*'|[^\\s>]+)",
        Pattern.CASE_INSENSITIVE
    );

    // 移除所有HTML标签
    private static final Pattern HTML_TAGS = Pattern.compile(
        "<[^>]*>"
    );

    // 移除HTML注释
    private static final Pattern HTML_COMMENTS = Pattern.compile(
        "<!--[\\s\\S]*?-->"
    );

    // HTML实体映射
    private static final Map<String, String> HTML_ENTITIES = new HashMap<>();
    static {
        HTML_ENTITIES.put("&amp;", "&");
        HTML_ENTITIES.put("&lt;", "<");
        HTML_ENTITIES.put("&gt;", ">");
        HTML_ENTITIES.put("&quot;", "\"");
        HTML_ENTITIES.put("&apos;", "'");
        HTML_ENTITIES.put("&#39;", "'");
        HTML_ENTITIES.put("&nbsp;", " ");
        HTML_ENTITIES.put("&#160;", " ");
        HTML_ENTITIES.put("&copy;", "\u00a9");
        HTML_ENTITIES.put("&reg;", "\u00ae");
        HTML_ENTITIES.put("&mdash;", "\u2014");
        HTML_ENTITIES.put("&ndash;", "\u2013");
        HTML_ENTITIES.put("&ldquo;", "\u201c");
        HTML_ENTITIES.put("&rdquo;", "\u201d");
    }

    /**
     * 移除所有 HTML 标签，提取纯文本
     */
    public static String stripHtml(String html) {
        if (html == null || html.isBlank()) return "";

        // 1. 移除 script 和 style 标签及其内容
        String result = SCRIPT_STYLE.matcher(html).replaceAll("");
        // 2. 移除注释
        result = HTML_COMMENTS.matcher(result).replaceAll("");
        // 3. 将 <br> <p> 等块级标签替换为换行
        result = result.replaceAll("(?i)<br\\s*/?>", "\n");
        result = result.replaceAll("(?i)</?p[^>]*>", "\n");
        result = result.replaceAll("(?i)</?(?:div|li|tr|h[1-6])[^>]*>", "\n");
        // 4. 移除所有标签
        result = HTML_TAGS.matcher(result).replaceAll("");
        // 5. 处理HTML实体
        for (Map.Entry<String, String> entry : HTML_ENTITIES.entrySet()) {
            result = result.replace(entry.getKey(), entry.getValue());
        }
        // 6. 处理数字实体 &#...;
        result = result.replaceAll("&#(\\d+);", match -> {
            int code = Integer.parseInt(match.group(1));
            return String.valueOf((char) code);
        });
        // 7. 压缩多个空白行
        result = result.replaceAll("\\n{3,}", "\n\n").trim();

        return result;
    }

    /**
     * XSS 安全清洗（仅移除危险标签和属性，保留安全HTML）
     */
    public static String sanitize(String html) {
        if (html == null || html.isBlank()) return html;

        String result = html;
        result = SCRIPT_STYLE.matcher(result).replaceAll("");
        result = EVENT_ATTR.matcher(result).replaceAll("");
        // 移除 javascript: 协议
        result = result.replaceAll("(?i)javascript\\s*:", "");
        // 移除 vbscript: 协议
        result = result.replaceAll("(?i)vbscript\\s*:", "");
        // 移除 data: 协议（防止data URI攻击）
        result = result.replaceAll("(?i)data\\s*:image/[a-z]+;base64,", "data:removed,");

        return result;
    }
}
```

### 场景 10：金额格式化与解析

**需求描述**：在财务系统或支付接口中，经常需要在"1234567.89"和"1,234,567.89"之间转换，还要处理各种奇怪的金额输入：中文大写金额、"$1,000.50"、"¥1234.56" 等。

**AI Prompt**：

```
请写Java方法，使用正则表达式实现金额格式化和解析：
1. 格式化：1234567.89 → "1,234,567.89"（千分位逗号分隔）
2. 解析："1,234,567.89" → 1234567.89 (BigDecimal)
3. 解析带货币符号的："$1,000.50"、"¥1234.56" → 纯数字金额
4. 解析中文金额："1,234.56万元"、"12.3亿" → 纯数字金额
5. 金额大写转数字（仅限常见模式）
注意使用BigDecimal避免浮点精度问题。
```

**AI 生成的代码**：

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class AmountFormatter {

    // 数字每三位加逗号的正则（从右向左匹配）
    private static final Pattern ADD_COMMA = Pattern.compile("(\\d)(?=(\\d{3})+(?!\\d))");

    // 提取数字部分（含千分位逗号、小数点和负号）
    private static final Pattern EXTRACT_NUM = Pattern.compile(
        "(-?[\\d,]+(?:\\.\\d+)?)"
    );

    // 中文单位转数字乘数
    // 万元 = 10000, 亿 = 100000000
    private static final Pattern CN_UNIT = Pattern.compile(
        "(-?[\\d,]+(?:\\.\\d+)?)\\s*(万|亿)?\\s*(元)?"
    );

    /**
     * 格式化：1234567.89 → "1,234,567.89"
     */
    public static String format(BigDecimal amount) {
        if (amount == null) return "0.00";
        BigDecimal rounded = amount.setScale(2, RoundingMode.HALF_UP);
        String[] parts = rounded.toPlainString().split("\\.");
        String integerPart = ADD_COMMA.matcher(parts[0]).replaceAll("$1,");
        return parts.length > 1 ? integerPart + "." + parts[1] : integerPart + ".00";
    }

    /**
     * 格式化（double重载）
     */
    public static String format(double amount) {
        return format(BigDecimal.valueOf(amount));
    }

    /**
     * 解析："1,234,567.89" → BigDecimal 1234567.89
     */
    public static BigDecimal parse(String amountStr) {
        if (amountStr == null || amountStr.isBlank()) return BigDecimal.ZERO;
        // 移除所有非数字字符（保留小数点、负号）
        String cleaned = amountStr.replaceAll("[^\\d.\\-]", "");
        if (cleaned.isEmpty()) return BigDecimal.ZERO;
        return new BigDecimal(cleaned);
    }

    /**
     * 解析带货币符号的金额："$1,000.50" → BigDecimal 1000.50
     */
    public static BigDecimal parseWithCurrency(String amountStr) {
        if (amountStr == null || amountStr.isBlank()) return BigDecimal.ZERO;
        Matcher matcher = EXTRACT_NUM.matcher(amountStr.replaceAll("\\s+", ""));
        if (matcher.find()) {
            String numStr = matcher.group(1).replace(",", "");
            return new BigDecimal(numStr);
        }
        return BigDecimal.ZERO;
    }

    /**
     * 解析中文金额："1,234.56万元" → BigDecimal 12345600
     */
    public static BigDecimal parseChineseAmount(String amountStr) {
        if (amountStr == null || amountStr.isBlank()) return BigDecimal.ZERO;

        Matcher matcher = CN_UNIT.matcher(amountStr.replaceAll("\\s+", ""));
        if (matcher.find()) {
            String numStr = matcher.group(1).replace(",", "");
            BigDecimal value = new BigDecimal(numStr);
            String unit = matcher.group(2);
            if ("万".equals(unit)) {
                value = value.multiply(new BigDecimal("10000"));
            } else if ("亿".equals(unit)) {
                value = value.multiply(new BigDecimal("100000000"));
            }
            return value;
        }
        return BigDecimal.ZERO;
    }

    /**
     * 人民币大写金额转数字（仅支持常见模式）
     * "壹佰贰拾叁元肆角伍分" → 123.45
     */
    public static BigDecimal parseChineseUpperCase(String amountStr) {
        if (amountStr == null || amountStr.isBlank()) return BigDecimal.ZERO;

        String s = amountStr
            .replace("壹", "1").replace("贰", "2").replace("叁", "3")
            .replace("肆", "4").replace("伍", "5").replace("陆", "6")
            .replace("柒", "7").replace("捌", "8").replace("玖", "9")
            .replace("零", "0")
            .replace("拾", "*10").replace("佰", "*100").replace("仟", "*1000")
            .replace("万", "*10000").replace("亿", "*100000000")
            .replace("元", "+").replace("角", "+").replace("分", "/100")
            .replace("整", "");

        // 简单实现：提取所有数字并计算
        s = s.replaceAll("[^0-9+*/.]", "");
        // 这里简化处理，实际项目中建议用完整的解析库
        if (!s.isEmpty() && s.replaceAll("[0-9]", "").isEmpty()) {
            return new BigDecimal(s);
        }
        // 复杂情况返回默认值
        return BigDecimal.ZERO;
    }
}
```

### 3.2 验证正则的 5 个维度

```java
public class RegexValidator {

    /**
     * 对正则表达式进行全方位验证
     */
    public static void validate(String regex, List<String> shouldMatch, List<String> shouldNotMatch) {
        Pattern pattern = Pattern.compile(regex);
        List<String> failures = new ArrayList<>();

        // 维度1：正向匹配（应该匹配的必须匹配）
        for (String s : shouldMatch) {
            if (!pattern.matcher(s).matches()) {
                failures.add("应匹配但未匹配: " + s);
            }
        }

        // 维度2：反向匹配（不应该匹配的不能匹配）
        for (String s : shouldNotMatch) {
            if (pattern.matcher(s).matches()) {
                failures.add("不应匹配但匹配了: " + s);
            }
        }

        // 维度3：空值和null安全
        try {
            pattern.matcher(null);
            failures.add("null输入应抛出异常或返回false");
        } catch (Exception e) { /* 预期行为 */ }

        // 维度4：极端输入（超长字符串、Unicode特殊字符）
        String extreme = "x".repeat(10000);
        long start = System.nanoTime();
        boolean matched = pattern.matcher(extreme).matches();
        long elapsed = System.nanoTime() - start;
        if (elapsed > 1_000_000_000L) { // 超过1秒
            failures.add("超长字符串匹配耗时过长: " + elapsed / 1_000_000 + "ms");
        }

        // 维度5：输出验证报告
        if (failures.isEmpty()) {
            System.out.println("✅ 正则验证通过！所有测试用例符合预期。");
        } else {
            System.out.println("❌ 发现 " + failures.size() + " 个问题：");
            failures.forEach(f -> System.out.println("  - " + f));
        }
    }
}
```

## 四、正则性能优化：AI 也能帮你排查回溯爆炸

正则表达式中最致命的性能问题叫做 **灾难性回溯**（Catastrophic Backtracking）。来看一个经典例子：

```java
// ❌ 危险正则：嵌套量词导致回溯爆炸
Pattern evil = Pattern.compile("(a+)+b");
evil.matcher("aaaaaaaaaaaaaaaaaaaaac").matches(); // 可能卡死
```

### 4.1 让 AI 帮你优化正则

**Prompt**：

```
请检查以下正则表达式是否存在灾难性回溯的风险，如果有请给出优化方案：

Pattern: (a+|b+)*c
Pattern: ([a-zA-Z]+)*\d+
Pattern: .*(x|y|z).*

对每个正则，说明问题所在、回溯路径，以及优化后的正则。
```

### 4.2 Java 正则防回溯的 4 条铁律

```java
public class RegexPerformanceGuide {

    /**
     * 铁律1：用占有量词（Possessive Quantifier）防止回溯
     */
    // ❌ 可能回溯
    Pattern greedy = Pattern.compile("a.*b");
    // ✅ 占有量词，不回溯
    Pattern possessive = Pattern.compile("a.*+b");

    /**
     * 铁律2：用原子组（Atomic Group）锁定匹配结果
     */
    // ❌ 嵌套量词
    Pattern nested = Pattern.compile("(a+)+b");
    // ✅ 原子组：匹配成功后立即锁定，不会回溯
    Pattern atomic = Pattern.compile("(?>a+)+b");

    /**
     * 铁律3：控制输入长度
     */
    public static Pattern safePattern(String regex) {
        return Pattern.compile(regex);
    }

    public static boolean safeMatch(Pattern pattern, String input) {
        // 输入过长直接拒绝，防止DDoS
        if (input.length() > 10_000) return false;
        return pattern.matcher(input).matches();
    }

    /**
     * 铁律4：使用预编译 + 缓存
     * 绝对不要在循环中 Pattern.compile()
     */
    // ❌ 每次循环都编译
    public boolean badUsage(List<String> inputs, String regex) {
        for (String s : inputs) {
            if (Pattern.compile(regex).matcher(s).matches()) { // 灾难！
                return true;
            }
        }
        return false;
    }

    // ✅ 预编译一次
    private static final Pattern PRE_COMPILED = Pattern.compile("your-regex-here");

    public boolean goodUsage(List<String> inputs) {
        for (String s : inputs) {
            if (PRE_COMPILED.matcher(s).matches()) {
                return true;
            }
        }
        return false;
    }
}
```

## 五、成为"AI + 正则"高手的最佳实践

经过上面的实战演练，我们来总结一套工作流：

1. **用自然语言描述需求**：不要写"I need a regex for..."，而是向 AI 描述"我要从用户输入中提取中文手机号，格式可能是 13812345678、+8613812345678，甚至 +86 138 1234 5678"
2. **让 AI 给出多个版本**：宽松版（高召回）和严格版（高精确），根据场景选
3. **要求 AI 附带测试用例**：每次生成正则后追问"请为这个正则写 20 个测试用例"
4. **让 AI 解释正则**：用 Prompt"逐段解释这个正则"来生成"正则说明书"
5. **让 AI 审阅正则**：把正则丢给 AI 问"这个正则有没有回溯风险？"
6. **性能测试**：用上文提到的压力测试验证你的正则在极端输入下的表现
