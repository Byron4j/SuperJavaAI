## 一、那个让CTO睡不着觉的凌晨三点

凌晨 3:12，手机疯狂震动。

"服务器被挖矿了，AWS 账单已经飙到 $18,000，还在涨。"

CTO 老张从床上弹起来，打开监控面板——EC2 实例全部 100% CPU，MongoDB 被勒索，S3 桶里多了几百个陌生的文件名。

溯源花了整整两天。最终定位到的根因让人窒息：

```java
// 某个两年前的工具类里
private static final String API_SECRET = new String(Base64.getDecoder().decode(
    "QUtJQ" + "TVGR" + "TklH" + "..."  // 拼接后 Base64 编码的 AWS Secret Key
));
```

一个"聪明"的开发为了绕过公司的正则扫描规则，把 AWS Secret Key 用 Base64 编码后拆成 4 段拼接。**SonarQube 没发现，SpotBugs 没发现，Code Review 也没发现。**

这个 Key 在代码仓库里安静地躺了 3 个月，直到那个实习生把代码 fork 到了他的公开 GitHub——被 bot 扫描到，然后矿工比你更早发现了它。

**最终损失：$20,347 + 品牌声誉的隐形代价。**

这不是虚构。GitHub 每年扫描到超过 **1700 万个**泄露的密钥。但传统正则扫描只能发现"明文密钥"，对于变形、编码、加密后的敏感信息，几乎无能为力。

而这，正是 AI 安全扫描的战场。

## 二、传统 SAST 工具的"能力天花板"

我们先来理解传统工具为什么"看不见"这些东西。

### 2.1 正则的局限：形式匹配 vs 语义理解

SonarQube、SpotBugs、GitGuardian 的核心引擎是什么？**正则表达式 + 规则库**。

```java
// 传统工具能发现的
String password = "admin123";  // ✅ 匹配到硬编码密码

// 传统工具发现不了的
String pwd = new String(Base64.getDecoder().decode("YWRtaW4xMjM="));  // ❌ 扫不到
String secret = "SK-" + getEnv("KEY_PART_1") + getEnv("KEY_PART_2");  // ❌ 扫不到
String token = decrypt(loadFromConfig("token.enc"));  // ❌ 扫不到
```

传统工具的检测逻辑本质是"字符串匹配"，它不理解：
- **数据流追踪**不够深（跨方法、跨类的编码/解码链路）
- **语义意图**（这个变量是真的密码还是单元测试的 mock 数据）
- **业务逻辑漏洞**（老张把 admin 权限校验写成了 `if (role != "admin")` 的反向判断）

### 2.2 误报地狱

每个用过 SonarQube 的人都有这种体验：

```
Security Hotspot: Hard-coded password (CRITICAL)
File: UserServiceTest.java:42
String testPassword = "test123";
```

500 个 Security Hotspot，400 个是单元测试里的 mock 数据，剩下 100 个有 80 个是配置文件里的默认值。真正需要关注的只有 20 个——**但你已经花了 3 个小时去排查。**

## 三、AI 安全扫描的"降维打击"能力

AI（特别是大语言模型）在安全扫描上带来了三个传统工具做不到的能力。

### 3.1 识别变形敏感信息

AI 理解代码的执行语义。当你告诉它"检查是否有硬编码的密钥"，它会追踪数据流：

```java
// AI 能理解这种变形
String part1 = "QUtJQ";
String part2 = "TVGRTklH";
String combined = part1 + part2;
byte[] decodedBytes = Base64.getDecoder().decode(combined);
String apiKey = new String(decodedBytes);
// AI 判定：这是一个通过 Base64 解码+拼接来隐藏的硬编码密钥 —— HIGH RISK
```

它不只是在匹配 `AKIA` 开头的正则，而是**理解了这段代码的执行结果会产生一个密钥**。

### 3.2 上下文感知的误报过滤

AI 能理解代码的**使用场景**：

```java
// 场景A：单元测试 —— AI 判断为 LOW RISK（误报）
@Test
public void testLogin() {
    String testPassword = "test123"; // 测试数据，无实际权限
    mockUser.setPassword(testPassword);
}

// 场景B：生产代码 —— AI 判断为 CRITICAL
public class DatabaseConfig {
    private static final String DB_PASSWORD = "prod_db_pass_2024"; // 生产密码硬编码
}
```

AI 通过分析类名、方法名、注解、import 语句、变量使用方式，来判断一个敏感信息是"真的危险"还是"测试桩代码"。

### 3.3 检测逻辑级别的安全漏洞

这是最"降维打击"的能力——AI 能发现**业务逻辑漏洞**：

```java
// SonarQube 不会报错，因为语法完全正确
@PreAuthorize("hasRole('USER')")
public UserDTO getUserProfile(Long userId) {
    // 漏洞：没有校验 userId 是否属于当前登录用户
    // 任何登录用户都能查看任意用户的信息 —— IDOR 漏洞
    return userService.findById(userId);
}

// AI 能识别出："这个方法缺少用户身份校验，userId 参数来自外部输入，
// 任意登录用户可以通过遍历 userId 来获取其他用户的敏感信息"
```

## 四、实战：构建 AI 代码安全扫描流水线

### 4.1 整体架构

```
GitHub Push → GitHub Actions → AI Security Scanner (Java) → OpenAI API → 扫描报告
                                    ↑
                              OWASP Dependency-Check
```

### 4.2 核心代码实现

#### 4.2.1 扫描器引擎（Java）

```java
package com.example.security.scanner;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.node.ArrayNode;
import com.fasterxml.jackson.databind.node.ObjectNode;

import java.io.*;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.file.*;
import java.time.Duration;
import java.util.*;
import java.util.concurrent.*;
import java.util.stream.Collectors;

/**
 * AI 驱动的代码安全扫描器
 * 结合 LLM 进行语义级安全分析，检测传统工具无法识别的隐藏风险
 */
public class AISecurityScanner {

    private static final String OPENAI_API_KEY = System.getenv("OPENAI_API_KEY");
    private static final String OPENAI_API_URL = "https://api.openai.com/v1/chat/completions";
    private static final int MAX_FILE_SIZE_BYTES = 50_000;
    private static final int MAX_CONCURRENT = 5;

    private final HttpClient httpClient;
    private final ObjectMapper objectMapper;
    private final Set<String> targetExtensions;
    private final Path repoRoot;

    public AISecurityScanner(Path repoRoot) {
        this.repoRoot = repoRoot;
        this.httpClient = HttpClient.newBuilder()
                .connectTimeout(Duration.ofSeconds(30))
                .readTimeout(Duration.ofMinutes(2))
                .build();
        this.objectMapper = new ObjectMapper();
        this.targetExtensions = Set.of(".java", ".xml", ".yaml", ".yml",
                ".properties", ".json", ".kt", ".kts", ".sql");
    }

    /**
     * 入口：扫描整个仓库
     */
    public ScanReport scan() throws IOException {
        List<Path> filesToScan = collectTargetFiles();
        System.out.println("🔍 收集到 " + filesToScan.size() + " 个待扫描文件");

        List<SecurityIssue> allIssues = new ArrayList<>();
        ExecutorService executor = Executors.newFixedThreadPool(MAX_CONCURRENT);

        try {
            List<CompletableFuture<List<SecurityIssue>>> futures = filesToScan.stream()
                    .map(file -> CompletableFuture.supplyAsync(() -> scanFile(file), executor))
                    .collect(Collectors.toList());

            for (CompletableFuture<List<SecurityIssue>> future : futures) {
                try {
                    allIssues.addAll(future.get());
                } catch (ExecutionException e) {
                    System.err.println("⚠️  文件扫描失败: " + e.getCause().getMessage());
                }
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            executor.shutdown();
        }

        // 依赖漏洞检测
        List<DependencyVulnerability> depVulns = scanDependencies();

        return new ScanReport(allIssues, depVulns);
    }

    /**
     * 扫描单个文件
     */
    private List<SecurityIssue> scanFile(Path file) {
        try {
            String content = Files.readString(file);
            if (content.length() > MAX_FILE_SIZE_BYTES) {
                return scanLargeFile(file, content);
            }

            String aiResponse = callOpenAI(file, content);
            return parseAIResponse(file, aiResponse);

        } catch (IOException e) {
            return List.of(SecurityIssue.error(file.toString(), "文件读取失败: " + e.getMessage()));
        }
    }

    /**
     * 大文件分块扫描
     */
    private List<SecurityIssue> scanLargeFile(Path file, String content) {
        List<SecurityIssue> issues = new ArrayList<>();
        int chunkSize = MAX_FILE_SIZE_BYTES;
        int chunks = (content.length() + chunkSize - 1) / chunkSize;

        for (int i = 0; i < chunks; i++) {
            int start = i * chunkSize;
            int end = Math.min(content.length(), start + chunkSize);
            String chunk = content.substring(start, end);

            try {
                String response = callOpenAIWithChunk(file, chunk, i + 1, chunks);
                issues.addAll(parseAIResponse(file, response));
            } catch (IOException e) {
                issues.add(SecurityIssue.error(file.toString(), "分块[" + (i + 1) + "]扫描失败"));
            }
        }
        return issues;
    }

    /**
     * 调用 OpenAI API 进行安全分析
     */
    private String callOpenAI(Path file, String content) throws IOException {
        return callOpenAIWithChunk(file, content, 0, 1);
    }

    private String callOpenAIWithChunk(Path file, String content, int chunkIndex, int totalChunks)
            throws IOException {
        String relativePath = repoRoot.relativize(file).toString();
        String fileType = detectFileType(relativePath);

        String systemPrompt = buildSecurityScanSystemPrompt();
        String userPrompt = String.format("""
                请分析以下代码文件的安全问题：
                
                【文件路径】%s
                【文件类型】%s
                【扫描片段】%d/%d
                
                ```%s
                %s
                ```
                
                请按 JSON 格式返回检测结果，格式如下：
                {
                  "issues": [
                    {
                      "severity": "CRITICAL|HIGH|MEDIUM|LOW",
                      "type": "HARDCODED_SECRET|SQL_INJECTION|XSS|INSECURE_CRYPTO|LOG_LEAK|LOGIC_VULN",
                      "line_number": 42,
                      "title": "简短描述",
                      "description": "详细说明风险和可能的攻击场景",
                      "remediation": "具体的修复建议",
                      "is_false_positive_likely": false
                    }
                  ]
                }
                
                如果没有发现问题，返回 {"issues": []}
                """, relativePath, fileType, chunkIndex, totalChunks, fileType, content);

        ObjectNode requestBody = objectMapper.createObjectNode();
        requestBody.put("model", "gpt-4o");
        requestBody.put("temperature", 0.1); // 低温度，提高一致性
        requestBody.put("max_tokens", 4096);

        ArrayNode messages = objectMapper.createArrayNode();

        ObjectNode systemMsg = objectMapper.createObjectNode();
        systemMsg.put("role", "system");
        systemMsg.put("content", systemPrompt);
        messages.add(systemMsg);

        ObjectNode userMsg = objectMapper.createObjectNode();
        userMsg.put("role", "user");
        userMsg.put("content", userPrompt);
        messages.add(userMsg);

        requestBody.set("messages", messages);

        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(OPENAI_API_URL))
                .header("Authorization", "Bearer " + OPENAI_API_KEY)
                .header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString(objectMapper.writeValueAsString(requestBody)))
                .build();

        try {
            HttpResponse<String> response = httpClient.send(request, HttpResponse.BodyHandlers.ofString());
            if (response.statusCode() == 200) {
                return response.body();
            } else {
                throw new IOException("API 返回错误: " + response.statusCode() + " " + response.body());
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            throw new IOException("API 调用被中断", e);
        }
    }

    /**
     * 构建安全检测 System Prompt
     */
    private String buildSecurityScanSystemPrompt() {
        return """
                你是一个资深的应用安全专家（Application Security Expert），精通 OWASP Top 10、CWE Top 25 以及 Java 安全最佳实践。
                
                你的任务是审查代码文件，检测以下安全问题：
                
                ## 检测规则
                
                ### 1. 硬编码密钥/密码/Token（含变形检测）
                - 明文密钥：password = "xxx", apiKey = "sk-xxx", secret = "xxx"
                - Base64 编码隐藏：Base64.getDecoder().decode("xxx") → 如果解码结果是密钥
                - 字符串拼接隐藏：secret = part1 + part2 → 如果拼接后是密钥
                - 从非安全来源加载：从 properties/xml 加载后硬编码使用
                - 加密后硬编码但解密密钥也在代码中
                - ⚠️ 区分测试代码和真实密钥：
                  - 在 @Test 方法或 *Test.java 中的 mock 数据 → 标记 is_false_positive_likely: true
                  - 在 src/test/ 路径下的 → 降低严重级别
                - 关注的模式：AWS Key (AKIA*)、GitHub Token (ghp_*、gho_*)、OpenAI Key (sk-*)、
                  JWT Secret、数据库密码、SSH 私钥、证书、API Key 等
                
                ### 2. SQL 注入风险
                - 字符串拼接构建 SQL： "SELECT * FROM users WHERE id = " + userId
                - 动态 SQL 中直接使用用户输入
                - MyBatis ${} (非预编译) 使用用户输入
                - JPA 原生查询拼接
                - ⚠️ 注意识别使用了 PreparedStatement/参数化查询的情况 → 不标记
                
                ### 3. XSS 漏洞
                - 用户输入直接输出到前端，未经过滤
                - innerHTML 设置未过滤的用户数据
                - 模板引擎未转义输出
                - @ResponseBody 返回未过滤的用户输入（反射型 XSS）
                
                ### 4. 不安全的加密算法
                - MD5/SHA1 用于密码哈希（仅用于校验和/哈希ID时可降低级别）
                - 使用 ECB 模式
                - 硬编码的 IV（初始化向量）
                - 硬编码的加密密钥/Salt
                - 使用不安全的随机数生成器（java.util.Random 用于安全场景）
                - 密钥长度不足（RSA < 2048 位）
                
                ### 5. 日志泄露敏感信息
                - log.info() 打印用户密码、Token、身份证号、手机号
                - log.debug() 打印完整请求体（可能包含敏感字段）
                - 异常堆栈中暴露敏感信息
                - System.out.println 打印敏感数据
                
                ### 6. 业务逻辑漏洞
                - 权限校验缺失：获取用户信息未校验用户身份（IDOR）
                - 越权操作：普通用户可执行管理操作
                - 金额/数量参数未做服务端校验
                - 敏感操作缺少二次确认
                - 验证码/Token 可重复使用
                - 条件竞争（TOCTOU）风险
                
                ## 重要原则
                1. **宁可漏报，不可误报**：如果无法确定是否是真实风险，不要报告
                2. **上下文优先**：分析代码的使用场景，区分测试代码、开发环境配置
                3. **可操作的建议**：每个问题给出具体、可执行的修复方案
                4. **严格 JSON**：只返回合法的 JSON，不要包含 markdown 代码块标记
                """;
    }

    /**
     * 解析 AI 返回的安全问题
     */
    private List<SecurityIssue> parseAIResponse(Path file, String jsonResponse) {
        try {
            // OpenAI 返回的 JSON 在 choices[0].message.content 中
            ObjectNode root = (ObjectNode) objectMapper.readTree(jsonResponse);
            String content = root.get("choices").get(0).get("message").get("content").asText();

            // 清理可能的 markdown 代码块标记
            content = content.trim();
            if (content.startsWith("```")) {
                content = content.substring(content.indexOf("\n") + 1);
                if (content.endsWith("```")) {
                    content = content.substring(0, content.lastIndexOf("```"));
                }
            }

            ObjectNode result = (ObjectNode) objectMapper.readTree(content);
            List<SecurityIssue> issues = new ArrayList<>();

            if (result.has("issues")) {
                for (var node : result.get("issues")) {
                    ObjectNode issueNode = (ObjectNode) node;
                    issues.add(new SecurityIssue(
                            file.toString(),
                            issueNode.get("severity").asText(),
                            issueNode.get("type").asText(),
                            issueNode.get("line_number").asInt(0),
                            issueNode.get("title").asText(),
                            issueNode.get("description").asText(),
                            issueNode.get("remediation").asText(),
                            issueNode.has("is_false_positive_likely")
                                    && issueNode.get("is_false_positive_likely").asBoolean()
                    ));
                }
            }
            return issues;
        } catch (Exception e) {
            return List.of(SecurityIssue.error(file.toString(),
                    "AI 响应解析失败: " + e.getMessage()));
        }
    }

    /**
     * 依赖漏洞扫描（集成 OWASP Dependency-Check）
     */
    private List<DependencyVulnerability> scanDependencies() {
        List<DependencyVulnerability> vulns = new ArrayList<>();

        // 1. 查找 pom.xml/build.gradle 等依赖文件
        Path pomFile = repoRoot.resolve("pom.xml");
        Path gradleFile = repoRoot.resolve("build.gradle");
        Path gradleKts = repoRoot.resolve("build.gradle.kts");

        // 2. 读取依赖列表
        List<DependencyInfo> deps = new ArrayList<>();
        if (Files.exists(pomFile)) {
            deps.addAll(parseMavenDependencies(pomFile));
        }
        if (Files.exists(gradleFile)) {
            deps.addAll(parseGradleDependencies(gradleFile));
        }
        if (Files.exists(gradleKts)) {
            deps.addAll(parseGradleDependencies(gradleKts));
        }

        // 3. 通过 OpenAI 分析依赖风险
        if (!deps.isEmpty()) {
            vulns.addAll(analyzeDependencyRisks(deps));
        }

        return vulns;
    }

    // ==================== 辅助方法 ====================

    private List<Path> collectTargetFiles() throws IOException {
        return Files.walk(repoRoot)
                .filter(Files::isRegularFile)
                .filter(this::isTargetFile)
                .filter(this::notExcluded)
                .collect(Collectors.toList());
    }

    private boolean isTargetFile(Path path) {
        String name = path.toString().toLowerCase();
        return targetExtensions.stream().anyMatch(name::endsWith);
    }

    private boolean notExcluded(Path path) {
        String p = path.toString();
        return !p.contains("/node_modules/")
                && !p.contains("/target/")
                && !p.contains("/build/")
                && !p.contains("/.git/")
                && !p.contains("/dist/")
                && !p.contains("/vendor/");
    }

    private String detectFileType(String path) {
        if (path.endsWith(".java")) return "java";
        if (path.endsWith(".xml")) return "xml";
        if (path.endsWith(".yaml") || path.endsWith(".yml")) return "yaml";
        if (path.endsWith(".properties")) return "properties";
        if (path.endsWith(".json")) return "json";
        if (path.endsWith(".kt")) return "kotlin";
        if (path.endsWith(".sql")) return "sql";
        return "text";
    }

    }

    // ==================== 内部类 ====================

    record DependencyInfo(String groupId, String artifactId, String version) {}
    record DependencyVulnerability(String dependency, String riskLevel,
                                    String cveId, String description,
                                    String recommendedVersion) {
        public DependencyVulnerability {
            if (cveId == null) cveId = "N/A";
        }
    }

    static class SecurityIssue {
        private final String filePath;
        private final String severity;
        private final String type;
        private final int lineNumber;
        private final String title;
        private final String description;
        private final String remediation;
        private final boolean likelyFalsePositive;

        public SecurityIssue(String filePath, String severity, String type,
                             int lineNumber, String title, String description,
                             String remediation, boolean likelyFalsePositive) {
            this.filePath = filePath;
            this.severity = severity;
            this.type = type;
            this.lineNumber = lineNumber;
            this.title = title;
            this.description = description;
            this.remediation = remediation;
            this.likelyFalsePositive = likelyFalsePositive;
        }

        public static SecurityIssue error(String filePath, String message) {
            return new SecurityIssue(filePath, "ERROR", "SCAN_ERROR",
                    0, "扫描异常", message, "请检查文件编码和内容", false);
        }

        // Getters...
        public String getFilePath() { return filePath; }
        public String getSeverity() { return severity; }
        public String getType() { return type; }
        public int getLineNumber() { return lineNumber; }
        public String getTitle() { return title; }
        public String getDescription() { return description; }
        public String getRemediation() { return remediation; }
        public boolean isLikelyFalsePositive() { return likelyFalsePositive; }
    }

    static class ScanReport {
        private final List<SecurityIssue> issues;
        private final List<DependencyVulnerability> dependencyVulns;
        private final int criticalCount;
        private final int highCount;
        private final int mediumCount;
        private final int lowCount;
        private final int falsePositiveCount;

        public ScanReport(List<SecurityIssue> issues,
                          List<DependencyVulnerability> dependencyVulns) {
            this.issues = issues;
            this.dependencyVulns = dependencyVulns;
            this.criticalCount = countBySeverity(issues, "CRITICAL");
            this.highCount = countBySeverity(issues, "HIGH");
            this.mediumCount = countBySeverity(issues, "MEDIUM");
            this.lowCount = countBySeverity(issues, "LOW");
            this.falsePositiveCount = (int) issues.stream()
                    .filter(SecurityIssue::isLikelyFalsePositive).count();
        }

        private int countBySeverity(List<SecurityIssue> issues, String severity) {
            return (int) issues.stream()
                    .filter(i -> severity.equalsIgnoreCase(i.getSeverity()))
                    .filter(i -> !i.isLikelyFalsePositive())
                    .count();
        }

        /**
         * 输出 Markdown 格式报告
         */
        public String toMarkdown() {
            StringBuilder sb = new StringBuilder();
            sb.append("# 🔒 AI 安全扫描报告\n\n");
            sb.append("## 📊 扫描概览\n\n");
            sb.append("| 严重级别 | 数量 |\n");
            sb.append("|---------|------|\n");
            sb.append("| 🔴 CRITICAL | ").append(criticalCount).append(" |\n");
            sb.append("| 🟠 HIGH     | ").append(highCount).append(" |\n");
            sb.append("| 🟡 MEDIUM   | ").append(mediumCount).append(" |\n");
            sb.append("| 🟢 LOW      | ").append(lowCount).append(" |\n");
            sb.append("| ⚪ 疑似误报  | ").append(falsePositiveCount).append(" |\n\n");

            if (!dependencyVulns.isEmpty()) {
                sb.append("## 📦 依赖漏洞\n\n");
                for (var v : dependencyVulns) {
                    sb.append("- **").append(v.riskLevel()).append("**: ")
                            .append(v.dependency()).append("\n");
                    if (!"N/A".equals(v.cveId())) {
                        sb.append("  - CVE: ").append(v.cveId()).append("\n");
                    }
                    sb.append("  - 建议: ").append(v.recommendedVersion()).append("\n\n");
                }
            }

            sb.append("## 🔍 详细问题列表\n\n");
            for (var issue : issues) {
                if (issue.isLikelyFalsePositive()) continue;
                sb.append("### [").append(issue.getSeverity()).append("] ")
                        .append(issue.getTitle()).append("\n\n");
                sb.append("- **文件**: `").append(issue.getFilePath()).append("`\n");
                if (issue.getLineNumber() > 0) {
                    sb.append("- **行号**: ").append(issue.getLineNumber()).append("\n");
                }
                sb.append("- **类型**: ").append(issue.getType()).append("\n");
                sb.append("- **描述**: ").append(issue.getDescription()).append("\n");
                sb.append("- **修复建议**: ").append(issue.getRemediation()).append("\n\n");
                sb.append("---\n\n");
            }

            return sb.toString();
        }
    }

    /**
     * 主入口
     */
    public static void main(String[] args) {
        if (args.length < 1) {
            System.out.println("用法: java AISecurityScanner <仓库路径>");
            System.exit(1);
        }

        Path repoPath = Path.of(args[0]);
        AISecurityScanner scanner = new AISecurityScanner(repoPath);

        try {
            ScanReport report = scanner.scan();
            System.out.println(report.toMarkdown());

            // 写报告文件
            Path reportFile = repoPath.resolve("target/ai-security-report.md");
            Files.createDirectories(reportFile.getParent());
            Files.writeString(reportFile, report.toMarkdown());

            // CI 集成：有 CRITICAL 问题则退出码非 0
            if (report.criticalCount > 0) {
                System.err.println("🚨 发现 " + report.criticalCount + " 个严重安全问题！");
                System.exit(1);
            }

        } catch (Exception e) {
            e.printStackTrace();
            System.exit(2);
        }
    }
}

#### 4.2.3 报告合并脚本（Python）

```python
#!/usr/bin/env python3
"""
merge_security_reports.py - 合并 AI 扫描报告和 OWASP Dependency-Check 报告
"""
import json
import re
import sys
from pathlib import Path
from datetime import datetime

def parse_markdown_report(md_path: Path) -> dict:
    """解析 AI 生成的 Markdown 报告"""
    content = md_path.read_text(encoding='utf-8')

    # 提取各级别数量
    counts = {}
    for level in ['CRITICAL', 'HIGH', 'MEDIUM', 'LOW']:
        match = re.search(rf'\|\s*.*?{level}\s*\|\s*(\d+)\s*\|', content)
        counts[level.lower()] = int(match.group(1)) if match else 0

    return counts

def parse_owasp_report(json_path: Path) -> dict:
    """解析 OWASP Dependency-Check JSON 报告"""
    data = json.loads(json_path.read_text(encoding='utf-8'))

    severity_map = {
        'CRITICAL': 'critical',
        'HIGH': 'high',
        'MEDIUM': 'medium',
        'LOW': 'low'
    }

    vulns_by_severity = {'critical': 0, 'high': 0, 'medium': 0, 'low': 0}
    all_vulns = []

    for dep in data.get('dependencies', []):
        for vuln in dep.get('vulnerabilities', []):
            sev = vuln.get('severity', 'MEDIUM').upper()
            key = severity_map.get(sev, 'medium')
            vulns_by_severity[key] += 1
            all_vulns.append({
                'dependency': f"{dep.get('fileName', 'unknown')}",
                'cve': vuln.get('name', 'N/A'),
                'severity': sev,
                'cvss_score': vuln.get('cvssScore', 0),
                'description': vuln.get('description', '')[:300]
            })

    return vulns_by_severity

def main():
    import argparse

    parser = argparse.ArgumentParser()
    parser.add_argument('--ai-report', required=True)
    parser.add_argument('--owasp-report', required=True)
    parser.add_argument('--output', required=True)
    args = parser.parse_args()

    ai_counts = parse_markdown_report(Path(args.ai_report))
    owasp_counts = parse_owasp_report(Path(args.owasp_report))

    total_critical = ai_counts['critical'] + owasp_counts['critical']
    total_high = ai_counts['high'] + owasp_counts['high']
    total_medium = ai_counts['medium'] + owasp_counts['medium']
    total_low = ai_counts['low'] + owasp_counts['low']

    combined = f"""# 🔒 综合安全扫描报告
**扫描时间**: {datetime.now().strftime('%Y-%m-%d %H:%M:%S')}

## 📊 汇总统计

| 来源 | CRITICAL | HIGH | MEDIUM | LOW |
|------|----------|------|--------|-----|
| AI 代码扫描 | {ai_counts['critical']} | {ai_counts['high']} | {ai_counts['medium']} | {ai_counts['low']} |
| OWASP 依赖检查 | {owasp_counts['critical']} | {owasp_counts['high']} | {owasp_counts['medium']} | {owasp_counts['low']} |
| **合计** | **{total_critical}** | **{total_high}** | **{total_medium}** | **{total_low}** |

{open(args.ai_report, encoding='utf-8').read()}
"""

    Path(args.output).write_text(combined, encoding='utf-8')

    # 输出给 GitHub Actions 使用的变量
    print(f"::set-output name=critical_count::{total_critical}")
    print(f"::set-output name=high_count::{total_high}")

    if total_critical > 0:
        print(f"🚨 发现 {total_critical} 个严重安全风险！")

if __name__ == '__main__':
    main()
```

| 时间竞争条件 | 1 | 需要理解多线程执行时序 |
| 序列化漏洞 | 1 | `ObjectInputStream` 直接反序列化未校验来源 |

**漏报率约 12.8%**，主要集中在需要全链路追踪和多文件联合分析的场景。

---

## 八、落地建议与最佳实践

### 8.1 分级部署策略

```
Level 1（免费）: 只用 OWASP Dependency-Check → 覆盖依赖漏洞
Level 2（基础）: + GitLeaks/GitGuardian 免费版 → 覆盖明文密钥
Level 3（推荐）: + AI 安全扫描（本文方案）→ 覆盖变形密钥+逻辑漏洞
Level 4（企业）: + 人工安全专家 Review → 100% 覆盖
```

### 8.2 成本分析

| 项目规模 | 文件数 | API 调用量（Token） | 月成本（GPT-4o） |
|---------|-------|-------------------|----------------|
| 小项目（<1万行） | ~50 | ~200K tokens | ~$0.50 |
| 中型项目（1-5万行） | ~200 | ~800K tokens | ~$2.00 |
| 大型项目（5-20万行） | ~800 | ~3.2M tokens | ~$8.00 |
| 每次 PR 变更 | ~10 | ~40K tokens | ~$0.10 |

**一个 CRITICAL 安全漏洞的修复成本远超过一年的 AI 扫描费用。**

### 8.3 关键注意事项

1. **不要在 Prompt 中包含真实敏感数据**：如果 Prompt 被日志记录，可能二次泄露
2. **数据脱敏**：发送给 AI 前，对代码中已识别的明文密钥做模糊处理
3. **不要完全依赖 AI**：AI 扫描作为补充，不能替代传统 SAST 和安全专家 Review
4. **私有部署考虑**：敏感项目可使用私有化部署的模型（如 CodeLlama + vLLM）

### 8.4 推荐的 CI/CD 集成策略

```yaml
# 推荐：分层触发策略
AI安全扫描触发条件:
  - PR 创建/更新 → 仅扫描变更文件（Diff 模式，快速反馈）
  - 合并到 main → 全量扫描（Full 模式，生成完整报告）
  - 每日凌晨 → 依赖漏洞重新检测（NVD 数据库有更新时）
  - 手动触发 → 支持指定目录/文件扫描
```

## 九、总结

AI 代码安全扫描不是要替代 SonarQube 或 SpotBugs，而是**填补它们能力边界之外的空白**：

| 传统工具擅长 | AI 擅长 |
|------------|--------|
| 已知模式匹配（快、稳） | 变形/隐藏风险识别（深、准） |
| 规则可解释、可审计 | 语义理解、上下文分析 |
| 低延迟、高吞吐 | 低误报、发现未知模式 |

**两者结合，才能构成真正完整的代码安全防线。**

## 十、附：Prompt 调优技巧

如果你使用自己的 Prompt，以下几个技巧能显著提升扫描质量：

### 技巧 1：Few-Shot 示例

在 System Prompt 中加入 2-3 个"正确的检测结果"示例：

```
## 检测示例

输入代码：
String secret = new String(Base64.getDecoder().decode("c2st..."));
System.out.println("User logged in: " + user.getPassword());

你应该输出：
{
  "issues": [
    {
      "severity": "CRITICAL",
      "type": "HARDCODED_SECRET",
      "line_number": 1,
      "title": "Base64编码隐藏的API密钥",
      "description": "...",
      "remediation": "...",
      "is_false_positive_likely": false
    },
    {
      "severity": "HIGH",
      "type": "LOG_LEAK",
      "line_number": 2,
      "title": "日志泄露用户密码",
      ...
    }
  ]
}
```

### 技巧 2：要求 AI 逐行审查

```
请逐行分析代码，对每一行进行以下判断：
1. 是否包含敏感信息？
2. 是否涉及用户输入？
3. 是否涉及加密/编码操作？
4. 是否有权限校验？

只有确认存在风险时才输出告警。
```

### 技巧 3：约束 JSON 格式

```
⚠️ 严格格式要求：
- 只返回 JSON，不要用 ```json 包裹
- severity 只能是 CRITICAL/HIGH/MEDIUM/LOW
- type 只能是枚举值之一
- 如果没问题，返回 {"issues": []}
```
