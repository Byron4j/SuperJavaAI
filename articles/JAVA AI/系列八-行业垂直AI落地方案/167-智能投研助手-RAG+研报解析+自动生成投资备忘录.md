# 智能投研助手：RAG + 研报解析 + 自动生成投资备忘录，AI帮你3分钟读完100份研报

## 一、投研人的痛点：信息过载与时间稀缺

凌晨2点，某券商研究所的分析师小王刚关掉第47份研报PDF。明天晨会要汇报新能源赛道的最新动态，而卖方刚发了100+份更新研报。他揉了揉发红的眼睛，在备忘录里勉强敲下几行要点。

这是中国几十万投研从业者的日常缩影。据中国证券业协会数据，全市场每天新增研报超过500份，加上公告、新闻、社交舆情，一个行业分析师每天要处理的信息量超过20万字——相当于一部中篇小说的体量。

**核心痛点有三个：**

- **信息过载**：每天数百份研报，人工阅读效率极限约为每份15分钟，100份就需要25小时，根本不可能读完。
- **知识孤岛**：研报分散在Wind、Choice、慧博等多个平台，历史研报检索困难，分析师80%的时间花在"找信息"而非"做判断"。
- **输出效率低**：投资备忘录、晨报、周报等固定产出占用大量精力，一份像样的备忘录从阅读到撰写通常需要4-6小时。

## 二、解决方案：RAG + 智能解析 + 自动生成

我们的方案基于三层架构：

```
┌─────────────────────────────────────────────────────────┐
│                    用户交互层                              │
│   Web/App → 输入查询/上传研报 → 获得摘要/问答/备忘录       │
├─────────────────────────────────────────────────────────┤
│                    智能处理层                              │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐       │
│  │ 研报解析  │  │ 向量检索  │  │  备忘录生成Agent  │       │
│  │ (PDF→文本)│  │ (RAG引擎) │  │  (LLM + 模板)    │       │
│  └──────────┘  └──────────┘  └──────────────────┘       │
├─────────────────────────────────────────────────────────┤
│                    数据存储层                              │
│  Milvus向量库 + ElasticSearch全文索引 + MySQL元数据       │
└─────────────────────────────────────────────────────────┘
```

**核心流程三步走：**

1. **研报解析与入库**：PDF→结构化文本→分块→向量化→存入Milvus
2. **RAG智能检索**：用户查询→向量检索+关键词检索混合召回→重排序
3. **备忘录自动生成**：检索结果作为Context→注入LLM Prompt→按模板生成备忘录

## 三、Java代码实现

### 3.1 研报PDF解析模块

使用Apache PDFBox + LangChain4j实现PDF解析与智能分块：

```java
@Service
public class ResearchReportParser {

    private static final int CHUNK_SIZE = 800;  // 分块大小
    private static final int CHUNK_OVERLAP = 100; // 重叠量

    @Autowired
    private EmbeddingService embeddingService;

    @Autowired
    private MilvusClient milvusClient;

    public ParseResult parseAndIndex(InputStream pdfStream, String reportId) {
        // Step 1: PDF文本提取
        String fullText = extractTextFromPdf(pdfStream);

        // Step 2: 智能分块（按段落+语义边界）
        List<TextChunk> chunks = smartChunk(fullText, CHUNK_SIZE, CHUNK_OVERLAP);

        // Step 3: 提取研报元信息
        ReportMeta meta = extractMeta(fullText);
        // 提取标题、作者、机构、日期、行业分类、核心观点等

        // Step 4: 向量化并写入Milvus
        for (int i = 0; i < chunks.size(); i++) {
            TextChunk chunk = chunks.get(i);
            float[] embedding = embeddingService.encode(chunk.getText());

            InsertParam insertParam = InsertParam.newBuilder()
                    .withCollectionName("research_reports")
                    .withFields(List.of(
                            new InsertParam.Field("report_id", List.of(reportId)),
                            new InsertParam.Field("chunk_id", List.of(i)),
                            new InsertParam.Field("text", List.of(chunk.getText())),
                            new InsertParam.Field("embedding", List.of(embedding))
                    ))
                    .build();

            milvusClient.insert(insertParam);
        }

        return new ParseResult(reportId, meta, chunks.size());
    }

    private List<TextChunk> smartChunk(String text, int chunkSize, int overlap) {
        List<TextChunk> chunks = new ArrayList<>();
        List<String> paragraphs = Arrays.asList(text.split("\\n\\s*\\n"));

        StringBuilder buffer = new StringBuilder();
        int sectionIndex = 0;

        for (String paragraph : paragraphs) {
            paragraph = paragraph.trim();
            if (paragraph.isEmpty()) continue;

            // 检测章节标题（常见研报格式）
            if (isSectionTitle(paragraph)) {
                if (buffer.length() > 0) {
                    chunks.add(new TextChunk(buffer.toString(), sectionIndex++));
                }
                buffer = new StringBuilder(paragraph + "\n\n");
            } else if (buffer.length() + paragraph.length() > chunkSize
                    && buffer.length() > overlap) {
                chunks.add(new TextChunk(buffer.toString(), sectionIndex++));
                // 保留overlap部分
                String overlapText = buffer.substring(
                        Math.max(0, buffer.length() - overlap));
                buffer = new StringBuilder(overlapText + "\n\n" + paragraph);
            } else {
                buffer.append(paragraph).append("\n\n");
            }
        }

        if (buffer.length() > 0) {
            chunks.add(new TextChunk(buffer.toString(), sectionIndex));
        }

        return chunks;
    }

    private boolean isSectionTitle(String text) {
        return text.matches("^[（(]?[一二三四五六七八九十\\d]+[）)）].*") ||
               text.length() < 30 && (text.contains("分析") ||
               text.contains("展望") || text.contains("观点") ||
               text.contains("风险") || text.contains("估值"));
    }

    private String extractTextFromPdf(InputStream stream) {
        try (PDDocument document = Loader.loadPDF(stream.readAllBytes())) {
            PDFTextStripper stripper = new PDFTextStripper();
            stripper.setSortByPosition(true);
            return stripper.getText(document);
        } catch (IOException e) {
            throw new RuntimeException("PDF解析失败", e);
        }
    }
}
```

### 3.2 混合检索引擎

向量检索 + BM25关键词检索，实现高召回率：

```java
@Service
public class HybridSearchService {

    @Autowired
    private MilvusClient milvusClient;

    @Autowired
    private RestHighLevelClient esClient;

    @Autowired
    private EmbeddingService embeddingService;

    public List<SearchResult> hybridSearch(String query, int topK) {
        // Step 1: 向量检索
        float[] queryEmbedding = embeddingService.encode(query);

        SearchParam vectorSearchParam = SearchParam.newBuilder()
                .withCollectionName("research_reports")
                .withMetricType(MetricType.IP)  // 内积相似度
                .withTopK(topK * 2)
                .withVectors(List.of(List.of(queryEmbedding)))
                .withVectorFieldName("embedding")
                .withParams("{\"nprobe\": 16}")
                .withOutFields(List.of("report_id", "chunk_id", "text"))
                .build();

        List<List<SearchResult>> vectorResults =
                milvusClient.search(vectorSearchParam).getResults();

        // Step 2: BM25关键词检索
        List<SearchResult> keywordResults = bm25Search(query, topK * 2);

        // Step 3: RRF（Reciprocal Rank Fusion）融合
        return rrfMerge(vectorResults.get(0), keywordResults, topK, 60);
    }

    private List<SearchResult> bm25Search(String query, int size) {
        SearchRequest request = new SearchRequest("reports_index");
        SearchSourceBuilder sourceBuilder = new SearchSourceBuilder();

        sourceBuilder.query(
                QueryBuilders.multiMatchQuery(query, "title", "content", "summary")
                        .type(MultiMatchQueryBuilder.Type.BEST_FIELDS)
        );
        sourceBuilder.size(size);

        request.source(sourceBuilder);
        // ES查询结果转换为统一SearchResult格式
        return executeEsSearch(request);
    }

    private List<SearchResult> rrfMerge(
            List<SearchResult> vectorResults,
            List<SearchResult> keywordResults,
            int topK, int k) {

        Map<String, Double> scoreMap = new HashMap<>();

        for (int i = 0; i < vectorResults.size(); i++) {
            String docId = vectorResults.get(i).getId();
            scoreMap.merge(docId, 1.0 / (k + i + 1), Double::sum);
        }

        for (int i = 0; i < keywordResults.size(); i++) {
            String docId = keywordResults.get(i).getId();
            scoreMap.merge(docId, 1.0 / (k + i + 1), Double::sum);
        }

        return scoreMap.entrySet().stream()
                .sorted(Map.Entry.<String, Double>comparingByValue().reversed())
                .limit(topK)
                .map(e -> new SearchResult(e.getKey(), e.getValue()))
                .collect(Collectors.toList());
    }
}
```

### 3.3 投资备忘录自动生成Agent

这是核心价值模块。通过精心设计的Prompt模板 + ReAct模式，让LLM基于检索到的研报内容生成结构化备忘录：

```java
@Service
public class MemoGenerationAgent {

    private static final String SYSTEM_PROMPT = """
            你是一位资深证券分析师，拥有20年行业研究经验。
            请基于提供的研报摘要和关键数据，生成一份专业的投资备忘录。
            
            备忘录结构要求：
            1. 核心结论（3-5句话，包含明确的投资建议）
            2. 行业概况（估值水平、景气度、政策环境）
            3. 重点公司跟踪（营收、利润、核心逻辑变化）
            4. 催化剂与风险（近期需关注的重大事件）
            5. 操作建议（仓位、买入区间、止损线）
            
            要求：
            - 使用专业但通俗的语言
            - 每段不超过150字
            - 引用具体数据支撑观点
            - 如数据不足则明确标注"待进一步确认"
            """;

    private static final String MEMO_TEMPLATE = """
            # 投资备忘录
            **日期**：%s
            **行业**：%s
            **分析师**：AI投研助手
            
            ---
            
            ## 一、核心结论
            %s
            
            ## 二、行业概况
            %s
            
            ## 三、重点公司跟踪
            %s
            
            ## 四、催化剂与风险
            %s
            
            ## 五、操作建议
            %s
            
            ---
            *本备忘录由AI投研助手基于检索到的研报自动生成，仅供参考*
            """;

    @Autowired
    private HybridSearchService searchService;

    @Autowired
    private ChatLanguageModel chatModel;

    public String generateMemo(String industry, String focusArea) {
        // Step 1: 多轮检索 - 覆盖行业概览+重点公司+最新动态
        String industryQuery = String.format(
                "%s 行业 近期 估值 景气度 政策 2024", industry);
        String companyQuery = String.format(
                "%s 重点公司 营收 净利润 目标价 评级", industry);
        String eventQuery = String.format(
                "%s 催化剂 风险 重大事件 公告 %s", industry, focusArea);

        List<SearchResult> industryResults = searchService.hybridSearch(industryQuery, 10);
        List<SearchResult> companyResults = searchService.hybridSearch(companyQuery, 10);
        List<SearchResult> eventResults = searchService.hybridSearch(eventQuery, 10);

        // Step 2: 构建上下文
        String context = buildContext(industryResults, companyResults, eventResults);

        // Step 3: 分步生成各SECTION
        String conclusion = generateSection(SYSTEM_PROMPT, context,
                "请生成核心结论部分，包含明确的投资建议。");

        String overview = generateSection(SYSTEM_PROMPT, context,
                "请生成行业概况部分，包含估值水平、景气度、政策环境数据。");

        String companies = generateSection(SYSTEM_PROMPT, context,
                "请生成重点公司跟踪部分，列出3-5家核心公司及其关键数据变化。");

        String catalysts = generateSection(SYSTEM_PROMPT, context,
                "请生成催化剂与风险部分，列出近期重大事件和潜在风险。");

        String suggestion = generateSection(SYSTEM_PROMPT, context,
                "请生成操作建议部分，包含仓位建议和关键价格区间。");

        // Step 4: 组装最终备忘录
        return String.format(MEMO_TEMPLATE,
                LocalDate.now().toString(),
                industry,
                conclusion,
                overview,
                companies,
                catalysts,
                suggestion
        );
    }

    private String generateSection(String systemPrompt, String context, String instruction) {
        String fullPrompt = String.format("""
                %s
                
                ## 参考研报内容
                %s
                
                ## 任务
                %s
                """, systemPrompt, context, instruction);

        return chatModel.generate(fullPrompt);
    }

    private String buildContext(List<SearchResult>... resultLists) {
        StringBuilder ctx = new StringBuilder();
        int chunkNum = 1;

        for (List<SearchResult> results : resultLists) {
            for (SearchResult result : results) {
                ctx.append(String.format("【资料片段%d】%s\n\n",
                        chunkNum++, result.getText()));
            }
        }

        // Token控制：截断至8000字
        String contextStr = ctx.toString();
        if (contextStr.length() > 8000) {
            contextStr = contextStr.substring(0, 8000);
        }
        return contextStr;
    }
}
```

## 五、关键技术细节

几个容易踩的坑：

1. **研报分块策略**：不能简单按字数切割。研报有严格的章节结构（公司概况→行业分析→财务分析→盈利预测→风险提示），按章节边界分块能大幅提升检索精度。

2. **数据时效性权重**：给发布时间加上时间衰减因子，计算公式：`score = similarity * e^(-λ * days_ago)`，λ建议取0.01，即半衰期约70天。

3. **幻觉防控**：在Prompt中要求"如数据不足则明确标注"，并在前端对生成内容中的数字做研报原文溯源标注——用户点击任何数据都能看到原始出处。
