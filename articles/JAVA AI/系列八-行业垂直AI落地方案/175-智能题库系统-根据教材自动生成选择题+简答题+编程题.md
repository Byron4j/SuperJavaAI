# 智能题库系统：根据教材自动生成选择题+简答题+编程题，老师再也不用熬夜出卷了

## 一、凌晨两点，还在憋题

张老师是某高校计算机学院的副教授，这学期负责《Java面向对象程序设计》课程。期末考试前两周，他正在电脑前焦头烂额——教务处要求A/B两套试卷，每套包含20道选择题、5道简答题、2道编程题，且两套试卷题目重复率不得超过30%。

"每年都要出新题，知识点就那么多，我头发都快掉光了。"张老师跟我吐槽，"更烦的是还得配答案、标分值、排难度梯度，一套卷子至少花三个晚上。"

这不是个例。教育行业每年产出海量教学内容，但题库建设始终是"手工活"——出题效率低、题目质量参差不齐、知识点覆盖不全面、更新周期长。尤其在在线教育爆发式增长的今天，传统的人工出题模式已经成为教学数字化的最大瓶颈。

有没有办法让AI根据教材内容自动生成高质量试题？答案是肯定的。

本文将手把手带你搭建一套基于大语言模型的智能题库系统，支持从教材PDF/Word文档中自动提取知识点，并生成选择题、简答题和编程题三种题型，附带答案、解析和难度标注。

## 二、行业痛点深度拆解

在动手写代码之前，我们先搞清楚传统题库建设到底痛在哪里：

**痛点一：出题效率极低**

一位老师一学期至少承担2-3门课，每门课需要期中、期末、补考至少3套试卷。按每套卷子耗时10小时计算，每学期仅出卷就要花60-90小时。这些时间本可以用来辅导学生、做科研、写论文。

**痛点二：题目质量难以保障**

手工出题容易出现知识盲区——老师习惯出自己熟悉的考点，导致某些重要知识点年年被遗漏。选择题的干扰项设计更是个技术活，设计得不好学生一眼就能排除，失去考核意义。

**痛点三：题目更新滞后**

教材改版、考纲调整时，题库需要大面积更新。但现实情况是很多老师直接用往年的题目，改改年份就发下去，考试沦为走过场。

**痛点四：个性化练习缺失**

一个班50个学生，水平参差不齐。理想情况下应该给每个学生推送适合其水平的练习，但靠人工根本不可能实现。

## 三、系统架构设计

我们设计的智能题库系统采用经典的"文档解析→知识抽取→题目生成→质量校验"四阶段流水线架构：

```
┌──────────────────────────────────────────────────────────────────┐
│                      智能题库系统架构                             │
├───────────────┬───────────────┬───────────────┬──────────────────┤
│  文档解析层   │  知识抽取层   │  题目生成层   │   质量校验层      │
│              │              │              │                  │
│ ┌──────────┐ │ ┌──────────┐ │ ┌──────────┐ │ ┌──────────────┐ │
│ │ PDF解析  │ │ │ 知识点   │ │ │ 选择题   │ │ │ 去重校验     │ │
│ │ Word解析 │→│ │ 提取     │→│ │ 生成     │→│ │ 难度评分     │ │
│ │ Markdown │ │ │ Bloom分类│ │ │ 简答题   │ │ │ 答案验证     │ │
│ └──────────┘ │ └──────────┘ │ │ 编程题   │ │ └──────────────┘ │
│              │              │ └──────────┘ │                  │
│ Spring Boot  │  LangChain4j │  OpenAI API  │  规则引擎+LLM    │
│ + Apache Tika│  + Neo4j     │  + 模板引擎  │                  │
└──────────────┴──────────────┴──────────────┴──────────────────┘
```

**各层职责：**

- **文档解析层**：负责将教材的PDF、Word、Markdown等格式统一解析为结构化文本，使用Apache Tika实现多格式适配。
- **知识抽取层**：基于LangChain4j调用LLM，从教材文本中抽取出结构化的知识点，包括知识点名称、所属章节、Bloom认知层次（记忆/理解/应用/分析/评价/创造）。
- **题目生成层**：根据知识点和题型要求，通过设计精良的Prompt模板，调用LLM生成题目。
- **质量校验层**：对生成的题目进行去重、难度标定、答案正确性验证，确保题目质量。

### 4.1 文档解析服务

```java
@Service
public class DocumentParseService {

    private final Tika tika = new Tika();

    /**
     * 解析教材文档，返回纯文本内容
     */
    public ParsedDocument parse(InputStream inputStream, String fileName) throws IOException {
        String content = tika.parseToString(inputStream);
        String mimeType = tika.detect(fileName);

        // 按章节切分
        List<Chapter> chapters = splitByChapter(content);

        return ParsedDocument.builder()
                .fileName(fileName)
                .mimeType(mimeType)
                .rawContent(content)
                .chapters(chapters)
                .build();
    }

    /**
     * 按标题模式切分章节
     */
    private List<Chapter> splitByChapter(String content) {
        List<Chapter> chapters = new ArrayList<>();
        // 匹配 "第X章" 或 "Chapter X" 等模式
        Pattern pattern = Pattern.compile(
            "(第[一二三四五六七八九十百千万\\d]+章[\\s\\S]*?)(?=第[一二三四五六七八九十百千万\\d]+章|$)"
        );
        Matcher matcher = pattern.matcher(content);

        int index = 1;
        while (matcher.find()) {
            String chapterText = matcher.group().trim();
            if (chapterText.length() > 50) {
                Chapter chapter = Chapter.builder()
                        .index(index++)
                        .title(extractTitle(chapterText))
                        .content(chapterText)
                        .build();
                chapters.add(chapter);
            }
        }

        // 如果正则没匹配到，按长度切分
        if (chapters.isEmpty()) {
            return splitByLength(content, 3000);
        }
        return chapters;
    }

    private String extractTitle(String chapterText) {
        int lineEnd = chapterText.indexOf('\n');
        return lineEnd > 0 ? chapterText.substring(0, lineEnd).trim() : chapterText.substring(0, Math.min(50, chapterText.length()));
    }

    private List<Chapter> splitByLength(String content, int maxLength) {
        List<Chapter> chapters = new ArrayList<>();
        int start = 0;
        int index = 1;
        while (start < content.length()) {
            int end = Math.min(start + maxLength, content.length());
            chapters.add(Chapter.builder()
                    .index(index++)
                    .title("第" + index + "节")
                    .content(content.substring(start, end))
                    .build());
            start = end;
        }
        return chapters;
    }
}
```

### 4.2 知识点抽取服务

这是整个系统的核心——如何从教材文本中提取结构化的知识点。我们设计了一套基于LangChain4j的抽取链路：

```java
@Service
public class KnowledgeExtractionService {

    @Autowired
    private ChatLanguageModel chatModel;

    /**
     * 从章节内容中抽取知识点，返回带Bloom分类的结构化知识树
     */
    public List<KnowledgePoint> extract(Chapter chapter) {
        String prompt = buildExtractionPrompt(chapter.getContent());
        String response = chatModel.generate(prompt);

        return parseKnowledgePoints(response, chapter.getIndex());
    }

    private String buildExtractionPrompt(String chapterContent) {
        return """
            你是一位资深课程设计专家。请从以下教材内容中提取所有知识点，
            并按照Bloom认知层次进行分类。

            教材内容：
            %s

            请严格按照以下JSON格式输出：
            [
              {
                "name": "知识点名称",
                "bloomLevel": "记忆|理解|应用|分析|评价|创造",
                "keywords": ["关键词1", "关键词2"],
                "prerequisites": ["前置知识点名称"],
                "summary": "一句话概括"
              }
            ]

            要求：
            1. 知识点粒度适中，不要太细（如单个概念），也不要太粗（如整章）
            2. 前置知识点使用准确的知识点名称，方便建立依赖关系
            3. Bloom层次根据知识点在教材中的呈现方式判断
            """.formatted(chapterContent);
    }

    private List<KnowledgePoint> parseKnowledgePoints(String jsonResponse, int chapterIndex) {
        try {
            ObjectMapper mapper = new ObjectMapper();
            JsonNode array = mapper.readTree(extractJsonBlock(jsonResponse));

            List<KnowledgePoint> points = new ArrayList<>();
            for (JsonNode node : array) {
                KnowledgePoint kp = KnowledgePoint.builder()
                        .name(node.get("name").asText())
                        .chapterIndex(chapterIndex)
                        .bloomLevel(BloomLevel.valueOf(node.get("bloomLevel").asText()))
                        .keywords(mapper.convertValue(node.get("keywords"), new TypeReference<List<String>>() {}))
                        .prerequisites(mapper.convertValue(node.get("prerequisites"), new TypeReference<List<String>>() {}))
                        .summary(node.get("summary").asText())
                        .build();
                points.add(kp);
            }
            return points;
        } catch (Exception e) {
            log.error("Failed to parse knowledge points from LLM response", e);
            return Collections.emptyList();
        }
    }

    private String extractJsonBlock(String response) {
        int start = response.indexOf('[');
        int end = response.lastIndexOf(']');
        if (start >= 0 && end > start) {
            return response.substring(start, end + 1);
        }
        return response;
    }
}
```

### 4.3 选择题生成器

选择题是最常用的题型，也是生成难度最高的——因为需要设计合理的干扰项。

```java
@Component
public class MultipleChoiceGenerator {

    private static final String CHOICE_PROMPT = """
        你是一位经验丰富的考试命题专家。请根据以下知识点，生成一道高质量的选择题。

        知识点：%s
        Bloom层次：%s
        章节：%s

        要求：
        1. 题干简洁明确，避免双重否定和歧义
        2. 提供4个选项（A/B/C/D），按逻辑顺序排列
        3. 干扰项必须具有迷惑性——来自常见误解、相似概念或不完全正确的说法
        4. 正确答案应该是唯一且无争议的
        5. 标注题目难度（简单/中等/困难）

        输出JSON格式：
        {
          "stem": "题干内容",
          "options": [
            {"label": "A", "content": "选项A内容", "isCorrect": true/false},
            {"label": "B", "content": "选项B内容", "isCorrect": true/false},
            {"label": "C", "content": "选项C内容", "isCorrect": true/false},
            {"label": "D", "content": "选项D内容", "isCorrect": true/false}
          ],
          "correctAnswer": "A/B/C/D",
          "analysis": "解析：为什么选这个，其他选项为什么错",
          "difficulty": "简单/中等/困难"
        }
        """;

    @Autowired
    private ChatLanguageModel chatModel;

    public MultipleChoiceQuestion generate(KnowledgePoint kp) {
        String prompt = CHOICE_PROMPT.formatted(kp.getName(), kp.getBloomLevel(), "第" + kp.getChapterIndex() + "章");
        String response = chatModel.generate(prompt);
        return parseChoiceQuestion(response);
    }

    /**
     * 批量生成——根据知识点列表按Bloom层次递增生成
     */
    public List<MultipleChoiceQuestion> batchGenerate(List<KnowledgePoint> points, int count) {
        // 按Bloom层次排序，优先出低层次知识点的题
        List<KnowledgePoint> sorted = points.stream()
                .sorted(Comparator.comparingInt(p -> p.getBloomLevel().ordinal()))
                .collect(Collectors.toList());

        List<MultipleChoiceQuestion> questions = new ArrayList<>();
        for (int i = 0; i < Math.min(count, sorted.size()); i++) {
            MultipleChoiceQuestion q = generate(sorted.get(i));
            q.setKnowledgePointId(sorted.get(i).getId());
            questions.add(q);
        }
        return questions;
    }

    private MultipleChoiceQuestion parseChoiceQuestion(String jsonResponse) {
        try {
            ObjectMapper mapper = new ObjectMapper();
            return mapper.readValue(extractJsonBlock(jsonResponse), MultipleChoiceQuestion.class);
        } catch (Exception e) {
            log.error("Failed to parse multiple choice question", e);
            return null;
        }
    }

    private String extractJsonBlock(String response) {
        int start = response.indexOf('{');
        int end = response.lastIndexOf('}');
        if (start >= 0 && end > start) {
            return response.substring(start, end + 1);
        }
        return response;
    }
}
```

### 4.4 编程题生成器

编程题生成是最有挑战性的——需要确保题目描述清晰、有明确的功能需求、并且答案代码是可编译运行的。

```java
@Component
public class ProgrammingQuestionGenerator {

    private static final String CODING_PROMPT = """
        你是一位Java编程教学专家。请根据以下知识点，生成一道编程题。

        知识点：%s
        Bloom层次：%s

        要求：
        1. 题目描述包含明确的输入输出规范
        2. 提供至少2个示例，包含输入和期望输出
        3. 指定需要考察的核心知识点
        4. 提供参考解答代码（可以直接编译运行）
        5. 提供评分标准（分项计分）

        输出JSON格式：
        {
          "title": "题目名称",
          "description": "详细题目描述，包括功能需求和约束条件",
          "inputFormat": "输入格式说明",
          "outputFormat": "输出格式说明",
          "examples": [
            {"input": "示例输入", "output": "示例输出", "explanation": "说明"}
          ],
          "coreKnowledge": ["考察点1", "考察点2"],
          "referenceAnswer": "完整的Java参考代码",
          "scoringRubric": [
            {"criterion": "评分项", "points": 分数}
          ],
          "difficulty": "简单/中等/困难",
          "estimatedMinutes": 预估完成时间(分钟)
        }
        """;

    @Autowired
    private ChatLanguageModel chatModel;

    public ProgrammingQuestion generate(KnowledgePoint kp) {
        String prompt = CODING_PROMPT.formatted(kp.getName(), kp.getBloomLevel());
        String response = chatModel.generate(prompt);
        return parseProgrammingQuestion(response);
    }

    /**
     * 编译验证生成的参考代码
     */
    public ValidationResult validateReferenceCode(ProgrammingQuestion question) {
        String code = question.getReferenceAnswer();

        // 提取public class名，保存为临时文件
        String className = extractClassName(code);
        Path tempDir = null;
        try {
            tempDir = Files.createTempDirectory("code_validation_");
            Path sourceFile = tempDir.resolve(className + ".java");
            Files.writeString(sourceFile, code);

            // 使用javax.tools.JavaCompiler编译
            JavaCompiler compiler = ToolProvider.getSystemJavaCompiler();
            DiagnosticCollector<JavaFileObject> diagnostics = new DiagnosticCollector<>();
            StandardJavaFileManager fileManager = compiler.getStandardFileManager(diagnostics, null, null);
            Iterable<? extends JavaFileObject> compilationUnits = fileManager.getJavaFileObjects(sourceFile.toFile());
            JavaCompiler.CompilationTask task = compiler.getTask(null, fileManager, diagnostics, null, null, compilationUnits);

            boolean success = task.call();

            List<String> errors = diagnostics.getDiagnostics().stream()
                    .map(d -> String.format("Line %d: %s", d.getLineNumber(), d.getMessage(Locale.CHINA)))
                    .collect(Collectors.toList());

            return new ValidationResult(success, errors);
        } catch (Exception e) {
            return new ValidationResult(false, List.of("Compilation error: " + e.getMessage()));
        } finally {
            if (tempDir != null) {
                try { Files.walk(tempDir).sorted(Comparator.reverseOrder()).forEach(p -> p.toFile().delete()); } catch (Exception ignored) {}
            }
        }
    }

    private String extractClassName(String code) {
        Pattern pattern = Pattern.compile("public\\s+class\\s+(\\w+)");
        Matcher matcher = pattern.matcher(code);
        if (matcher.find()) {
            return matcher.group(1);
        }
        return "TempClass";
    }

    private ProgrammingQuestion parseProgrammingQuestion(String jsonResponse) {
        try {
            ObjectMapper mapper = new ObjectMapper();
            return mapper.readValue(extractJsonBlock(jsonResponse), ProgrammingQuestion.class);
        } catch (Exception e) {
            log.error("Failed to parse programming question", e);
            return null;
        }
    }

    private String extractJsonBlock(String response) {
        int start = response.indexOf('{');
        int end = response.lastIndexOf('}');
        if (start >= 0 && end > start) {
            return response.substring(start, end + 1);
        }
        return response;
    }
}
```

### 4.5 整体编排服务

```java
@Service
public class ExamPaperGenerator {

    @Autowired
    private DocumentParseService documentParseService;

    @Autowired
    private KnowledgeExtractionService knowledgeExtractionService;

    @Autowired
    private MultipleChoiceGenerator mcGenerator;

    @Autowired
    private ProgrammingQuestionGenerator prGenerator;

    @Autowired
    private QuestionDedupService dedupService;

    /**
     * 从教材文件生成完整试卷
     */
    public ExamPaper generateExamPaper(InputStream inputStream, String fileName, ExamConfig config) {
        // Step 1: 解析教材
        ParsedDocument doc = documentParseService.parse(inputStream, fileName);

        // Step 2: 抽取知识点
        List<KnowledgePoint> allKnowledgePoints = new ArrayList<>();
        for (Chapter chapter : doc.getChapters()) {
            List<KnowledgePoint> points = knowledgeExtractionService.extract(chapter);
            allKnowledgePoints.addAll(points);
        }
        log.info("Extracted {} knowledge points from {} chapters", allKnowledgePoints.size(), doc.getChapters().size());

        // Step 3: 按Bloom层次分组
        Map<BloomLevel, List<KnowledgePoint>> grouped = allKnowledgePoints.stream()
                .collect(Collectors.groupingBy(KnowledgePoint::getBloomLevel));

        // Step 4: 生成选择题
        List<MultipleChoiceQuestion> mcQuestions = mcGenerator.batchGenerate(allKnowledgePoints, config.getMcCount());

        // Step 5: 生成简答题(复用选择题生成逻辑，调整prompt)
        List<KnowledgePoint> shortAnswerPoints = pickFromLevels(grouped, BloomLevel.UNDERSTANDING, config.getShortAnswerCount());
        // ... 简答题生成逻辑

        // Step 6: 生成编程题(侧重应用及以上层次)
        List<KnowledgePoint> codingPoints = pickFromLevels(grouped, BloomLevel.APPLYING, config.getCodingCount());
        List<ProgrammingQuestion> codingQuestions = new ArrayList<>();
        for (KnowledgePoint kp : codingPoints) {
            ProgrammingQuestion q = prGenerator.generate(kp);
            ValidationResult validation = prGenerator.validateReferenceCode(q);
            if (validation.isSuccess()) {
                codingQuestions.add(q);
            } else {
                log.warn("Reference code validation failed for question: {}, retrying...", q.getTitle());
            }
        }

        // Step 7: 去重与组装
        List<MultipleChoiceQuestion> dedupedMC = dedupService.dedupMC(mcQuestions);

        return ExamPaper.builder()
                .title(fileName + " - 自动生成试卷")
                .multipleChoiceQuestions(dedupedMC)
                .programmingQuestions(codingQuestions)
                .totalScore(100)
                .build();
    }

    private List<KnowledgePoint> pickFromLevels(Map<BloomLevel, List<KnowledgePoint>> grouped,
                                                  BloomLevel minLevel, int count) {
        return grouped.entrySet().stream()
                .filter(e -> e.getKey().ordinal() >= minLevel.ordinal())
                .flatMap(e -> e.getValue().stream())
                .limit(count)
                .collect(Collectors.toList());
    }
}
```

4. **微调专用模型**：使用历年优质试题对模型进行SFT微调，提升出题风格一致性

## 七、总结

智能题库系统不是要取代老师，而是把老师从机械重复的出题劳动中解放出来，让他们有更多精力投入教学设计和学生辅导。四分钟出一套卷子，老师审核一小时就能用——这就是AI给教育行业带来的实实在在的生产力提升。

### 从工具到平台的演进路径

很多教育科技团队止步于"AI出题工具"，但真正的价值在平台化：

**Step 1 - 单机版出题助手（当前）**：老师上传教材→AI出题→人工审核→导出Word/PDF。这一步验证了AI出题的可行性，但仅限于个人使用。开发周期2-3周，投入1-2人。

**Step 2 - 校内共享题库平台**：教研组共享题库，支持多老师协作审核、题目版本管理、按难度/章节/题型筛选。这一步需要前后端完整开发，周期1-2个月，投入3-4人。

**Step 3 - 与学习管理系统(LMS)打通**：题库与考试系统、作业系统、自适应学习系统对接。学生做错的题目自动加入个人错题本，AI根据错题生成同类变式题，形成"测→评→练"闭环。这一步涉及系统集成，周期3-6个月。

**Step 4 - 知识图谱驱动的自适应学习**：不只是出题，而是构建学科知识图谱，追踪每个学生在每个知识点上的掌握程度，动态推荐最合适的练习。这是题库系统的终极形态——从"出题工具"进化为"学习引擎"。

大部分高校的现状在Step 1到Step 2之间。建议先做出题助手验证价值，拿到老师正面反馈后再推动平台化——教育行业的技术采购决策链条长，没有一线用户的背书很难推进。
