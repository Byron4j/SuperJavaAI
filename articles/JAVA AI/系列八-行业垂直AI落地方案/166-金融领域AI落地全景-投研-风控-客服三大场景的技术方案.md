## 二、金融 AI 的特殊约束

在讨论具体场景前，必须先理解金融 AI 独有的四重约束：

| 约束 | 描述 | 技术影响 |
|------|------|---------|
| **数据不出境/不出域** | 客户数据、交易数据必须在行内 | 必须私有化部署，不能用公有云 API |
| **可解释性** | 拒绝贷款、下调评级必须有依据 | 不能是"黑盒"推理，要求归因分析 |
| **审计追溯** | 每次 AI 辅助决策可被审计 | 参照系列文章第 159 篇的审计方案 |
| **模型稳定性** | 同一输入必须同一输出 | 温度参数必须为 0，禁止随机推理 |

## 三、场景一：投研智能助手——让分析师效率翻 3 倍

### 3.1 业务痛点

- 每天读 200+ 页研报，有效信息不到 20%
- 跨行业对比分析，手动 Excel 拉数据 3 小时
- 财报电话会议录音转文字 1 万字，找关键信息像大海捞针

### 3.2 RAG + 长上下文模型的混合方案

```
研报PDF → 文档解析 → 文本分块 → Embedding → 向量数据库(Milvus)
                                                ↓
用户问题 → Query改写 → 混合检索(向量+关键词) → 召回Top-20
                                                ↓
                                          LLM重排序 → 长上下文模型生成回答
                                                      ↓
                                                  引用溯源 + 置信度标注
```

```java
@Service
@Slf4j
public class ResearchReportQAService {

    @Autowired
    private MilvusClient milvusClient;
    
    @Autowired
    private ElasticsearchClient esClient;
    
    @Autowired
    private ModelGateway modelGateway;
    
    @Autowired
    private TextChunkingService chunkingService;

    /**
     * 研报智能问答
     */
    public ResearchAnswer answer(String question, String industryFilter) {
        // 1. Query 改写（扩展同义词、行业术语）
        String rewrittenQuery = rewriteFinancialQuery(question);
        
        // 2. 混合检索：向量相似度 + 关键词匹配
        List<SearchResult> vectorResults = searchByEmbedding(rewrittenQuery, 15);
        List<SearchResult> keywordResults = searchByKeyword(rewrittenQuery, 15);
        List<SearchResult> merged = mergeAndRerank(vectorResults, keywordResults, 20);
        
        // 3. 构建带引用的 Prompt
        String prompt = buildResearchPrompt(question, merged);
        
        // 4. 调用模型（零温度，保证确定性）
        ResearchAnswer answer = modelGateway.chat(FinancialChatRequest.builder()
            .scene("financial_research")
            .temperature(0.0)
            .systemPrompt(loadSystemPrompt("research_analyst.txt"))
            .userPrompt(prompt)
            .build());
        
        // 5. 附加引用溯源
        answer.setReferences(merged.stream()
            .map(r -> new Reference(r.getDocTitle(), r.getPageNumber(), r.getText()))
            .collect(Collectors.toList()));
        
        // 6. 置信度评估
        answer.setConfidenceScore(calculateConfidence(merged));
        
        return answer;
    }
    
    /**
     * 金融 Query 改写：扩展行业术语
     */
    private String rewriteFinancialQuery(String query) {
        // 调用金融词典替换专业术语
        return FinancialTermRewriter.rewrite(query, 
            Map.of(
                "PE", "市盈率 Price-to-Earnings Ratio",
                "ROE", "净资产收益率 Return on Equity",
                "NIM", "净息差 Net Interest Margin",
                "NPL", "不良贷款率 Non-Performing Loan Ratio"
            ));
    }
    
    /**
     * RRF (Reciprocal Rank Fusion) 混合排序
     */
    private List<SearchResult> mergeAndRerank(
            List<SearchResult> vector, List<SearchResult> keyword, int topK) {
        
        Map<String, Double> scores = new HashMap<>();
        int k = 60;  // RRF 参数
        
        for (int i = 0; i < vector.size(); i++) {
            String id = vector.get(i).getId();
            scores.merge(id, 1.0 / (k + i + 1), Double::sum);
        }
        for (int i = 0; i < keyword.size(); i++) {
            String id = keyword.get(i).getId();
            scores.merge(id, 1.0 / (k + i + 1), Double::sum);
        }
        
        return scores.entrySet().stream()
            .sorted(Map.Entry.<String, Double>comparingByValue().reversed())
            .limit(topK)
            .map(e -> findResultById(e.getKey()))
            .collect(Collectors.toList());
    }
}
```

```java
@Component
public class ResearchDataPipeline {

    /**
     * 研报自动入库流程
     */
    @Scheduled(cron = "0 0 6,12,18 * * *")  // 每天 3 次
    public void ingestNewReports() {
        // 1. 从数据源拉取新研报
        List<ReportMeta> newReports = reportSourceFetcher.fetchNewReports(
            LocalDateTime.now().minusHours(6));
        
        for (ReportMeta report : newReports) {
            try {
                // 2. PDF 解析
                String text = pdfParser.parse(report.getFileUrl());
                
                // 3. 智能分块（保持表格完整、章节语义完整）
                List<TextChunk> chunks = chunkingService.splitBySemantic(text, 
                    ChunkConfig.builder()
                        .maxChunkSize(1024)
                        .overlapSize(128)
                        .preserveTables(true)  // 保留表格完整性
                        .build());
                
                // 4. 生成 Embedding 并存入向量库
                List<float[]> embeddings = embeddingService.embedBatch(
                    chunks.stream().map(TextChunk::getContent).collect(Collectors.toList()));
                
                milvusClient.insert(new InsertRequest.Builder()
                    .collectionName("research_reports")
                    .data(chunks.stream().map(chunk -> Map.of(
                        "id", chunk.getId(),
                        "doc_id", report.getDocId(),
                        "title", report.getTitle(),
                        "publish_date", report.getPublishDate(),
                        "content", chunk.getContent(),
                        "embedding", embeddings.get(chunks.indexOf(chunk))
                    )).collect(Collectors.toList()))
                    .build());
                
                log.info("✅ 研报入库: {} ({} 个分块)", report.getTitle(), chunks.size());
                
            } catch (Exception e) {
                log.error("❌ 研报处理失败: {}", report.getTitle(), e);
            }
        }
    }
}
```

## 四、场景二：智能风控——从规则引擎到因果推理

### 4.1 业务痛点

- 传统规则引擎维护了 3000+ 条规则，每季度变更 200+ 条
- 小微企业贷款材料非结构化（合同、流水、发票），人工审核效率低
- 拒绝贷款时需要给客户明确的"为什么"，监管要求可解释

### 4.2 风控 AI 的三层架构

```
第一层：规则引擎（硬约束）
  ├─ 黑名单检查（反洗钱、制裁名单）
  ├─ 监管红线（杠杆率、集中度）
  └─ 硬性指标（逾期记录、收入负债比）

第二层：AI 模型（软决策）
  ├─ NLP 解析非结构化材料（合同条款、银行流水）
  ├─ 异常检测模型（交易模式识别）
  └─ 信用评分模型（多维度评估）

第三层：解释引擎（合规要求）
  ├─ 生成拒绝理由（引用具体条款）
  ├─ 关联证据链（文档 → 段落 → 原文）
  └─ 决策追溯报告（可审计格式）
```

```java
@Service
public class RiskAssessmentService {

    @Autowired
    private RuleEngine ruleEngine;
    
    @Autowired
    private ModelGateway modelGateway;
    
    @Autowired
    private DocumentAnalyzer documentAnalyzer;
    
    @Autowired
    private ExplainabilityEngine explainEngine;

    /**
     * 企业贷款风险评估
     */
    public RiskAssessmentResult assessLoanApplication(LoanApplication app) {
        RiskAssessmentResult result = new RiskAssessmentResult();
        result.setApplicationId(app.getId());
        
        // ===== 第一层：硬规则（不可逾越） =====
        List<RuleResult> hardRules = ruleEngine.evaluateHardRules(app);
        result.setHardRuleResults(hardRules);
        
        if (hardRules.stream().anyMatch(r -> !r.isPassed())) {
            result.setDecision(Decision.REJECT);
            result.setReasons(hardRules.stream()
                .filter(r -> !r.isPassed())
                .map(RuleResult::getReason)
                .collect(Collectors.toList()));
            return result;
        }
        
        // ===== 第二层：AI 分析非结构化材料 =====
        List<DocumentAnalysis> docAnalyses = documentAnalyzer.analyze(app.getDocuments());
        result.setDocumentAnalyses(docAnalyses);
        
        // 构造风控评估 Prompt
        String riskPrompt = buildRiskAssessmentPrompt(app, docAnalyses);
        
        FinancialChatResponse aiResponse = modelGateway.chat(FinancialChatRequest.builder()
            .scene("risk_assessment")
            .temperature(0.0)  // 零温度
            .systemPrompt(loadSystemPrompt("risk_assessor.txt"))
            .userPrompt(riskPrompt)
            .responseFormat("json")  // 结构化输出
            .build());
        
        AIAssessment aiAssessment = JSON.parseObject(
            aiResponse.getContent(), AIAssessment.class);
        result.setAiAssessment(aiAssessment);
        
        // ===== 第三层：可解释性 =====
        Explanation explanation = explainEngine.generateExplanation(
            app, hardRules, aiAssessment, docAnalyses);
        result.setExplanation(explanation);
        
        // 最终决策
        result.setDecision(determineFinalDecision(hardRules, aiAssessment));
        
        // ===== 审计记录 =====
        generateAuditReport(result);
        
        return result;
    }
    
    /**
     * 构建风控评估 Prompt
     */
    private String buildRiskAssessmentPrompt(LoanApplication app, 
            List<DocumentAnalysis> analyses) {
        StringBuilder sb = new StringBuilder();
        sb.append("## 贷款申请信息\n");
        sb.append("- 企业名称: ").append(app.getCompanyName()).append("\n");
        sb.append("- 申请金额: ").append(app.getAmount()).append(" 万元\n");
        sb.append("- 贷款期限: ").append(app.getTermMonths()).append(" 个月\n");
        sb.append("- 所属行业: ").append(app.getIndustry()).append("\n");
        sb.append("- 成立年限: ").append(app.getFoundedYears()).append(" 年\n\n");
        
        sb.append("## 关键财务指标\n");
        sb.append("- 近三年营收: ").append(app.getRevenueHistory()).append("\n");
        sb.append("- 资产负债率: ").append(app.getDebtRatio()).append("%\n");
        sb.append("- 净利率: ").append(app.getNetMargin()).append("%\n");
        sb.append("- 经营现金流: ").append(app.getOperatingCashflow()).append(" 万元\n\n");
        
        sb.append("## 文档分析结果\n");
        for (DocumentAnalysis analysis : analyses) {
            sb.append("- [").append(analysis.getDocType()).append("] ");
            sb.append(analysis.getSummary()).append("\n");
            sb.append("  风险信号: ").append(analysis.getRiskSignals()).append("\n");
        }
        
        sb.append("\n请从以下维度评估风险并给出 1-10 评分：\n");
        sb.append("1. 还款能力（基于现金流）\n");

        sb.append("3. 担保质量（如有抵押物）\n");
        sb.append("4. 行业风险（政策、市场环境）\n");
        sb.append("5. 综合建议\n");
        
        return sb.toString();
    }
```

### 4.4 可解释性引擎

```java
@Component
public class ExplainabilityEngine {

    /**
     * 生成监管级解释报告
     */
    public Explanation generateExplanation(
            LoanApplication app,
            List<RuleResult> hardRules,
            AIAssessment aiAssessment,
            List<DocumentAnalysis> docAnalyses) {
        
        Explanation explanation = new Explanation();
        explanation.setApplicationId(app.getId());
        explanation.setTimestamp(Instant.now());
        
        // 1. 硬规则解释（引用法规条文）
        for (RuleResult rule : hardRules) {
            if (!rule.isPassed()) {
                explanation.addHardRuleReason(
                    rule.getRuleName(),
                    rule.getReason(),
                    rule.getRegulationRef()  // 如：《商业银行法》第 35 条
                );
            }
        }
        
        // 2. AI 决策的证据链
        for (AIFactor factor : aiAssessment.getFactors()) {
            EvidenceChain chain = new EvidenceChain();
            chain.setFactor(factor.getName());
            chain.setScore(factor.getScore());
            chain.setWeight(factor.getWeight());
            
            // 关联到原始文档的段落
            for (DocumentAnalysis doc : docAnalyses) {
                if (doc.getRelatedFactors().contains(factor.getName())) {
                    chain.addEvidence(Evidence.builder()
                        .sourceDoc(doc.getFileName())
                        .pageNumber(doc.getRelevantPage())
                        .highlightedText(doc.getHighlightedSection())
                        .build());
                }
            }
            
            explanation.addEvidenceChain(chain);
        }
        
        // 3. 决策摘要（给客户看的版本）
        explanation.setDecisionSummary(generateDecisionSummary(
            app.getAmount(), aiAssessment.getCompositeScore()));
        
        return explanation;
    }
}
```

## 五、场景三：智能客服——不只是 FAQ 机器人

### 5.1 金融客服的特殊需求

普通的客服 AI 能回答"如何开户"，但金融客服需要：
- 多轮对话中记住上下文（"我说的那张卡是建行的"）
- 精确回答产品条款（"理财产品第 3.2 条关于提前赎回的规定"）
- 敏感信息脱敏（卡号、身份证号自动打码）
- 转人工的时机判断（涉及投诉、法律问题）

### 5.2 智能客服架构

```java
@Service
public class FinancialCustomerService {

    @Autowired
    private ModelGateway modelGateway;
    
    @Autowired
    private KnowledgeBaseService kbService;
    
    @Autowired
    private SensitiveDataMasker masker;
    
    @Autowired
    private HumanHandoffService handoffService;

    /**
     * 金融客服对话
     */
    public CustomerResponse chat(CustomerRequest request) {
        // 1. 敏感信息脱敏（在发到模型之前）
        String maskedInput = masker.mask(request.getMessage());
        
        // 2. 意图识别 + 场景路由
        Intent intent = classifyIntent(maskedInput);
        
        switch (intent.getPrimaryIntent()) {
            case COMPLAINT:
            case LEGAL_QUERY:
                // 敏感意图直接转人工
                return handoffService.transferToHuman(request, intent);
                
            case PRODUCT_QUERY:
                // 产品查询：精准 RAG
                return handleProductQuery(request, intent);
                
            case TRANSACTION:
                // 交易相关：需要身份验证 + 脱敏
                return handleTransactionQuery(request, intent);
                
            case ACCOUNT_INFO:
                // 账户信息：仅脱敏展示，不做 AI 推理
                return handleAccountInfo(request, intent);
                
            default:
                return handleGeneralQuery(request, intent);
        }
    }
    
    /**
     * 产品条款精准查询（RAG + 引用原文）
     */
    private CustomerResponse handleProductQuery(CustomerRequest request, Intent intent) {
        // 从知识库检索相关产品条款
        List<KBDocument> docs = kbService.search(
            intent.getProductCode() + " " + request.getMessage(), 5);
        
        String prompt = buildProductQueryPrompt(request.getMessage(), docs);
        
        FinancialChatResponse aiResponse = modelGateway.chat(FinancialChatRequest.builder()
            .scene("customer_service")
            .temperature(0.0)
            .systemPrompt("你是一个专业的金融客服助手。回答必须基于提供的产品条款原文，" +
                "不得添加条款外的信息。引用原文时标注条款编号。")
            .userPrompt(prompt)
            .build());
        
        return CustomerResponse.builder()
            .answer(aiResponse.getContent())
            .references(docs.stream()
                .map(d -> new Reference(d.getTitle(), d.getClauseNumber(), d.getSnippet()))
                .collect(Collectors.toList()))
            .intent(intent)
            .build();
    }
    
    /**
     * 转人工判断条件
     */
    private boolean shouldTransferToHuman(String message, SessionContext context) {
        // 1. 连续重复问题 > 3 次
        if (context.getRepeatCount() > 3) return true;
        
        // 2. 情感分析判定为愤怒
        if (sentimentAnalyzer.isAngry(message)) return true;
        
        // 3. 关键字触发（投诉、起诉、媒体、银保监）
        Set<String> escalationKeywords = Set.of(
            "投诉", "起诉", "律师", "媒体", "银保监", "12378");
        if (escalationKeywords.stream().anyMatch(message::contains)) return true;
        
        // 4. 模型置信度 < 阈值
        if (context.getLastConfidence() < 0.7) return true;
        
        return false;
    }
}
```

### 5.3 敏感信息脱敏

```java
@Component
public class SensitiveDataMasker {

    // 身份证: 前 3 后 4
    private static final Pattern ID_CARD = Pattern.compile(
        "(\\d{3})\\d{11}(\\d{4})");
    
    // 银行卡: 前 4 后 4
    private static final Pattern BANK_CARD = Pattern.compile(
        "(\\d{4})\\d{8,12}(\\d{4})");
    
    // 手机号: 前 3 后 4
    private static final Pattern PHONE = Pattern.compile(
        "(1[3-9]\\d)\\d{4}(\\d{4})");
    
    /**
     * 脱敏处理
     */
    public String mask(String input) {
        String masked = ID_CARD.matcher(input).replaceAll("$1***********$2");
        masked = BANK_CARD.matcher(masked).replaceAll("$1 **** **** $2");
        masked = PHONE.matcher(masked).replaceAll("$1****$2");
        return masked;
    }
    
    /**
     * 检查是否包含敏感信息（用于审计日志过滤）
     */
    public boolean containsSensitiveInfo(String text) {
        return ID_CARD.matcher(text).find() 
            || BANK_CARD.matcher(text).find()
            || PHONE.matcher(text).find();
    }
}
```

## 七、金融 AI 落地的关键 Checklist

### 7.1 合规优先

```yaml
# 金融 AI 上线前合规自查清单
compliance_checklist:
  data_security:
    - 确认模型推理数据不出机柜/不出专线
    - 确认客户隐私数据已脱敏后再给模型
    - 确认模型输出不包含其他客户数据（防泄漏）
    
  explainability:
    - 拒绝类决策必须有不少于 3 条具体理由
    - 每条理由必须可追溯到原始数据或法规条款
    - 生成标准格式的"决策说明书"供客户下载
    
  audit:
    - 全部模型调用 100% 记录审计日志
    - 日志保留不少于 3 年（风控 5 年）
    - 每季度生成审计报告（自动或半自动）
    
  model_governance:
    - 模型上线前通过合规评审（至少风控+法务）
    - 模型版本变更必须有变更记录
    - 定期（季度）模型效果评估
```

## 八、总结与展望

金融 AI 的三条核心原则：

1. **合规不是阻碍，是护栏**——在合规框架下设计的 AI 系统，反而更容易通过审批上线
2. **零温度是底线**——金融决策不能有随机性，同一输入必须同一输出
3. **可解释性不是可选的**——监管、客户、风控经理都需要知道"为什么"

三个场景的落地优先级建议：
- **客服**：难度最低，见效最快，建议第一个落地（2-3 个月）
- **投研**：技术成熟度高，ROI 明显，建议第二个（3-4 个月）
- **风控**：合规最严，必须打好前面两个的地基再做（4-6 个月）

金融 AI 不是追风口，而是实实在在的降本增效。当你的风控审批从 7 天缩短到 1.5 小时，当你的投研分析从 3 小时变成 15 分钟——这些数字就是 AI 最好的价值证明。
