# 医疗知识库：基于 RAG 的临床指南智能检索与问答系统，医生查指南从30分钟到3秒

## 一、"医生的时间花在了哪里？"

2024年某三甲医院内部的工时调研显示了一个令人震惊的数据：一个主治医师每天平均花2.7小时在"查找信息"上——查指南、查文献、查药典、查操作规程。

- "高血压合并糖尿病患者的首选降压药是什么？"→ 翻《中国高血压防治指南》第87页，耗时15分钟
- "房颤患者围手术期抗凝方案？"→ 需要同时查询《房颤管理指南》+《围手术期管理规范》，耗时30分钟
- "某罕见病的诊断标准？"→ 可能查遍5本指南都找不到，最终求助上级医生

80岁的张教授每周四上午在特需门诊，桌上永远摞着10本以上的指南手册。他的学生统计过：张教授每次接诊前"翻书"的时间，比"看病"的时间还长。

**核心痛点：**

- **指南数量庞大且分散**：仅内科领域就超过300本临床指南，每本动辄200页以上
- **更新频繁**：指南平均3-5年更新一版，医生难以追踪最新版本
- **查询效率低**：依赖目录、索引和记忆，跨指南交叉查询几乎不可能
- **基层医院信息匮乏**：县级医院医生获取最新指南的渠道有限，诊疗规范化程度不足40%

## 三、Java代码实现

### 3.1 临床指南的智能分块与索引

指南不同于普通文档——它有严格的层级结构（篇-章-节-条），而且推荐等级（I/II/III类，A/B/C级）至关重要：

```java
@Service
public class GuidelineIndexingService {

    @Autowired
    private MilvusClient milvusClient;

    @Autowired
    private EmbeddingService embeddingService;

    /**
     * 指南分块入库 —— 按推荐条目分块而非纯字数切割
     */
    public void indexGuideline(Guideline guideline) {
        List<GuidelineChunk> chunks = chunkByRecommendation(guideline);

        for (GuidelineChunk chunk : chunks) {
            // 富文本编码：将元数据融入向量化文本，提升语义检索精度
            String enrichedText = String.format("" +
                    "指南名称:%s | 版本:%s | 章节:%s | 分类:%s | " +
                    "推荐等级:%s | 证据等级:%s | 内容:%s",
                    guideline.getTitle(),
                    guideline.getVersion(),
                    chunk.getSection(),
                    guideline.getCategory(),
                    chunk.getRecommendationLevel(),
                    chunk.getEvidenceLevel(),
                    chunk.getContent()
            );

            float[] embedding = embeddingService.encode(enrichedText);

            InsertParam insertParam = InsertParam.newBuilder()
                    .withCollectionName("clinical_guidelines")
                    .withFields(List.of(
                            new InsertParam.Field("guideline_id",
                                    List.of(guideline.getId())),
                            new InsertParam.Field("chunk_id",
                                    List.of(chunk.getChunkId())),
                            new InsertParam.Field("title",
                                    List.of(guideline.getTitle())),
                            new InsertParam.Field("version",
                                    List.of(guideline.getVersion())),
                            new InsertParam.Field("section",
                                    List.of(chunk.getSection())),
                            new InsertParam.Field("recommendation_level",
                                    List.of(chunk.getRecommendationLevel())),
                            new InsertParam.Field("evidence_level",
                                    List.of(chunk.getEvidenceLevel())),
                            new InsertParam.Field("content",
                                    List.of(chunk.getContent())),
                            new InsertParam.Field("embedding",
                                    List.of(embedding))
                    ))
                    .build();

            milvusClient.insert(insertParam);
        }
    }

    /**
     * 按"推荐条目"切分指南——而非机械按字数切分
     * 指南的推荐条目通常以"I类推荐"、"IIa类推荐"等标识
     */
    private List<GuidelineChunk> chunkByRecommendation(Guideline guideline) {
        List<GuidelineChunk> chunks = new ArrayList<>();

        // 正则匹配推荐等级标识
        Pattern pattern = Pattern.compile(
                "(?:【?([IV]+[ab]?类推荐|[ABC]级证据)】?[\\s\\S]*?)" +
                "(?=【?(?:[IV]+[ab]?类推荐|[ABC]级证据)】?|参考文献|$)");

        Matcher matcher = pattern.matcher(guideline.getContent());

        int chunkIdx = 0;
        String currentSection = "";
        String currentRecLevel = "";
        String currentEvLevel = "";

        while (matcher.find()) {
            String chunkText = matcher.group().trim();
            if (chunkText.isEmpty()) continue;

            // 提取推荐等级
            if (chunkText.contains("I类推荐")) {
                currentRecLevel = "I";
            } else if (chunkText.contains("IIa类推荐")) {
                currentRecLevel = "IIa";
            } else if (chunkText.contains("IIb类推荐")) {
                currentRecLevel = "IIb";
            } else if (chunkText.contains("III类推荐")) {
                currentRecLevel = "III";
            }

            // 提取证据等级
            if (chunkText.contains("A级证据")) {
                currentEvLevel = "A";
            } else if (chunkText.contains("B级证据")) {
                currentEvLevel = "B";
            } else if (chunkText.contains("C级证据")) {
                currentEvLevel = "C";
            }

            // 如果分块超过2000字，递归切分
            if (chunkText.length() > 2000) {
                chunks.addAll(splitLongChunk(chunkText, currentSection,
                        currentRecLevel, currentEvLevel, chunkIdx));
            } else {
                chunks.add(GuidelineChunk.builder()
                        .chunkId(guideline.getId() + "_" + chunkIdx++)
                        .section(extractSection(guideline.getContent(), chunkText))
                        .recommendationLevel(currentRecLevel)
                        .evidenceLevel(currentEvLevel)
                        .content(chunkText)
                        .build());
            }
        }

        return chunks;
    }
}
```

### 3.2 混合检索 + 条件过滤

医生查询时可以指定过滤条件（如只看I类推荐、只看2022年后版本），提升检索精度：

```java
@Service
public class GuidelineSearchService {

    @Autowired
    private MilvusClient milvusClient;

    @Autowired
    private EmbeddingService embeddingService;

    public List<GuidelineHit> search(ClinicalQuery query) {
        float[] embedding = embeddingService.encode(query.getText());

        // 构建过滤表达式
        String filterExpr = buildFilterExpression(query);

        SearchParam searchParam = SearchParam.newBuilder()
                .withCollectionName("clinical_guidelines")
                .withMetricType(MetricType.IP)
                .withTopK(query.getTopK())
                .withVectors(List.of(List.of(embedding)))
                .withVectorFieldName("embedding")
                .withParams("{\"nprobe\": 32}")
                .withOutFields(List.of("guideline_id", "title", "section",
                        "recommendation_level", "evidence_level", "content"))
                .withExpr(filterExpr)
                .build();

        List<List<SearchResult>> results =
                milvusClient.search(searchParam).getResults();

        return results.get(0).stream()
                .map(GuidelineHit::fromSearchResult)
                .collect(Collectors.toList());
    }

    private String buildFilterExpression(ClinicalQuery query) {
        List<String> conditions = new ArrayList<>();

        // 只检索I类/Iia类高等级推荐
        if (query.isHighLevelOnly()) {
            conditions.add(
                "recommendation_level in [\"I\", \"IIa\"]");
        }

        // 按科室过滤
        if (query.getDepartment() != null) {
            conditions.add(String.format(
                "department == \"%s\"", query.getDepartment()));
        }

        // 只看最新版本（如2022年后）
        if (query.getMinYear() > 0) {
            conditions.add(String.format(
                "effective_year >= %d", query.getMinYear()));
        }

        // 按指南名称过滤
        if (query.getGuidelineFilter() != null && !query.getGuidelineFilter().isEmpty()) {
            String titles = query.getGuidelineFilter().stream()
                    .map(t -> "\"" + t + "\"")
                    .collect(Collectors.joining(", "));
            conditions.add(String.format("title in [%s]", titles));
        }

        return conditions.isEmpty() ? "" : String.join(" and ", conditions);
    }
}
```

### 3.3 循证问答引擎

最核心的模块——基于检索到的指南内容，给出循证医学级别的回答：

```java
@Service
public class EvidenceBasedQAService {

    @Autowired
    private GuidelineSearchService searchService;

    @Autowired
    private ChatLanguageModel chatModel;

    private static final String QA_SYSTEM_PROMPT = "" +
        "你是一位资深循证医学专家，精通各类临床指南。请基于提供的指南内容回答问题。\n" +
        "\n" +
        "回答原则：\n" +
        "1. 严格基于[参考资料]中的指南内容，不要编造\n" +
        "2. 每一条临床建议必须标注：[推荐等级]和[证据等级]，如[I类推荐，A级证据]\n" +
        "3. 如果存在不同指南的矛盾建议，列出各方观点并标注指南来源\n" +
        "4. 如果参考资料不足以回答问题，明确说明，不要猜测\n" +
        "5. 优先引用最新版本指南（近3年内）\n" +
        "6. 如果涉及药物，附上标准用法用量\n" +
        "7. 在回答末尾列出[参考文献]（即引用的指南名称和版本）\n" +
        "\n" +
        "回答格式：\n" +
        "## 建议方案\n" +
        "（核心建议，按优先级排列）\n" +
        "\n" +
        "## 证据依据\n" +
        "（每条建议对应的指南推荐和证据等级）\n" +
        "\n" +
        "## 注意事项\n" +
        "（禁忌症、特殊人群调整、药物相互作用等）\n" +
        "\n" +
        "## 参考文献\n" +
        "1. 《指南名》版本号，推荐等级XX\n" +
        "2. ...";

    public QAAnswer answer(ClinicalQuery query) {
        // Step 1: 检索相关指南内容
        List<GuidelineHit> hits = searchService.search(query);

        if (hits.isEmpty()) {
            return QAAnswer.noAnswer("未找到相关临床指南内容，" +
                    "建议扩大检索范围或咨询专科医生。");
        }

        // Step 2: 按推荐等级排序（高等级推荐优先）
        hits.sort(Comparator.comparingInt(this::getLevelPriority)
                .thenComparing(GuidelineHit::getScore, Comparator.reverseOrder()));

        // Step 3: 构建上下文（保留Top 10个分块）
        String context = buildContext(hits.stream()
                .limit(10).collect(Collectors.toList()));

        // Step 4: LLM生成循证回答
        String fullPrompt = QA_SYSTEM_PROMPT
                + "\n\n[参考资料]\n" + context
                + "\n\n[医生提问]\n" + query.getText();

        String answer = chatModel.generate(fullPrompt);

        return QAAnswer.builder()
                .query(query.getText())
                .answer(answer)
                .sources(hits.stream().limit(5)
                        .map(h -> Source.builder()
                                .guidelineTitle(h.getTitle())
                                .section(h.getSection())
                                .recommendationLevel(h.getRecommendationLevel())
                                .evidenceLevel(h.getEvidenceLevel())
                                .build())
                        .collect(Collectors.toList()))
                .disclaimer("本回答由AI基于临床指南生成，仅供参考，" +
                        "临床决策请结合患者具体情况和医生专业判断。")
                .build();
    }

    private int getLevelPriority(GuidelineHit hit) {
        return switch (hit.getRecommendationLevel()) {
            case "I" -> 1;
            case "IIa" -> 2;
            case "IIb" -> 3;
            case "III" -> 4;
            default -> 5;
        };
    }

    private String buildContext(List<GuidelineHit> hits) {
        StringBuilder ctx = new StringBuilder();
        for (int i = 0; i < hits.size(); i++) {
            GuidelineHit hit = hits.get(i);
            ctx.append(String.format(
                    "[资料%d] %s（%s, %s推荐/%s证据）\n%s\n\n",
                    i + 1,
                    hit.getTitle(),
                    hit.getSection(),
                    hit.getRecommendationLevel(),
                    hit.getEvidenceLevel(),
                    hit.getContent()
            ));
        }
        return ctx.toString();
    }
}
```

### 3.4 多轮对话与追问

医生通常会追问细化条件，需要保持上下文的连续性：

```java
@Service
public class MultiTurnQAService {

    @Autowired
    private EvidenceBasedQAService qaService;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final int MAX_HISTORY = 10;

    public QAAnswer chat(String sessionId, String message) {
        // 获取对话历史
        List<ChatHistory> history = getHistory(sessionId);
        history.add(new ChatHistory("user", message));

        // 如果是追问，在query中加入历史上下文
        String enrichedQuery = message;
        if (!history.isEmpty()) {
            enrichedQuery = enrichWithContext(message, history);
        }

        // 检索+问答
        ClinicalQuery query = ClinicalQuery.builder()
                .text(enrichedQuery)
                .build();

        QAAnswer answer = qaService.answer(query);

        // 保存历史
        history.add(new ChatHistory("assistant", answer.getAnswer()));
        saveHistory(sessionId, history);

        return answer;
    }

    /**
     * 如果是追问（缺少完整主语），从历史中补充上下文
     */
    private String enrichWithContext(String message, List<ChatHistory> history) {
        // 检测问句是否缺少主语（典型的追问句式）
        String[] followupPatterns = {
            "那.*呢", "如果.*呢", "还有.*吗", "为什么", "怎么.*呢",
            "剂量.*多少", "能用.*吗", "可以.*吗", "需要.*吗"
        };

        boolean isFollowup = false;
        for (String pattern : followupPatterns) {
            if (message.matches(".*" + pattern + ".*")) {
                isFollowup = true;
                break;
            }
        }

        if (isFollowup && history.size() >= 2) {
            // 取上一轮用户问题和系统回答作为上下文
            ChatHistory lastUserMsg = history.get(history.size() - 3); // 上一轮user
            String context = String.format("" +
                    "之前的问题和回答：\n问：%s\n答：%s\n\n当前追问：%s",
                    lastUserMsg.getContent(),
                    history.get(history.size() - 2).getContent(), // 上一轮assistant
                    message);
            return context;
        }

        return message;
    }

    private List<ChatHistory> getHistory(String sessionId) {
        String json = redisTemplate.opsForValue()
                .get("qa_session:" + sessionId);
        if (json == null) return new ArrayList<>();
        return JSON.parseArray(json, ChatHistory.class);
    }

    private void saveHistory(String sessionId, List<ChatHistory> history) {
        if (history.size() > MAX_HISTORY * 2) {
            history = history.subList(
                    history.size() - MAX_HISTORY * 2, history.size());
        }
        redisTemplate.opsForValue().set("qa_session:" + sessionId,
                JSON.toJSONString(history), 30, TimeUnit.MINUTES);
    }
}
```

## 五、技术亮点与难点

1. **指南效应期管理**：指南版本间的"继承与替换"关系需要明确管理。新指南发布后，旧版本不是直接删除，而是标记为"历史参考"，检索时默认优先最新版本。

2. **多种语言混合**：指南可能引用英文文献原文、药品英文名，需要混合检索能力。

3. **敏感信息阻断**：对于非执业医师的查询（如患者自诊），需要在Prompt中增加强免责声明，并限制用药推荐的具体剂量信息。
