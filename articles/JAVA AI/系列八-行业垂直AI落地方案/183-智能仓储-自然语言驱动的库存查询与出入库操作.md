# 智能仓储：自然语言驱动的库存查询与出入库操作，仓管说"还有多少货"AI直接告诉答案

## 一、仓库管理员的"查询地狱"

张伟是某电商仓库的仓管组长，管理着2万平方米的仓库，SKU超过5000个。每天他要打开ERP系统，在各种下拉菜单和筛选条件中反复操作：选择仓库区域→选择库位→输入SKU编码→点击查询→等待结果→导出Excel。

"这还不算最麻烦的，"张伟说，"最烦的是老板突然走过来问'蓝牙耳机A区还有多少？马上要发一批货，够不够2000件？'我就得当着老板的面，手忙脚乱地在系统里翻半天。"

普通仓库管理员每天至少进行50-80次库存查询操作，每次操作平均耗时3-5分钟。掌握复杂的ERP系统需要至少2周培训，新员工前3个月查询错误率高达15%。

**如果仓库管理系统能像问同事一样自然交流呢？**

"查一下A区蓝牙耳机的库存，再帮我看看最近7天的出库记录，如果库存不足2000就生成补货单。"

AI精确理解，一步完成。这就是智能仓储的核心——**用自然语言驱动仓储操作**。

## 二、行业痛点

### 仓储管理的"剪刀差"困境

中国物流行业正面临一个越来越大的剪刀差：一边是电商订单量年增长20%+，SKU数量爆炸式增长；另一边是仓储劳动力持续短缺，年轻人不愿从事"搬箱子"的重复劳动。这个剪刀差带来了仓储管理的系统性效率危机。

传统WMS/ERP系统在设计时追求的是"功能完备"，代价是"学习成本高"。一个典型WMS系统有上百个菜单项，执行一个简单操作需要多次点击。在用工流动性大的仓储行业，这意味着持续的培训成本和操作错误率。

自然语言交互是破局之道——降低了系统使用门槛，让一个第一天入职的临时工也能高效完成库存操作。

**痛点一：ERP操作门槛高**

传统WMS/ERP系统功能强大但界面复杂。一个简单的库存查询需要点击6-8次，培训一个合格的仓管员至少2周。在用工荒的背景下，这个门槛直接影响了招工效率。

**痛点二：多系统割裂**

仓管员日常操作至少涉及3个系统：WMS（仓储管理）、ERP（企业资源计划）、TMS（运输管理）。查一个信息要来回切换，效率极低。

**痛点三：数据实时性差**

仓库数据与销售数据之间存在延迟。客服承诺的"有货"，到了仓库发现实际库存已过期。自然语言查询能实时联动多系统的数据状态。

**痛点四：错误操作代价高**

ERP操作错误可能造成严重后果——出库单开错、库存数对不上、发货到错误地址。AI辅助能减少手误，提升操作正确性。

### 4.1 仓储意图定义与NLU引擎

```java
@Service
public class WarehouseNLUEngine {

    @Autowired
    private ChatLanguageModel chatModel;

    /**
     * 理解用户的自然语言仓储查询
     */
    public WarehouseIntent parseIntent(String userQuery, String userId) {
        String prompt = String.format("""
            你是仓库管理系统NLU引擎。将用户的自然语言请求解析为结构化的操作意图。

            已登录用户：%s (仓库操作员)
            用户请求：%s

            支持的操作类型：
            - INVENTORY_QUERY: 库存查询
            - INBOUND_RECORD: 入库操作
            - OUTBOUND_RECORD: 出库操作
            - STOCK_TRANSFER: 库位调拨
            - INVENTORY_ALERT: 库存预警
            - ORDER_STATUS: 订单/运单状态
            - REPORT_GENERATION: 报表生成
            - CHITCHAT: 闲聊/问候

            请输出JSON：
            {
              "intent": "操作类型",
              "confidence": 0.0-1.0,
              "entities": {
                "productName": "商品名称/关键词",
                "skuCode": "SKU编码(如有)",
                "warehouseZone": "仓库区域(如A区/B区)",
                "locationCode": "库位编码(如有)",
                "quantity": 数量,
                "timeRange": "时间范围(如最近7天/本月/2025-03)",
                "orderId": "订单号(如有)",
                "operation": "具体操作(查询/入库/出库/调拨)"
              },
              "requiresConfirmation": true/false
            }
            """, userId, userQuery);

        String response = chatModel.generate(prompt);
        return parseWarehouseIntent(response);
    }

    private WarehouseIntent parseWarehouseIntent(String json) {
        try {
            String block = json.substring(json.indexOf('{'), json.lastIndexOf('}') + 1);
            ObjectMapper mapper = new ObjectMapper();
            JsonNode root = mapper.readTree(block);

            return WarehouseIntent.builder()
                    .intent(root.get("intent").asText())
                    .confidence(root.get("confidence").asDouble())
                    .entities(parseEntities(root.get("entities")))
                    .requiresConfirmation(root.get("requiresConfirmation").asBoolean())
                    .build();
        } catch (Exception e) {
            return WarehouseIntent.builder().intent("UNCLEAR").confidence(0.0).build();
        }
    }
}
```

### 4.2 自然语言到SQL的转换

```java
@Service
public class NaturalLanguageToSQLService {

    @Autowired
    private ChatLanguageModel chatModel;

    @Autowired
    private JdbcTemplate jdbcTemplate;

    // 数据库Schema提供给LLM
    private static final String DB_SCHEMA = """
        数据库Schema:
        表 inventory (库存表):
          - id BIGINT PRIMARY KEY
          - sku_code VARCHAR(50) -- SKU编码
          - product_name VARCHAR(200) -- 商品名称
          - category VARCHAR(100) -- 品类
          - warehouse_zone VARCHAR(10) -- 仓库区域(A/B/C/D区)
          - location_code VARCHAR(20) -- 库位编码(如A-03-15)
          - quantity INT -- 库存数量
          - available_quantity INT -- 可用库存
          - locked_quantity INT -- 锁定库存(已下单未发货)
          - unit VARCHAR(20) -- 单位(件/箱/个)
          - last_updated DATETIME

        表 inbound_record (入库记录):
          - id BIGINT PRIMARY KEY
          - sku_code VARCHAR(50)
          - quantity INT
          - warehouse_zone VARCHAR(10)
          - inbound_time DATETIME
          - operator VARCHAR(50)

        表 outbound_record (出库记录):
          - id BIGINT PRIMARY KEY
          - sku_code VARCHAR(50)
          - quantity INT
          - order_id VARCHAR(50)
          - outbound_time DATETIME
          - operator VARCHAR(50)
        """;

    /**
     * 将自然语言查询转换为SQL并执行
     */
    public QueryResult executeNaturalLanguageQuery(WarehouseIntent intent) {
        // 当用户查询意图明确时，直接生成SQL
        if (intent.getConfidence() > 0.85) {
            String sql = generateSQL(intent);
            if (sql != null) {
                List<Map<String, Object>> rows = jdbcTemplate.queryForList(sql);
                return QueryResult.success(rows, sql);
            }
        }

        // 降级：使用LLM判断如何查询
        return queryWithLLM(intent);
    }

    private String generateSQL(WarehouseIntent intent) {
        Map<String, String> e = intent.getEntities();

        return switch (intent.getIntent()) {
            case "INVENTORY_QUERY" -> buildInventoryQuery(e);
            case "OUTBOUND_RECORD" -> buildOutboundRecordQuery(e);
            case "INBOUND_RECORD" -> buildInboundRecordQuery(e);
            case "INVENTORY_ALERT" -> buildAlertQuery(e);
            default -> null;
        };
    }

    private String buildInventoryQuery(Map<String, String> e) {
        StringBuilder sql = new StringBuilder(
            "SELECT sku_code, product_name, category, warehouse_zone, " +
            "location_code, quantity, available_quantity, locked_quantity, unit " +
            "FROM inventory WHERE 1=1"
        );

        if (e.containsKey("skuCode")) {
            sql.append(" AND sku_code = '").append(sanitize(e.get("skuCode"))).append("'");
        }
        if (e.containsKey("productName")) {
            sql.append(" AND product_name LIKE '%").append(sanitize(e.get("productName"))).append("%'");
        }
        if (e.containsKey("warehouseZone")) {
            sql.append(" AND warehouse_zone = '").append(sanitize(e.get("warehouseZone"))).append("'");
        }
        if (e.containsKey("locationCode")) {
            sql.append(" AND location_code = '").append(sanitize(e.get("locationCode"))).append("'");
        }

        sql.append(" ORDER BY warehouse_zone, location_code LIMIT 100");
        return sql.toString();
    }

    private String buildOutboundRecordQuery(Map<String, String> e) {
        return String.format(
            "SELECT o.sku_code, i.product_name, o.quantity, o.order_id, " +
            "o.outbound_time, o.operator " +
            "FROM outbound_record o " +
            "LEFT JOIN inventory i ON o.sku_code = i.sku_code " +
            "WHERE o.sku_code LIKE '%%%s%%' " +
            "AND o.outbound_time >= DATE_SUB(NOW(), INTERVAL 7 DAY) " +
            "ORDER BY o.outbound_time DESC LIMIT 50",
            sanitize(e.getOrDefault("productName", ""))
        );
    }

    private String buildAlertQuery(Map<String, String> e) {
        return "SELECT sku_code, product_name, warehouse_zone, location_code, " +
               "quantity, available_quantity FROM inventory " +
               "WHERE available_quantity < 50 ORDER BY available_quantity ASC LIMIT 20";
    }

    private String sanitize(String input) {
        return input.replaceAll("['\"\\\\;]", "");
    }
}
```

### 4.3 出库操作Agent

```java
@Service
public class OutboundOperationAgent {

    @Autowired
    private ChatLanguageModel chatModel;

    @Autowired
    private NaturalLanguageToSQLService sqlService;

    @Autowired
    private WarehouseNLUEngine nluEngine;

    /**
     * 自然语言驱动的出库操作
     * 用户例："把A区蓝牙耳机出库200件，发到订单ORD202503001"
     */
    public OperationResult processOutbound(String userMessage, String operatorId) {
        // Step 1: 解析意图
        WarehouseIntent intent = nluEngine.parseIntent(userMessage, operatorId);

        // Step 2: 如果意图需要确认，先确认
        if (intent.isRequiresConfirmation()) {
            String confirmMsg = generateConfirmation(intent);
            return OperationResult.needConfirmation(confirmMsg, intent);
        }

        // Step 3: 查询库存是否充足
        QueryResult stockCheck = checkStock(intent);

        // Step 4: 库存不足 → 提示
        if (!isStockSufficient(stockCheck, intent)) {
            return OperationResult.insufficientStock(stockCheck);
        }

        // Step 5: 执行出库事务
        OutboundTransaction txn = executeOutboundTransaction(intent, operatorId);

        // Step 6: 生成出库单并返回结果
        return OperationResult.success(txn, generateOutboundSummary(txn));
    }

    private QueryResult checkStock(WarehouseIntent intent) {
        Map<String, String> e = intent.getEntities();
        String sql = String.format(
            "SELECT sku_code, product_name, warehouse_zone, location_code, " +
            "available_quantity, locked_quantity FROM inventory " +
            "WHERE product_name LIKE '%%%s%%'",
            sanitize(e.getOrDefault("productName", ""))
        );
        if (e.containsKey("warehouseZone")) {
            sql += " AND warehouse_zone = '" + sanitize(e.get("warehouseZone")) + "'";
        }
        List<Map<String, Object>> rows = jdbcTemplate.queryForList(sql);
        return QueryResult.success(rows, sql);
    }

    private boolean isStockSufficient(QueryResult checkResult, WarehouseIntent intent) {
        int required = Integer.parseInt(intent.getEntities().getOrDefault("quantity", "0"));
        int totalAvailable = checkResult.getRows().stream()
                .mapToInt(row -> (int) row.getOrDefault("available_quantity", 0))
                .sum();
        return totalAvailable >= required;
    }

    @Transactional
    private OutboundTransaction executeOutboundTransaction(WarehouseIntent intent, String operatorId) {
        Map<String, String> e = intent.getEntities();
        int quantity = Integer.parseInt(e.getOrDefault("quantity", "0"));
        String productName = e.get("productName");
        String orderId = e.getOrDefault("orderId", "MANUAL-" + System.currentTimeMillis());

        // 扣减库存
        String updateSql = """
            UPDATE inventory SET available_quantity = available_quantity - ?,
            locked_quantity = locked_quantity + ?, last_updated = NOW()
            WHERE product_name LIKE ? AND available_quantity >= ? LIMIT 1
            """;
        int updated = jdbcTemplate.update(updateSql, quantity, quantity,
                "%" + productName + "%", quantity);

        if (updated == 0) {
            throw new BusinessException("出库失败：库存不足或商品不存在");
        }

        // 插入出库记录
        String insertSql = """
            INSERT INTO outbound_record (sku_code, quantity, order_id, operator, outbound_time)
            VALUES ((SELECT sku_code FROM inventory WHERE product_name LIKE ? LIMIT 1),
                    ?, ?, ?, NOW())
            """;
        jdbcTemplate.update(insertSql, "%" + productName + "%", quantity, orderId, operatorId);

        return OutboundTransaction.builder()
                .productName(productName)
                .quantity(quantity)
                .orderId(orderId)
                .operator(operatorId)
                .timestamp(LocalDateTime.now())
                .build();
    }

    private String generateOutboundSummary(OutboundTransaction txn) {
        return String.format("""
            ✅ 出库操作成功！
            - 商品：%s
            - 数量：%d件
            - 关联订单：%s
            - 操作人：%s
            - 时间：%s

            库存已自动更新，出库单已生成。
            """, txn.getProductName(), txn.getQuantity(), txn.getOrderId(),
                txn.getOperator(), txn.getTimestamp().toString());
    }
}
```

### 4.4 对话式库存查询

```java
@Service
public class ConversationalInventoryService {

    @Autowired
    private WarehouseNLUEngine nluEngine;

    @Autowired
    private NaturalLanguageToSQLService sqlService;

    @Autowired
    private ChatLanguageModel chatModel;

    /**
     * 处理自然语言查询，返回人性化的回答
     */
    public String conversationalQuery(String userMessage, String userId) {
        // 解析意图
        WarehouseIntent intent = nluEngine.parseIntent(userMessage, userId);

        if (intent.getConfidence() < 0.5) {
            return "抱歉，我没太理解您的问题。您可以试试这样问：" +
                   "\"A区蓝牙耳机库存\" \"最近7天出库记录\" \"库存不足50的预警\"";
        }

        // 执行查询
        QueryResult result = sqlService.executeNaturalLanguageQuery(intent);
        List<Map<String, Object>> data = result.getRows();

        if (data.isEmpty()) {
            return "查询结果为空。可能是商品不存在或没有相关记录，要不要换个条件试试？";
        }

        // 用LLM生成自然语言回复
        String summary = generateNaturalLanguageSummary(data, intent);
        return summary;
    }

    private String generateNaturalLanguageSummary(List<Map<String, Object>> data,
                                                    WarehouseIntent intent) {
        String dataStr = data.stream()
                .map(Object::toString)
                .collect(Collectors.joining("\n"));

        return chatModel.generate(String.format("""
            将以下查询结果用自然语言总结回复用户。语气友好、简洁。

            查询意图：%s
            结果数据：
            %s

            要求：
            1. 先概括总体情况
            2. 列出关键数据
            3. 如果数据异常（如库存过低），主动提醒
            4. 结尾询问是否需要进一步操作
            5. 回复不超过200字
            """, intent.getIntent(), dataStr));
    }
}
```

## 七、总结

智能仓储的本质不是"用语音替代键盘"，而是**降低仓管员的认知负荷**——让一个刚入职的新人能像老员工一样高效操作。自然语言驱动不仅提升效率，更是"去经验化"——把系统的使用门槛从"两周培训"降到"会说人话就行"。对于面临着用工荒的仓储行业，这可能是最务实的AI应用。

### 安全红线——NL2SQL的防护

自然语言转SQL有一个绕不开的安全问题：SQL注入。虽然理论上LLM不会恶意生成注入攻击，但用户的输入可能诱导LLM生成危险的SQL。我们的防护策略是三层：

**第一层：输入过滤。** 对用户输入做正则清洗，移除所有SQL关键字（DROP、DELETE、TRUNCATE、UPDATE、INSERT INTO）和注释符号（--、/*）。

**第二层：SQL白名单校验。** 生成的SQL在执行前过一遍语法解析器，拒绝任何包含多语句（用分号分隔）、子查询、UNION操作的SQL。我们的NL2SQL场景只需要简单的SELECT查询，复杂SQL直接拒绝。

**第三层：数据库权限隔离。** 为NL2SQL创建专门的数据库用户，只授予SELECT权限，禁止任何写操作。这是最后一道防线——即使前面两层被绕过，数据库层面也不会造成数据破坏。

**三层防护上线后，零安全事故。** 这也是ToB场景下客户最关心的合规问题之一。
