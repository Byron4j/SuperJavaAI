## 二、审计日志的五个维度：不止记个请求日志那么简单

### 2.1 传统 API 日志 vs AI 审计日志

很多人第一反应："不就是加个请求拦截器记日志吗？"

来看看这俩的区别：

| 维度 | 传统 API 日志 | AI 模型审计日志 |
|------|--------------|----------------|
| 请求体 | 记录原始 JSON | 需要脱敏 + Token 估算 |
| 响应体 | 通常不记录（太大） | 必须记录，涉及合规 |
| 成本 | 不关心 | 精确到每次调用的 Token 消耗 |
| 模型版本 | 不适用 | 必须记录（GPT-4 vs GPT-4o 成本差 2-4 倍） |
| 敏感词检测 | 不需要 | 必须（防止数据泄露） |
| 留存周期 | 7-30 天 | 至少 1 年，金融通常 3-5 年 |

## 三、核心实现：AOP + 异步落库 + 事件驱动

### 3.1 整体架构

```
用户请求 → Controller → AI调用服务 → [AOP拦截] → 审计事件发布
                                                    ↓
                                              Kafka/消息队列
                                                    ↓
                                              审计日志消费者 → ES + MySQL 双写
```

**为什么用异步？** 审计日志写得再快，也是额外的 I/O 开销。在高并发下用同步写库，P99 延迟会从 2 秒飙升到 5 秒以上。异步事件驱动是最佳实践。

### 3.2 核心注解定义

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface AuditLog {
    
    /** 审计动作类型 */
    String actionType() default "MODEL_CALL";
    
    /** 是否记录 Prompt 原文（金融级建议 true） */
    boolean recordPrompt() default true;
    
    /** 是否记录 Completion 原文 */
    boolean recordCompletion() default true;
    
    /** 敏感等级: LOW/MEDIUM/HIGH/CRITICAL */
    String sensitivity() default "MEDIUM";
}
```

### 3.3 AOP 切面实现

```java
@Aspect
@Component
@Slf4j
public class ModelAuditAspect {

    @Autowired
    private AuditEventPublisher eventPublisher;
    
    @Autowired
    private SensitiveWordFilter sensitiveFilter;
    
    @Autowired
    private TokenCostCalculator costCalculator;

    @Around("@annotation(auditLog)")
    public Object audit(ProceedingJoinPoint joinPoint, AuditLog auditLog) {
        // 1. 构造审计日志基础数据
        ModelAuditLog audit = new ModelAuditLog();
        audit.setRequestTime(System.currentTimeMillis());
        audit.setTraceId(MDC.get("traceId"));
        audit.setUserId(AuditContextHolder.getCurrentUserId());
        audit.setUserName(AuditContextHolder.getCurrentUserName());
        audit.setDepartment(AuditContextHolder.getCurrentDepartment());
        audit.setSource(AuditContextHolder.getCurrentSource());
        audit.setClientIp(AuditContextHolder.getCurrentIp());
        
        // 2. 从方法参数提取模型名、Prompt 等
        Object[] args = joinPoint.getArgs();
        for (Object arg : args) {
            if (arg instanceof ModelRequest) {
                ModelRequest req = (ModelRequest) arg;
                audit.setModelName(req.getModel());
                audit.setPrompt(req.getMessages().stream()
                    .map(Message::getContent)
                    .collect(Collectors.joining("\n")));
                audit.setPromptDigest(digest(audit.getPrompt()));
            }
        }
        
        // 3. 敏感词检测（在发送模型之前）
        if (sensitiveFilter.containsSensitiveWord(audit.getPrompt())) {
            audit.setIsBlocked(true);
            audit.setBlockReason(sensitiveFilter.hitWords(audit.getPrompt()).toString());
            eventPublisher.publish(audit);
            throw new SensitiveContentBlockedException("内容包含敏感词，已被拦截");
        }
        
        // 4. 执行原始方法（调用模型）
        Object result;
        try {
            result = joinPoint.proceed();
        } catch (Throwable e) {
            audit.setCompletion("ERROR: " + e.getMessage());
            audit.setEndTime(System.currentTimeMillis());
            eventPublisher.publish(audit);
            throw new RuntimeException(e);
        }
        
        // 5. 提取模型返回
        if (result instanceof ModelResponse) {
            ModelResponse resp = (ModelResponse) result;
            audit.setCompletion(resp.getContent());
            audit.setCompletionDigest(digest(audit.getCompletion()));
            audit.setPromptTokens(resp.getUsage().getPromptTokens());
            audit.setCompletionTokens(resp.getUsage().getCompletionTokens());
            audit.setTotalTokens(resp.getUsage().getTotalTokens());
            audit.setFirstTokenTime(resp.getFirstTokenTime());
        }
        
        audit.setEndTime(System.currentTimeMillis());
        
        // 6. 计算成本
        audit.setCost(costCalculator.calculate(
            audit.getModelName(), 
            audit.getPromptTokens(), 
            audit.getCompletionTokens()
        ));
        
        // 7. 异步发布审计事件
        eventPublisher.publish(audit);
        
        return result;
    }
}
```

### 3.4 成本计算器：精确到 6 位小数

```java
@Component
public class TokenCostCalculator {

    /** 模型定价表（元/1000 tokens） */
    private static final Map<String, Pricing> PRICING = Map.of(
        "gpt-4o", new Pricing(0.035, 0.105),       // 输入/输出
        "gpt-4o-mini", new Pricing(0.00105, 0.0042),
        "gpt-4-turbo", new Pricing(0.07, 0.21),
        "claude-3-opus", new Pricing(0.105, 0.525),
        "claude-3-sonnet", new Pricing(0.021, 0.105),
        "deepseek-v3", new Pricing(0.0014, 0.0028),
        "qwen-max", new Pricing(0.028, 0.084),
        "local-model", new Pricing(0, 0)  // 本地模型
    );
    
    @Autowired
    private PricingConfigDAO pricingConfigDAO;

    /**
     * 计算单次调用成本
     * @return 成本（人民币元）
     */
    public double calculate(String modelName, int promptTokens, int completionTokens) {
        Pricing pricing = getPricing(modelName);
        
        double promptCost = (promptTokens / 1000.0) * pricing.getInputPrice();
        double completionCost = (completionTokens / 1000.0) * pricing.getOutputPrice();
        double totalCost = promptCost + completionCost;
        
        // 精确到小数点后 6 位
        return Math.round(totalCost * 1_000_000.0) / 1_000_000.0;
    }
    
    /**
     * 获取定价，优先从数据库读取（支持动态调价）
     */
    private Pricing getPricing(String modelName) {
        Pricing dbPricing = pricingConfigDAO.findByModelName(modelName);
        if (dbPricing != null) {
            return dbPricing;
        }
        return PRICING.getOrDefault(modelName, new Pricing(0.01, 0.03));
    }
    
    @Data
    @AllArgsConstructor
    public static class Pricing {
        private double inputPrice;   // 输入价格（元/1000 tokens）
        private double outputPrice;  // 输出价格（元/1000 tokens）
    }
}
```

## 四、数据存储方案：MySQL + Elasticsearch 双写

### 4.1 为什么双写？

| 需求 | MySQL | Elasticsearch |
|------|-------|---------------|
| 精确存储、永不丢失 | ✅ 核心能力 | ❌ 可能丢数据 |
| 全文检索（Prompt 内容搜索） | ❌ LIKE 太慢 | ✅ 天生支持 |
| 聚合分析（按部门/模型/时间） | ❌ 大表 GROUP BY 卡死 | ✅ 秒级聚合 |
| 数据归档/备份 | ✅ 易于导出 | ❌ 不好操作 |
| 合规留存（3-5 年） | ✅ 归档到 OSS | ❌ 成本太高 |

### 4.3 敏感数据加密存储

```java
@Component
public class AuditDataEncryptor {

    @Value("${audit.encryption.key}")
    private String encryptionKey;  // 32字节 AES-256 密钥
    
    /**
     * 加密保存内容，加密后存 MySQL，原文同步到 ES
     */
    public String encrypt(String plainText) {
        try {
            Cipher cipher = Cipher.getInstance("AES/GCM/NoPadding");
            SecretKeySpec keySpec = new SecretKeySpec(
                Base64.getDecoder().decode(encryptionKey), "AES");
            byte[] iv = new byte[12];
            SecureRandom.getInstanceStrong().nextBytes(iv);
            GCMParameterSpec gcmSpec = new GCMParameterSpec(128, iv);
            cipher.init(Cipher.ENCRYPT_MODE, keySpec, gcmSpec);
            byte[] encrypted = cipher.doFinal(plainText.getBytes(StandardCharsets.UTF_8));
            
            // IV + 密文 Base64 编码
            byte[] combined = new byte[12 + encrypted.length];
            System.arraycopy(iv, 0, combined, 0, 12);
            System.arraycopy(encrypted, 0, combined, 12, encrypted.length);
            return Base64.getEncoder().encodeToString(combined);
        } catch (Exception e) {
            throw new RuntimeException("加密失败", e);
        }
    }
}
```

### 5.1 每日成本汇总（ES 聚合查询）

```java
@RestController
@RequestMapping("/api/audit/dashboard")
public class AuditDashboardController {

    @Autowired
    private ElasticsearchClient esClient;

    /**
     * 按模型统计今日成本
     */
    @GetMapping("/cost-by-model")
    public List<ModelCostVO> getCostByModelToday() {
        long todayStart = LocalDate.now()
            .atStartOfDay(ZoneId.systemDefault())
            .toInstant().toEpochMilli();
        
        SearchRequest request = SearchRequest.of(s -> s
            .index("model_audit_log")
            .query(q -> q.range(r -> r
                .field("request_time")
                .gte(String.valueOf(todayStart))))
            .aggregations("by_model", a -> a
                .terms(t -> t.field("model_name").size(20))
                .aggregations("total_cost", sa -> sa
                    .sum(sum -> sum.field("cost")))
                .aggregations("call_count", sa -> sa
                    .valueCount(vc -> vc.field("model_name"))))
            .size(0)
        );
        
        // 解析聚合结果...
        return parseCostAggregation(esClient.search(request, Map.class));
    }
    
    /**
     * 用户用量排行榜
     */
    @GetMapping("/top-users")
    public List<UserCostVO> getTopUsers(
            @RequestParam(defaultValue = "7") int days) {
        
        long since = System.currentTimeMillis() - days * 86400000L;
        
        SearchRequest request = SearchRequest.of(s -> s
            .index("model_audit_log")
            .query(q -> q.range(r -> r
                .field("request_time")
                .gte(String.valueOf(since))))
            .aggregations("by_user", a -> a
                .terms(t -> t.field("user_id").size(30))
                .aggregations("total_cost", sa -> sa
                    .sum(sum -> sum.field("cost"))))
            .size(0)
        );
        
        return parseUserAggregation(esClient.search(request, Map.class));
    }
}
```

### 5.2 成本异常告警

```java
@Component
@Slf4j
public class CostAlertService {

    @Autowired
    private ElasticsearchClient esClient;
    
    @Autowired
    private AlertSender alertSender;

    /** 每小时检查一次预算 */
    @Scheduled(fixedRate = 3600000)
    public void checkBudget() {
        double todayCost = getTodayCost();
        double budgetLimit = 5000.0;  // 日预算 5000 元
        
        if (todayCost > budgetLimit * 0.8) {
            alertSender.sendWarn(String.format(
                "⚠️ 今日模型调用成本已达 %.2f 元（预算 %.2f 元的 %.0f%%），请关注",
                todayCost, budgetLimit, todayCost / budgetLimit * 100
            ));
        }
        
        // 单用户异常检测
        Map<String, Double> userCosts = getTopUserCosts(5);
        for (Map.Entry<String, Double> entry : userCosts.entrySet()) {
            if (entry.getValue() > budgetLimit * 0.3) {
                alertSender.sendWarn(String.format(
                    "🚨 用户 %s 今日消费 %.2f 元，超过单用户阈值",
                    entry.getKey(), entry.getValue()
                ));
            }
        }
    }
}
```

## 八、生产环境注意事项

1. **密钥管理**：加密密钥绝不能硬编码，必须通过 HashiCorp Vault 或云 KMS 管理
2. **日志清理**：明文 Prompt 和 Completion 在同步到 ES 后，MySQL 仅保留加密版本
3. **合规留存**：金融行业至少保留 3 年，建议冷数据归档至对象存储（OSS/S3）
4. **性能监控**：ES 索引按天滚动，避免单索引过大导致写入延迟
5. **权限控制**：审计日志查询接口必须鉴权，普通用户只能看自己的记录
