## 引言：栈与队列的本质

栈（Stack）与队列（Queue）不是简单的"容器"，而是两种** fundamental access patterns（基本访问模式）**，它们定义了数据存取的时序约束。

核心认知：

```
数据结构的本质 = 数据的存储方式 + 数据的操作方式

栈的本质：LIFO（Last In First Out）
  - 时间维度：后进入的数据先被访问
  - 空间维度：所有操作在单一端点进行
  - 数学本质：一个只允许在表尾进行插入和删除的线性表

队列的本质：FIFO（First In First Out）
  - 时间维度：先进入的数据先被访问
  - 空间维度：插入在一端，删除在另一端
  - 数学本质：一个允许在一端插入、另一端删除的线性表

关键洞察：栈与队列的"限制"恰恰是其"力量"的来源。
  - 栈的LIFO特性天然匹配递归、回溯、嵌套结构的处理
  - 队列的FIFO特性天然匹配缓冲、调度、广度优先遍历
```

**为什么这两个看似简单的结构如此重要？**

1. **计算模型的基础**：图灵机、λ演算、下推自动机等计算模型都依赖栈作为核心数据结构
2. **程序执行的基石**：JVM的方法调用栈、操作系统的中断栈、CPU的硬件栈
3. **算法设计的利器**：从DFS到BFS，从括号匹配到滑动窗口，无处不在
4. **系统架构的核心**：消息队列、任务调度、请求缓冲、事件驱动架构

## 理论基础：为什么栈与队列如此重要

### 1. 栈与队列的数学定义

#### 形式化定义

**栈的形式化定义：**

栈是一个二元组 $S = (D, R)$，其中：
- $D$ 是数据元素的有限集合
- $R$ 是 $D$ 上的关系集合，仅包含一个关系：$R = \{<a_{i-1}, a_i> \mid a_{i-1}, a_i \in D, i = 2, ..., n\}$

栈的基本操作构成一个代数系统 $(S, \text{push}, \text{pop}, \text{peek}, \text{isEmpty})$，满足以下公理：

1. **初始化公理**：$\text{isEmpty}(\text{newStack}()) = \text{true}$
2. **空栈判定**：$\text{isEmpty}(s) \Rightarrow \text{pop}(s) = \text{ERROR} \land \text{peek}(s) = \text{ERROR}$
3. **push后非空**：$\neg \text{isEmpty}(\text{push}(s, e))$
4. **peek公理**：$\text{peek}(\text{push}(s, e)) = e$
5. **pop公理**：$\text{pop}(\text{push}(s, e)) = s$

**队列的形式化定义：**

队列是一个二元组 $Q = (D, R)$，其中：
- $D$ 是数据元素的有限集合
- $R = \{<a_i, a_{i+1}> \mid a_i, a_{i+1} \in D, i = 1, ..., n-1\}$

队列的操作公理系统 $(Q, \text{enqueue}, \text{dequeue}, \text{front}, \text{isEmpty})$：

1. **初始化公理**：$\text{isEmpty}(\text{newQueue}()) = \text{true}$
2. **空队列判定**：$\text{isEmpty}(q) \Rightarrow \text{dequeue}(q) = \text{ERROR} \land \text{front}(q) = \text{ERROR}$
3. **enqueue后非空**：$\neg \text{isEmpty}(\text{enqueue}(q, e))$
4. **front公理**（单元素）：$\text{front}(\text{enqueue}(\text{newQueue}(), e)) = e$
5. **dequeue公理**（单元素）：$\text{dequeue}(\text{enqueue}(\text{newQueue}(), e)) = \text{newQueue}()$

#### Catalan数与栈的合法性

包含 $n$ 次 push 和 $n$ 次 pop 的操作序列，合法序列数（任意前缀中 push 次数 $\geq$ pop 次数）为 Catalan 数：

$$C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!n!}$$

**证明（反射原理）：**

总序列数为 $\binom{2n}{n}$（从 $2n$ 个位置中选择 $n$ 个放 push）。

不合法序列：存在某个前缀，pop 次数 > push 次数。找到第一个这样的位置，将该位置之前的所有 push/pop 互换，得到一个包含 $(n+1)$ 个 push 和 $(n-1)$ 个 pop 的序列。

这种映射是双射，因此不合法序列数为 $\binom{2n}{n+1}$。

合法序列数：
$$C_n = \binom{2n}{n} - \binom{2n}{n+1} = \frac{(2n)!}{n!n!} - \frac{(2n)!}{(n+1)!(n-1)!} = \frac{1}{n+1}\binom{2n}{n}$$

**示例**：$n = 3$ 时，$C_3 = 5$ 种合法序列：
- push, push, push, pop, pop, pop → 输出序列：3, 2, 1
- push, push, pop, push, pop, pop → 输出序列：2, 3, 1
- push, push, pop, pop, push, pop → 输出序列：2, 1, 3
- push, pop, push, push, pop, pop → 输出序列：1, 3, 2
- push, pop, push, pop, push, pop → 输出序列：1, 2, 3

### 2. 复杂度分析与均摊分析

#### 栈操作的时间复杂度

| 操作 | 数组实现 | 链表实现 |
|------|----------|----------|
| push | $O(1)$ 均摊 | $O(1)$ |
| pop | $O(1)$ | $O(1)$ |
| peek | $O(1)$ | $O(1)$ |
| isEmpty | $O(1)$ | $O(1)$ |
| 空间 | $O(n)$ | $O(n)$ |

#### 均摊分析：动态数组扩容

**问题**：基于数组的栈在容量满时需要扩容，如何分析其性能？

**假设**：初始容量为 1，每次扩容为当前容量的 2 倍。

**聚合分析法（Aggregate Analysis）：**

对 $n$ 次 push 操作：
- 大多数 push：直接写入，成本 = 1
- 第 1, 2, 4, 8, ..., $2^k$ 次 push 时需要扩容

总成本：
$$T(n) = \underbrace{n}_{\text{基本push}} + \underbrace{(1 + 2 + 4 + ... + 2^{\lfloor \log_2 n \rfloor})}_{\text{扩容成本}}$$

$$T(n) = n + (2^{\lfloor \log_2 n \rfloor + 1} - 1) < n + 2n = 3n$$

均摊成本：
$$\text{Amortized cost} = \frac{T(n)}{n} < \frac{3n}{n} = O(1)$$

**记账法（Accounting Method）：**

为每次 push 操作收取 3 个单位的费用：
- 1 单位：支付当前 push 的基本成本
- 1 单位：预存，用于将来该元素的复制（扩容时）
- 1 单位：预存，用于将来帮助复制更早的元素

当容量为 $m$ 时扩容到 $2m$，需要将 $m$ 个元素复制到新数组。但此时我们已经存了 $m$ 个单位的信用（每个元素存了1个），刚好支付复制成本。

**势能法（Potential Method）：**

定义势函数：$\Phi(D_i) = 2 \times \text{num}_i - \text{size}_i$

其中 num_i 是元素个数，size_i 是数组容量。

- 初始：$\Phi(D_0) = 0$
- 扩容前（num = size = m）：$\Phi = 2m - m = m$
- 扩容后（num = m, size = 2m）：$\Phi = 2m - 2m = 0$

均摊成本 = 实际成本 + $\Delta \Phi$

对于非扩容 push：
- 实际成本 = 1
- $\Delta \Phi = (2(n+1) - m) - (2n - m) = 2$
- 均摊成本 = $1 + 2 = 3 = O(1)$

对于扩容 push（从 m 到 2m）：
- 实际成本 = $m + 1$（复制 m 个元素 + 新元素写入）
- $\Delta \Phi = (2(m+1) - 2m) - (2m - m) = 2 - m$
- 均摊成本 = $(m + 1) + (2 - m) = 3 = O(1)$

#### 队列操作的均摊分析

循环队列的 enqueue 操作均摊分析类似，但 dequeue 操作不需要扩容。然而，循环队列在多次 enqueue/dequeue 后可能出现"假溢出"，需要重新排列元素（如果不用 size 字段）。

使用 size 字段的循环队列：
- enqueue：$O(1)$ 均摊（可能需要扩容）
- dequeue：$O(1)$
- 扩容时需要将所有元素按顺序复制到新数组：$O(n)$，但均摊仍为 $O(1)$

### 3. 栈与递归的等价性

**定理**：任何递归算法都可以改写成使用显式栈的迭代算法，反之亦然。

**证明思路**：
- 递归调用时，系统隐式维护一个调用栈，保存：返回地址、局部变量、参数
- 显式栈模拟时，手动保存相同信息

**示例：递归 vs 显式栈**

```
递归计算阶乘：
fact(n):
  IF n <= 1: RETURN 1
  RETURN n * fact(n-1)

调用栈状态（fact(4)）：
┌─────────────┐
│ fact(1)=1   │ ←── 栈顶（最先返回）
├─────────────┤
│ fact(2)=2*1 │
├─────────────┤
│ fact(3)=3*2 │
├─────────────┤
│ fact(4)=4*6 │ ←── 栈底（最先调用）
└─────────────┘

显式栈模拟：
stack = [4, 3, 2, 1]  // 压入参数
result = 1
WHILE !stack.isEmpty():
  n = stack.pop()
  result *= n
```

## 栈的深度剖析

### 栈的数学定义与性质

**栈的基本性质：**

1. **封闭性**：栈操作不会改变元素的相对顺序（LIFO顺序内）
2. **可逆性**：对栈执行 push(e) 后 pop()，栈恢复原状
3. **幂等性**：连续两次 peek() 返回相同结果
4. **单调性**：栈的大小随 push 增加，随 pop 减少

**栈的代数结构：**

栈与空栈元素 $\epsilon$ 构成一个幺半群（Monoid）：
- 二元运算：栈的连接（concatenation），但需要保持LIFO语义
- 单位元：空栈
- 结合律：$(s_1 \cdot s_2) \cdot s_3 = s_1 \cdot (s_2 \cdot s_3)$（在LIFO语义下成立）

### 栈的抽象数据类型（ADT）

```java
/**
 * 栈的抽象数据类型定义

 */
public interface StackADT<T> {
    /**
     * 将元素压入栈顶
     * 前置条件：无
     * 后置条件：栈顶为e，栈大小增加1
     */
    void push(T element);
    
    /**
     * 弹出栈顶元素
     * 前置条件：!isEmpty()
     * 后置条件：返回原栈顶元素，栈大小减少1
     */
    T pop();
    
    /**
     * 查看栈顶元素（不弹出）
     * 前置条件：!isEmpty()
     * 后置条件：栈不变
     */
    T peek();
    
    /**
     * 判断栈是否为空
     */
    boolean isEmpty();
    
    /**
     * 返回栈中元素个数
     */
    int size();
    
    /**
     * 清空栈
     */
    void clear();
}
```

### 基于数组的实现与扩容机制

#### 完整实现（含扩容缩容）

```java
import java.util.Arrays;
import java.util.EmptyStackException;

/**
 * 基于动态数组的栈实现
 * 支持自动扩容和缩容，优化内存使用
 */
public class ArrayStack<T> implements StackADT<T> {
    private static final int DEFAULT_CAPACITY = 10;
    private static final double GROWTH_FACTOR = 2.0;
    private static final double SHRINK_THRESHOLD = 0.25; // 当使用率低于25%时缩容
    
    private Object[] data;
    private int top; // 指向栈顶元素，-1表示空栈
    
    public ArrayStack() {
        this(DEFAULT_CAPACITY);
    }
    
    public ArrayStack(int initialCapacity) {
        if (initialCapacity <= 0) {
            throw new IllegalArgumentException("Initial capacity must be positive");
        }
        data = new Object[initialCapacity];
        top = -1;
    }
    
    @Override
    public void push(T element) {
        ensureCapacity();
        data[++top] = element;
    }
    
    @Override
    @SuppressWarnings("unchecked")
    public T pop() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        T element = (T) data[top];
        data[top--] = null; // 帮助GC，防止内存泄漏
        shrinkIfNeeded();
        return element;
    }
    
    @Override
    @SuppressWarnings("unchecked")
    public T peek() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        return (T) data[top];
    }
    
    @Override
    public boolean isEmpty() {
        return top == -1;
    }
    
    @Override
    public int size() {
        return top + 1;
    }
    
    @Override
    public void clear() {
        // 帮助GC
        for (int i = 0; i <= top; i++) {
            data[i] = null;
        }
        top = -1;
        // 缩容到默认大小
        if (data.length > DEFAULT_CAPACITY) {
            data = new Object[DEFAULT_CAPACITY];
        }
    }
    
    /**
     * 查看栈底元素（调试用，非标准操作）
     */
    @SuppressWarnings("unchecked")
    public T bottom() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        return (T) data[0];
    }
    
    /**
     * 获取当前容量
     */
    public int capacity() {
        return data.length;
    }
    
    private void ensureCapacity() {
        if (top == data.length - 1) {
            grow();
        }
    }
    
    private void grow() {
        int newCapacity = (int) (data.length * GROWTH_FACTOR);
        data = Arrays.copyOf(data, newCapacity);
    }
    
    private void shrinkIfNeeded() {
        int size = size();
        // 当使用率低于阈值且容量大于默认容量时缩容
        if (size > 0 && size < data.length * SHRINK_THRESHOLD 
            && data.length > DEFAULT_CAPACITY) {
            int newCapacity = Math.max(DEFAULT_CAPACITY, size * 2);
            data = Arrays.copyOf(data, newCapacity);
        }
    }
    
    @Override
    public String toString() {
        if (isEmpty()) return "Stack: []";
        StringBuilder sb = new StringBuilder("Stack: [");
        for (int i = 0; i <= top; i++) {
            sb.append(data[i]);
            if (i < top) sb.append(", ");
        }
        sb.append("] (top: ").append(data[top]).append(")");
        return sb.toString();
    }
}
```

```
- 1点：预存给自己将来被复制时使用

当容量为m时，已有m个元素，信用总额为2m。
```

### 基于链表的实现与内存模型

#### 完整实现（带头节点和不带头节点两种）

```java
/**
 * 基于单向链表的栈实现
 * 头插法实现push/pop，时间复杂度O(1)
 */
public class LinkedStack<T> implements StackADT<T> {
    private Node<T> top;
    private int size;
    
    private static class Node<T> {
        T data;
        Node<T> next;
        
        Node(T data) {
            this.data = data;
            this.next = null;
        }
    }
    
    public LinkedStack() {
        top = null;
        size = 0;
    }
    
    @Override
    public void push(T element) {
        Node<T> newNode = new Node<>(element);
        newNode.next = top;
        top = newNode;
        size++;
    }
    
    @Override
    public T pop() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        T data = top.data;
        Node<T> oldTop = top;
        top = top.next;
        // 帮助GC
        oldTop.data = null;
        oldTop.next = null;
        size--;
        return data;
    }
    
    @Override
    public T peek() {
        if (isEmpty()) {
            throw new EmptyStackException();
        }
        return top.data;
    }
    
    @Override
    public boolean isEmpty() {
        return top == null;
    }
    
    @Override
    public int size() {
        return size;
    }
    
    @Override
    public void clear() {
        // 帮助GC，避免内存泄漏
        while (top != null) {
            Node<T> temp = top;
            top = top.next;
            temp.data = null;
            temp.next = null;
        }
        size = 0;
    }
}

/**
 * 基于循环数组的队列实现
 * 使用size字段区分空和满，空间利用率高
 */
public class CircularQueue<T> {
    private static final int DEFAULT_CAPACITY = 10;
    
    private Object[] data;
    private int head; // 队首索引
    private int tail; // 队尾下一个位置（下一个enqueue的位置）
    private int size;
    
    public CircularQueue() {
        this(DEFAULT_CAPACITY);
    }
    
    public CircularQueue(int capacity) {
        if (capacity <= 0) {
            throw new IllegalArgumentException("Capacity must be positive");
        }
        data = new Object[capacity];
        head = 0;
        tail = 0;
        size = 0;
    }
    
    public void enqueue(T element) {
        ensureCapacity();
        data[tail] = element;
        tail = (tail + 1) % data.length;
        size++;
    }
    
    @SuppressWarnings("unchecked")
    public T dequeue() {
        if (isEmpty()) {
            throw new NoSuchElementException("Queue is empty");
        }
        T element = (T) data[head];
        data[head] = null; // 帮助GC
        head = (head + 1) % data.length;
        size--;
        return element;
    }
    
    @SuppressWarnings("unchecked")
    public T peek() {
        if (isEmpty()) {
            throw new NoSuchElementException("Queue is empty");
        }
        return (T) data[head];
    }
    
    public boolean isEmpty() {
        return size == 0;
    }
    
    public boolean isFull() {
        return size == data.length;
    }
    
    public int size() {
        return size;
    }
    
    public int capacity() {
        return data.length;
    }
    
    /**
     * 获取指定位置的元素（调试用，非标准队列操作）
     */
    @SuppressWarnings("unchecked")
    public T get(int index) {
        if (index < 0 || index >= size) {
            throw new IndexOutOfBoundsException();
        }
        return (T) data[(head + index) % data.length];
    }
    
    private void ensureCapacity() {
        if (size == data.length) {
            grow();
        }
    }
    
    private void grow() {
        int oldCapacity = data.length;
        int newCapacity = oldCapacity * 2;
        Object[] newData = new Object[newCapacity];
        
        // 将元素按逻辑顺序复制到新数组
        for (int i = 0; i < size; i++) {
            newData[i] = data[(head + i) % oldCapacity];
        }
        
        head = 0;
        tail = size;
        data = newData;
    }
    
    @Override
    public String toString() {
        if (isEmpty()) return "Queue: []";
        StringBuilder sb = new StringBuilder("Queue: [");
        for (int i = 0; i < size; i++) {
            sb.append(data[(head + i) % data.length]);
            if (i < size - 1) sb.append(", ");
        }
        sb.append("]");
        sb.append(" (head: ").append(head)
          .append(", tail: ").append(tail)
          .append(", size: ").append(size).append(")");
        return sb.toString();
    }
}
```

### 链式队列的实现

```java
/**
 * 基于单向链表的队列实现
 * 维护head和tail两个指针，enqueue在tail，dequeue在head
 */
public class LinkedQueue<T> {
    private Node<T> head;
    private Node<T> tail;
    private int size;
    
    private static class Node<T> {
        T data;
        Node<T> next;
        
        Node(T data) {
            this.data = data;
            this.next = null;
        }
    }
    
    public LinkedQueue() {
        head = null;
        tail = null;
        size = 0;
    }
    
    public void enqueue(T element) {
        Node<T> newNode = new Node<>(element);
        if (tail != null) {
            tail.next = newNode;
        }
        tail = newNode;
        if (head == null) {
            head = tail;
        }
        size++;
    }
    
    public T dequeue() {
        if (isEmpty()) {
            throw new NoSuchElementException("Queue is empty");
        }
        T data = head.data;
        Node<T> oldHead = head;
        head = head.next;
        if (head == null) {
            tail = null; // 队列变空
        }
        // 帮助GC
        oldHead.data = null;
        oldHead.next = null;
        size--;
        return data;
    }
    
    public T peek() {
        if (isEmpty()) {
            throw new NoSuchElementException("Queue is empty");
        }
        return head.data;
    }
    
    public boolean isEmpty() {
        return head == null;
    }
    
    public int size() {
        return size;
    }
}
```

### 双端队列（Deque）的设计哲学

双端队列（Double-Ended Queue）是一种允许在两端进行插入和删除操作的线性数据结构。

**Deque的抽象定义：**

```java
public interface DequeADT<T> {
    // 队首操作
    void addFirst(T element);      // 队首插入
    T removeFirst();               // 队首删除
    T getFirst();                  // 查看队首
    
    // 队尾操作
    void addLast(T element);       // 队尾插入
    T removeLast();                // 队尾删除
    T getLast();                   // 查看队尾
    
    // 栈操作（使用队首）
    default void push(T element) { addFirst(element); }
    default T pop() { return removeFirst(); }
    default T peek() { return getFirst(); }
    
    // 队列操作（队尾入，队首出）
    default void offer(T element) { addLast(element); }
    default T poll() { return removeFirst(); }
    
    boolean isEmpty();
    int size();
}
```

**Deque的两种实现策略：**

```
策略1：循环数组实现（ArrayDeque）
- 维护head和tail两个指针
- head指向队首元素，tail指向队尾下一个位置
- 两端操作都是O(1)均摊

数组布局：
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  D  │  E  │     │     │  A  │  B  │
└─────┴─────┴─────┴─────┴─────┴─────┘
        ↑                       ↑
       tail                    head

addFirst(F):
head = (head - 1 + capacity) % capacity
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  D  │  E  │     │     │  A  │  B  │
└─────┴─────┴─────┴─────┴─────┴─────┘
        ↑                   ↑
       tail               head (指向F的位置)

addLast(G):
tail位置写入G，tail = (tail + 1) % capacity
┌─────┬─────┬─────┬─────┬─────┬─────┐
│  D  │  E  │  G  │     │  A  │  B  │
└─────┴─────┴─────┴─────┴─────┴─────┘
                ↑           ↑
               tail        head

策略2：双向链表实现（LinkedList）
- 维护head和tail两个节点引用
- 每个节点有prev和next引用
- 两端操作都是严格的O(1)

链表布局：
null ← [A] ⇄ [B] ⇄ [C] ⇄ [D] → null
        ↑                       ↑
       head                    tail

addFirst(E):
[E] ⇄ [A] ⇄ [B] ⇄ [C] ⇄ [D]
 ↑
head

addLast(F):
[E] ⇄ [A] ⇄ [B] ⇄ [C] ⇄ [D] ⇄ [F]
 ↑                               ↑
head                           tail
```

### ArrayDeque源码逐行解析

`ArrayDeque` 是Java集合框架中Deque接口的主力实现，基于循环数组。

#### 核心字段与构造器

```java
public class ArrayDeque<E> extends AbstractCollection<E>
                           implements Deque<E>, Cloneable, Serializable {
    // 最小初始容量，必须是2的幂（方便位运算取模）
    private static final int MIN_INITIAL_CAPACITY = 8;
    
    // 存储元素的数组，长度始终是2的幂
    transient Object[] elements;
    
    // 队首索引（指向下一个要被removeFirst的位置）
    transient int head;
    
    // 队尾索引（指向下一个要被addLast的位置）
    transient int tail;
    
    // 无参构造器：默认容量16
    public ArrayDeque() {
        elements = new Object[16];
    }
    
    // 指定初始容量
    public ArrayDeque(int numElements) {
        allocateElements(numElements);
    }
    
    // 计算合适的容量（向上取到2的幂）
    private void allocateElements(int numElements) {
        int initialCapacity = MIN_INITIAL_CAPACITY;
        // 找到大于numElements的最小2的幂
        if (numElements >= initialCapacity) {
            initialCapacity = numElements;
            initialCapacity |= (initialCapacity >>>  1);
            initialCapacity |= (initialCapacity >>>  2);
            initialCapacity |= (initialCapacity >>>  4);
            initialCapacity |= (initialCapacity >>>  8);
            initialCapacity |= (initialCapacity >>> 16);
            initialCapacity++;
            
            if (initialCapacity < 0)   // Too many elements, must back off
                initialCapacity >>>= 1; // Good luck allocating 2^30 elements
        }
        elements = new Object[initialCapacity];
    }
}
```

**关键洞察**：为什么容量必须是2的幂？

```
当容量为2的幂时，取模运算可以优化为位运算：
  i % capacity == i & (capacity - 1)

例如 capacity = 16 (二进制 10000)，capacity - 1 = 15 (二进制 01111)
  20 % 16 = 4
  20 & 15 = 10100 & 01111 = 00100 = 4

位运算 & 比取模 % 快得多（CPU指令周期更少）
```

#### 核心操作源码解析

```java
// addFirst：在队首插入元素
public void addFirst(E e) {
    if (e == null)
        throw new NullPointerException();
    // head - 1，如果为负则循环到数组末尾
    // 使用位运算 &(elements.length - 1) 替代取模
    elements[head = (head - 1) & (elements.length - 1)] = e;
    // 检查是否需要扩容（head == tail 表示满了）
    if (head == tail)
        doubleCapacity();
}

// addLast：在队尾插入元素
public void addLast(E e) {
    if (e == null)
        throw new NullPointerException();
    elements[tail] = e;
    // tail + 1，如果超出则循环
    if ((tail = (tail + 1) & (elements.length - 1)) == head)
        doubleCapacity();
}

// removeFirst：从队首删除元素
public E removeFirst() {
    E x = pollFirst();
    if (x == null)
        throw new NoSuchElementException();
    return x;
}

// pollFirst：从队首删除（不抛异常）
@SuppressWarnings("unchecked")
public E pollFirst() {
    int h = head;
    @SuppressWarnings("unchecked")
    E result = (E) elements[h];
    if (result == null)
        return null;
    elements[h] = null;     // 帮助GC
    head = (h + 1) & (elements.length - 1);
    return result;
}

// removeLast：从队尾删除
@SuppressWarnings("unchecked")
public E removeLast() {
    int t = (tail - 1) & (elements.length - 1);
    @SuppressWarnings("unchecked")
    E result = (E) elements[t];
    if (result == null)
        throw new NoSuchElementException();
    elements[t] = null;
    tail = t;
    return result;
}
```

#### 双倍扩容机制

```java
private void doubleCapacity() {
    assert head == tail;
    int p = head;
    int n = elements.length;
    int r = n - p; // 从head到数组末尾的元素个数
    
    // 容量翻倍
    int newCapacity = n << 1;
    if (newCapacity < 0)
        throw new IllegalStateException("Sorry, deque too big");
    Object[] a = new Object[newCapacity];
    
    // 复制元素：先复制head到数组末尾的元素，再复制数组开头到tail的元素
    System.arraycopy(elements, p, a, 0, r);
    System.arraycopy(elements, 0, a, r, p);
    
    elements = a;
    head = 0;
    tail = n;
}
```

```
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
  ↑                             ↑
 tail                          head

扩容步骤：
1. 创建新数组（容量=16）
```

```java
public class LinkedList<E> extends AbstractSequentialList<E>
    implements List<E>, Deque<E>, Cloneable, java.io.Serializable {
    
    transient int size = 0;
    transient Node<E> first; // 队首
    transient Node<E> last;  // 队尾
    
    private static class Node<E> {
        E item;
        Node<E> next;
        Node<E> prev;
        
        Node(Node<E> prev, E element, Node<E> next) {
            this.item = element;
            this.next = next;
            this.prev = prev;
        }
    }
    
    // 队首插入
    public void addFirst(E e) {
        linkFirst(e);
    }
    
    private void linkFirst(E e) {
        final Node<E> f = first;
        final Node<E> newNode = new Node<>(null, e, f);
        first = newNode;
        if (f == null)
            last = newNode;
        else
            f.prev = newNode;
        size++;
        modCount++;
    }
    
    // 队尾插入
    public void addLast(E e) {
        linkLast(e);
    }
    
    void linkLast(E e) {
        final Node<E> l = last;
        final Node<E> newNode = new Node<>(l, e, null);
        last = newNode;
        if (l == null)
            first = newNode;
        else
            l.next = newNode;
        size++;
        modCount++;
    }
    
    // 队首删除
    public E removeFirst() {
        final Node<E> f = first;
        if (f == null)
            throw new NoSuchElementException();
        return unlinkFirst(f);
    }
    
    private E unlinkFirst(Node<E> f) {
        final E element = f.item;
        final Node<E> next = f.next;
        f.item = null;
        f.next = null; // help GC
        first = next;
        if (next == null)
            last = null;
        else
            next.prev = null;
        size--;
        modCount++;
        return element;
    }
}
```

### ArrayBlockingQueue源码分析

```java
/**
 * 基于循环数组的有界阻塞队列
 * 使用单锁 + 两个Condition实现阻塞语义
 */
public class ArrayBlockingQueue<E> extends AbstractQueue<E>
        implements BlockingQueue<E>, java.io.Serializable {
    
    final Object[] items; // 循环数组
    int takeIndex;        // 下一个take的位置
    int putIndex;         // 下一个put的位置
    int count;            // 元素数量
    
    final ReentrantLock lock;
    private final Condition notEmpty; // 队列非空条件
    private final Condition notFull;  // 队列未满条件
    
    public ArrayBlockingQueue(int capacity) {
        this(capacity, false);
    }
    
    public ArrayBlockingQueue(int capacity, boolean fair) {
        if (capacity <= 0)
            throw new IllegalArgumentException();
        this.items = new Object[capacity];
        lock = new ReentrantLock(fair);
        notEmpty = lock.newCondition();
        notFull = lock.newCondition();
    }
    
    // 入队（阻塞式）
    public void put(E e) throws InterruptedException {
        checkNotNull(e);
        final ReentrantLock lock = this.lock;
        lock.lockInterruptibly();
        try {
            while (count == items.length)
                notFull.await(); // 队列满，等待
            enqueue(e);
        } finally {
            lock.unlock();
        }
    }
    
    // 入队（非阻塞）
    public boolean offer(E e) {
        checkNotNull(e);
        final ReentrantLock lock = this.lock;
        lock.lock();
        try {
            if (count == items.length)
                return false;
            else {
                enqueue(e);
                return true;
            }
        } finally {
            lock.unlock();
        }
    }
    
    private void enqueue(E x) {
        final Object[] items = this.items;
        items[putIndex] = x;
        if (++putIndex == items.length)
            putIndex = 0;
        count++;
        notEmpty.signal(); // 通知等待的消费者
    }
    
    // 出队（阻塞式）
    public E take() throws InterruptedException {
        final ReentrantLock lock = this.lock;
        lock.lockInterruptibly();
        try {
            while (count == 0)
                notEmpty.await(); // 队列空，等待
            return dequeue();
        } finally {
            lock.unlock();
        }
    }
    
    private E dequeue() {
        final Object[] items = this.items;
        @SuppressWarnings("unchecked")
        E x = (E) items[takeIndex];
        items[takeIndex] = null;
        if (++takeIndex == items.length)
            takeIndex = 0;
        count--;
        if (itrs != null)
            itrs.elementDequeued();
        notFull.signal(); // 通知等待的生产者
        return x;
    }
}
```

**ArrayBlockingQueue的设计特点**：

```
1. 有界队列：防止内存无限增长
2. 单锁设计：put和take共用一把锁，简单但并发度受限
3. Condition等待：使用notEmpty和notFull两个条件队列
4. 公平性选项：支持公平锁（按等待时间获取锁）

并发性能瓶颈：
- 单锁导致生产者和消费者串行
- LinkedBlockingQueue使用双锁（putLock和takeLock），并发度更高
- Disruptor使用无锁队列（CAS + 环形缓冲区），性能最高
```

## 单调栈与单调队列

### 单调栈的数学原理

**定义**：单调栈是一种特殊的栈，栈内元素保持单调递增或单调递减的顺序。

**核心性质**：
- 单调递减栈：栈底到栈顶元素值递减（即新元素 < 栈顶时入栈）
- 单调递增栈：栈底到栈顶元素值递增（即新元素 > 栈顶时入栈）

**数学原理——正确性证明**：

以"下一个更大元素"问题为例：

```
问题：给定数组nums，找每个元素右边第一个比它大的元素。

单调递减栈解法：
维护一个递减栈，栈中存索引。
当遇到nums[i] > nums[stack.top]时，nums[i]就是nums[stack.top]的下一个更大元素。

正确性证明：
1. 栈中索引对应的值是递减的（栈底到栈顶）
2. 对于栈中任意元素nums[j]，其左边比它小的元素已经被弹出
   （因为这些元素遇到nums[j]时会被弹出，nums[j]是它们的下一个更大元素）
3. 当nums[i] > nums[stack.top]时：
   - nums[i] 在 nums[stack.top] 的右边（i > stack.top）
   - nums[i] 比 nums[stack.top] 大
   - 且 stack.top 和 i 之间没有比 nums[stack.top] 更大的元素
     （否则 stack.top 早就被弹出了）
   因此 nums[i] 就是 nums[stack.top] 的下一个更大元素

时间复杂度证明：
每个元素最多入栈一次、出栈一次。
总操作次数 = 2n = O(n)
```

#### 单调栈完整实现

```java
/**
 * 单调栈工具类
 * 提供多种单调栈问题的通用解法
 */
public class MonotonicStack {
    
    /**
     * 下一个更大元素 I（数组内）
     * 返回每个元素右边第一个比它大的元素，不存在返回-1
     */
    public int[] nextGreaterElement(int[] nums) {
        int n = nums.length;
        int[] result = new int[n];
        Arrays.fill(result, -1);
        Deque<Integer> stack = new ArrayDeque<>(); // 存索引，递减栈
        
        for (int i = 0; i < n; i++) {
            // 当前元素比栈顶大，说明找到了栈顶元素的下一个更大元素
            while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
                result[stack.pop()] = nums[i];
            }
            stack.push(i);
        }
        // 栈中剩余元素没有下一个更大元素，保持-1
        return result;
    }
    
    /**
     * 接雨水问题（Trapping Rain Water）
     * 使用单调栈找两边第一个更高的柱子
     */
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>(); // 递减栈
        int water = 0;
        
        for (int i = 0; i < height.length; i++) {
            while (!stack.isEmpty() && height[i] > height[stack.peek()]) {
                int top = stack.pop();
                if (stack.isEmpty()) break;
                int distance = i - stack.peek() - 1;
                int boundedHeight = Math.min(height[i], height[stack.peek()]) - height[top];
                water += distance * boundedHeight;
            }
            stack.push(i);
        }
        return water;
    }
    
    /**
     * 柱状图中最大的矩形
     * 找每个柱子两边第一个小于它的位置
     */
    public int largestRectangleArea(int[] heights) {
        Deque<Integer> stack = new ArrayDeque<>();
        int maxArea = 0;
        int n = heights.length;
        
        for (int i = 0; i <= n; i++) {
            int h = (i == n) ? 0 : heights[i];
            while (!stack.isEmpty() && h < heights[stack.peek()]) {
                int height = heights[stack.pop()];
                int width = stack.isEmpty() ? i : i - stack.peek() - 1;
                maxArea = Math.max(maxArea, height * width);
            }
            stack.push(i);
        }
        return maxArea;
    }
}
```

### 单调队列与滑动窗口

#### 滑动窗口最大值实现

```java
/**
 * 单调队列实现滑动窗口最大值
 * 队列中存储索引，保持递减（队首是窗口最大值）
 */
public int[] maxSlidingWindow(int[] nums, int k) {
    if (nums == null || nums.length == 0 || k <= 0) {
        return new int[0];
    }
    
    int n = nums.length;
    int[] result = new int[n - k + 1];
    Deque<Integer> deque = new LinkedList<>(); // 存索引
    
    for (int i = 0; i < n; i++) {
        // 1. 移除窗口外的元素（队首超出窗口左边界）
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }
        
        // 2. 保持递减：移除所有比当前小的元素（它们不可能是最大值）
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.pollLast();
        }
        
        // 3. 当前元素入队
        deque.offerLast(i);
        
        // 4. 记录结果（窗口形成后）
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    
    return result;
}
```

### 表达式求值引擎

实现一个支持加减乘除和括号的表达式求值器。

```java
/**
 * 表达式求值引擎
 * 使用双栈法：一个存操作数，一个存运算符
 */
public class ExpressionEvaluator {
    
    public int evaluate(String expression) {
        Deque<Integer> values = new ArrayDeque<>();
        Deque<Character> ops = new ArrayDeque<>();
        
        for (int i = 0; i < expression.length(); i++) {
            char c = expression.charAt(i);
            
            if (c == ' ') continue;
            
            if (Character.isDigit(c)) {
                // 解析多位数
                int num = 0;
                while (i < expression.length() && 
                       Character.isDigit(expression.charAt(i))) {
                    num = num * 10 + (expression.charAt(i) - '0');
                    i++;
                }
                i--; // 回退一位
                values.push(num);
                System.out.println("Push value: " + num);
            } else if (c == '(') {
                ops.push(c);
                System.out.println("Push op: " + c);
            } else if (c == ')') {
                // 计算到左括号
                while (!ops.isEmpty() && ops.peek() != '(') {
                    applyOp(values, ops);
                }
                ops.pop(); // 弹出'('
                System.out.println("Pop '('");
            } else if (isOperator(c)) {
                // 处理运算符优先级
                while (!ops.isEmpty() && precedence(c) <= precedence(ops.peek())) {
                    applyOp(values, ops);
                }
                ops.push(c);
                System.out.println("Push op: " + c);
            }
        }
        
        // 计算剩余操作
        while (!ops.isEmpty()) {
            applyOp(values, ops);
        }
        
        return values.pop();
    }
    
    private void applyOp(Deque<Integer> values, Deque<Character> ops) {
        int b = values.pop();
        int a = values.pop();
        char op = ops.pop();
        int result;
        switch (op) {
            case '+': result = a + b; break;
            case '-': result = a - b; break;
            case '*': result = a * b; break;
            case '/': result = a / b; break;
            default: throw new IllegalArgumentException("Invalid operator: " + op);
        }
        values.push(result);
        System.out.println("Apply: " + a + " " + op + " " + b + " = " + result);
    }
    
    private boolean isOperator(char c) {
        return c == '+' || c == '-' || c == '*' || c == '/';
    }
    
    private int precedence(char op) {
        if (op == '+' || op == '-') return 1;
        if (op == '*' || op == '/') return 2;
        return 0;
    }
    
    public static void main(String[] args) {
        ExpressionEvaluator evaluator = new ExpressionEvaluator();
        String expr = "3 + 5 * 2 - (8 / 4)";
        System.out.println("Expression: " + expr);
        int result = evaluator.evaluate(expr);
        System.out.println("Result: " + result);
    }
}
```

**执行追踪（"3 + 5 * 2 - (8 / 4)"）**：

```
步骤1-5: 读取 3, +, 5, *, 2 → values: [2, 5, 3], ops: [*, +]
步骤6: 遇到 '-'，优先级低于 '*' 和 '+' 
  → 先计算 5*2=10，再计算 3+10=13 → values: [13], ops: [-]
步骤7-10: 读取 (, 8, /, 4 → values: [4, 8, 13], ops: [/, (, -]
步骤11: 遇到 ')' → 计算 8/4=2 → values: [2, 13], ops: [-]
步骤12: 结束 → 计算 13-2=11

Result: 11
```

### 浏览器前进后退实现

```java
/**
 * 浏览器历史记录管理
 * 使用两个栈实现前进后退功能
 */
public class BrowserHistory {
    private Deque<String> backStack;
    private Deque<String> forwardStack;
    private String current;
    
    public BrowserHistory(String homepage) {
        backStack = new ArrayDeque<>();
        forwardStack = new ArrayDeque<>();
        current = homepage;
    }
    
    /**
     * 访问新页面
     */
    public void visit(String url) {
        if (current != null) {
            backStack.push(current);
        }
        current = url;
        forwardStack.clear(); // 清空前进栈
        System.out.println("Visit: " + url);
        printState();
    }
    
    /**
     * 后退
     */
    public String back() {
        if (backStack.isEmpty()) {
            System.out.println("Cannot go back");
            return current;
        }
        forwardStack.push(current);
        current = backStack.pop();
        System.out.println("Back to: " + current);
        printState();
        return current;
    }
    
    /**
     * 前进
     */
    public String forward() {
        if (forwardStack.isEmpty()) {
            System.out.println("Cannot go forward");
            return current;
        }
        backStack.push(current);
        current = forwardStack.pop();
        System.out.println("Forward to: " + current);
        printState();
        return current;
    }
    
    private void printState() {
        System.out.println("  Current: " + current);
        System.out.println("  Back: " + backStack);
        System.out.println("  Forward: " + forwardStack);
    }
    
    public static void main(String[] args) {
        BrowserHistory browser = new BrowserHistory("google.com");
        browser.visit("youtube.com");
        browser.visit("github.com");
        browser.back();
        browser.back();
        browser.forward();
        browser.visit("stackoverflow.com");
        browser.forward(); // 应该无法前进
    }
}
```

## 常见陷阱与最佳实践

### 陷阱1：使用Stack类而不是Deque

```java
// 陷阱：Java官方已不推荐Stack类
Stack<Integer> stack = new Stack<>();
```

**问题分析**：
- Stack继承自Vector，所有方法都是synchronized
- 单线程环境下不必要的同步开销
- 设计过时，与集合框架不一致

**最佳实践**：
```java
// 正确做法
Deque<Integer> stack = new ArrayDeque<>();
stack.push(1);      // 等效于addFirst
int x = stack.pop(); // 等效于removeFirst
int y = stack.peek(); // 等效于peekFirst
```

### 陷阱2：忘记判空就pop/peek

```java
// 陷阱
public void process(Deque<Integer> stack) {
    int x = stack.pop(); // 可能抛NoSuchElementException
}
```

**最佳实践**：
```java
public Optional<Integer> safePop(Deque<Integer> stack) {
    return stack.isEmpty() ? Optional.empty() : Optional.of(stack.pop());
}

// 或者在使用前检查
if (!stack.isEmpty()) {
    int x = stack.pop();
}
```

```java
// 错误写法：浪费一个位置
public boolean isFull() {
    return (tail + 1) % capacity == head;
}

// 正确写法：使用size字段
public boolean isFull() {
    return size == capacity;
}
```

### 陷阱4：递归过深导致栈溢出

```java
// 陷阱：递归斐波那契，调用栈深度=n
public long fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

**最佳实践**：
```java
// 改迭代实现
public long fibIterative(int n) {
    if (n <= 1) return n;
    long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long temp = a + b;
        a = b;
        b = temp;
    }
    return b;
}

// 或者使用尾递归（Java不自动优化，需手动）
public long fibTailRecursive(int n) {
    return fibHelper(n, 0, 1);
}

private long fibHelper(int n, long a, long b) {
    if (n == 0) return a;
    return fibHelper(n - 1, b, a + b);
}
```

### 陷阱5：在遍历时修改集合

```java
// 陷阱：遍历时删除
Deque<Integer> deque = new ArrayDeque<>();
for (Integer num : deque) {
    if (num % 2 == 0) {
        deque.remove(num); // ConcurrentModificationException！
    }
}
```

**最佳实践**：
```java
// 使用迭代器的remove方法
Iterator<Integer> it = deque.iterator();
while (it.hasNext()) {
    if (it.next() % 2 == 0) {
        it.remove();
    }
}

// 或者使用removeIf（Java 8+）
deque.removeIf(num -> num % 2 == 0);
```

**最佳实践总结**：
```java
// 栈：用ArrayDeque（不要用Stack类，不要用LinkedList）
Deque<Integer> stack = new ArrayDeque<>();

// 队列：用ArrayDeque（非阻塞）
Queue<Integer> queue = new ArrayDeque<>();

// 阻塞队列：根据并发需求选择
// 低并发：ArrayBlockingQueue，高并发：LinkedBlockingQueue，极高并发：Disruptor
```

## 面试题与参考答案

### Q1：如何用栈实现队列？

**参考答案：**

使用两个栈：`in`栈负责入队，`out`栈负责出队。

```java
class MyQueue {
    private Deque<Integer> in = new ArrayDeque<>();
    private Deque<Integer> out = new ArrayDeque<>();
    
    // 入队：直接压入in栈
    public void push(int x) {
        in.push(x);
    }
    
    // 出队：如果out栈为空，将in栈全部倒入out栈
    public int pop() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());
            }
        }
        return out.pop();
    }
    
    public int peek() {
        if (out.isEmpty()) {
            while (!in.isEmpty()) {
                out.push(in.pop());
            }
        }
        return out.peek();
    }
    
    public boolean empty() {
        return in.isEmpty() && out.isEmpty();
    }
}
```

**均摊时间复杂度分析**：
- push：O(1)
- pop：均摊O(1)。每个元素最多入in栈1次、入out栈1次、出out栈1次，总成本O(n)，n次操作，均摊O(1)

**空间复杂度**：O(n)

### Q2：如何用队列实现栈？

**参考答案：**

**方法一：单队列（每次push后循环）**

```java
class MyStack {
    private Queue<Integer> queue = new LinkedList<>();
    
    public void push(int x) {
        queue.offer(x);
        // 将前面的size-1个元素移到后面
        for (int i = 0; i < queue.size() - 1; i++) {
            queue.offer(queue.poll());
        }
    }
    
    public int pop() {
        return queue.poll();
    }
    
    public int top() {
        return queue.peek();
    }
    
    public boolean empty() {
        return queue.isEmpty();
    }
}
```

时间复杂度：push O(n)，pop O(1)

**方法二：双队列**

```java
class MyStack {
    private Queue<Integer> main = new LinkedList<>();
    private Queue<Integer> helper = new LinkedList<>();
    
    public void push(int x) {
        main.offer(x);
    }
    
    public int pop() {
        // 将main中除最后一个元素外全部移到helper
        while (main.size() > 1) {
            helper.offer(main.poll());
        }
        int result = main.poll();
        // 交换main和helper
        Queue<Integer> temp = main;
        main = helper;
        helper = temp;
        return result;
    }
    
    // ...
}
```

时间复杂度：push O(1)，pop O(n)

### Q3：单调栈的应用场景和原理？

**参考答案：**

**应用场景**：找"下一个更大/更小元素"、"前一个更大/更小元素"

**常见题目**：
1. 每日温度（Next Greater Element的变体）
2. 接雨水（找两边第一个更高的柱子）
3. 柱状图中最大的矩形（找两边第一个更小的柱子）
4. 股票价格跨度
5. 最小栈（辅助栈保持单调递增）

**原理**：
- 单调递减栈：栈底到栈顶元素递减
- 当遇到比栈顶大的元素时，该元素就是栈顶元素的"下一个更大元素"
- 每个元素最多入栈、出栈各一次，时间复杂度O(n)

**代码模板**：
```java
public int[] nextGreaterElement(int[] nums) {
    int n = nums.length;
    int[] result = new int[n];
    Arrays.fill(result, -1);
    Deque<Integer> stack = new ArrayDeque<>(); // 存索引
    
    for (int i = 0; i < n; i++) {
        while (!stack.isEmpty() && nums[stack.peek()] < nums[i]) {
            result[stack.pop()] = nums[i];
        }
        stack.push(i);
    }
    return result;
}
```

### Q4：滑动窗口最大值的单调队列解法？

**参考答案：**

使用单调递减队列，存储索引，队首始终是窗口最大值。

```java
public int[] maxSlidingWindow(int[] nums, int k) {
    if (nums == null || nums.length == 0) return new int[0];
    int n = nums.length;
    int[] result = new int[n - k + 1];
    Deque<Integer> deque = new LinkedList<>();
    
    for (int i = 0; i < n; i++) {
        // 移除窗口外元素
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }
        // 保持递减
        while (!deque.isEmpty() && nums[deque.peekLast()] < nums[i]) {
            deque.pollLast();
        }
        deque.offerLast(i);
        // 记录结果
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    return result;
}
```

**时间复杂度**：O(n)，每个元素最多入队出队各一次。

**空间复杂度**：O(k)，队列最多存储k个元素。

### Q5：括号匹配问题的栈解法？

**参考答案：**

```java
public boolean isValid(String s) {
    Deque<Character> stack = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') stack.push(')');
        else if (c == '[') stack.push(']');
        else if (c == '{') stack.push('}');
        else if (stack.isEmpty() || stack.pop() != c) return false;
    }
    return stack.isEmpty();
}
```

**关键点**：
1. 左括号入栈对应的右括号（方便比较）
2. 最后检查栈是否为空（防止"(("这种不完整输入）
3. 时间O(n)，空间O(n)

### Q6：ArrayDeque和LinkedList的区别？

**参考答案：**

| 特性 | ArrayDeque | LinkedList |
|------|------------|------------|
| 底层结构 | 循环数组 | 双向链表 |
| 内存占用 | 连续空间，无节点开销 | 离散空间，每个节点额外两个指针 |
| CPU缓存 | 友好（局部性） | 不友好 |
| 操作性能 | 均摊O(1)，实际更快 | O(1)，但缓存未命中多 |
| null元素 | 不允许 | 允许 |
| 容量限制 | 无界（自动扩容） | 无界 |
| 线程安全 | 否 | 否 |
| 适用场景 | 栈、队列、双端队列 | 频繁中间插入删除 |

**结论**：绝大多数场景用ArrayDeque，除非需要频繁在链表中间插入删除。

### Q7：栈溢出的原因及解决方法？

**参考答案：**

**原因**：
1. 递归过深：如未优化的斐波那契、倾斜二叉树的深度遍历
2. 无限递归：缺少终止条件或条件错误
3. 大量局部变量：每个栈帧占用空间大
4. 大量线程：每个线程有独立栈空间，线程过多耗尽内存

**解决方法**：
1. **改递归为迭代**：使用显式栈或循环
2. **尾递归优化**：编译器/语言支持时自动优化（Java不支持）
3. **增大栈空间**：JVM参数`-Xss2m`（默认1m）
4. **减少局部变量**：避免大对象直接分配在栈上
5. **限制线程数**：使用线程池

### Q8：如何设计一个线程安全的栈？

```java
public class SynchronizedStack<E> {
    private final Deque<E> deque = new ArrayDeque<>();
    private final Object lock = new Object();
    
    public void push(E e) {
        synchronized (lock) {
            deque.push(e);
        }
    }
    
    public E pop() {
        synchronized (lock) {
            return deque.pop();
        }
    }
}
```

```java
Deque<E> stack = new ConcurrentLinkedDeque<>();
```

### Q10：实现一个最小栈，要求push/pop/getMin都是O(1)？

**参考答案：**

**方法一：辅助栈**

```java
class MinStack {
    private Deque<Integer> stack;
    private Deque<Integer> minStack; // 辅助栈，保持递减
    
    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }
    
    public void push(int x) {
        stack.push(x);
        if (minStack.isEmpty() || x <= minStack.peek()) {
            minStack.push(x);
        }
    }
    
    public void pop() {
        int x = stack.pop();
        if (x == minStack.peek()) {
            minStack.pop();
        }
    }
    
    public int top() {
        return stack.peek();
    }
    
    public int getMin() {
        return minStack.peek();
    }
}
```
