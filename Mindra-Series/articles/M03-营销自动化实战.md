## 用户洞察 Agent

### 功能：实时用户画像分析

```java
/**
 * 用户洞察 Agent
 */
@Component
public class UserInsightAgent {
    
    @Autowired
    private UserBehaviorRepository behaviorRepo;
    
    @Autowired
    private MLService mlService;
    
    /**
     * 实时更新用户画像
     */
    public UserProfile analyze(String userId) {
        // 1. 收集用户行为数据
        List<UserBehavior> behaviors = behaviorRepo.findRecent(userId, Duration.ofDays(30));
        
        // 2. 特征提取
        UserFeatures features = extractFeatures(behaviors);
        
        // 3. 预测用户价值
        double ltv = mlService.predictLTV(features);
        
        // 4. 预测流失概率
        double churnRisk = mlService.predictChurn(features);
        
        // 5. 推荐偏好
        List<String> interests = mlService.predictInterests(features);
        
        return UserProfile.builder()
            .userId(userId)
            .ltv(ltv)
            .churnRisk(churnRisk)
            .interests(interests)
            .segment(classifySegment(ltv, churnRisk))
            .build();
    }
    
    /**
     * 用户分群
     */
    private UserSegment classifySegment(double ltv, double churnRisk) {
        if (ltv > 10000 && churnRisk < 0.3) {
            return UserSegment.VIP;
        } else if (ltv > 5000 && churnRisk < 0.5) {
            return UserSegment.VALUE;
        } else if (churnRisk > 0.7) {
            return UserSegment.AT_RISK;
        } else {
            return UserSegment.NORMAL;
        }
    }
}
```

```java
            product.getPrice()
        );
    }
    
    /**
     * A/B 测试标题优化
     */
    public List<String> generateHeadlineVariants(String baseHeadline, int count) {

        variants.add(baseHeadline);

                baseHeadline + "\n" +
                "要求：吸引人点击，但不标题党"
            );
            variants.add(variant);
        }
        
        return variants;
    }
}
```

## 投放优化 Agent

### 功能：自动优化广告投放

```java
/**
 * 投放优化 Agent
 */
@Component
public class AdOptimizationAgent {
    
    @Autowired
    private AdPlatformService adService;
    
    @Autowired
    private AttributionService attributionService;
    
    /**
     * 实时优化投放策略
     */
    public void optimizeCampaign(String campaignId) {
        Campaign campaign = adService.getCampaign(campaignId);
        
        // 1. 获取实时数据
        CampaignMetrics metrics = adService.getRealTimeMetrics(campaignId);
        
        // 2. 分析各渠道效果
        Map<String, ChannelPerformance> channelPerformance = analyzeChannels(metrics);
        
        // 3. 自动调整预算分配
        adjustBudget(campaign, channelPerformance);
        
        // 4. 优化出价策略
        optimizeBidding(campaign, channelPerformance);
        
        // 5. 调整受众定向
        refineTargeting(campaign, metrics);
    }
    
    /**
     * 预算自动分配
     */
    private void adjustBudget(Campaign campaign, Map<String, ChannelPerformance> performance) {
        double totalBudget = campaign.getTotalBudget();
        
        // 根据 ROI 重新分配
        Map<String, Double> newAllocation = performance.entrySet().stream()
            .collect(Collectors.toMap(
                Map.Entry::getKey,
                e -> {
                    double roi = e.getValue().getROI();
                    // ROI 高的渠道分配更多预算
                    return totalBudget * (roi / getTotalROI(performance));
                }
            ));
        
        // 应用新预算
        newAllocation.forEach((channel, budget) -> 
            adService.setBudget(campaign.getId(), channel, budget));
    }
    
    /**
     * 智能出价
     */
    private void optimizeBidding(Campaign campaign, Map<String, ChannelPerformance> performance) {
        performance.forEach((channel, perf) -> {
            double currentCpa = perf.getCPA();  // 当前获取成本
            double targetCpa = campaign.getTargetCPA();
            
            if (currentCpa > targetCpa * 1.2) {
                // 成本过高，降低出价 10%
                adService.adjustBid(campaign.getId(), channel, 0.9);
            } else if (currentCpa < targetCpa * 0.8) {
                // 成本有空间，提高出价 15%
                adService.adjustBid(campaign.getId(), channel, 1.15);
            }
        });
    }
}
```

## 转化分析 Agent

### 功能：全链路转化分析

```java
/**
 * 转化分析 Agent
 */
@Component
public class ConversionAnalysisAgent {
    
    @Autowired
    private EventTracker eventTracker;
    
    /**
     * 分析转化漏斗
     */
    public ConversionFunnel analyzeFunnel(String campaignId) {
        // 1. 获取漏斗数据
        List<FunnelStage> stages = Arrays.asList(
            new FunnelStage("曝光", eventTracker.count("impression", campaignId)),
            new FunnelStage("点击", eventTracker.count("click", campaignId)),
            new FunnelStage("访问", eventTracker.count("visit", campaignId)),
            new FunnelStage("注册", eventTracker.count("register", campaignId)),
            new FunnelStage("下单", eventTracker.count("order", campaignId)),
            new FunnelStage("支付", eventTracker.count("payment", campaignId))
        );
        
        // 2. 计算转化率
        for (int i = 1; i < stages.size(); i++) {
            double conversionRate = (double) stages.get(i).getCount() / stages.get(i-1).getCount();
            stages.get(i).setConversionRate(conversionRate);
        }
        
        // 3. 识别瓶颈
        FunnelStage bottleneck = stages.stream()
            .max(Comparator.comparingDouble(FunnelStage::getDropOffRate))
            .orElse(null);
        
        return ConversionFunnel.builder()
            .stages(stages)
            .bottleneck(bottleneck)
            .suggestions(generateSuggestions(bottleneck))
            .build();
    }
    
    /**
     * 归因分析
     */
    public AttributionReport analyzeAttribution(String userId) {
        List<TouchPoint> touchPoints = eventTracker.getTouchPoints(userId);
        
        // 多触点归因模型
        AttributionModel model = new AttributionModel();
        
        // 1. 首次触点归因
        Map<String, Double> firstTouch = model.firstTouch(touchPoints);
        
        // 2. 末次触点归因
        Map<String, Double> lastTouch = model.lastTouch(touchPoints);
        
        // 3. 线性归因
        Map<String, Double> linear = model.linear(touchPoints);
        
        // 4. 时间衰减归因
        Map<String, Double> timeDecay = model.timeDecay(touchPoints);
        
        return AttributionReport.builder()
            .firstTouch(firstTouch)
            .lastTouch(lastTouch)
            .linear(linear)
            .timeDecay(timeDecay)
            .build();
    }
}
```

## 全渠道编排实战

### 场景：新品发布全渠道营销

```java
/**
 * 新品发布营销活动编排
 */
@Service
public class ProductLaunchCampaign {
    
    @Autowired
    private UserInsightAgent insightAgent;
    
    @Autowired
    private ContentCreationAgent contentAgent;
    
    @Autowired
    private AdOptimizationAgent adAgent;
    
    @Autowired
    private ConversionAnalysisAgent conversionAgent;
    
    /**
     * 执行新品发布营销
     */
    public CampaignResult launch(Product product, List<String> targetUsers) {
        CampaignResult result = new CampaignResult();
        
        // Phase 1: 预热期（T-7天）
        PhaseResult warmUp = executeWarmUpPhase(product, targetUsers);
        result.addPhase(warmUp);
        
        // Phase 2: 爆发期（T-Day）
        PhaseResult launch = executeLaunchPhase(product, targetUsers);
        result.addPhase(launch);
        
        // Phase 3: 持续期（T+7天）
        PhaseResult sustain = executeSustainPhase(product, targetUsers);
        result.addPhase(sustain);
        
        // Phase 4: 复盘
        PhaseResult review = executeReviewPhase(result);
        result.addPhase(review);
        
        return result;
    }
    
    private PhaseResult executeWarmUpPhase(Product product, List<String> users) {
        // 1. 生成悬念内容
        List<MarketingContent> teasers = users.stream()
            .map(userId -> {
                UserProfile profile = insightAgent.analyze(userId);
                return contentAgent.generateContent(profile, product, ContentType.TEASER);
            })
            .collect(Collectors.toList());
        
        // 2. 社交媒体预热
        publishToSocialMedia(teasers);
        
        // 3. KOL 预热
        List<KOL> kols = selectKOLs(product);
        kols.forEach(kol -> kol.publishTeaser(product));
        
        // 4. 预约收集
        return PhaseResult.builder()
            .phase("WARM_UP")
            .preOrders(countPreOrders())
            .socialEngagement(getEngagement())
            .build();
    }
    
    private PhaseResult executeLaunchPhase(Product product, List<String> users) {
        // 1. 全渠道同步发布
        publishEverywhere(product);
        
        // 2. 实时投放优化
        String campaignId = startAdCampaign(product);
        
        // 3. 实时监控
        while (isLaunchDay()) {
            adAgent.optimizeCampaign(campaignId);
            
            ConversionFunnel funnel = conversionAgent.analyzeFunnel(campaignId);
            if (funnel.getBottleneck() != null) {
                fixBottleneck(funnel.getBottleneck());
            }
            
            sleep(300000);  // 每5分钟优化一次
        }
        
        return PhaseResult.builder()
            .phase("LAUNCH")
            .sales(getLaunchDaySales())
            .conversionRate(getConversionRate())
            .build();
    }
}
```

## 常见陷阱与最佳实践

### 陷阱1：过度个性化导致 creepy

```markdown
❌ 错误：
"我们知道您昨晚 11:30 浏览了我们的产品，现在给您推送相关广告"

✅ 正确：
"根据您的兴趣，为您推荐相关产品"

界限：
- 不说出具体行为细节
- 不追踪敏感场景（医院、心理咨询等）
- 提供关闭个性化选项
```

### 陷阱2：忽视品牌一致性

```markdown
❌ 错误：
AI 生成的内容风格不一致，有的正式有的随意

✅ 正确：
- 预设品牌语料库训练 Agent
- 统一文案风格指南
- 人工审核关键内容
```

### 陷阱3：只看短期指标

```markdown
❌ 错误：
为了提升 CTR，使用标题党，导致转化率下降

✅ 正确：
- 关注全链路指标（曝光→点击→转化→留存）
- 设置长期价值（LTV）目标
- 避免为了短期 KPI 损害品牌
```

### 最佳实践

```markdown
1. 始终保持人工审核关键内容
2. A/B 测试所有重大变更
3. 建立品牌安全过滤机制
4. 关注用户隐私和合规
5. 设置投放上限，防止预算耗尽
6. 建立快速止损机制
7. 定期清理低效渠道
8. 持续优化用户旅程
```

## 面试题与参考答案

### 1. 如何评估 AI 生成内容的质量？

**答案：**
- 人工抽样评估（相关性、准确性、品牌一致性）
- A/B 测试（点击率、转化率对比）
- 用户反馈（投诉率、满意度）
- 自动化检测（语法、敏感词、重复度）

### 2. 多触点归因哪个模型最好？

**答案：**
- 没有最好，只有最适合
- 首次触点：适合品牌认知阶段
- 末次触点：适合效果广告
- 线性归因：适合长决策周期
- 时间衰减：适合考虑短期转化
- 建议：同时使用多种模型对比

### 3. 如何防止 AI 投放预算浪费？

**答案：**
- 设置日预算上限
- 实时监控 CPA/ROI
- 自动暂停低效广告
- 人群包排除已转化用户
- 频次控制（避免过度曝光）

### 4. AI 营销中的数据隐私如何保障？

- 获得用户明确授权
- 遵循 GDPR/CCPA 等法规
- 提供数据删除选项
- 定期安全审计

### 5. 如何实现营销内容的千人千面？

- 用户标签体系（人口属性、行为、偏好）

- 推荐算法匹配
- 实时 A/B 测试优化
- 边缘计算降低延迟
