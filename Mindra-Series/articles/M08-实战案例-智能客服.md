## 项目背景与目标

### 背景

```markdown
企业：某 SaaS 平台（用户 100万+）
现状：
- 客服团队 20人
- 日均咨询量 5000+
- 响应时间平均 5分钟
- 用户满意度 3.5/5

痛点：
- 重复问题占比 70%
- 夜间无客服
- 高峰期排队严重
- 人工成本高
```

### 目标

```markdown
短期目标（1个月）：
- 自动解决率 60%
- 响应时间 < 30秒
- 7×24 服务

中期目标（3个月）：
- 自动解决率 80%
- 用户满意度 4.5/5
- 人工处理复杂问题

长期目标（6个月）：
- 自动解决率 90%
- 预测性服务
- 主动关怀
```

```java
@Configuration
public class CustomerServiceAgentConfig {
    
    /**
     * 意图识别 Agent

            .name("intent-agent")

            .model("gpt-5.5")
            .capabilities(Arrays.asList(
                "account_issue",
                "product_usage", 
                "order_query",
                "technical_support",
                "complaint"
            ))
            .build();
    }
    
    /**
     * 知识问答 Agent
     */
    @Bean
    public Agent knowledgeAgent() {
        return Agent.builder()
            .name("knowledge-agent")
            .type(AgentType.KNOWLEDGE_QA)
            .model("gpt-5.5")
            .ragConfig(RAGConfig.builder()
                .knowledgeBase("customer-service-kb")
                .embeddingModel("text-embedding-3")
                .topK(5)
                .build())
            .build();

    /**
     * 订单处理 Agent

        return Agent.builder()

                "refund-order",
                "modify-order"

            .governance(GovernanceConfig.builder()
                .approvalRequired(true)
                .approvalThreshold(new BigDecimal("1000"))
                .build())
            .build();
    }

     * 情感分析 Agent
     */
    @Bean

        return Agent.builder()
            .name("sentiment-agent")
```

### 团队编排

```java
@Service
public class CustomerServiceOrchestrator {
    
    @Autowired
    private Agent intentAgent;
    
    @Autowired
    private Agent knowledgeAgent;
    
    @Autowired
    private Agent orderAgent;
    
    @Autowired
    private Agent sentimentAgent;
    
    @Autowired
    private Agent escalationAgent;
    
    /**
     * 处理用户咨询
     */
    public Response handleQuery(String sessionId, String userMessage) {
        // 1. 意图识别
        Intent intent = (Intent) intentAgent.execute(
            Task.builder().input(userMessage).build()
        ).getData();
        
        // 2. 情感分析（并行）
        Sentiment sentiment = (Sentiment) sentimentAgent.execute(
            Task.builder().input(userMessage).build()
        ).getData();
        
        // 3. 根据意图路由
        Response response = switch (intent.getType()) {
            case KNOWLEDGE_QUERY -> handleKnowledgeQuery(intent);
            case ORDER_ISSUE -> handleOrderIssue(intent);
            case COMPLAINT -> handleComplaint(intent, sentiment);
            case TECHNICAL_SUPPORT -> handleTechnicalSupport(intent);
            default -> handleUnknown(intent);
        };
        
        // 4. 如果用户情绪激动，添加安抚
        if (sentiment.isNegative() && sentiment.getScore() < -0.7) {
            response = addEmpathy(response, sentiment);
        }
        
        return response;
    }
    
    private Response handleOrderIssue(Intent intent) {
        // 订单相关处理
        return (Response) orderAgent.execute(
            Task.builder()
                .input(intent.getOriginalMessage())
                .entities(intent.getEntities())
                .build()
        ).getData();
    }
    
    private Response handleComplaint(Intent intent, Sentiment sentiment) {
        // 投诉处理 - 直接升级
        return (Response) escalationAgent.execute(
            Task.builder()
                .input(intent.getOriginalMessage())
                .priority(Priority.HIGH)
                .sentiment(sentiment)
                .build()
        ).getData();
    }
}
```

## 核心功能实现

### 1. 多轮对话管理

```java
@Service
public class ConversationManager {
    
    @Autowired
    private RedisTemplate<String, Conversation> redisTemplate;
    
    /**
     * 获取或创建会话
     */
    public Conversation getOrCreate(String sessionId) {
        Conversation conv = redisTemplate.opsForValue().get(sessionId);
        
        if (conv == null) {
            conv = Conversation.builder()
                .sessionId(sessionId)
                .startTime(Instant.now())
                .messages(new ArrayList<>())
                .context(new HashMap<>())
                .build();
        }
        
        return conv;
    }
    
    /**
     * 添加消息
     */
    public void addMessage(String sessionId, Message message) {
        Conversation conv = getOrCreate(sessionId);
        conv.getMessages().add(message);
        
        // 更新上下文
        updateContext(conv, message);
        
        // 保存（带过期时间）
        redisTemplate.opsForValue().set(sessionId, conv, 30, TimeUnit.MINUTES);
    }
    
    /**
     * 更新上下文
     */
    private void updateContext(Conversation conv, Message message) {
        // 提取关键信息
        if (message.getIntent().equals("ORDER_QUERY")) {
            String orderId = message.getEntity("orderId");
            if (orderId != null) {
                conv.getContext().put("currentOrderId", orderId);
            }
        }
    }
}
```

### 2. 知识库 RAG

```java
@Service
public class KnowledgeBaseService {
    
    @Autowired
    private EmbeddingService embeddingService;
    
    @Autowired
    private VectorStore vectorStore;
    
    /**
     * 检索相关知识
     */
    public List<Knowledge> retrieve(String query, int topK) {
        // 1. 向量化查询
        float[] queryVector = embeddingService.embed(query);
        
        // 2. 向量检索
        List<VectorResult> results = vectorStore.search(queryVector, topK);
        
        // 3. 重排序
        results = rerank(results, query);
        
        // 4. 返回知识
        return results.stream()
            .map(VectorResult::getKnowledge)
            .collect(Collectors.toList());
    }
    
    /**
     * 添加知识
     */
    public void addKnowledge(Knowledge knowledge) {
        // 1. 分块
        List<Chunk> chunks = chunkingService.split(knowledge);
        
        // 2. 向量化
        for (Chunk chunk : chunks) {
            float[] vector = embeddingService.embed(chunk.getContent());
            
            // 3. 存储
            vectorStore.store(chunk.getId(), vector, Map.of(
                "content", chunk.getContent(),
                "source", knowledge.getSource(),
                "category", knowledge.getCategory()
            ));
        }
    }
}
```

### 3. 人工无缝转接

```java
@Service
public class HumanTransferService {
    
    @Autowired
    private HumanAgentService humanAgentService;
    
    @Autowired
    private ConversationManager conversationManager;
    
    /**
     * 转人工
     */
    public TransferResult transferToHuman(String sessionId, String reason) {
        Conversation conv = conversationManager.getOrCreate(sessionId);
        
        // 1. 查找在线人工客服
        HumanAgent agent = humanAgentService.findAvailableAgent();
        
        if (agent == null) {
            // 排队
            int queuePosition = humanAgentService.joinQueue(sessionId);
            return TransferResult.queued(queuePosition);
        }
        
        // 2. 准备上下文
        String context = prepareContext(conv);
        
        // 3. 转接
        agent.accept(sessionId, context);
        
        // 4. 通知用户
        return TransferResult.success(agent.getName());
    }
    
    private String prepareContext(Conversation conv) {
        StringBuilder sb = new StringBuilder();
        sb.append("用户咨询摘要：\n");
        sb.append("- 咨询次数：").append(conv.getMessages().size()).append("\n");
        sb.append("- 主要问题：").append(conv.getMainIssue()).append("\n");
        sb.append("- 已尝试方案：").append(conv.getAttemptedSolutions()).append("\n");
        sb.append("- 用户情绪：").append(conv.getSentiment()).append("\n");
        sb.append("\n对话历史：\n");
        
        for (Message msg : conv.getLastNMessages(10)) {
            sb.append(msg.getRole()).append(": ").append(msg.getContent()).append("\n");
        }
        
        return sb.toString();
    }
}
```

## 常见陷阱与最佳实践

### 陷阱1：期望过高

```markdown
❌ 错误：
期望上线就能解决 100% 问题

✅ 正确：
- 设定合理目标（60% → 80% → 90%）
- 持续优化
- 保留人工兜底
```

### 陷阱2：忽视知识库建设

```markdown
❌ 错误：
知识库内容少、质量差

✅ 正确：
- 初始投入 1-2 周整理知识库
- 持续更新
- 用户反馈驱动优化
```

### 陷阱3：缺少降级方案

```markdown
❌ 错误：
Agent 故障时无备用方案

✅ 正确：
- 设置默认回复
- 自动转人工
- 故障快速恢复
```

### 最佳实践

```markdown
1. 从高频简单问题开始
2. 建立完善的测试集
3. 持续收集用户反馈
4. 定期更新知识库
5. 监控关键指标
6. 保持人机协作
7. 做好应急预案
8. 培训人工客服
```

## 小结

从零搭建智能客服中心的关键步骤：

1. **需求分析**：明确目标、分析场景
2. **架构设计**：合理分层、选择技术
3. **Agent 组建**：职责清晰、协同配合
4. **核心功能**：多轮对话、RAG、转人工
5. **治理监督**：合规、审计、风控
6. **性能优化**：缓存、异步、数据库
7. **上线监控**：灰度、指标、应急
8. **持续优化**：反馈、迭代、提升

成功要素：
- 合理的期望管理
- 完善的知识库
- 有效的人机协作
- 持续的优化迭代
