## 单 Agent vs 多 Agent

### 能力对比

| 维度 | 单 Agent | 多 Agent 团队 |
|------|---------|-------------|
| **处理能力** | 单一技能，串行执行 | 多技能并行，协同处理 |
| **可靠性** | 单点故障 | 故障转移，冗余备份 |
| **扩展性** | 垂直扩展有限 | 水平扩展无限 |
| **复杂度** | 低 | 高（需要编排） |
| **适用场景** | 简单问答、代码生成 | 复杂业务流程、决策 |

```java
/**
 * Agent 间通过消息总线通信，不直接依赖
 */
public class MessageBus {
    
    private Map<String, List<MessageHandler>> subscribers = new ConcurrentHashMap<>();
    
    public void subscribe(String topic, MessageHandler handler) {
        subscribers.computeIfAbsent(topic, k -> new CopyOnWriteArrayList<>()).add(handler);
    }
    
    public void publish(String topic, Message message) {
        List<MessageHandler> handlers = subscribers.get(topic);
        if (handlers != null) {
            handlers.forEach(h -> h.handle(message));
        }
    }
}

// Agent A 发布消息
public class IntentAgent {
    @Autowired

    public void process(String userMessage) {

    }
}

// Agent B 订阅消息
public class OrderAgent {

}

 * Agent 包装器，提供容错能力
 */
public class ResilientAgent {
    
    private Agent delegate;
    private CircuitBreaker circuitBreaker;
    private RetryPolicy retryPolicy;
    
    public Result execute(Task task) {
        return circuitBreaker.execute(() -> {
            return retryPolicy.execute(() -> {
                return delegate.execute(task);
            });
        });
    }
    
    /**
     * 备用 Agent（同类型）
     */
    private Agent fallbackAgent;
    
    public Result executeWithFallback(Task task) {
        try {
            return execute(task);
        } catch (Exception e) {
            if (fallbackAgent != null) {
                return fallbackAgent.execute(task);
            }
            throw e;
        }
    }
}

/**
 * 意图识别 Agent
 */
@Component
public class IntentAgent {
    
    @Autowired
    private NLPService nlpService;
    
    public Intent recognize(String message) {
        // 1. 预处理
        String cleanMsg = preprocess(message);
        
        // 2. 意图分类
        Intent intent = nlpService.classify(cleanMsg);
        
        // 3. 实体提取
        List<Entity> entities = nlpService.extractEntities(cleanMsg);
        intent.setEntities(entities);
        
        // 4. 置信度检查
        if (intent.getConfidence() < 0.7) {
            intent.setType(IntentType.UNKNOWN);
        }
        
        return intent;
    }
    
    private String preprocess(String message) {
        return message.toLowerCase()
                     .replaceAll("[^a-z0-9\\s\\u4e00-\\u9fa5]", "")
                     .trim();
    }
}

/**
 * 路由分发 Agent
 */
@Component
public class RouterAgent {
    
    @Autowired
    private Map<IntentType, Agent> agentRegistry;
    
    @Autowired
    private SessionAgent sessionAgent;
    
    public Response route(Intent intent, Session session) {
        // 1. 获取处理 Agent
        Agent agent = agentRegistry.get(intent.getType());
        
        if (agent == null) {
            // 未知意图，转人工
            return escalateToHuman(intent, session);
        }
        
        // 2. 检查会话上下文
        Context context = sessionAgent.getContext(session.getId());
        
        // 3. 构建任务
        Task task = Task.builder()
            .intent(intent)
            .context(context)
            .session(session)
            .build();
        
        // 4. 执行并记录
        Response response = agent.execute(task);
        sessionAgent.recordInteraction(session.getId(), intent, response);
        
        return response;
    }
    
    private Response escalateToHuman(Intent intent, Session session) {
        return Response.builder()
            .type(ResponseType.HUMAN_TRANSFER)
            .message("正在为您转接人工客服...")
            .data(Map.of("sessionId", session.getId()))
            .build();
    }
}

/**
 * 知识问答 Agent
 */
@Component
public class FAQAgent implements Agent {
    
    @Autowired
    private KnowledgeBase kb;
    
    @Autowired
    private EmbeddingService embedding;
    
    @Override
    public Response execute(Task task) {
        String question = task.getIntent().getOriginalMessage();
        
        // 1. 向量化查询
        float[] queryVector = embedding.embed(question);
        
        // 2. 检索相关知识
        List<Knowledge> knowledges = kb.search(queryVector, 5);
        
        // 3. 生成答案
        String answer = generateAnswer(question, knowledges);
        
        return Response.builder()
            .type(ResponseType.ANSWER)
            .message(answer)
            .sources(knowledges)
            .build();
    }
    
    private String generateAnswer(String question, List<Knowledge> knowledges) {
        // 使用 LLM 生成自然语言答案
        StringBuilder context = new StringBuilder();
        knowledges.forEach(k -> context.append(k.getContent()).append("\n"));
        
        return llmService.generate("基于以下知识回答：\n" + context + "\n问题：" + question);
    }
}

/**
 * 订单处理 Agent
 */
@Component
public class OrderAgent implements Agent {
    
    @Autowired
    private OrderService orderService;
    
    @Autowired
    private PaymentService paymentService;
    
    @Override
    public Response execute(Task task) {
        Intent intent = task.getIntent();
        String action = intent.getAction();
        
        return switch (action) {
            case "QUERY" -> queryOrder(intent);
            case "CANCEL" -> cancelOrder(intent);
            case "REFUND" -> refundOrder(intent);
            default -> throw new UnsupportedOperationException("Unknown action: " + action);
        };
    }
    
    private Response queryOrder(Intent intent) {
        String orderId = intent.getEntity("orderId");
        Order order = orderService.findById(orderId);
        
        return Response.builder()
            .type(ResponseType.ORDER_INFO)
            .message(formatOrderInfo(order))
            .data(order)
            .build();
    }
    
    private Response cancelOrder(Intent intent) {
        String orderId = intent.getEntity("orderId");
        
        // 检查是否可取消
        Order order = orderService.findById(orderId);
        if (!order.canCancel()) {
            return Response.builder()
                .type(ResponseType.ERROR)
                .message("订单已发货，无法取消")
                .build();
        }
        
        // 执行取消
        orderService.cancel(orderId);
        
        return Response.builder()
            .type(ResponseType.SUCCESS)
            .message("订单已取消，退款将在3-5个工作日到账")
            .build();
    }
}

/**
 * 情感分析 Agent
 */
@Component
public class EmotionAgent implements Agent {
    
    @Autowired
    private SentimentAnalyzer analyzer;
    
    @Override
    public Response execute(Task task) {
        String message = task.getIntent().getOriginalMessage();
        
        // 1. 情感分析
        Sentiment sentiment = analyzer.analyze(message);
        
        // 2. 如果负面情绪强烈，安抚用户
        if (sentiment.getScore() < -0.5) {
            String empathyResponse = generateEmpathyResponse(sentiment);
            
            // 3. 通知升级 Agent
            bus.publish("user.angry", new AngryUserEvent(task.getSession(), sentiment));
            
            return Response.builder()
                .type(ResponseType.EMPATHY)
                .message(empathyResponse)
                .build();
        }
        
        return null;  // 无需干预
    }
    
    private String generateEmpathyResponse(Sentiment sentiment) {
        return switch (sentiment.getEmotion()) {
            case ANGRY -> "非常抱歉给您带来了不好的体验，我会立即为您处理...";
            case FRUSTRATED -> "我理解您的困扰，让我们一起来看看如何解决...";
            case WORRIED -> "请不要担心，我会帮您跟进这个问题...";
            default -> "感谢您的耐心，我正在为您处理...";
        };
    }
}

/**
 * 升级处理 Agent
 */
@Component
public class EscalateAgent implements Agent {
    
    @Autowired
    private HumanService humanService;
    
    @Autowired
    private PriorityCalculator priorityCalculator;
    
    @Override
    public Response execute(Task task) {
        // 1. 计算优先级
        Priority priority = priorityCalculator.calculate(task);
        
        // 2. 创建工单
        Ticket ticket = Ticket.builder()
            .sessionId(task.getSession().getId())
            .customerId(task.getSession().getCustomerId())
            .description(task.getIntent().getOriginalMessage())
            .priority(priority)
            .context(task.getContext())
            .build();
        
        // 3. 分配给人工客服
        HumanAgent agent = humanService.assign(ticket);
        
        // 4. 通知用户
        return Response.builder()
            .type(ResponseType.HUMAN_ASSIGNED)
            .message("已为您安排专属客服 " + agent.getName() + "，请稍候...")
            .data(Map.of("agentName", agent.getName(), "waitTime", "2分钟"))
            .build();
    }
}

### 团队协作流程

```java
/**
 * 主编排器
 */
@Service
public class CustomerServiceOrchestrator {
    
    @Autowired
    private IntentAgent intentAgent;
    
    @Autowired
    private RouterAgent routerAgent;
    
    @Autowired
    private EmotionAgent emotionAgent;
    
    @Autowired
    private SessionAgent sessionAgent;
    
    public Response handleMessage(String sessionId, String message) {
        // 1. 获取或创建会话
        Session session = sessionAgent.getOrCreate(sessionId);
        
        // 2. 意图识别
        Intent intent = intentAgent.recognize(message);
        
        // 3. 情感分析（并行）
        CompletableFuture<Response> emotionFuture = CompletableFuture.supplyAsync(() -
            emotionAgent.execute(Task.builder()
                .intent(intent)
                .session(session)
                .build()));
        
        // 4. 路由处理
        Response mainResponse = routerAgent.route(intent, session);
        
        // 5. 合并情感响应（如果有）
        Response emotionResponse = emotionFuture.join();
        if (emotionResponse != null) {
            return mergeResponses(emotionResponse, mainResponse);
        }
        
        return mainResponse;
    }
    
    private Response mergeResponses(Response emotion, Response main) {
        // 先安抚，再回答
        return Response.builder()
            .type(ResponseType.COMBINED)
            .message(emotion.getMessage() + "\n\n" + main.getMessage())
            .data(main.getData())
            .build();
    }
}
```

## 任务分解与分配策略

### 1. 基于技能的分配

```java
/**
 * 技能匹配算法
 */
public class SkillBasedAssignment {
    
    public Agent assign(Task task, List<Agent> availableAgents) {
        Map<Agent, Double> scores = new HashMap<>();
        
        for (Agent agent : availableAgents) {
            double score = calculateSkillMatch(agent.getSkills(), task.getRequiredSkills());
            scores.put(agent, score);
        }
        
        return scores.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(Map.Entry::getKey)
            .orElseThrow(() -> new NoSuitableAgentException("No agent has required skills"));
    }
    
    private double calculateSkillMatch(Set<String> agentSkills, Set<String> requiredSkills) {
        if (requiredSkills.isEmpty()) return 1.0;
        
        long matched = requiredSkills.stream()
            .filter(agentSkills::contains)
            .count();
        
        return (double) matched / requiredSkills.size();
    }
}
```

/**
 * 负载均衡分配
 */
public class LoadBasedAssignment {
    
    public Agent assign(Task task, List<Agent> availableAgents) {
        return availableAgents.stream()
            .min(Comparator.comparingInt(this::getCurrentLoad))
            .orElseThrow(() -> new NoAvailableAgentException("All agents are busy"));
    }
    
    private int getCurrentLoad(Agent agent) {
        return agent.getActiveTaskCount() * 100 / agent.getMaxCapacity();
    }
}

## 冲突解决与共识机制

### 1. 投票机制

```java
/**
 * 多 Agent 投票决策
 */
public class VotingConsensus {
    
    public Decision vote(Task task, List<Agent> agents) {
        Map<String, Integer> votes = new HashMap<>();
        
        // 收集各 Agent 的决策
        for (Agent agent : agents) {
            Decision decision = agent.decide(task);
            votes.merge(decision.getValue(), 1, Integer::sum);
        }
        
        // 选择得票最多的决策
        return votes.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(e -> new Decision(e.getKey(), e.getValue()))
            .orElseThrow(() -> new NoConsensusException("No consensus reached"));
    }
}
```

### 2. 权重投票

```java
/**
 * 加权投票（专家 Agent 权重更高）
 */
public class WeightedVotingConsensus {
    
    public Decision vote(Task task, List<WeightedAgent> agents) {
        Map<String, Double> weightedVotes = new HashMap<>();
        
        for (WeightedAgent agent : agents) {
            Decision decision = agent.getAgent().decide(task);
            double weight = agent.getWeight();
            weightedVotes.merge(decision.getValue(), weight, Double::sum);
        }
        
        return weightedVotes.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .map(e -> new Decision(e.getKey(), e.getValue()))
            .orElseThrow(() -> new NoConsensusException("No consensus reached"));
    }
}
```

## 性能优化与监控

### 1. 并行执行

```java
/**
 * 并行任务执行
 */
public class ParallelExecution {
    
    public List<Result> executeParallel(List<Task> tasks, List<Agent> agents) {
        ExecutorService executor = Executors.newFixedThreadPool(agents.size());
        
        List<Future<Result>> futures = new ArrayList<>();
        for (int i = 0; i < tasks.size(); i++) {
            Task task = tasks.get(i);
            Agent agent = agents.get(i % agents.size());
            
            futures.add(executor.submit(() -> agent.execute(task)));
        }
        
        return futures.stream()
            .map(f -> {
                try {
                    return f.get();
                } catch (Exception e) {
                    throw new RuntimeException(e);
                }
            })
            .collect(Collectors.toList());
    }
}
```

/**
 * Agent 结果缓存
 */
@Component
public class AgentResultCache {
    
    @Autowired
    private CacheManager cacheManager;
    
    public Response executeWithCache(Agent agent, Task task) {
        String cacheKey = generateCacheKey(agent, task);
        Cache cache = cacheManager.getCache("agent-results");
        
        // 1. 尝试从缓存获取
        Response cached = cache.get(cacheKey, Response.class);
        if (cached != null) {
            return cached;
        }
        
        // 2. 执行 Agent
        Response result = agent.execute(task);
        
        // 3. 缓存结果（如果可缓存）
        if (isCacheable(task)) {
            cache.put(cacheKey, result);
        }
        
        return result;
    }
    
    private boolean isCacheable(Task task) {
        // 查询类任务可缓存，修改类任务不可缓存
        return task.getType().equals(TaskType.QUERY);
    }
}

## 常见陷阱与最佳实践

### 陷阱1：Agent 职责划分不清

```markdown
❌ 错误：一个 Agent 既处理订单又处理退款还处理投诉

✅ 正确：订单 Agent、退款 Agent、投诉 Agent 各司其职

检测方法：
- 如果一个 Agent 的代码超过 500 行，考虑拆分
- 如果一个 Agent 需要处理 3 种以上不同类型的任务，考虑拆分
```

### 陷阱2：忽略 Agent 间通信开销

```markdown
❌ 错误：每个子任务都创建新的 HTTP 请求

✅ 正确：
- 同 JVM 内使用直接方法调用
- 跨 JVM 使用共享内存或本地消息队列
- 远程调用使用异步非阻塞方式

优化指标：
- 同机通信延迟 < 1ms
- 同机房通信延迟 < 5ms
- 跨机房通信延迟 < 50ms
```

### 陷阱3：缺乏熔断保护

```markdown
❌ 错误：Agent B 故障导致所有调用它的 Agent 都阻塞

✅ 正确：
- 设置超时时间（默认 5s）
- 失败率达到 50% 自动熔断
- 熔断后使用降级策略

代码：
```java
@CircuitBreaker(name = "orderAgent", fallbackMethod = "fallback")
public Order queryOrder(String orderId) {
    return orderAgent.query(orderId);
}

public Order fallback(String orderId, Exception ex) {
    return Order.empty();  // 返回空订单，不阻塞
}
```
```

### 最佳实践

```markdown
1. 每个 Agent 必须有健康检查端点
2. Agent 间通信使用事件驱动而非同步调用
3. 任务执行必须有超时控制
4. 结果必须可审计、可追溯
5. Agent 状态必须持久化（防止节点故障丢失）
6. 使用版本控制管理 Agent 逻辑变更
7. 灰度发布新 Agent 版本
8. 定期评估 Agent 性能并优化
```

## 面试题与参考答案

### 1. 多 Agent 系统中如何保证数据一致性？

**答案：**
- 使用 Saga 模式处理分布式事务
- 事件溯源（Event Sourcing）记录所有状态变更
- 最终一致性 + 补偿机制
- 避免分布式事务，使用业务层面的补偿

### 2. Agent 之间如何共享状态？

**答案：**
- 共享数据库（Redis/PostgreSQL）
- 分布式缓存（Hazelcast/Apache Ignite）
- 事件总线（Kafka/RabbitMQ）
- 避免共享内存（耦合度高）

### 3. 如何设计 Agent 的发现机制？

**答案：**
- 注册中心（Eureka/Nacos/Consul）
- 服务网格（Istio + Envoy）
- DNS 服务发现
- 静态配置（小规模）

### 4. Agent 故障如何快速恢复？

**答案：**
- 心跳检测 + 自动重启
- 状态持久化到共享存储
- 备用 Agent 热切换
- 任务重试 + 死信队列

### 5. 如何评估多 Agent 系统的性能？

**答案：**
- 任务吞吐量（TPS）
- 端到端延迟（P50/P95/P99）
- Agent 利用率
- 错误率
- 资源消耗（CPU/内存/网络）

## 小结

构建智能体团队的关键：

1. **职责清晰**：每个 Agent 只做一件事
2. **松耦合**：通过消息总线通信，不直接依赖
3. **容错设计**：熔断、降级、重试、备用
4. **可观测**：监控、日志、追踪、告警
5. **可扩展**：水平扩展，动态增删 Agent
